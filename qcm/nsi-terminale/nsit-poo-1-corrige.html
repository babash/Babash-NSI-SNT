1. [POO] Le rôle de __init__

QCU, une seule réponse

Objectif : Nommer la méthode exécutée à la création d'un objet.

La méthode __init__ d'une classe est exécutée automatiquement à la création de chaque instance.

Comment l'appelle-t-on dans les sujets de bac ?

Bonne réponse : A

  1. Bonne réponse : Le constructeurRetour : Oui. Au bac, on appelle __init__ le constructeur : elle s'exécute à chaque création d'objet et initialise ses attributs (en Python, c'est précisément une méthode d'initialisation).
  2. Distracteur : Un accesseurRetour : Un accesseur est une méthode qui renvoie la valeur d'un attribut (comme get_solde). __init__, elle, donne leurs premières valeurs aux attributs quand l'objet naît.
  3. Distracteur : La méthode principaleRetour : Le « programme principal » (ou le main d'autres langages) est autre chose : c'est la suite d'instructions qui lance le programme. __init__, elle, prépare chaque nouvel objet.
  4. Distracteur : Un attribut de classeRetour : Un attribut est une donnée (comme self.solde), pas une fonction. __init__ est une méthode : elle s'écrit avec def et reçoit self.

2. [POO] Écrire l'en-tête d'une classe

QCU, une seule réponse

Objectif : Reconnaître la syntaxe qui définit une classe.

Quelle ligne commence correctement la définition d'une classe Domino ?

Bonne réponse : A

  1. Bonne réponse : class Domino:Retour : Oui : le mot-clé class, le nom de la classe (avec une majuscule, par convention), puis les deux-points. Le corps de la classe est ensuite indenté.
  2. Distracteur : Class Domino:Retour : Python distingue majuscules et minuscules : le mot-clé s'écrit class, tout en minuscules. Class provoque une erreur de syntaxe.
  3. Distracteur : classe Domino:Retour : Les mots-clés de Python sont en anglais : on écrit class, pas classe. Ici, Python signale une erreur de syntaxe.
  4. Distracteur : class Domino(self):Retour : self est le premier paramètre des méthodes, pas de la classe. Entre parenthèses après le nom de la classe, Python attend une autre classe : ici, il ne connaît pas self et s'arrête (NameError).

3. [POO] Nommer les fonctions d'un objet

QCU, une seule réponse

Objectif : Distinguer méthode, attribut, classe et instance.

Les fonctions définies dans une classe, qui agissent sur les objets de cette classe ou les utilisent, s'appellent des …

Bonne réponse : D

  1. Distracteur : attributsRetour : Les attributs sont les données d'un objet (self.solde, self.nom). Les fonctions qui agissent sur l'objet sont ses méthodes.
  2. Distracteur : classesRetour : La classe est le modèle qui regroupe attributs et méthodes. Les fonctions qu'elle contient sont des méthodes.
  3. Distracteur : instancesRetour : Une instance est un objet fabriqué à partir de la classe, comme compte = Compte(...). Ce n'est pas une fonction.
  4. Bonne réponse : méthodesRetour : Oui : une méthode est une fonction définie dans la classe, avec self comme premier paramètre. On l'appelle sur un objet : objet.methode().

4. [POO] Nommer les objets d'une classe

QCU, une seule réponse

Objectif : Employer le mot « instance ».

Une classe sert de modèle pour fabriquer des objets. Ces objets, représentants de la classe, s'appellent aussi des …

Bonne réponse : C

  1. Distracteur : attributsRetour : Un attribut est une donnée rangée dans un objet, pas l'objet lui-même. Les objets fabriqués par une classe sont ses instances.
  2. Distracteur : fonctionsRetour : Une fonction est un morceau de code qu'on appelle. Les objets créés à partir d'une classe sont des instances.
  3. Bonne réponse : instancesRetour : Oui : chaque objet créé avec la classe est une instance de cette classe. On peut en créer autant qu'on veut, chacune avec ses propres valeurs d'attributs.
  4. Distracteur : méthodesRetour : Les méthodes sont les fonctions de la classe. Les objets qu'elle fabrique s'appellent des instances.

5. [POO] Suivre un attribut modifié par des méthodes

QCU, une seule réponse

Objectif : Prévoir la valeur d'un attribut après plusieurs appels de méthodes.

On considère le programme suivant.

class Compte:
    def __init__(self, numero, solde):
        self.numero = numero
        self.solde = solde
 
    def deposer(self, montant):
        self.solde = self.solde + montant
 
    def retirer(self, montant):
        self.solde = self.solde - montant
 
compte = Compte('123', 100)
compte.deposer(800)
compte.retirer(500)
compte.deposer(200)

Que vaut compte.solde à la fin de l'exécution ?

Bonne réponse : B

  1. Distracteur : 100Retour : 100 est la valeur donnée à la création. Mais deposer et retirer modifient self.solde : l'attribut change à chaque appel. Refais le calcul pas à pas.
  2. Bonne réponse : 600Retour : Oui : 100 au départ, puis 100 + 800 = 900, 900 - 500 = 400, 400 + 200 = 600. Chaque méthode modifie le même attribut self.solde.
  3. Distracteur : 800Retour : 800 est le montant du premier dépôt, pas le solde. Pars de 100, puis applique les trois appels dans l'ordre.
  4. Distracteur : 200Retour : 200 est le dernier montant déposé. Le solde garde la mémoire des opérations précédentes : 100, puis 900, 400 et 600.

6. [POO] Paramètre ou attribut ?

QCU, une seule réponse

Objectif : Distinguer le nom d'un paramètre du nom de l'attribut qui reçoit sa valeur.

class Test:
    def __init__(self, a, b):
        self.x = a
        self.y = b
 
u = Test(4, 5)

Laquelle des expressions suivantes a pour valeur 4 ?

Bonne réponse : A

  1. Bonne réponse : u.xRetour : Oui : self.x = a range la valeur du paramètre a (ici 4) dans l'attribut x. On la lit ensuite avec u.x.
  2. Distracteur : u.aRetour : a est le nom du paramètre, il n'existe que pendant l'exécution de __init__. La valeur 4 est rangée dans l'attribut x : u.a provoque une AttributeError.
  3. Distracteur : u.bRetour : b est un paramètre (il reçoit 5), pas un attribut de l'objet. Regarde à gauche des signes = : ce sont les attributs, self.x et self.y.
  4. Distracteur : u.yRetour : self.y reçoit b, c'est-à-dire 5. Le premier argument, 4, va dans self.x.

8. [POO] Appeler une méthode sur la classe au lieu de l'objet

QCU, une seule réponse

Objectif : Repérer qu'une méthode s'appelle sur une instance.

class Triangle:
    def __init__(self, a, b, c):
        self.a = a
        self.b = b
        self.c = c
 
    def est_rectangle(self):
        cotes = self.a**2 + self.b**2
        hypotenuse = self.c**2
        return cotes == hypotenuse
 
t = Triangle(3, 4, 5)
print(Triangle.est_rectangle())

Qu'affiche l'exécution de ce programme ?

Bonne réponse : B

  1. Distracteur : TrueRetour : Le triangle 3, 4, 5 est bien rectangle, et t.est_rectangle() afficherait True. Mais la dernière ligne appelle la méthode sur la classe Triangle, sans objet : self ne reçoit rien.
  2. Bonne réponse : Une erreurRetour : Oui : Triangle.est_rectangle() n'a pas d'objet à mettre dans self. Python affiche « TypeError: Triangle.est_rectangle() missing 1 required positional argument: 'self' ». Il fallait écrire t.est_rectangle().
  3. Distracteur : FalseRetour : Le calcul 9 + 16 = 25 donnerait True. Ici, le calcul n'a même pas lieu : la méthode est appelée sur la classe, sans objet pour self.
  4. Distracteur : L'adresse de l'objet, comme <__main__.Triangle object at 0x…>Retour : Ce texte s'affiche quand on fait print(t) sans méthode __str__. Ici, on appelle une méthode, et sans objet : c'est une erreur.

12. [POO] Une méthode qui compare deux objets

QCU, une seule réponse

Objectif : Identifier self et le paramètre dans un appel x.methode(y).

class Score:
    def __init__(self, valeur):
        self.valeur = valeur
 
    def mystere(self, autre):
        return self.valeur > autre.valeur
 
x = Score(100)
y = Score(80)

Laquelle de ces expressions vaut True ?

Bonne réponse : C

  1. Distracteur : x.mystere(x)Retour : self et autre sont alors le même objet : 100 > 100 est faux. Une valeur n'est jamais strictement plus grande qu'elle-même.

  4. Distracteur : y.mystere(y)Retour : 80 > 80 est faux : comparer un objet à lui-même avec > donne toujours False.

19. [POO] Appeler une méthode sans argument

Objectif : Écrire l'appel d'une méthode qui n'a que self comme paramètre.

class Objet3D:

        self.z = self.z + dz

20. [POO] Ce qu'affiche print avec __str__

QCU, une seule réponse

Objectif : Prévoir l'affichage d'un objet qui contient d'autres objets et a une méthode __str__.

class Point:
    def __init__(self, x, y):
        self.px = x
        self.py = y
 
class Segment:
    def __init__(self, x1, y1, x2, y2):
        self.orig = Point(x1, y1)
        self.extrem = Point(x2, y2)
 
    def __str__(self):
        o, e = self.orig, self.extrem
        return f'Segment : [({o.px}, {o.py}), ({e.px}, {e.py})]'
 
s = Segment(4.0, 3.0, 2.0, 1.0)
print(s)

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : Segment : [(4.0, 3.0), (2.0, 1.0)]Retour : Oui : print(s) utilise __str__, qui place l'origine (4.0, 3.0) puis l'extrémité (2.0, 1.0). Les valeurs gardent leur type flottant.
  2. Distracteur : Segment : [(4, 3), (2, 1)]Retour : Les coordonnées ont été données avec une virgule décimale (4.0, 3.0…) : ce sont des flottants, et Python les affiche 4.0, 3.0.
  3. Distracteur : Segment : [(2.0, 1.0), (4.0, 3.0)]Retour : L'ordre est inversé : orig reçoit les deux premiers arguments (4.0 et 3.0), extrem les deux derniers.
  4. Distracteur : <__main__.Segment object at 0x…>Retour : C'est l'affichage d'un objet sans méthode __str__. Ici, Segment en a une : print(s) affiche le texte qu'elle renvoie.
