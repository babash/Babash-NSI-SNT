1. [Jointures] Écrire la condition de jointure

QCU, une seule réponse

Objectif : Relier la clé étrangère d'une table à la clé primaire de l'autre.

Schéma : ELEVE (id_e, nom, #id_classe) et CLASSE (id_classe, nom_c).

Quelle est la condition de jointure correcte entre ELEVE et CLASSE ?

  1. ON ELEVE.id_e = CLASSE.id_classe
  2. WHERE ELEVE.nom = CLASSE.nom_c
  3. JOIN ON ELEVE = CLASSE
  4. ON ELEVE.id_classe = CLASSE.id_classe

2. [Jointures] Afficher des colonnes de deux tables

QCU, une seule réponse

Objectif : Écrire une jointure complète, sans produit cartésien.

Schéma : ELEVE (id_e, nom, #id_classe) et CLASSE (id_classe, nom_c).

Quelle requête affiche le nom de chaque élève et le nom de sa classe ?

  1. SELECT ELEVE.nom, CLASSE.nom_c FROM ELEVE, CLASSE;
  2. SELECT nom, nom_c FROM ELEVE JOIN CLASSE;
  3. SELECT nom, nom_c WHERE ELEVE JOIN CLASSE ON ELEVE.id_classe = CLASSE.id_classe;
  4. SELECT nom, nom_c FROM ELEVE JOIN CLASSE ON ELEVE.id_classe = CLASSE.id_classe;

QCU, une seule réponse

Objectif : Filtrer sur un attribut d'une autre table grâce à une jointure.

Schéma : VILLAGE (id_v, nom_v) et PIROGUE (id_p, nom_p, couleur, #id_v).

Quelle requête affiche les noms des pirogues du village de Bouéni ?

  1. SELECT nom_p FROM PIROGUE WHERE nom_v = 'Bouéni';
  2. SELECT nom_p FROM PIROGUE JOIN VILLAGE WHERE nom_v = 'Bouéni';
  3. SELECT nom_p FROM PIROGUE JOIN VILLAGE ON PIROGUE.id_v = VILLAGE.id_v WHERE nom_v = 'Bouéni';

4. [Jointures] Joindre trois tables

QCU, une seule réponse

Objectif : Enchaîner deux jointures en suivant les clés étrangères.

Schéma : ZONE (id_z, nom_z) ; RECIF (id_r, nom_r, #id_z) ; MESURE (id_m, valeur, #id_r).

Quelle clause FROM relie correctement les zones aux mesures ?

  1. FROM ZONE JOIN MESURE ON ZONE.id_z = MESURE.id_r
  2. FROM ZONE JOIN RECIF ON ZONE.id_z = RECIF.id_z JOIN MESURE ON RECIF.id_r = MESURE.id_r
  3. FROM ZONE, RECIF, MESURE
  4. FROM ZONE JOIN RECIF JOIN MESURE ON id_z = id_r

13. [SQL] Trouver l'erreur dans une requête

QCU, une seule réponse

Objectif : Lire le message de SQLite et corriger l'écriture d'une valeur texte.

SQLite exécute la requête suivante et affiche le message d'erreur de la console.

SELECT nom FROM CLIENT WHERE ville = Mamoudzou;

Console :

Parse error: no such column: Mamoudzou

Pourquoi cette requête provoque-t-elle une erreur ?

  1. Le nom Mamoudzou doit être écrit en majuscules
  2. Il manque des apostrophes autour de Mamoudzou
  3. On ne peut pas filtrer sur une ville
  4. Il manque un point-virgule après SELECT nom

15. [Mises à jour] Supprimer une ligne encore référencée

QCU, une seule réponse

Objectif : Prévoir la réponse du SGBD quand une ligne supprimée est encore référencée.

Schéma : VILLAGE (id_v, nom_v) et PIROGUE (id_p, nom_p, couleur, #id_v). Le contrôle des clés étrangères est activé (dans SQLite : PRAGMA foreign_keys = ON).

On tente de supprimer un village alors que des pirogues y sont encore reliées. Que se passe-t-il ?

  1. Le village est supprimé, et toutes ses pirogues sont effacées avec lui
  2. Le village est supprimé, et la clé étrangère des pirogues passe à 0
  3. La suppression est refusée, pour préserver l'intégrité référentielle
  4. Rien de spécial : la contrainte est ignorée
