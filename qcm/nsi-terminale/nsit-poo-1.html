1. [POO] Le rôle de __init__

QCU, une seule réponse · bonne réponse en A

Objectif : Nommer la méthode exécutée à la création d'un objet.

La méthode __init__ d'une classe est exécutée automatiquement à la création de chaque instance.

Comment l'appelle-t-on dans les sujets de bac ?

  1. Juste · Le constructeurOui. Au bac, on appelle __init__ le constructeur : elle s'exécute à chaque création d'objet et initialise ses attributs (en Python, c'est précisément une méthode d'initialisation).
  2. Un accesseurUn accesseur est une méthode qui renvoie la valeur d'un attribut (comme get_solde). __init__, elle, donne leurs premières valeurs aux attributs quand l'objet naît.
  3. La méthode principaleTu penses sans doute au « programme principal » ou au main d'autres langages. En Python, __init__ ne lance pas le programme : elle prépare chaque nouvel objet.
  4. Un attribut de classeUn attribut est une donnée (comme self.solde), pas une fonction. __init__ est une méthode : elle s'écrit avec def et reçoit self.

2. [POO] Écrire l'en-tête d'une classe

QCU, une seule réponse · bonne réponse en A

Objectif : Reconnaître la syntaxe qui définit une classe.

Quelle ligne commence correctement la définition d'une classe Domino ?

  1. Juste · class Domino:Oui : le mot-clé class, le nom de la classe (avec une majuscule, par convention), puis les deux-points. Le corps de la classe est ensuite indenté.
  2. Class Domino:Python distingue majuscules et minuscules : le mot-clé s'écrit class, tout en minuscules. Class provoque une erreur de syntaxe.
  3. classe Domino:Les mots-clés de Python sont en anglais : on écrit class, pas classe. Ici, Python signale une erreur de syntaxe.
  4. class Domino(self):self est le premier paramètre des méthodes, pas de la classe. Entre parenthèses après le nom de la classe, Python attend une autre classe : ici, il ne connaît pas self et s'arrête (NameError).

3. [POO] Nommer les fonctions d'un objet

QCU, une seule réponse · bonne réponse en D

Objectif : Distinguer méthode, attribut, classe et instance.

Les fonctions définies dans une classe, qui agissent sur les objets de cette classe ou les utilisent, s'appellent des …

  1. attributsLes attributs sont les données d'un objet (self.solde, self.nom). Les fonctions qui agissent sur l'objet sont ses méthodes.
  2. classesLa classe est le modèle qui regroupe attributs et méthodes. Les fonctions qu'elle contient sont des méthodes.
  3. instancesUne instance est un objet fabriqué à partir de la classe, comme compte = Compte(...). Ce n'est pas une fonction.
  4. Juste · méthodesOui : une méthode est une fonction définie dans la classe, avec self comme premier paramètre. On l'appelle sur un objet : objet.methode().

4. [POO] Nommer les objets d'une classe

QCU, une seule réponse · bonne réponse en C

Objectif : Employer le mot « instance ».

Une classe sert de modèle pour fabriquer des objets. Ces objets, représentants de la classe, s'appellent aussi des …

  1. attributsUn attribut est une donnée rangée dans un objet, pas l'objet lui-même. Les objets fabriqués par une classe sont ses instances.
  2. fonctionsUne fonction est un morceau de code qu'on appelle. Les objets créés à partir d'une classe sont des instances.
  3. Juste · instancesOui : chaque objet créé avec la classe est une instance de cette classe. On peut en créer autant qu'on veut, chacune avec ses propres valeurs d'attributs.
  4. méthodesLes méthodes sont les fonctions de la classe. Les objets qu'elle fabrique s'appellent des instances.

5. [POO] Suivre un attribut modifié par des méthodes

QCU, une seule réponse · bonne réponse en B

Objectif : Prévoir la valeur d'un attribut après plusieurs appels de méthodes.

On considère le programme suivant.

class Compte:
    def __init__(self, numero, solde):
        self.numero = numero
        self.solde = solde

    def deposer(self, montant):
        self.solde = self.solde + montant

    def retirer(self, montant):
        self.solde = self.solde - montant

compte = Compte('123', 100)
compte.deposer(800)
compte.retirer(500)
compte.deposer(200)

Que vaut compte.solde à la fin de l'exécution ?

  1. 100100 est la valeur donnée à la création. Mais deposer et retirer modifient self.solde : l'attribut change à chaque appel. Refais le calcul pas à pas.
  2. Juste · 600Oui : 100 au départ, puis 100 + 800 = 900, 900 - 500 = 400, 400 + 200 = 600. Chaque méthode modifie le même attribut self.solde.
  3. 800800 est le montant du premier dépôt, pas le solde. Pars de 100, puis applique les trois appels dans l'ordre.
  4. 200200 est le dernier montant déposé. Le solde garde la mémoire des opérations précédentes : 100, puis 900, 400 et 600.

6. [POO] Paramètre ou attribut ?

QCU, une seule réponse · bonne réponse en A

Objectif : Distinguer le nom d'un paramètre du nom de l'attribut qui reçoit sa valeur.

class Test:
    def __init__(self, a, b):
        self.x = a
        self.y = b

u = Test(4, 5)

Laquelle des expressions suivantes a pour valeur 4 ?

  1. Juste · u.xOui : self.x = a range la valeur du paramètre a (ici 4) dans l'attribut x. On la lit ensuite avec u.x.
  2. u.aa est le nom du paramètre, il n'existe que pendant l'exécution de __init__. La valeur 4 est rangée dans l'attribut x : u.a provoque une AttributeError.
  3. u.bb est un paramètre (il reçoit 5), pas un attribut de l'objet. Regarde à gauche des signes = : ce sont les attributs, self.x et self.y.
  4. u.yself.y reçoit b, c'est-à-dire 5. Le premier argument, 4, va dans self.x.

7. [POO] Créer une instance

QCU, une seule réponse · bonne réponse en C

Objectif : Écrire l'instruction qui crée un objet et le range dans une variable.

class Personne:
    def __init__(self, nom, annee_naissance, ville_naissance):
        self.nom = nom
        self.annee = annee_naissance
        self.ville = ville_naissance

Quelle instruction crée un nouvel objet p de la classe Personne ?

  1. p == Personne('Fatima', 2008, 'Sada')== compare deux valeurs, il ne range rien. Pour créer l'objet et le mettre dans p, il faut une affectation avec un seul signe =.
  2. p.Personne('Fatima', 2008, 'Sada')La notation p.quelque_chose sert à utiliser un objet qui existe déjà. Ici, p n'existe pas encore : on écrit p = Personne(...).
  3. Juste · p = Personne('Fatima', 2008, 'Sada')Oui : on appelle la classe comme une fonction, avec les arguments de __init__ (sauf self), et on range l'objet obtenu dans p.
  4. Personne.p('Fatima', 2008, 'Sada')Personne.p chercherait une méthode p dans la classe, qui n'existe pas. On crée un objet en appelant la classe : Personne(...).

8. [POO] Appeler une méthode sur la classe au lieu de l'objet

QCU, une seule réponse · bonne réponse en B

Objectif : Repérer qu'une méthode s'appelle sur une instance.

class Triangle:
    def __init__(self, a, b, c):
        self.a = a
        self.b = b
        self.c = c

    def est_rectangle(self):
        cotes = self.a**2 + self.b**2
        hypotenuse = self.c**2
        return cotes == hypotenuse

t = Triangle(3, 4, 5)
print(Triangle.est_rectangle())

Qu'affiche l'exécution de ce programme ?

  1. TrueLe triangle 3, 4, 5 est bien rectangle, et t.est_rectangle() afficherait True. Mais la dernière ligne appelle la méthode sur la classe Triangle, sans objet : self ne reçoit rien.
  2. Juste · Une erreurOui : Triangle.est_rectangle() n'a pas d'objet à mettre dans self, et Python signale TypeError: missing 1 required positional argument: 'self'. Il fallait écrire t.est_rectangle().
  3. FalseLe calcul 9 + 16 = 25 donnerait True. Ici, le calcul n'a même pas lieu : la méthode est appelée sur la classe, sans objet pour self.
  4. L'adresse de l'objet, comme <__main__.Triangle object at 0x…>Ce texte s'affiche quand on fait print(t) sans méthode __str__. Ici, on appelle une méthode, et sans objet : c'est une erreur.

class Identite:

        self.nom = nom
        self.prenom = prenom
        self.annee = annee

    def age(self, a):
        return a - self.annee

theo = Identite('Courant', 'Théo', 2001)
print(theo.age(2020))

Qu'affiche ce programme ?

  2. Juste · 19Oui : age(2020) renvoie 2020 - self.annee, soit 2020 - 2001 = 19. Le paramètre a reçoit 2020, self reçoit l'objet theo.
  3. 20012001 est l'attribut annee. La méthode ne le renvoie pas tel quel : elle le soustrait à l'année passée en argument.
  4. CourantCourant est l'attribut nom. age ne s'en sert pas : elle calcule a - self.annee.

10. [POO] Suivre une chaîne de maillons

Objectif : Enchaîner deux accès à des attributs (objet.attribut.attribut).

class Maillon:
    def __init__(self, val, suiv):
        self.valeur = val
        self.suivant = suiv

a = Maillon(10, None)
b = Maillon(20, a)
c = Maillon(30, b)

Laquelle de ces expressions a pour valeur 20 ?

  1. a.suivant.valeura.suivant vaut None : a est le dernier maillon. None n'a pas d'attribut valeur, d'où une AttributeError.
  2. a.valeur.suivanta.valeur vaut 10, un entier : un entier n'a pas d'attribut suivant. Lis de gauche à droite : d'abord le maillon, puis son attribut.
  3. c.valeur.suivantc.valeur vaut 30, un entier, qui n'a pas d'attribut suivant. Il faut d'abord passer au maillon suivant, puis lire sa valeur.
  4. Juste · c.suivant.valeurOui : c.suivant est le maillon b, et b.valeur vaut 20. On lit de gauche à droite, un attribut après l'autre.

class Bizarre:

    def truc(self, chose):
        return self.valeur + chose

a = Bizarre(5)
a.valeur = a.valeur + 2
b = a.truc(3)

12. [POO] Une méthode qui compare deux objets

QCU, une seule réponse · bonne réponse en C

Objectif : Identifier self et le paramètre dans un appel x.methode(y).

class Score:
    def __init__(self, valeur):
        self.valeur = valeur

    def mystere(self, autre):
        return self.valeur > autre.valeur

x = Score(100)
y = Score(80)

Laquelle de ces expressions vaut True ?

  1. x.mystere(x)self et autre sont alors le même objet : 100 > 100 est faux. Une valeur n'est jamais strictement plus grande qu'elle-même.
  2. y.mystere(x)Ici self est y (80) et autre est x (100) : 80 > 100 est faux. L'objet placé avant le point prend la place de self.
  3. Juste · x.mystere(y)Oui : self est x (100) et autre est y (80) ; 100 > 80 vaut True. L'objet avant le point devient self.
  4. y.mystere(y)80 > 80 est faux : comparer un objet à lui-même avec > donne toujours False.

13. [POO] Passer un attribut en argument

Objectif : Passer à une méthode l'attribut d'un autre objet, et non l'objet lui-même.

class Eleve:
    def __init__(self, nom):
        self.nom = nom

    def mystere(self, x):
        return self.nom + x

james = Eleve('JAMES')
bond = Eleve('BOND')

Laquelle de ces expressions a pour valeur 'JAMESBOND' ?

  1. james.mystere(bond)x reçoit alors l'objet bond, pas une chaîne : 'JAMES' + bond provoque une TypeError. Il faut passer son attribut, bond.nom.
  2. mystere(james, bond.nom)mystere est une méthode : elle n'existe pas seule, hors de la classe. Python répond NameError. On l'appelle sur un objet : james.mystere(...).
  3. Juste · james.mystere(bond.nom)Oui : self.nom vaut 'JAMES' et x reçoit bond.nom, la chaîne 'BOND'. 'JAMES' + 'BOND' donne 'JAMESBOND'.
  4. mystere(james, bond)Deux erreurs : mystere ne s'appelle pas sans objet devant (NameError), et bond est un objet, pas une chaîne.

15. [POO] Ce que désigne self

QCU, une seule réponse · bonne réponse en D

Objectif : Savoir ce que reçoit le paramètre self d'une méthode.

Dans la définition def deposer(self, montant): d'une classe Compte, on appelle ensuite compte.deposer(50).

Que désigne self pendant cet appel ?

  1. La classe CompteLa classe est le modèle commun. self désigne un objet précis : celui qui est écrit avant le point, ici compte.
  2. La valeur 5050 va dans le deuxième paramètre, montant. Le premier, self, reçoit automatiquement l'objet placé avant le point.
  3. Une copie de l'objet compteCe n'est pas une copie : self est l'objet lui-même. C'est pour cela que self.solde = ... modifie vraiment compte.
  4. Juste · L'objet compteOui : Python donne à self l'objet sur lequel on appelle la méthode. compte.deposer(50) revient à Compte.deposer(compte, 50).

17. [POO] Le mot-clé qui définit une classe

QCU, une seule réponse · bonne réponse en C

Objectif : Reconnaître le mot-clé class parmi les autres mots de la POO.

En Python, on définit un nouveau type d'objet avec le mot-clé …

  1. defdef définit une fonction ou une méthode. Pour définir un type d'objet, c'est-à-dire une classe, on utilise class.
  2. __init____init__ est le nom du constructeur, une méthode écrite dans la classe. Le mot-clé qui ouvre la classe est class.
  3. Juste · classOui : class Nom: ouvre la définition d'une classe, c'est-à-dire d'un nouveau type d'objet. Ses méthodes, dont __init__, sont définies dedans avec def.
  4. __str____str__ est une méthode spéciale qui donne le texte affiché par print. Elle se range dans une classe définie avec class.

class Objet3D:
    def __init__(self, x, y, z, longueur, hauteur, profondeur):
        self.x = x
        self.y = y
        self.z = z
        self.longueur = longueur
        self.hauteur = hauteur
        self.profondeur = profondeur

    def volume(self):
        return self.longueur * self.hauteur * self.profondeur

    def translation(self, dx, dy, dz):
        self.x = self.x + dx
        self.y = self.y + dy
        self.z = self.z + dz

o est une instance de la classe Objet3D. Quelle instruction calcule le volume de o ?

  1. volume(o)volume est une méthode : elle n'existe pas hors de la classe (NameError). On l'appelle sur l'objet : o.volume().
  2. Juste · o.volume()Oui : o.volume() appelle la méthode sur o, qui devient self. Les parenthèses restent vides, car volume n'a pas d'autre paramètre.
  3. o.volume(self)self ne s'écrit que dans la définition. À l'appel, Python remplit self tout seul avec o ; écrire self ici provoque une NameError.

20. [POO] Ce qu'affiche print avec __str__

QCU, une seule réponse · bonne réponse en A

Objectif : Prévoir l'affichage d'un objet qui contient d'autres objets et a une méthode __str__.

class Point:
    def __init__(self, x, y):
        self.px = x
        self.py = y

class Segment:
    def __init__(self, x1, y1, x2, y2):
        self.orig = Point(x1, y1)
        self.extrem = Point(x2, y2)

    def __str__(self):
        o, e = self.orig, self.extrem
        return f'Segment : [({o.px}, {o.py}), ({e.px}, {e.py})]'

s = Segment(4.0, 3.0, 2.0, 1.0)
print(s)

Qu'affiche ce programme ?

  1. Juste · Segment : [(4.0, 3.0), (2.0, 1.0)]Oui : print(s) utilise __str__, qui place l'origine (4.0, 3.0) puis l'extrémité (2.0, 1.0). Les valeurs gardent leur type flottant.
  2. Segment : [(4, 3), (2, 1)]Les coordonnées ont été données avec une virgule décimale (4.0, 3.0…) : ce sont des flottants, et Python les affiche 4.0, 3.0.
  3. Segment : [(2.0, 1.0), (4.0, 3.0)]L'ordre est inversé : orig reçoit les deux premiers arguments (4.0 et 3.0), extrem les deux derniers.
  4. <__main__.Segment object at 0x…>C'est l'affichage d'un objet sans méthode __str__. Ici, Segment en a une : print(s) affiche le texte qu'elle renvoie.
