1. [Binaire] Lire un nombre de 4 bits

QCU, une seule réponse

Objectif : Passer de l'écriture binaire d'un entier à son écriture décimale.

Quel nombre décimal s'écrit 1100 en binaire ?

Bonne réponse : B

  1. Distracteur : 6Retour : 6 s'écrit 0110 en binaire, pas 1100. Écris les poids au-dessus des bits (8, 4, 2, 1), puis additionne ceux des bits à 1 : 8 + 4.
  2. Bonne réponse : 12Retour : Oui : 1100 = 1 × 8 + 1 × 4 + 0 × 2 + 0 × 1 = 12. Chaque bit à 1 apporte son poids.
  3. Distracteur : 10Retour : 10 s'écrit 1010. Écris les poids au-dessus des bits (8, 4, 2, 1), puis additionne ceux des bits à 1.
  4. Distracteur : 14Retour : 14 s'écrit 1110 : il a trois bits à 1. Ici, seuls les bits de poids 8 et 4 sont à 1.

2. [Binaire] Écrire 7 sur 4 bits

QCU, une seule réponse

Objectif : Passer de l'écriture décimale d'un entier à son écriture binaire sur un nombre de bits donné.

Quelle est l'écriture binaire sur 4 bits du nombre 7 ?

Bonne réponse : D

  1. Distracteur : 1001Retour : 1001 vaut 8 + 1 = 9. Pour 7, cherche les poids qui donnent 7 : 4 + 2 + 1.
  2. Distracteur : 0011Retour : 0011 vaut 2 + 1 = 3. Il manque le bit de poids 4 : 7 = 4 + 2 + 1.
  3. Distracteur : 1100Retour : 1100 vaut 8 + 4 = 12, pas 7. Pour 7, cherche les poids qui donnent 7 : 4 + 2 + 1, donc 0111.
  4. Bonne réponse : 0111Retour : Oui : 7 = 4 + 2 + 1, donc les trois bits de droite sont à 1 : 0111. Le 0 de gauche complète les 4 bits.

3. [Binaire] Un seul bit à 1 dans un octet

QCU, une seule réponse

Objectif : Connaître les poids des bits d'un octet.

Quel nombre décimal représente l'octet 00001000 ?

Bonne réponse : B

  1. Distracteur : 16Retour : 16 s'écrit 00010000 : son bit à 1 est une case plus à gauche. Compte les poids depuis la droite : 1, 2, 4, 8.
  2. Bonne réponse : 8Retour : Oui : le seul bit à 1 a le poids 2³ = 8. Les poids, de droite à gauche : 1, 2, 4, 8, 16…
  3. Distracteur : 4Retour : 4 s'écrit 00000100. Ici, le bit à 1 est en quatrième position en partant de la droite : son poids est 8.
  4. Distracteur : 1Retour : 1 s'écrit 00000001 : seul le bit tout à droite est à 1. Ici, c'est le quatrième bit depuis la droite.

4. [Binaire] Le plus grand nombre sur 5 bits

QCU, une seule réponse

Objectif : Calculer la plus grande valeur codable sur n bits : 2ⁿ - 1.

Quel est le plus grand entier positif que l'on peut écrire avec 5 bits ?

Bonne réponse : A

  1. Bonne réponse : 31Retour : Oui : 11111 = 16 + 8 + 4 + 2 + 1 = 31, c'est-à-dire 2⁵ - 1. Retiens : sur n bits, de 0 à 2ⁿ - 1.
  2. Distracteur : 16Retour : 16 = 2⁴ est le nombre de valeurs sur 4 bits. Sur 5 bits, la plus grande valeur est 11111.
  3. Distracteur : 32Retour : 32 = 2⁵ est le nombre de valeurs possibles, de 0 à 31. Comme on commence à 0, la plus grande est 31.
  4. Distracteur : 63Retour : 63 = 2⁶ - 1 est la plus grande valeur sur 6 bits. Avec 5 bits, on s'arrête à 2⁵ - 1.

5. [Binaire] Lire un octet

QCU, une seule réponse

Objectif : Passer de l'écriture binaire d'un octet à son écriture décimale.

Quel nombre décimal représente l'octet 11000001 ?

Bonne réponse : C

  1. Distracteur : 129Retour : 129 s'écrit 10000001 : tu as oublié le bit de poids 64, le deuxième en partant de la gauche.
  2. Distracteur : 192Retour : 192 s'écrit 11000000 : tu as oublié le bit de poids 1, tout à droite.
  3. Bonne réponse : 193Retour : Oui : 11000001 = 128 + 64 + 1 = 193. N'oublie aucun bit à 1, même le dernier.
  4. Distracteur : 255Retour : 255 s'écrit 11111111 : tous les bits seraient à 1. Ici, trois bits seulement sont à 1.

6. [Binaire] Écrire 150 sur 8 bits

QCU, une seule réponse

Objectif : Décomposer un entier en somme de puissances de 2 pour l'écrire en binaire.

Quelle est l'écriture binaire sur 8 bits du nombre 150 ?

Bonne réponse : C

  1. Distracteur : 10101010Retour : 10101010 vaut 128 + 32 + 8 + 2 = 170. Pour 150, retire les plus grands poids possibles : 150 - 128 = 22, puis 22 - 16 = 6…
  2. Distracteur : 11110000Retour : 11110000 vaut 128 + 64 + 32 + 16 = 240 : c'est trop. Après 128, il reste 22, et 64 ne rentre pas dans 22.
  3. Bonne réponse : 10010110Retour : Oui : 150 = 128 + 16 + 4 + 2. On met un 1 sous chacun de ces poids : 10010110.
  4. Distracteur : 10011000Retour : 10011000 vaut 128 + 16 + 8 = 152. Après 128 et 16, il reste 6 = 4 + 2, et non 8.

7. [Binaire] Écrire 200 sur 8 bits

QCU, une seule réponse

Objectif : Décomposer un entier en somme de puissances de 2 pour l'écrire en binaire.

Quelle est l'écriture binaire sur 8 bits du nombre 200 ?

Bonne réponse : A

  1. Bonne réponse : 11001000Retour : Oui : 200 = 128 + 64 + 8, donc 11001000. Vérifie toujours en additionnant les poids des bits à 1.
  2. Distracteur : 10001000Retour : 10001000 vaut 128 + 8 = 136 : il manque le poids 64. Après 128, il reste 72 = 64 + 8.
  3. Distracteur : 11111111Retour : 11111111 vaut 255, le plus grand octet. Pour 200, tous les bits ne sont pas à 1.
  4. Distracteur : 00100100Retour : 00100100 vaut 32 + 4 = 36. Pour un nombre plus grand que 128, le bit de gauche est forcément à 1.

8. [Binaire] Un octet qui alterne

QCU, une seule réponse

Objectif : Passer de l'écriture binaire d'un octet à son écriture décimale.

Quel nombre décimal représente l'octet 01010101 ?

Bonne réponse : D

  1. Distracteur : 170Retour : 170 s'écrit 10101010 : ce sont les bits de l'autre série. Ici, le bit de gauche, de poids 128, est à 0.
  2. Distracteur : 128Retour : 128 s'écrit 10000000. Ici, le bit de poids 128 est à 0 : regarde les bits à 1 un par un.
  3. Distracteur : 64Retour : 64 n'est que le premier bit à 1. Il faut ajouter les poids de tous les bits à 1 : 64 + 16 + 4 + 1.
  4. Bonne réponse : 85Retour : Oui : 01010101 = 64 + 16 + 4 + 1 = 85. Les bits à 1 sont un sur deux, en partant de la droite.

9. [Binaire] Combien de bits pour 300 ?

QCU, une seule réponse

Objectif : Trouver le nombre minimal de bits pour écrire un entier.

Un compteur doit compter jusqu'à 300 passagers sur la barge.

Combien de bits faut-il, au minimum, pour écrire le nombre 300 en binaire ?

Bonne réponse : C

  1. Distracteur : 7 bitsRetour : Avec 7 bits, on va de 0 à 2⁷ - 1 = 127 : c'est trop peu pour 300.
  2. Distracteur : 8 bitsRetour : Un octet va jusqu'à 255 seulement. On peut écrire en binaire des nombres plus grands que 255, avec plus de bits.
  3. Bonne réponse : 9 bitsRetour : Oui : 8 bits vont jusqu'à 255, trop peu ; 9 bits vont jusqu'à 2⁹ - 1 = 511. 300 s'écrit 100101100.
  4. Distracteur : 10 bitsRetour : 10 bits suffisent, mais on peut faire avec moins : 9 bits vont déjà jusqu'à 511.

10. [Texte] Un mot en ASCII

QCU, une seule réponse

Objectif : Coder un texte en binaire avec la table ASCII.

Dans la table ASCII, L a le code 76, E a le code 69 et A a le code 65.

Quel est le codage binaire, un octet par lettre, du mot LEA ?

Bonne réponse : A

  1. Bonne réponse : 01001100 01000101 01000001Retour : Oui : 76 = 64 + 8 + 4 donne 01001100 ; 69 = 64 + 4 + 1 donne 01000101 ; 65 = 64 + 1 donne 01000001.
  2. Distracteur : 01000001 01000101 01001100Retour : Ce sont les bons octets, mais dans l'ordre A, E, L : le mot serait AEL. On garde l'ordre des lettres.
  3. Distracteur : 1001100 1000101 1000001Retour : Les valeurs sont justes, mais écrites sur 7 bits. Un octet a 8 bits : on ajoute un 0 à gauche.
  4. Distracteur : 1101000 1000101 1000001Retour : Le premier code ne vaut pas 76 : 1101000 vaut 104. Et chaque code doit avoir 8 bits.

11. [Architecture] Le composant de base d'un processeur

QCU, une seule réponse

Objectif : Connaître le composant de base des circuits d'un processeur.

Quel composant électronique fonctionne comme un interrupteur commandé, et sert de brique de base aux processeurs ?

Bonne réponse : B

  1. Distracteur : Le condensateurRetour : Un condensateur garde un peu de charge électrique, un court moment. Il ne commute pas : il ne joue pas le rôle d'un interrupteur.
  2. Bonne réponse : Le transistorRetour : Oui : un transistor laisse passer le courant ou non, selon une commande : c'est un 0 ou un 1. Un processeur en contient des milliards, assemblés en portes logiques.
  3. Distracteur : Le transformateurRetour : Un transformateur change la tension d'un courant alternatif, comme dans un chargeur. Il ne fait aucun calcul.
  4. Distracteur : La résistanceRetour : Une résistance limite le courant. Elle ne peut pas passer d'un état à l'autre, comme un interrupteur.

12. [Architecture] Le rôle du disque dur ou du SSD

QCU, une seule réponse

Objectif : Distinguer la mémoire de masse, la mémoire vive et le processeur.

Quel est le rôle principal du disque dur ou du SSD (une mémoire de masse sans pièce mobile) dans un ordinateur ?

Bonne réponse : D

  1. Distracteur : Exécuter les instructions des programmes et faire les calculsRetour : C'est le rôle du processeur. Le disque garde les données, mais il ne calcule pas.
  2. Distracteur : Garder un court moment les données utilisées par le processeurRetour : C'est le rôle de la mémoire vive (RAM) : rapide, mais effacée quand on éteint. Le disque, lui, garde tout.
  3. Distracteur : Calculer et afficher les images à l'écranRetour : C'est le rôle de la carte graphique. Le disque peut stocker des images, mais il ne les calcule pas.
  4. Bonne réponse : Garder les données et les programmes, même ordinateur éteintRetour : Oui : c'est la mémoire de masse. Elle garde les fichiers sans courant, alors que la mémoire vive s'efface à l'arrêt.
