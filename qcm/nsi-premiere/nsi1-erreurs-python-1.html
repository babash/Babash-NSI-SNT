1. [Erreurs] NameError : une faute de frappe

QCU, une seule réponse · bonne réponse en C

Objectif : Lire un NameError et trouver le nom mal écrit.

Le programme suivant est exécuté.

rayon = 5
pi = 3.14
surface = pii * rayon**2
print(surface)

Console :

NameError: name 'pii' is not defined. Did you mean: 'pi'?

Quelle correction faut-il faire ?

  1. Ajouter des guillemets autour de pii'pii' deviendrait un texte : Python ne pourrait plus le multiplier par un nombre pour calculer la surface. Le message montre une faute de frappe.
  2. Supprimer la ligne pi = 3.14Cette ligne crée la variable qu'il faut utiliser. Sans elle, l'erreur resterait, et même pi n'existerait plus.
  3. Juste · Écrire pi au lieu de piiOui : le message dit « le nom 'pii' n'est pas défini. Voulais-tu dire 'pi' ? ». La variable créée s'appelle pi : c'est une faute de frappe.
  4. Remplacer le symbole * par +Le signe * n'est pas en cause : NameError parle d'un nom inconnu, ici pii. Corrige le nom, le calcul sera bon.

2. [Erreurs] SyntaxError : les deux-points du if

QCU, une seule réponse · bonne réponse en C

Objectif : Lire « expected ':' » et compléter la ligne du if.

age = 16
if age >= 18
    print('Majeur')

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Mettre des parenthèses autour de 18Les parenthèses ne changent rien ici. Le message dit ce qui manque : « expected ':' », des deux-points à la fin de la ligne.
  2. Écrire IF en majusculesPython distingue majuscules et minuscules : les mots-clés s'écrivent en minuscules, comme if. IF serait une nouvelle erreur.
  3. Juste · Ajouter « : » à la fin de la ligne du ifOui : « expected ':' » veut dire « deux-points attendus ». Toute ligne qui ouvre un bloc (if, else, for, while, def) se termine par deux-points.
  4. Retirer l'indentation devant printprint doit justement être indenté, car il fait partie du bloc du if. Ce qui manque, ce sont les deux-points.

3. [Erreurs] IndentationError : le corps d'une boucle

QCU, une seule réponse · bonne réponse en A

Objectif : Lire une IndentationError et indenter le corps d'une boucle.

for i in range(3):
print(i)

Console :

IndentationError: expected an indented block after 'for' statement on line 1

Quelle correction faut-il faire ?

  1. Juste · Indenter print(i) de 4 espacesOui : le message dit « un bloc indenté était attendu après l'instruction for de la ligne 1 ». Le corps de la boucle se décale de 4 espaces.
  2. Supprimer les deux-points après range(3)Les deux-points sont obligatoires après for. Le message parle d'autre chose : « bloc indenté attendu après le for ».
  3. Remplacer i par xLe nom de la variable n'a pas d'importance. Le message demande un bloc indenté, c'est-à-dire décalé vers la droite.
  4. Supprimer la boucle forLe programme n'afficherait plus 0, 1 et 2. On garde la boucle et on décale print(i) pour qu'il soit dans son bloc.

4. [Erreurs] IndexError : un indice de trop

QCU, une seule réponse · bonne réponse en D

Objectif : Lire une IndexError et retrouver les indices valides d'une liste.

couleurs = ['rouge', 'vert', 'bleu']
print(couleurs[3])

Console :

IndexError: list index out of range

Pourquoi cette erreur ?

  1. On ne peut pas mettre de texte dans une listeUne liste peut contenir des textes, des nombres, et même d'autres listes. Le message parle d'un indice « hors limites ».
  2. Il faut des parenthèses au lieu des crochetscouleurs(3) provoquerait une autre erreur : on lit un élément d'une liste avec des crochets. Le problème est la valeur 3.
  3. La liste doit être triée par ordre alphabétiqueL'ordre des éléments ne change rien à l'accès par indice. Ce qui compte, c'est que l'indice existe : ici, il va de 0 à 2.
  4. Juste · L'indice 3 n'existe pas : les indices vont de 0 à 2Oui : « list index out of range » veut dire « indice de liste hors limites ». Avec 3 éléments, les indices sont 0, 1 et 2.

5. [Erreurs] KeyError : une clé mal écrite

QCU, une seule réponse · bonne réponse en D

Objectif : Lire une KeyError et respecter l'écriture exacte d'une clé.

capitales = {'France': 'Paris', 'Italie': 'Rome'}
print(capitales['italie'])

Console :

KeyError: 'italie'

Quelle correction faut-il faire ?

  1. Utiliser un indice numérique : capitales[1]Un dictionnaire n'a pas d'indices 0, 1, 2 : on y accède par ses clés. capitales[1] donnerait une nouvelle KeyError.
  2. Inverser les clés et les valeursLe dictionnaire est bien construit. KeyError signale seulement que la clé 'italie' n'existe pas : regarde son écriture.
  3. Remplacer les crochets par des accoladesLes accolades servent à écrire le dictionnaire. Pour lire une valeur, on garde les crochets, avec la clé exacte.
  4. Juste · Écrire capitales['Italie']Oui : KeyError: 'italie' signifie « clé introuvable ». Python distingue majuscules et minuscules : 'Italie' et 'italie' sont deux clés différentes.

6. [Erreurs] TypeError : ajouter un nombre à un texte

QCU, une seule réponse · bonne réponse en A

Objectif : Lire une TypeError de concaténation et insérer un nombre dans un texte.

points = 50
bilan = 'Total : ' + points

Console :

TypeError: can only concatenate str (not "int") to str

Quelle correction donne à bilan la valeur 'Total : 50' ?

  1. Juste · bilan = f'Total : {points}'Oui : le message dit « on ne peut coller (concaténer) à un str qu'un autre str, pas un int ». La f-string convertit points en texte. str(points) marcherait aussi.
  2. bilan = 'Total : ' * pointsMultiplier un texte par 50 le répète 50 fois : « Total : Total : … ». Ce n'est pas le résultat voulu.
  3. bilan = int('Total : ') + points'Total : ' ne contient pas de chiffres : int() ne peut pas le convertir (ValueError). C'est le nombre qu'il faut transformer en texte.
  4. bilan = 'Total : ' + 'points'Avec des guillemets, 'points' est le mot points, pas la valeur 50 : on obtiendrait 'Total : points'.

7. [Erreurs] TypeError : des crochets sur un entier

QCU, une seule réponse · bonne réponse en B

Objectif : Lire « not subscriptable » et reconnaître qu'un entier n'a pas d'indices.

vitesse = 90
print(vitesse[0])

Console :

TypeError: 'int' object is not subscriptable

Que signifie ce message ?

  1. L'entier 90 est trop grand pour PythonPython accepte des entiers immenses. Le message dit qu'un int « n'accepte pas les indices » (not subscriptable).
  2. Juste · Des crochets sont utilisés sur un entierOui : « subscriptable » veut dire « qui accepte des indices ». Seules les listes, les chaînes ou les tuples s'utilisent avec [ ].
  3. Il faut utiliser l'indice 1Aucun indice ne convient : un entier n'est pas une suite d'éléments. vitesse[1] donnerait la même erreur.
  4. La variable vitesse n'est pas définieCe serait une NameError. Ici, vitesse existe et vaut 90 : c'est l'usage des crochets qui pose problème.

8. [Erreurs] ValueError : convertir des lettres en entier

QCU, une seule réponse · bonne réponse en A

Objectif : Lire une ValueError de int() et en trouver la cause.

saisie = 'abc'
nombre = int(saisie)

Console :

ValueError: invalid literal for int() with base 10: 'abc'

Pourquoi cette erreur ?

  1. Juste · int() n'accepte pas des lettresOui : le message dit « écriture invalide pour int() en base 10 : 'abc' ». int() attend une chaîne de chiffres, comme '42'.
  2. Il faut utiliser float('abc') à la placefloat() refuse aussi des lettres : il donnerait une ValueError du même genre. Le problème vient du contenu de la chaîne.
  3. La base 10 n'existe pas en PythonLa base 10 est la base par défaut de int(). Le message cite la base pour dire que 'abc' n'est pas un nombre écrit en base 10.
  4. La variable saisie doit être une listeint() attend une chaîne ou un nombre, pas une liste. Ici, c'est le contenu de la chaîne, des lettres, qui pose problème.

9. [Erreurs] SyntaxError : une chaîne jamais fermée

QCU, une seule réponse · bonne réponse en C

Objectif : Lire « unterminated string literal » et trouver le guillemet manquant.

message = "Bienvenue à tous
print(message)

Console :

SyntaxError: unterminated string literal (detected at line 1)

Quelle est l'erreur ?

  1. Il manque un point-virgule à la fin de la ligneEn Python, on ne termine pas les lignes par un point-virgule. Le message parle d'une chaîne non terminée.
  2. Le mot message est réservé par Pythonmessage est un nom de variable autorisé. L'erreur vient de la chaîne de la ligne 1, qui n'est jamais fermée.
  3. Juste · Il manque le guillemet fermant à la fin du texteOui : « unterminated string literal » veut dire « chaîne de caractères non terminée », détectée à la ligne 1. Il faut fermer le guillemet après « tous ».
  4. L'accent du « à » provoque l'erreurPython accepte les accents dans les chaînes. Ce qui manque, c'est le guillemet de fin.

10. [Erreurs] ZeroDivisionError : éviter la division par zéro

QCU, une seule réponse · bonne réponse en C

Objectif : Lire une ZeroDivisionError et la prévenir par un test.

total = 100
nb_personnes = 0
part = total / nb_personnes

Console :

ZeroDivisionError: division by zero

Comment éviter cet arrêt du programme ?

  1. Utiliser // au lieu de /La division entière // par zéro est aussi impossible : Python donnerait la même erreur.
  2. Multiplier par zéro à la placeOn obtiendrait 0, un résultat faux : partager 100 entre des personnes n'est pas multiplier. Il faut éviter le cas nb_personnes = 0.
  3. Juste · Tester avec un if que nb_personnes != 0Oui : « division by zero » veut dire « division par zéro ». On ne divise que si nb_personnes != 0, et on traite l'autre cas à part.
  4. Mettre nb_personnes entre guillemets'0' serait un texte : diviser un nombre par un texte provoque une TypeError. Il faut tester la valeur avant de diviser.

11. [Erreurs] AttributeError : append sur un texte

QCU, une seule réponse · bonne réponse en B

Objectif : Lire une AttributeError et savoir quelles méthodes a un type.

nom = 'Alice'
nom.append(' ')

Console :

AttributeError: 'str' object has no attribute 'append'

Pourquoi cette erreur ?

  1. Il faut écrire APPEND en majusculesLes noms de méthodes sont en minuscules, et append n'existe pour les chaînes ni en minuscules ni en majuscules.
  2. Juste · Les chaînes n'ont pas de méthode appendOui : le message dit « un objet str n'a pas d'attribut append ». Pour un texte, on fabrique une nouvelle chaîne : nom = nom + ' '.
  3. La variable nom est videnom vaut 'Alice', elle n'est pas vide. Le message dit que le type str n'a pas de méthode append.
  4. Il manque une ligne import mathappend ne vient d'aucun module. C'est une méthode des listes, que les chaînes n'ont pas.

12. [Erreurs] NameError : utiliser une variable trop tôt

QCU, une seule réponse · bonne réponse en B

Objectif : Voir qu'une variable doit recevoir une valeur avant d'être utilisée.

print(valeur)
valeur = 20

Console :

NameError: name 'valeur' is not defined

Le nom valeur est pourtant bien écrit. Pourquoi l'erreur ?

  1. Il faut écrire valeur = '20'Le type de la valeur ne change rien : à la ligne 1, valeur n'existe pas encore, quelle que soit sa future valeur.
  2. Juste · La variable est utilisée avant d'avoir reçu une valeurOui : « name 'valeur' is not defined » veut dire « le nom valeur n'est pas défini ». Python lit de haut en bas : il faut échanger les deux lignes.
  3. Python lit le programme de bas en hautC'est l'inverse : Python exécute les lignes de haut en bas. Quand il arrive à print, la ligne valeur = 20 n'a pas encore été exécutée.
  4. Python ne gère pas les entiers au début d'un programmeUn entier peut apparaître n'importe où. Le problème est l'ordre des lignes : la variable est utilisée avant d'être créée.

13. [Erreurs] ValueError : trop de variables à remplir

QCU, une seule réponse · bonne réponse en A

Objectif : Lire « not enough values to unpack » et compter variables et valeurs.

coords = (10, 20)
x, y, z = coords

Console :

ValueError: not enough values to unpack (expected 3, got 2)

Quel est le problème ?

  1. Juste · 3 variables à remplir, mais 2 valeurs seulementOui : le message dit « pas assez de valeurs à répartir (3 attendues, 2 reçues) ». Il faut autant de variables que de valeurs.
  2. On ne peut pas nommer une variable zz est un nom de variable autorisé. Le message compte : 3 variables attendent une valeur, le tuple n'en a que 2.
  3. Il faut des crochets autour de (10, 20)Une liste [10, 20] a aussi 2 valeurs : l'erreur serait la même. Le problème est le nombre de valeurs.
  4. Les valeurs 10 et 20 doivent être des textesLe type des valeurs ne compte pas ici : Python ne trouve que 2 valeurs pour remplir 3 variables.

14. [Erreurs] TypeError : boucler sur un entier

QCU, une seule réponse · bonne réponse en B

Objectif : Lire « not iterable » et utiliser range pour répéter une action.

score = 10
for i in score:
    print(i)

Console :

TypeError: 'int' object is not iterable

Comment corriger pour répéter l'affichage 10 fois ?

  1. Écrire score = '10'La boucle parcourrait la chaîne '10' : elle afficherait 1 puis 0, soit 2 tours seulement.
  2. Juste · Écrire for i in range(score):Oui : « not iterable » veut dire « qu'on ne peut pas parcourir ». range(score) fabrique la suite 0, 1, …, 9 : 10 tours.
  3. Retirer l'indentation de printprint sortirait de la boucle, et l'erreur de la ligne 2 resterait : un entier ne se parcourt pas.
  4. Écrire while i in score:i n'existe pas encore, et le test « in » sur un entier provoque aussi une TypeError. Pour répéter n fois, on utilise for i in range(n).

15. [Erreurs] SyntaxError : une parenthèse jamais fermée

QCU, une seule réponse · bonne réponse en D

Objectif : Lire « '(' was never closed » et trouver la parenthèse manquante.

print('Début'
print('Fin')

Console :

SyntaxError: '(' was never closed

D'où vient l'erreur ?

  1. On ne peut pas écrire deux print à la suiteOn peut enchaîner autant de print qu'on veut, un par ligne. Le message parle d'une parenthèse ouverte jamais fermée.
  2. Il faut écrire Début et Fin en majusculesLe contenu des chaînes est libre. Le message dit « la parenthèse ( n'a jamais été fermée ».
  3. Il manque les deux-points à la finLes deux-points ne s'écrivent qu'après if, for, while, def… Un print n'en a pas besoin.
  4. Juste · La parenthèse fermante de la première ligne manqueOui : « '(' was never closed » veut dire « la parenthèse ( n'a jamais été fermée ». Python montre la ligne où elle s'ouvre : la première.
