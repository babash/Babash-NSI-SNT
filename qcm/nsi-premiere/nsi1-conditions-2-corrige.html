1. [Conditions] Un if … else dans un if

QCU, une seule réponse

Objectif : Suivre deux niveaux de blocs et l'instruction qui les suit.

a = 10
b = 1
if a > 5:
    a = a - 5
    if a < b:
        b = 100
    else:
        b = 20
    a = a + 1
else:
    a = 0
    b = 0
print(a + b)

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 26Retour : Oui. 10 > 5 : a devient 5. 5 < 1 est faux : b devient 20. Puis a = a + 1 : a vaut 6. Le print affiche 6 + 20 = 26.
  2. Distracteur : 101Retour : 101 ne correspond à aucun chemin du programme. Quand on teste a < b, a vaut 5 et b vaut 1 : 5 < 1 est faux, c'est le else intérieur qui donne b = 20.
  3. Distracteur : 25Retour : Tu as oublié a = a + 1. Cette ligne est indentée au niveau du premier if : elle s'exécute après le if … else intérieur. a vaut 6.
  4. Distracteur : 7Retour : b change bien : le if intérieur est faux, donc son else s'exécute et b reçoit 20. Puis 6 + 20 = 26.

2. [Conditions] Le test in sur un texte

QCU, une seule réponse

Objectif : Suivre un test in, puis un if … elif … else intérieur.

c = "rouge"
x = 0
if "r" in c:
    x = 1
    if c == "vert":
        x = x + 10
    elif c == "rouge":
        x = x * 2
    else:
        x = x + 100
else:
    x = 5
print(x)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : 1Retour : Après x = 1, le bloc intérieur s'exécute encore : c == "rouge" est vrai, et x = x * 2 change x.
  2. Distracteur : 101Retour : Le else intérieur n'est pas atteint : le elif c == "rouge" est vrai, la suite est ignorée.
  3. Distracteur : 5Retour : "r" in c ne demande pas si c vaut "r" : il demande si la lettre r apparaît dans le texte. Elle y est : on n'entre pas dans le else.
  4. Bonne réponse : 2Retour : Oui. "r" est dans "rouge" : x devient 1. Puis c == "vert" est faux, c == "rouge" est vrai : x = 1 × 2 = 2.

3. [Conditions] Un print dans le bloc, un autre après

QCU, une seule réponse

Objectif : Suivre une variable modifiée dans un bloc et après lui.

Dans les réponses, le signe « / » sépare deux lignes affichées.

s = 10
if s > 5:
    s = s + 5
    if s > 15:
        print(s)
    else:
        print(s - 10)
s = s * 2
print(s)

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : 15 / 30Retour : s vaut 15, et 15 > 15 est faux : c'est le else intérieur qui s'exécute. Il affiche s - 10, soit 5.
  2. Distracteur : 30Retour : Le bloc intérieur affiche déjà une ligne avant le dernier print : 5, puis 30.
  3. Bonne réponse : 5 / 30Retour : Oui. s devient 15 ; 15 > 15 est faux : le else affiche 15 - 10 = 5. Puis s = s * 2 (hors du bloc) : 30 s'affiche.
  4. Distracteur : 5 / 10Retour : print(s - 10) affiche un calcul mais ne change pas s : s vaut toujours 15. Puis s * 2 donne 30.

4. [Conditions] Un if … else dans un elif

QCU, une seule réponse

Objectif : Suivre un bloc imbriqué dans une branche elif.

Dans les réponses, le signe « / » sépare deux lignes affichées.

h = 14
if h < 10:
    print("Matin")
elif h < 18:
    print("Jour")
    if h > 15:
        print("Fin")
    else:
        print("Milieu")
else:
    print("Soir")

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : Jour / FinRetour : 14 > 15 est faux : le if intérieur est sauté et son else affiche Milieu.
  2. Distracteur : SoirRetour : Le else extérieur n'est pas atteint : le elif (14 < 18) est vrai.
  3. Distracteur : MilieuRetour : Dans le bloc du elif, print("Jour") vient avant le if intérieur : il s'affiche d'abord.
  4. Bonne réponse : Jour / MilieuRetour : Oui. 14 < 10 est faux, 14 < 18 est vrai : Jour s'affiche. Puis 14 > 15 est faux : le else intérieur affiche Milieu.

5. [Conditions] Des conditions avec and et or

QCU, une seule réponse

Objectif : Évaluer une condition avec or, puis une avec and.

a = 15
b = 5
if a % 2 == 0 or b > 10:
    a = 1
    b = 1
elif a > 10 and b < 10:
    a = 2
    b = 2
else:
    a = 3
    b = 3
print(a * b)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : 1Retour : 15 % 2 vaut 1 et 5 > 10 est faux : faux or faux donne faux. Le premier bloc est sauté.
  2. Distracteur : 9Retour : Le else n'est pas atteint : 15 > 10 et 5 < 10 sont vrais tous les deux, donc le elif s'exécute.
  3. Distracteur : 2Retour : Le programme affiche a * b, le produit, pas a seul. a et b valent 2 : 2 × 2 = 4.
  4. Bonne réponse : 4Retour : Oui. Le if est faux (faux or faux). Le elif est vrai : 15 > 10 et 5 < 10. a et b valent 2 : 2 × 2 = 4.

6. [Conditions] Construire un texte morceau par morceau

QCU, une seule réponse

Objectif : Suivre une chaîne modifiée dans plusieurs blocs.

resultat = ""
x = 10
if x > 20:
    resultat = "A"
else:
    resultat = "B"
    if x > 5:
        resultat = resultat + "C"
    else:
        resultat = resultat + "D"
resultat = resultat + "E"
print(resultat)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : BDERetour : 10 > 5 est vrai : c'est "C" qui est ajouté, pas "D".
  2. Bonne réponse : BCERetour : Oui. 10 > 20 est faux : resultat vaut "B". 10 > 5 est vrai : "BC". La ligne suivante, hors des blocs, ajoute "E".
  3. Distracteur : ARetour : 10 > 20 est faux : on passe dans le else, où resultat reçoit "B".
  4. Distracteur : BCRetour : resultat = resultat + "E" n'est pas indentée : elle s'exécute après les blocs, dans tous les cas.

7. [Conditions] Un test de divisibilité dans un if

QCU, une seule réponse

Objectif : Suivre un if imbriqué qui teste un reste.

val = 15
res = 0
if val < 20:
    res = 1
    if val % 3 == 0:
        res = res + 2
    else:
        res = res + 5
elif val < 30:
    res = 10
 
print(res)

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 3Retour : Oui. 15 < 20 : res vaut 1. 15 % 3 vaut 0 (15 = 3 × 5) : res = 1 + 2 = 3.
  2. Distracteur : 10Retour : Le elif n'est pas testé : le premier if (15 < 20) est vrai.
  3. Distracteur : 6Retour : 15 est divisible par 3 : 15 % 3 vaut 0, la condition est vraie. C'est + 2, pas + 5.
  4. Distracteur : 1Retour : Après res = 1, le if intérieur s'exécute aussi : 15 % 3 == 0 est vrai, et res devient 3.

8. [Conditions] Une condition est une valeur

QCU, une seule réponse

Objectif : Savoir qu'une comparaison donne un booléen, qu'on peut ranger dans une variable.

Le matin, il y a souvent un bouchon jusqu'à Mamoudzou.

heure = 7
bouchon = heure >= 6 and heure <= 9
print(bouchon)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : FalseRetour : Les deux comparaisons sont vraies pour heure = 7 : avec and, le résultat est True.
  2. Distracteur : Une erreur : il manque ifRetour : Une comparaison peut s'écrire sans if : elle donne True ou False, qu'on range dans une variable.
  3. Distracteur : 7Retour : bouchon ne reçoit pas heure : il reçoit le résultat de la condition, True ou False.
  4. Bonne réponse : TrueRetour : Oui. 7 >= 6 est vrai, 7 <= 9 est vrai : vrai and vrai donne True. Une comparaison donne une valeur, rangée ici dans bouchon.

9. [Conditions] L'ordre des tests

QCU, une seule réponse

Objectif : Comprendre pourquoi l'ordre des elif compte.

Ce programme doit classer une mangue selon son poids, en grammes : « grosse » au-dessus de 400 g, « moyenne » au-dessus de 200 g, « petite » sinon.

poids = 450
if poids > 200:
    print("moyenne")
elif poids > 400:
    print("grosse")
else:
    print("petite")

Qu'affiche-t-il pour une mangue de 450 g ?

Bonne réponse : B

  1. Distracteur : grosseRetour : C'est ce qu'on voudrait, mais Python teste dans l'ordre : 450 > 200 est vrai d'abord, il affiche moyenne et s'arrête.
  2. Bonne réponse : moyenneRetour : Oui, et c'est une erreur du programme : 450 > 200 est vrai, le elif n'est jamais testé. Il faut tester poids > 400 en premier.
  3. Distracteur : moyenne / grosseRetour : Une seule branche s'exécute : la première vraie. Python ne teste pas le elif après le if vrai.
  4. Distracteur : petiteRetour : Le else ne s'exécute que si toutes les conditions sont fausses. Ici, 450 > 200 est vrai.

10. [Conditions] Un if sans else

QCU, une seule réponse

Objectif : Savoir qu'une condition fausse sans else ne bloque pas le programme.

Dans les réponses, le signe « / » sépare deux lignes affichées.

maree = "basse"
if maree == "haute":
    print("Départ en pirogue")
print("Fin")

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : FinRetour : Oui. "basse" == "haute" est faux : le bloc est sauté. print("Fin") n'est pas indenté : il s'exécute toujours.
  2. Distracteur : Rien ne s'afficheRetour : Une condition fausse n'arrête pas le programme : Python saute le bloc et continue à la ligne suivante.
  3. Distracteur : Départ en pirogue / FinRetour : La condition est fausse : maree vaut "basse". Le print indenté sous le if est sauté.
  4. Distracteur : Une erreur : il manque elseRetour : Le else n'est pas obligatoire. Sans else, si la condition est fausse, Python ne fait rien de plus et continue.

11. [Conditions] or au lieu de and

QCU, une seule réponse

Objectif : Repérer une condition toujours vraie, écrite avec or au lieu de and.

Dans cet exercice, le tarif de jour d'un taxi s'applique de 6 h à 20 h ; sinon, c'est le tarif de nuit.

heure = 22
if heure >= 6 or heure < 20:
    print("tarif de jour")
else:
    print("tarif de nuit")

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : tarif de nuitRetour : C'est le bon tarif, mais pas ce qu'affiche ce programme : avec or, 22 >= 6 suffit à rendre la condition vraie.
  2. Distracteur : tarif de jour / tarif de nuitRetour : Une seule branche s'exécute. Ici, la condition est vraie : c'est le if.
  3. Bonne réponse : tarif de jourRetour : Oui, et c'est une erreur : avec or, 22 >= 6 suffit, la condition est toujours vraie. Il faut and : heure >= 6 and heure < 20.
  4. Distracteur : Rien ne s'afficheRetour : Chaque branche a un print : le programme affiche forcément un tarif.

12. [Conditions] Majuscules et minuscules

QCU, une seule réponse

Objectif : Savoir que == distingue les majuscules des minuscules.

reponse = "Oui"
if reponse == "oui":
    print("On y va")
else:
    print("On attend")

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : On attendRetour : Oui. "Oui" == "oui" est faux : Python distingue les majuscules. Le else affiche On attend.
  2. Distracteur : On y vaRetour : Pour Python, "Oui" et "oui" sont deux textes différents : le O majuscule n'est pas le o minuscule. Le test est faux.
  3. Distracteur : Une erreurRetour : Le programme est bien écrit. Comparer deux textes avec == est permis ; le résultat est simplement faux ici.
  4. Distracteur : OuiRetour : Le programme n'affiche pas reponse : il affiche On y va ou On attend.

13. [Erreurs] Corriger la condition d'un if

QCU, une seule réponse

Objectif : Lire le message d'une SyntaxError et corriger une condition.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

maree = "haute"
if maree = "haute":
    print("La barge accoste")

Console :

SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Quelle correction faut-il faire ?

Bonne réponse : C

  1. Distracteur : Mettre la condition entre parenthèsesRetour : Les parenthèses ne changent rien : Python affiche la même erreur. Le problème est le signe =, qui n'est pas une comparaison.
  2. Distracteur : Retirer les guillemets autour de hauteRetour : Sans guillemets, haute serait un nom de variable inconnu. Les guillemets sont justes : "haute" est un texte.
  3. Bonne réponse : Écrire == au lieu de = dans la conditionRetour : Oui. = range une valeur dans une variable (affectation) ; == compare deux valeurs. Le message le propose : « Maybe you meant '==' » (« voulais-tu dire == ? »).
  4. Distracteur : Ajouter un else à la finRetour : Le else n'est pas obligatoire. Le message « invalid syntax » (« syntaxe invalide ») vise le signe = de la ligne 2.

14. [Erreurs] Les deux-points oubliés

QCU, une seule réponse

Objectif : Lire le message « expected ':' » et le corriger.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

note = 12
if note >= 10
    print("Admis·e")

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

Bonne réponse : B

  1. Distracteur : Écrire => au lieu de >=Retour : => n'existe pas en Python : « supérieur ou égal » s'écrit bien >=. Le message parle d'autre chose.
  2. Bonne réponse : Ajouter : à la fin de la ligne ifRetour : Oui. « expected ':' » veut dire « deux-points attendus ». Une ligne if se termine toujours par deux-points, avant le bloc indenté.
  3. Distracteur : Ajouter un else après le printRetour : Le else n'est pas obligatoire, et il lui faudrait aussi ses deux-points. Lis le message : il manque « : ».
  4. Distracteur : Retirer l'indentation du printRetour : Le print sortirait du bloc du if, et Python afficherait la même erreur, « expected ':' » : les deux-points manquent toujours.

15. [Erreurs] Le bloc non indenté

QCU, une seule réponse

Objectif : Lire une IndentationError et indenter le bloc d'un if.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

n = 3
if n > 0:
print("positif")

Console :

IndentationError: expected an indented block after 'if' statement on line 2

Quelle correction faut-il faire ?

Bonne réponse : B

  1. Distracteur : Retirer les deux-points de la ligne 2Retour : Les deux-points sont obligatoires après un if : sans eux, Python signalerait « expected ':' ».
  2. Bonne réponse : Décaler le print de 4 espaces vers la droiteRetour : Oui. Le message dit « bloc indenté attendu après le if de la ligne 2 ». Le bloc d'un if se décale de 4 espaces.
  3. Distracteur : Ajouter ; à la fin de la ligne 2Retour : Python n'utilise pas de point-virgule pour finir une ligne if : il afficherait une autre erreur de syntaxe.
  4. Distracteur : Écrire Print avec une majusculeRetour : Python distingue les majuscules : Print n'existe pas. La fonction s'écrit print ; le problème est l'indentation.

16. [Erreurs] Un else avec une condition

QCU, une seule réponse

Objectif : Savoir qu'un else ne porte pas de condition, et écrire une deuxième condition.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

x = -2
if x > 0:
    print("positif")
else x < 0:
    print("négatif")

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

Bonne réponse : C

  1. Distracteur : Écrire else if x < 0:Retour : else if existe dans d'autres langages, pas en Python : Python affiche la même erreur. Il attend « : » juste après else.
  2. Distracteur : Retirer les deux-points après x < 0Retour : Python affiche la même erreur, « expected ':' » : il attend « : » juste après else. Le problème n'est pas la fin de la ligne : un else ne porte pas de condition.
  3. Bonne réponse : Écrire elif x < 0:Retour : Oui. Un else ne porte jamais de condition : Python attend « : » juste après else. Pour une deuxième condition, on écrit elif.
  4. Distracteur : Écrire else (x < 0):Retour : Les parenthèses ne changent rien : un else n'a pas de condition. Il faut un elif.

17. [Erreurs] Comparer un texte et un nombre

QCU, une seule réponse

Objectif : Lire une TypeError dans une condition et convertir le texte en nombre.

La variable age contient un texte, comme ce que renvoie input(). Le programme suivant est exécuté.

age = "16"
if age >= 18:
    print("majeur·e")
else:
    print("mineur·e")

Console :

TypeError: '>=' not supported between instances of 'str' and 'int'

Quelle correction faut-il faire ?

Bonne réponse : A

  1. Bonne réponse : Écrire if int(age) >= 18:Retour : Oui. Le message dit « >= impossible entre un str (texte) et un int (entier) ». int(age) transforme "16" en 16 : la comparaison marche.
  2. Distracteur : Écrire elif au lieu de elseRetour : Le else est bien écrit. Le message parle de types : >= ne compare pas un texte (str) et un nombre entier (int).
  3. Distracteur : Écrire "18" entre guillemetsRetour : Le programme ne s'arrêterait plus, mais il comparerait deux textes, lettre par lettre : "9" >= "18" serait vrai ! Il faut comparer des nombres.
  4. Distracteur : Écrire => au lieu de >=Retour : => n'existe pas en Python. Le message vise les types : "16" est un texte, 18 est un nombre.
