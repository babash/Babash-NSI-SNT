Associer chaque numération à sa base.

La base est le nombre de chiffres différents : 2 en binaire (0 et 1), 10 en décimal (0 à 9), 16 en hexadécimal (0 à 9, puis A à F).

Choix multiple

Objectif : Reconnaître les bases dans lesquelles une écriture est possible.

Sans autre indication, le nombre 10111 peut être écrit dans quelles bases ? Cocher toutes les bonnes réponses.

  1. Juste · Base 2Oui : 10111 n'utilise que les chiffres 0 et 1, permis en base 2. Il vaudrait alors 23.
  2. Juste · Base 10Oui : 0 et 1 sont aussi des chiffres de la base 10. Lu en décimal, c'est dix mille cent onze.
  3. Juste · Base 16Oui : 0 et 1 sont aussi des chiffres hexadécimaux. Sans préfixe ni indice, on ne peut pas savoir dans quelle base il est écrit.

4. [Bases] Dans quelle base lire 10A11 ?

QCU, une seule réponse · bonne réponse en B

Objectif : Reconnaître qu'une lettre de A à F impose la base 16.

Sans autre indication, le nombre 10A11 est écrit dans quelle base ?

  1. Base 2La base 2 n'a que les chiffres 0 et 1 : A n'y existe pas.
  2. Juste · Base 16Oui : en base 16, les chiffres vont de 0 à 9, puis de A (qui vaut 10) à F (qui vaut 15). C'est la seule base possible ici.
  3. Base 8La base 8 a les chiffres 0 à 7 : la lettre A n'y existe pas.
  4. Base 10La base 10 n'a que les chiffres 0 à 9. La lettre A est un chiffre de la base 16, qui vaut 10.

5. [Bases] Les préfixes 0b et 0x de Python

Objectif : Lire les préfixes 0b et 0x d'un nombre en Python.

a = 0b1011
b = 0x1011

Dans quelles bases sont écrits les nombres a et b ?

  1. a en base 16, b en base 2C'est l'inverse : le b de 0b vient de binary (binaire), le x de 0x vient de hexadecimal.
  2. a et b en base 2Les chiffres sont les mêmes, mais les préfixes diffèrent : 0x annonce la base 16.
  3. a et b en base 10Les préfixes servent justement à dire que le nombre n'est pas en base 10 : 0b pour la base 2, 0x pour la base 16.
  4. Juste · a en base 2, b en base 16Oui : 0b (pour binary) annonce la base 2, 0x (pour hexadecimal) la base 16. a vaut 11 et b vaut 4113.

6. [Bases] La fonction native hex

QCU, une seule réponse · bonne réponse en C

Objectif : Connaître la fonction native de Python qui donne l'écriture hexadécimale.

Quelle fonction native de Python (fournie sans importer de module) donne l'écriture hexadécimale d'un entier ?

  1. int()int() fait le chemin inverse : int('ff', 16) lit un texte hexadécimal et donne l'entier 255.
  2. bin()bin() donne l'écriture binaire : bin(255) vaut '0b11111111'.
  3. Juste · hex()Oui : hex(255) renvoie la chaîne '0xff'. Le résultat est un texte, précédé du préfixe 0x.
  4. oct()oct() donne l'écriture en base 8 (octale) : oct(255) vaut '0o377'.

7. [Bases] Convertir 0xBAC en décimal

QCU, une seule réponse · bonne réponse en A

Objectif : Convertir un nombre hexadécimal en décimal.

Quelle est l'écriture décimale du nombre hexadécimal 0xBAC ?

  1. Juste · 2988Oui : B × 16² + A × 16 + C = 11 × 256 + 10 × 16 + 12 = 2816 + 160 + 12 = 2988.
  2. 8829Tu as peut-être lu les chiffres de droite à gauche. B est le chiffre de poids fort : B × 256 + A × 16 + C.
  3. 8892Vérifie les valeurs des lettres : B = 11, A = 10, C = 12, et les poids 256, 16, 1.
  4. 2898Presque : les chiffres sont bons, mais deux sont inversés. Refais l'addition : 2816 + 160 + 12.

9. [Bases] Convertir A340 en binaire

Réponse courte

Objectif : Convertir un nombre hexadécimal en binaire, chiffre par chiffre.

Écrire en binaire le nombre hexadécimal A340. Écrire seulement des 0 et des 1, sans préfixe (par exemple : 1101000000).

Réponses acceptées : 1010001101000000 ; 1010 0011 0100 0000 ; 0b1010001101000000 (majuscules indifférentes)

Chaque chiffre hexadécimal donne 4 bits : A = 1010, 3 = 0011, 4 = 0100, 0 = 0000. On les met bout à bout : 1010 0011 0100 0000.

10. [Bases] Bits nécessaires pour un chiffre hexadécimal

Réponse numérique

Objectif : Savoir qu'un chiffre hexadécimal s'écrit sur 4 bits.

Combien de bits faut-il pour écrire n'importe quel chiffre hexadécimal (de 0 à F) ? Répondre par un nombre.

Réponse : 4 (tolérance 0)

Il y a 16 chiffres hexadécimaux, et 4 bits donnent 2⁴ = 16 combinaisons : de 0000 (0) à 1111 (F). C'est pourquoi 1 chiffre hexadécimal = 4 bits.

11. [Bases] Les nombres 1, 10, 100… en base 16

QCU, une seule réponse · bonne réponse en D

Objectif : Relier l'écriture 1 suivi de zéros aux puissances de la base.

Les entiers dont l'écriture en base 16 est un 1 suivi de zéros (1, 10, 100, 1000…) sont :

  1. les puissances de 2C'est vrai en base 2 : 1, 10, 100 y valent 1, 2, 4. En base 16, chaque zéro ajouté multiplie par 16.
  2. les puissances de 8Ce serait le cas en base 8. En base 16, 10 vaut 16, 100 vaut 16² = 256.
  3. les puissances de 10C'est vrai en base 10. En base 16, chaque position vaut 16 fois la précédente.
  4. Juste · les puissances de 16Oui : en base 16, 1 = 16⁰, 10 = 16¹ = 16, 100 = 16² = 256, 1000 = 16³ = 4096. Cela marche dans toutes les bases.

12. [Bases] Le nombre qui suit 9F

QCU, une seule réponse · bonne réponse en C

Objectif : Compter en base 16 avec une retenue.

Quel nombre hexadécimal suit 9F ?

  1. 9F1Ajouter 1, ce n'est pas écrire un 1 à la fin. F + 1 donne 0 avec une retenue sur le chiffre de gauche.
  2. 9GG n'est pas un chiffre hexadécimal : après F (15), on revient à 0 et on ajoute une retenue.
  3. Juste · A0Oui : F + 1 = 10 en base 16, on écrit 0 et on retient 1 ; 9 + 1 = A. Donc 9F + 1 = A0 (de 159 à 160).
  4. 910F + 1 donne bien « 10 », mais le 1 est une retenue : il s'ajoute au 9, il ne s'écrit pas à part.

14. [Bases] Combien de nombres avec 2 chiffres hexadécimaux ?

QCU, une seule réponse · bonne réponse en B

Objectif : Compter les valeurs qu'on écrit avec 2 chiffres hexadécimaux.

Combien de nombres différents peut-on écrire avec 2 chiffres hexadécimaux ?

  1. 1616, c'est avec un seul chiffre. Avec deux, chaque chiffre a 16 valeurs : 16 × 16.
  2. Juste · 256Oui : 16 × 16 = 256 nombres, de 00 à FF (0 à 255). C'est exactement un octet.
  3. 3232 = 16 + 16 : on additionne au lieu de multiplier. Chaque valeur du premier chiffre se combine avec les 16 du second.
  4. 128128 = 2⁷, ce serait avec 7 bits. Deux chiffres hexadécimaux font 8 bits : 2⁸ = 256.

15. [Bases] Un code couleur RVB en hexadécimal

QCU, une seule réponse · bonne réponse en A

Objectif : Convertir chaque composante d'une couleur RVB en hexadécimal.

Une couleur se code par trois nombres de 0 à 255 (rouge, vert, bleu). Le « vert impérial » est codé (0, 86, 27) en décimal.

Quel est son codage hexadécimal ?

  1. Juste · (0, 56, 1B)Oui : 86 = 5 × 16 + 6, donc 56 ; 27 = 1 × 16 + 11, donc 1B. En HTML, on écrirait #00561B.
  2. (0, 134, 1B)134 est l'écriture décimale de 0x86 : tu as converti dans le mauvais sens. 86 en décimal vaut 5 × 16 + 6, soit 56.
  3. (0, 134, 39)Les deux composantes ont été converties à l'envers : 0x86 vaut 134 et 0x27 vaut 39. Il faut partir de 86 et de 27, en décimal.
  4. (0, 56, 39)56 est juste, mais 39 est l'écriture décimale de 0x27. 27 en décimal vaut 1 × 16 + 11, soit 1B.

16. [Bases] Compléter une fonction de conversion en hexadécimal

Texte à trous

Objectif : Compléter une fonction qui convertit un entier de 0 à 255 en deux chiffres hexadécimaux.

La fonction dec_vers_hex prend un entier de 0 à 255 (une composante d'une couleur RVB) et renvoie son écriture hexadécimale sur deux chiffres, sous forme de chaîne.

def dec_vers_hex(d):
    HEX = '0123456789ABCDEF'
    q = d // 16     # quotient
    r = d % 16      # reste
    x_hex = HEX[ q ] + HEX[ r ]
    return x_hex

assert dec_vers_hex(255) == 'FF'

Compléter les cases.

Le quotient par 16 (d // 16) donne le chiffre de gauche, le reste (d % 16) celui de droite ; on lit chaque chiffre dans la chaîne HEX. Pour 255 : 255 // 16 = 15 (F) et 255 % 16 = 15 (F), d'où 'FF'.
