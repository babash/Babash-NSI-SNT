1. [Erreurs] NameError dans une fonction

QCU, une seule réponse

Objectif : Trouver le nom mal écrit dans le corps d'une fonction.

def calculer_surface(rayon):
    pi = 3.14
    return pii * rayon**2
 
print(calculer_surface(5))

Console :

NameError: name 'pii' is not defined. Did you mean: 'pi'?

Quelle correction faut-il faire ?

  1. Écrire pi au lieu de pii dans le return
  2. Définir pii à l'extérieur de la fonction
  3. Ajouter des guillemets autour de pii
  4. Remplacer pii par input()

2. [Erreurs] SyntaxError : les deux-points du def

QCU, une seule réponse

Objectif : Lire « expected ':' » sur la ligne d'une définition de fonction.

def verifier_age(age)
    if age >= 18:
        return 'Majeur'
    return 'Mineur'

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Ajouter des parenthèses autour de age >= 18
  2. Ajouter « : » à la fin de la ligne def
  3. Écrire 'Majeur' avec des guillemets doubles
  4. Indenter la ligne def

3. [Erreurs] IndentationError : le corps d'une fonction

QCU, une seule réponse

Objectif : Indenter le corps d'une fonction.

def doubler(n):
resultat = n * 2
    return resultat

Console :

IndentationError: expected an indented block after function definition on line 1

Quelle correction faut-il faire ?

  1. Ajouter 4 espaces devant la ligne resultat = n * 2
  2. Supprimer l'indentation de la ligne return
  3. Remplacer n * 2 par n + n
  4. Ajouter une ligne pass après le return

4. [Erreurs] IndexError dans une fonction

QCU, une seule réponse

Objectif : Lire une IndexError et trouver l'indice qui pose problème.

def obtenir_dernier(ma_liste):
    n = len(ma_liste)
    return ma_liste[n]
 
print(obtenir_dernier([10, 20, 30]))

Console :

IndexError: list index out of range

Pourquoi cette erreur ?

  1. La liste est vide
  2. On ne peut pas utiliser une variable comme indice
  3. L'indice du dernier élément est len(ma_liste) - 1
  4. Il faut écrire ma_liste(n)

5. [Erreurs] KeyError : l'argument mal écrit

QCU, une seule réponse

Objectif : Trouver qu'une clé passée en argument ne respecte pas les majuscules.

def afficher_score(nom):
    scores = {'Alia': 15, 'Yanis': 12}
    print(scores[nom])
 
afficher_score('alia')

Console :

KeyError: 'alia'

Quelle correction faut-il faire ?

  1. Écrire scores.nom au lieu de scores[nom]
  2. Utiliser une liste plutôt qu'un dictionnaire
  3. Respecter la majuscule : afficher_score('Alia')
  4. Définir nom = 'Alia' dans la fonction

6. [Erreurs] TypeError : concaténer un texte et un nombre

QCU, une seule réponse

Objectif : Insérer un nombre dans un texte sans changer son type.

score = 10
msg = 'Ton score est : ' + score
print(msg)

Console :

TypeError: can only concatenate str (not "int") to str

Quelle correction est la plus adaptée ?

  1. Remplacer le + par un *
  2. Utiliser une f-string : f'Ton score est : {score}'
  3. Écrire score = '10' au lieu de score = 10
  4. Ajouter des parenthèses : (score)

7. [Erreurs] TypeError : un argument du mauvais type

QCU, une seule réponse

Objectif : Lire « not subscriptable » quand une fonction reçoit un argument du mauvais type.

def traiter_valeur(x):
    return x[0]
 
traiter_valeur(42)

Console :

TypeError: 'int' object is not subscriptable

Que signifie ce message ?

  1. L'indice 0 n'existe pas dans la liste
  2. On utilise des crochets sur un entier
  3. La fonction doit renvoyer x et non x[0]
  4. Il manque un return devant traiter_valeur

8. [Erreurs] ValueError : une conversion avec int()

QCU, une seule réponse

Objectif : Lire une ValueError de int() et en trouver la cause.

reponse = '12.5'
nombre = int(reponse)

Console :

ValueError: invalid literal for int() with base 10: '12.5'

Pourquoi l'erreur se produit-elle ?

  1. int() refuse une chaîne qui contient un point décimal
  2. int() ne convertit que des nombres négatifs
  3. Il faut écrire Integer(reponse)
  4. reponse doit être entre crochets

9. [Erreurs] Le message unterminated string literal

QCU, une seule réponse

Objectif : Comprendre le message « unterminated string literal ».

print("Bonjour tout le monde)

Console :

SyntaxError: unterminated string literal (detected at line 1)

Que signifie ce message ?

  1. La ligne 1 contient trop de caractères
  2. Il manque la parenthèse fermante de l'instruction print
  3. Une chaîne n'est pas fermée : il manque un guillemet
  4. print ne peut afficher qu'un seul mot

10. [Erreurs] TypeError : trop d'arguments

QCU, une seule réponse

Objectif : Corriger un appel qui donne plus d'arguments que la fonction n'a de paramètres.

def somme(a, b):
    return a + b
 
print(somme(10, 20, 30))

Console :

TypeError: somme() takes 2 positional arguments but 3 were given

Comment corriger l'appel, sans modifier la fonction ?

  1. Ne garder que deux arguments : somme(10, 20)
  2. Ajouter un paramètre c : def somme(a, b, c)
  3. Mettre les arguments dans une liste : somme([10, 20, 30])
  4. Remplacer les virgules par des points

11. [Erreurs] AttributeError : une liste devenue None

QCU, une seule réponse

Objectif : Comprendre pourquoi une variable reçoit None après un appel.

def ajouter_element(liste, x):
    liste.append(x)
    # pas de return
 
ma_liste = [1, 2]
ma_liste = ajouter_element(ma_liste, 3)
ma_liste.append(4)

Console :

AttributeError: 'NoneType' object has no attribute 'append'

Pourquoi ma_liste est-elle devenue None ?

  1. On ne peut pas faire deux append de suite
  2. La méthode append n'existe pas en Python
  3. Sans return, la fonction renvoie None
  4. Il faut importer le module NoneType

12. [Erreurs] NameError : une variable créée dans une fonction

QCU, une seule réponse

Objectif : Comprendre la portée d'une variable créée dans une fonction.

def calcul():
    valeur = 10
    return valeur * 2
 
calcul()
print(valeur)

Console :

NameError: name 'valeur' is not defined

La variable valeur est pourtant définie dans la fonction. Pourquoi l'erreur ?

  1. print(valeur) doit être placé dans calcul()
  2. Il manque une ligne global valeur au début du programme
  3. La fonction calcul() n'a pas été appelée
  4. valeur est locale à la fonction : elle n'existe pas en dehors

13. [Erreurs] ValueError : répartir un tuple renvoyé

QCU, une seule réponse

Objectif : Compter les valeurs renvoyées et les variables qui les reçoivent.

def obtenir_coords():
    return (10, 20)
 
x, y, z = obtenir_coords()

Console :

ValueError: not enough values to unpack (expected 3, got 2)

Que signifie ce message ?

  1. La fonction renvoie trop de valeurs
  2. Il faut une liste à gauche : [x, y, z]
  3. Les variables x, y et z ne sont pas définies avant
  4. On veut ranger 2 valeurs dans 3 variables

14. [Erreurs] TypeError : parcourir un entier

QCU, une seule réponse

Objectif : Corriger une boucle for pour faire 5 tours.

nb = 5
for i in nb:
    print(i)

Console :

TypeError: 'int' object is not iterable

Comment corriger pour faire 5 tours de boucle ?

  1. Écrire nb = '5'
  2. Utiliser range(nb)
  3. Remplacer la boucle par while nb:
  4. Mettre nb entre crochets : [nb]

15. [Erreurs] SyntaxError : '[' was never closed

QCU, une seule réponse

Objectif : Lire « '[' was never closed » et trouver ce qui manque.

valeurs = [1, 2, 3
print('Fin du programme')

Console :

SyntaxError: '[' was never closed

Quelle est l'origine du problème ?

  1. La liste valeurs contient trop d'éléments
  2. Il manque une virgule après le 3
  3. print doit être indenté
  4. Le crochet fermant de la liste manque
