1. [Erreurs] NameError dans une fonction

QCU, une seule réponse · bonne réponse en A

Objectif : Trouver le nom mal écrit dans le corps d'une fonction.

def calculer_surface(rayon):
    pi = 3.14
    return pii * rayon**2

print(calculer_surface(5))

Console :

NameError: name 'pii' is not defined. Did you mean: 'pi'?

Quelle correction faut-il faire ?

  1. Juste · Écrire pi au lieu de pii dans le returnOui : le message dit « le nom 'pii' n'est pas défini. Voulais-tu dire 'pi' ? ». La variable créée dans la fonction est pi.
  2. Définir pii à l'extérieur de la fonctionLe programme marcherait peut-être, mais avec deux variables pour la même valeur. Le message indique une faute de frappe : la variable créée s'appelle pi.
  3. Ajouter des guillemets autour de pii'pii' deviendrait un texte, et le calcul pii * rayon**2 ne donnerait plus une surface. Il faut corriger le nom.
  4. Remplacer pii par input()input() demanderait une valeur au clavier, alors que pi est déjà défini juste au-dessus. Il suffit d'utiliser ce nom.

2. [Erreurs] SyntaxError : les deux-points du def

QCU, une seule réponse · bonne réponse en B

Objectif : Lire « expected ':' » sur la ligne d'une définition de fonction.

def verifier_age(age)
    if age >= 18:
        return 'Majeur'
    return 'Mineur'

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Ajouter des parenthèses autour de age >= 18En Python, la condition d'un if n'a pas besoin de parenthèses. Le message dit ce qui manque : des deux-points.
  2. Juste · Ajouter « : » à la fin de la ligne defOui : « expected ':' » veut dire « deux-points attendus ». Toute ligne qui ouvre un bloc (def, if, for, while) se termine par deux-points.
  3. Écrire 'Majeur' avec des guillemets doublesLes guillemets simples et doubles sont équivalents en Python. Le problème est sur la première ligne.
  4. Indenter la ligne defUne définition de fonction commence en début de ligne. Le message « expected ':' » signale des deux-points manquants.

3. [Erreurs] IndentationError : le corps d'une fonction

QCU, une seule réponse · bonne réponse en A

Objectif : Indenter le corps d'une fonction.

def doubler(n):
resultat = n * 2
    return resultat

Console :

IndentationError: expected an indented block after function definition on line 1

Quelle correction faut-il faire ?

  1. Juste · Ajouter 4 espaces devant la ligne resultat = n * 2Oui : le message dit « un bloc indenté était attendu après la définition de fonction de la ligne 1 ». Tout le corps de la fonction est décalé de 4 espaces.
  2. Supprimer l'indentation de la ligne returnLa fonction n'aurait alors aucune ligne dans son corps : l'erreur resterait. Il faut décaler resultat = n * 2.
  3. Remplacer n * 2 par n + nLe calcul est juste. Le problème est la place de la ligne (son indentation), pas son contenu.
  4. Ajouter une ligne pass après le returnpass sert à remplir un bloc vide. Ici, le bloc existe, mais sa première ligne n'est pas décalée.

4. [Erreurs] IndexError : le dernier élément

QCU, une seule réponse · bonne réponse en C

Objectif : Voir que l'indice du dernier élément est len(liste) - 1.

def obtenir_dernier(ma_liste):
    n = len(ma_liste)
    return ma_liste[n]

print(obtenir_dernier([10, 20, 30]))

Console :

IndexError: list index out of range

Pourquoi cette erreur ?

  1. La liste est videL'appel donne la liste [10, 20, 30], qui a 3 éléments. Le message dit que l'indice est hors limites.
  2. On ne peut pas utiliser une variable comme indiceUn indice peut être n'importe quelle expression entière, comme n. C'est sa valeur, 3, qui est trop grande.
  3. Juste · L'indice du dernier élément est len(ma_liste) - 1Oui : « list index out of range » veut dire « indice hors limites ». Pour 3 éléments, les indices sont 0, 1 et 2 : il faut ma_liste[n - 1].
  4. Il faut écrire ma_liste(n)Les parenthèses appellent une fonction. Pour lire un élément de liste, on garde les crochets, avec un indice valide.

5. [Erreurs] KeyError : l'argument mal écrit

QCU, une seule réponse · bonne réponse en C

Objectif : Trouver qu'une clé passée en argument ne respecte pas les majuscules.

def afficher_score(nom):
    scores = {'Alia': 15, 'Yanis': 12}
    print(scores[nom])

afficher_score('alia')

Console :

KeyError: 'alia'

Quelle correction faut-il faire ?

  1. Écrire scores.nom au lieu de scores[nom]Un dictionnaire ne se lit pas avec un point : scores.nom provoquerait une AttributeError. On garde les crochets.
  2. Utiliser une liste plutôt qu'un dictionnaireLe dictionnaire est bien choisi pour associer un prénom à un score. Le message dit seulement que la clé 'alia' n'existe pas.
  3. Juste · Respecter la majuscule : afficher_score('Alia')Oui : KeyError: 'alia' signifie « clé 'alia' introuvable ». Python distingue majuscules et minuscules : la clé est 'Alia'.
  4. Définir nom = 'Alia' dans la fonctionLa fonction n'afficherait plus que le score d'Alia, quel que soit l'argument. C'est l'argument de l'appel qui est mal écrit.

6. [Erreurs] TypeError : concaténer un texte et un nombre

QCU, une seule réponse · bonne réponse en B

Objectif : Insérer un nombre dans un texte sans changer son type.

score = 10
msg = 'Ton score est : ' + score
print(msg)

Console :

TypeError: can only concatenate str (not "int") to str

Quelle correction est la plus adaptée ?

  1. Remplacer le + par un *Multiplier un texte par 10 le répète 10 fois : ce n'est pas le message voulu.
  2. Juste · Utiliser une f-string : f'Ton score est : {score}'Oui : le message dit « on ne peut coller à un str qu'un autre str, pas un int ». La f-string convertit score en texte pour l'affichage, sans changer la variable.
  3. Écrire score = '10' au lieu de score = 10Le message s'afficherait, mais score deviendrait un texte : on ne pourrait plus calculer avec (score + 1 serait une erreur).
  4. Ajouter des parenthèses : (score)Les parenthèses ne changent pas le type : (score) est toujours l'entier 10.

7. [Erreurs] TypeError : un argument du mauvais type

QCU, une seule réponse · bonne réponse en B

Objectif : Lire « not subscriptable » quand une fonction reçoit un entier au lieu d'une liste.

def traiter_valeur(x):
    return x[0]

traiter_valeur(42)

Console :

TypeError: 'int' object is not subscriptable

Que signifie ce message ?

  1. L'indice 0 n'existe pas dans la listeCe serait une IndexError, pour une liste vide. Ici, x n'est pas une liste du tout : c'est l'entier 42.
  2. Juste · On utilise des crochets sur un entierOui : « subscriptable » veut dire « qui accepte des indices ». L'argument 42 est un entier : x[0] n'a pas de sens. Il faudrait passer une liste ou une chaîne.
  3. La fonction doit renvoyer x et non x[0]Changer la fonction ferait disparaître l'erreur, mais pas son explication : le problème est l'argument 42, qui n'est pas du bon type.
  4. Il manque un return devant traiter_valeurreturn ne s'écrit que dans une fonction. Le message parle d'un type : un int n'accepte pas d'indices.

8. [Erreurs] ValueError : int() et le point décimal

QCU, une seule réponse · bonne réponse en A

Objectif : Lire une ValueError de int() sur une chaîne qui contient un point.

reponse = '12.5'
nombre = int(reponse)

Console :

ValueError: invalid literal for int() with base 10: '12.5'

Pourquoi l'erreur se produit-elle ?

  1. Juste · int() refuse une chaîne qui contient un point décimalOui : le message dit « écriture invalide pour int() en base 10 : '12.5' ». Pour un nombre à virgule, on utilise float('12.5'), puis int() si besoin.
  2. int() ne convertit que des nombres négatifsint() convertit aussi les positifs : int('12') donne 12. Le problème est le point dans '12.5'.
  3. Il faut écrire Integer(reponse)Integer n'existe pas en Python : la fonction s'appelle bien int(). C'est le contenu de la chaîne qui pose problème.
  4. reponse doit être entre crochetsint(['12.5']) donnerait une autre erreur (TypeError). La chaîne est bien placée : c'est le point décimal qui gêne int().

9. [Erreurs] Le message d'une chaîne non terminée

QCU, une seule réponse · bonne réponse en C

Objectif : Comprendre le message « unterminated string literal ».

print("Bonjour tout le monde)

Console :

SyntaxError: unterminated string literal (detected at line 1)

Que signifie ce message ?

  1. La ligne 1 contient trop de caractèresUne ligne peut être longue. « detected at line 1 » dit seulement où Python a vu l'erreur.
  2. Il manque la parenthèse fermante de l'instruction printLa parenthèse est bien là, mais elle est dans la chaîne, puisque le guillemet n'est pas fermé : Python la lit comme du texte. Il manque le guillemet.
  3. Juste · Une chaîne n'est pas fermée : il manque un guillemetOui : « unterminated string literal » veut dire « chaîne de caractères non terminée ». Le guillemet ouvert avant Bonjour n'est jamais refermé.
  4. print ne peut afficher qu'un seul motprint affiche des phrases entières. Le message parle d'une chaîne non terminée, pas de sa longueur.

10. [Erreurs] TypeError : trop d'arguments

QCU, une seule réponse · bonne réponse en A

Objectif : Corriger un appel qui donne plus d'arguments que la fonction n'a de paramètres.

def somme(a, b):
    return a + b

print(somme(10, 20, 30))

Console :

TypeError: somme() takes 2 positional arguments but 3 were given

Comment corriger l'appel, sans modifier la fonction ?

  1. Juste · Ne garder que deux arguments : somme(10, 20)Oui : le message dit « somme() prend 2 arguments, mais 3 ont été donnés ». L'appel doit fournir autant d'arguments que de paramètres.
  2. Ajouter un paramètre c : def somme(a, b, c)Cela marcherait, mais la question demande de corriger l'appel sans toucher à la fonction.
  3. Mettre les arguments dans une liste : somme([10, 20, 30])La fonction recevrait un seul argument au lieu de deux : b manquerait, et Python signalerait une autre TypeError.
  4. Remplacer les virgules par des pointssomme(10.20.30) n'est pas du Python valide, et le nombre d'arguments resterait faux.

11. [Erreurs] AttributeError : une fonction qui ne renvoie rien

QCU, une seule réponse · bonne réponse en C

Objectif : Voir qu'une fonction sans return renvoie None.

def ajouter_element(liste, x):
    liste.append(x)
    # pas de return

ma_liste = [1, 2]
ma_liste = ajouter_element(ma_liste, 3)
ma_liste.append(4)

Console :

AttributeError: 'NoneType' object has no attribute 'append'

Pourquoi ma_liste est-elle devenue None ?

  1. On ne peut pas faire deux append de suiteOn peut appeler append autant de fois qu'on veut sur une liste. Le problème est que ma_liste n'est plus une liste.
  2. La méthode append n'existe pas en Pythonappend existe pour les listes, et la fonction l'utilise sans erreur. C'est sur None que l'appel échoue.
  3. Juste · Sans return, la fonction renvoie NoneOui : sans return, une fonction renvoie None. La ligne ma_liste = ajouter_element(...) range donc None dans ma_liste, qui n'a pas de méthode append.
  4. Il faut importer le module NoneTypeNoneType n'est pas un module : c'est le type de la valeur None. Le message dit que None n'a pas d'attribut append.

12. [Erreurs] NameError : une variable locale

QCU, une seule réponse · bonne réponse en D

Objectif : Comprendre qu'une variable créée dans une fonction n'existe pas en dehors.

def calcul():
    valeur = 10
    return valeur * 2

calcul()
print(valeur)

Console :

NameError: name 'valeur' is not defined

La variable valeur est pourtant définie dans la fonction. Pourquoi l'erreur ?

  1. print(valeur) doit être placé dans calcul()Cela afficherait la valeur, mais n'explique pas l'erreur. La question est : pourquoi valeur n'existe-t-elle pas en dehors de la fonction ?
  2. Il manque une ligne global valeur au début du programmeglobal changerait la portée, mais ce n'est pas la cause de l'erreur, et on l'évite. Ici, valeur est locale : on utilise ce que renvoie la fonction.
  3. La fonction calcul() n'a pas été appeléeElle est bien appelée à la ligne 5. Son résultat est perdu, car il n'est rangé dans aucune variable.
  4. Juste · valeur est locale à la fonction : elle n'existe pas en dehorsOui : une variable créée dans une fonction est locale, elle disparaît à la fin de l'appel. On récupère plutôt le résultat : resultat = calcul().

13. [Erreurs] ValueError : répartir un tuple renvoyé

QCU, une seule réponse · bonne réponse en D

Objectif : Compter les valeurs renvoyées et les variables qui les reçoivent.

def obtenir_coords():
    return (10, 20)

x, y, z = obtenir_coords()

Console :

ValueError: not enough values to unpack (expected 3, got 2)

Que signifie ce message ?

  1. La fonction renvoie trop de valeursC'est l'inverse : le message dit « 3 attendues, 2 reçues ». La fonction en renvoie moins que de variables.
  2. Il faut une liste à gauche : [x, y, z]Changer l'écriture à gauche ne crée pas de troisième valeur : l'erreur serait la même.
  3. Les variables x, y et z ne sont pas définies avantC'est justement cette ligne qui doit les créer. Le problème est le nombre de valeurs reçues.
  4. Juste · On veut ranger 2 valeurs dans 3 variablesOui : « not enough values to unpack » veut dire « pas assez de valeurs à répartir ». Il faut autant de variables que de valeurs renvoyées.

14. [Erreurs] TypeError : parcourir un entier

QCU, une seule réponse · bonne réponse en B

Objectif : Répéter une action n fois avec range.

nb = 5
for i in nb:
    print(i)

Console :

TypeError: 'int' object is not iterable

Comment corriger pour faire 5 tours de boucle ?

  1. Écrire nb = '5'La boucle parcourrait la chaîne '5' : un seul tour, avec le caractère '5'.
  2. Juste · Utiliser range(nb)Oui : « not iterable » veut dire « qu'on ne peut pas parcourir ». range(nb) fabrique la suite 0, 1, 2, 3, 4 : 5 tours.
  3. Remplacer la boucle par while nb:nb vaut 5 et ne change jamais : while nb: serait une boucle infinie, car 5 est considéré comme vrai.
  4. Mettre nb entre crochets : [nb]for i in [nb] parcourt une liste d'un seul élément : un seul tour, avec i = 5.

15. [Erreurs] SyntaxError : un crochet jamais fermé

QCU, une seule réponse · bonne réponse en D

Objectif : Lire « '[' was never closed » et trouver le crochet manquant.

valeurs = [1, 2, 3
print('Fin du programme')

Console :

SyntaxError: '[' was never closed

Quelle est l'origine du problème ?

  1. La liste valeurs contient trop d'élémentsUne liste peut contenir des milliers d'éléments. Le message dit qu'un crochet ouvert n'a jamais été fermé.
  2. Il manque une virgule après le 3Une virgule ne fermerait pas la liste. Le message « '[' was never closed » signale le crochet ouvert à la ligne 1.
  3. print doit être indentéprint est dans le programme principal : il commence en début de ligne. Le problème est le crochet de la ligne 1.
  4. Juste · Le crochet fermant de la liste manqueOui : « '[' was never closed » veut dire « le crochet [ n'a jamais été fermé ». Il faut écrire valeurs = [1, 2, 3].
