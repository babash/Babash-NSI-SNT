1. [Dictionnaires] Écrire un dictionnaire

QCU, une seule réponse

Objectif : Reconnaître la syntaxe d'un dictionnaire : des accolades et des couples clé : valeur.

Zaïnaba veut associer à chaque commune desservie par la barge l'île où elle se trouve.

Quelle instruction crée un dictionnaire ?

Bonne réponse : B

  1. Distracteur : iles = ["Dzaoudzi", "Mamoudzou"]Retour : Les crochets créent une liste : des valeurs repérées par leur position (0, 1…), sans clés. Ici, il n'y a pas d'île associée.
  2. Bonne réponse : iles = {"Dzaoudzi": "Petite-Terre", "Mamoudzou": "Grande-Terre"}Retour : Oui : des accolades, et des couples clé : valeur séparés par des virgules. La clé "Dzaoudzi" donne la valeur "Petite-Terre".
  3. Distracteur : iles = ("Dzaoudzi", "Mamoudzou")Retour : Les parenthèses créent un tuple : une suite de valeurs qu'on ne peut pas modifier, sans clés.
  4. Distracteur : iles = {"Dzaoudzi"; "Petite-Terre", "Mamoudzou"; "Grande-Terre"}Retour : Entre une clé et sa valeur, on écrit deux-points, pas un point-virgule : Python signale une SyntaxError.

2. [Dictionnaires] Lire une valeur par sa clé

QCU, une seule réponse

Objectif : Accéder à une valeur avec dictionnaire[clé].

Anli range les tarifs d'un taxi, en euros :

tarifs = {"Mamoudzou": 2, "Koungou": 3}

Quelle expression donne le prix pour Koungou ?

Bonne réponse : B

  1. Distracteur : tarifs(Koungou)Retour : Les parenthèses servent à appeler une fonction. Et sans guillemets, Koungou est un nom de variable inconnu : NameError.
  2. Bonne réponse : tarifs["Koungou"]Retour : Oui : des crochets et la clé entre guillemets. tarifs["Koungou"] vaut 3.
  3. Distracteur : tarifs{3}Retour : Les accolades servent à écrire un dictionnaire, pas à le lire : SyntaxError. Et on cherche par la clé, pas par la valeur 3.
  4. Distracteur : tarifs[1]Retour : Un dictionnaire ne se lit pas par position : 1 n'est pas une clé, Python répond KeyError: 1. La clé est le texte "Koungou".

3. [Dictionnaires] Ajouter un couple clé : valeur

QCU, une seule réponse

Objectif : Ajouter une clé à un dictionnaire par une affectation.

Faouzia gère un club de handball :

club = {"nom": "ASC", "effectif": 12}

Quelle instruction ajoute la ville "Tsingoni" au dictionnaire, avec la clé "ville" ?

Bonne réponse : A

  1. Bonne réponse : club["ville"] = "Tsingoni"Retour : Oui : si la clé "ville" n'existe pas, cette affectation la crée, avec la valeur "Tsingoni".
  2. Distracteur : club.append("ville", "Tsingoni")Retour : append est une méthode des listes. Un dictionnaire n'en a pas : AttributeError.
  3. Distracteur : club = {"ville": "Tsingoni"}Retour : Cette instruction remplace tout le dictionnaire : le nom et l'effectif seraient perdus.
  4. Distracteur : club["Tsingoni"] = "ville"Retour : La clé et la valeur sont inversées : on aurait une clé "Tsingoni" de valeur "ville". La clé s'écrit entre les crochets.

4. [Dictionnaires] Compter les clés avec len

QCU, une seule réponse

Objectif : Savoir que len compte les couples clé : valeur.

Nassim compte les poissons vus dans le lagon :

p = {"murene": 2, "perroquet": 5, "merou": 1}

Que renvoie len(p) ?

Bonne réponse : B

  1. Distracteur : 8Retour : 8 est la somme des valeurs (2 + 5 + 1). len ne fait pas de somme : il compte les couples clé : valeur.
  2. Bonne réponse : 3Retour : Oui : le dictionnaire a 3 clés, donc 3 couples. len(p) vaut 3.
  3. Distracteur : 6Retour : len ne compte pas les clés et les valeurs séparément : un couple clé : valeur compte pour 1.
  4. Distracteur : 1Retour : Le dictionnaire contient 3 éléments, pas un seul : chaque couple clé : valeur compte.

5. [Dictionnaires] Tester une clé avec in

QCU, une seule réponse

Objectif : Savoir que in cherche parmi les clés, pas parmi les valeurs.

Sitti suit les pontes de tortues sur deux plages :

sites = {"Moya": 12, "Saziley": 8}

Quelle expression vaut True ?

Bonne réponse : D

  1. Distracteur : 12 in sitesRetour : in cherche parmi les clés, pas parmi les valeurs : 12 est une valeur. 12 in sites vaut False.
  2. Distracteur : "Moya" == sitesRetour : On compare ici un texte et tout le dictionnaire : ils sont différents, cela vaut False. Pour tester une clé, on écrit in.
  3. Distracteur : "Boueni" in sitesRetour : "Boueni" n'est pas une clé de ce dictionnaire : l'expression vaut False.
  4. Bonne réponse : "Saziley" in sitesRetour : Oui : "Saziley" est une clé du dictionnaire. in teste la présence d'une clé.

6. [Dictionnaires] La méthode keys

QCU, une seule réponse

Objectif : Savoir que keys donne les clés d'un dictionnaire.

d = {"A": 1, "B": 2}

À quoi sert d.keys() ?

Bonne réponse : C

  1. Distracteur : Modifier les valeurs du dictionnaireRetour : keys ne modifie rien : elle permet de lire les clés. Pour modifier une valeur, on écrit d["A"] = 5.
  2. Distracteur : Obtenir les valeurs 1 et 2Retour : Les valeurs s'obtiennent avec d.values(). keys (« clés ») donne "A" et "B".
  3. Bonne réponse : Obtenir les clés "A" et "B"Retour : Oui : print(d.keys()) affiche dict_keys(['A', 'B']). On peut la parcourir avec for, ou en faire une liste avec list(d.keys()).
  4. Distracteur : Supprimer toutes les clésRetour : keys ne supprime rien. Pour vider un dictionnaire, on utilise d.clear() ; pour une seule clé, del d["A"].

7. [Dictionnaires] Obtenir seulement les valeurs

QCU, une seule réponse

Objectif : Choisir la méthode qui donne les valeurs d'un dictionnaire.

Rayanti range des notes :

notes = {"Anli": 15, "Sitti": 18}

Quelle méthode donne seulement 15 et 18 ?

Bonne réponse : A

  1. Bonne réponse : notes.values()Retour : Oui : values (« valeurs ») donne 15 et 18, sans les prénoms.
  2. Distracteur : notes.keys()Retour : keys donne les clés, ici les prénoms "Anli" et "Sitti".
  3. Distracteur : notes.items()Retour : items donne les couples (clé, valeur) : ("Anli", 15) et ("Sitti", 18). On veut les valeurs seules.
  4. Distracteur : notes.content()Retour : content n'existe pas pour un dictionnaire : Python répond AttributeError. La méthode s'appelle values.

8. [Dictionnaires] La méthode items

QCU, une seule réponse

Objectif : Savoir que items donne des couples (clé, valeur).

Houssame range le stock d'un étal du marché :

stock = {"mangue": 40, "papaye": 12}

Que contient chaque élément de stock.items() ?

Bonne réponse : C

  1. Distracteur : Seulement la cléRetour : Seulement les clés, c'est keys. items donne la clé et la valeur ensemble.
  2. Distracteur : Seulement la valeurRetour : Seulement les valeurs, c'est values. items donne la clé et la valeur ensemble.
  3. Bonne réponse : Un tuple (clé, valeur)Retour : Oui : list(stock.items()) vaut [('mangue', 40), ('papaye', 12)]. On l'utilise dans for cle, valeur in stock.items().
  4. Distracteur : Le nombre total d'articlesRetour : items ne fait pas de calcul. Pour le total, il faudrait additionner les valeurs, par exemple avec sum(stock.values()).

9. [Dictionnaires] Modifier une valeur

QCU, une seule réponse

Objectif : Remplacer la valeur d'une clé qui existe.

Zaïnaba note la pluie tombée, en millimètres :

m = {"pluie": 10}

Quelle instruction remplace 10 par 20 ?

Bonne réponse : A

  1. Bonne réponse : m["pluie"] = 20Retour : Oui : on désigne la valeur par sa clé, entre crochets, et on lui donne la nouvelle valeur.
  2. Distracteur : m = 20Retour : Cette instruction remplace tout le dictionnaire par le nombre 20 : la clé "pluie" disparaît.
  3. Distracteur : m{"pluie"}: 20Retour : Ce n'est pas une instruction Python : SyntaxError. On lit et on modifie une valeur avec des crochets.
  4. Distracteur : m[20] = "pluie"Retour : Cette instruction crée une nouvelle clé 20, de valeur "pluie". La clé à modifier est "pluie".

10. [Dictionnaires] Lire une clé absente

QCU, une seule réponse

Objectif : Prévoir ce qui se passe quand on lit une clé qui n'existe pas.

Anli a ce répertoire :

tel = {"Papa": "0639..."}
print(tel["Maman"])

Que se passe-t-il à l'exécution ?

Bonne réponse : A

  1. Bonne réponse : Python s'arrête sur une erreur KeyErrorRetour : Oui : Python affiche KeyError: 'Maman', c'est-à-dire « clé 'Maman' introuvable ». Pour éviter l'erreur, on teste d'abord "Maman" in tel.
  2. Distracteur : Le programme affiche NoneRetour : Lire une clé absente avec des crochets ne donne pas None : c'est une erreur. tel.get("Maman") donnerait None.
  3. Distracteur : Le programme affiche 0Retour : Python n'invente pas de valeur : la clé "Maman" n'existe pas, il s'arrête sur une KeyError.
  4. Distracteur : Le dictionnaire crée la clé "Maman", videRetour : Lire une clé ne la crée pas. Seule une affectation, tel["Maman"] = …, ajoute une clé.

11. [Dictionnaires] Une liste dans un dictionnaire

QCU, une seule réponse

Objectif : Lire un élément d'une liste rangée dans un dictionnaire.

Faouzia note les scores de deux équipes :

s = {"Bleus": [10, 12], "Rouges": [15, 8]}

Quelle expression donne le score 12 ?

Bonne réponse : B

  1. Distracteur : s["Bleus"][0]Retour : s["Bleus"] est la liste [10, 12]. L'indice 0 donne le premier élément, 10. Le score 12 est à l'indice 1.
  2. Bonne réponse : s["Bleus"][1]Retour : Oui : s["Bleus"] donne la liste [10, 12], puis [1] donne son deuxième élément, 12 (les indices commencent à 0).
  3. Distracteur : s[0][1]Retour : Un dictionnaire ne se lit pas par position : 0 n'est pas une clé, Python répond KeyError: 0.
  4. Distracteur : s["Bleus", 1]Retour : Python chercherait la clé ("Bleus", 1), qui n'existe pas : KeyError. On écrit deux paires de crochets, l'une après l'autre.

12. [Dictionnaires] Une liste de dictionnaires

QCU, une seule réponse

Objectif : Lire une valeur dans une liste de dictionnaires.

Nassim range des fiches d'élèves dans une liste :

b = [{"nom": "Anli", "age": 16}, {"nom": "Sitti", "age": 17}]

Quelle expression donne l'âge de Sitti ?

Bonne réponse : C

  1. Distracteur : b["Sitti"]["age"]Retour : b est une liste : elle se lit par un indice entier, pas par un texte (TypeError). "Sitti" est une valeur, pas une clé.
  2. Distracteur : b[0]["age"]Retour : b[0] est la première fiche, celle d'Anli : on obtiendrait 16.
  3. Bonne réponse : b[1]["age"]Retour : Oui : b est une liste. b[1] est la deuxième fiche, celle de Sitti ; ["age"] lit son âge, 17.
  4. Distracteur : b["age"][1]Retour : On lit d'abord la liste par un indice, puis le dictionnaire par une clé. b["age"] provoque une TypeError.

13. [Dictionnaires] Un dictionnaire dans un dictionnaire

QCU, une seule réponse

Objectif : Modifier une valeur dans un dictionnaire imbriqué.

Sitti range le prix (en euros) et le stock des fruits de son étal :

m = {"mangue": {"prix": 2, "stock": 40}}

Quelle instruction change le stock de mangues en 35 ?

Bonne réponse : D

  1. Distracteur : m["stock"] = 35Retour : "stock" n'est pas une clé de m : cette instruction ajouterait une nouvelle clé "stock" à côté de "mangue".
  2. Distracteur : m["mangue"] = 35Retour : Le dictionnaire intérieur serait remplacé par 35 : le prix et le stock seraient perdus.
  3. Distracteur : m[0][1] = 35Retour : Un dictionnaire ne se lit pas par position : 0 n'est pas une clé, Python répond KeyError: 0.
  4. Bonne réponse : m["mangue"]["stock"] = 35Retour : Oui : m["mangue"] donne le dictionnaire intérieur, et ["stock"] désigne la valeur à changer.

14. [Dictionnaires] Ajouter à une valeur

QCU, une seule réponse

Objectif : Modifier une valeur à partir de l'ancienne, dans une liste de dictionnaires.

Kamel suit les recettes de deux taxis, en euros :

g = [{"id": "T1", "total": 100}, {"id": "T2", "total": 50}]

Il veut ajouter 20 € à la recette du taxi T1. Quelle instruction est correcte ?

Bonne réponse : A

  1. Bonne réponse : g[0]["total"] = g[0]["total"] + 20Retour : Oui : g[0] est la fiche du taxi T1. On lit son total, on ajoute 20, et on range le résultat au même endroit : 120.
  2. Distracteur : g["T1"] = 120Retour : g est une liste : elle se lit par un indice entier. "T1" est une valeur, pas une clé : TypeError.
  3. Distracteur : g[0] = 120Retour : Toute la fiche du taxi T1 serait remplacée par le nombre 120 : l'identifiant serait perdu.
  4. Distracteur : g[1]["total"] = 120Retour : g[1] est le deuxième taxi, T2. Les indices commencent à 0 : T1 est g[0].

15. [Dictionnaires] La méthode get et sa valeur par défaut

QCU, une seule réponse

Objectif : Lire une clé sans risque d'erreur avec get.

La méthode d.get(cle, defaut) renvoie la valeur de la clé si elle existe ; sinon, elle renvoie defaut.

stock = {"livre": 5}

Que renvoie stock.get("stylo", 0) ?

Bonne réponse : B

  1. Distracteur : NoneRetour : get renvoie None quand on ne donne pas de valeur par défaut. Ici, on a donné 0.
  2. Bonne réponse : 0Retour : Oui : "stylo" n'est pas une clé ; get renvoie la valeur par défaut, 0.
  3. Distracteur : Une erreur KeyErrorRetour : Justement, get évite la KeyError : si la clé manque, il renvoie la valeur par défaut.
  4. Distracteur : 5Retour : 5 est la valeur de la clé "livre". La clé demandée, "stylo", n'existe pas.

16. [Dictionnaires] Supprimer une clé avec del

QCU, une seule réponse

Objectif : Prévoir la taille d'un dictionnaire après un del.

d = {"A": 1, "B": 2, "C": 3}
del d["B"]

Que vaut len(d) après ces deux lignes ?

Bonne réponse : D

  1. Distracteur : 3Retour : del d["B"] retire bien le couple "B": 2 : il en reste deux.
  2. Distracteur : 1Retour : del ne retire qu'une clé : celle qui est entre crochets, "B". Il en reste deux.
  3. Distracteur : 0Retour : del d["B"] ne vide pas le dictionnaire : il retire seulement la clé "B".
  4. Bonne réponse : 2Retour : Oui : del retire la clé "B" et sa valeur. Il reste "A" et "C" : len(d) vaut 2.

17. [Dictionnaires] Parcourir les clés avec for

QCU, une seule réponse

Objectif : Suivre une boucle for sur les clés d'un dictionnaire.

Zaïnaba exécute ce programme :

d = {"pomme": 2, "mangue": 3}
s = 0
for k in d:
    s = s + d[k]

Que vaut s à la fin ?

Bonne réponse : C

  1. Distracteur : 2Retour : La boucle passe par toutes les clés, pas seulement la première : elle ajoute 2, puis 3.
  2. Distracteur : 3Retour : La boucle commence par la clé "pomme" et ajoute aussi sa valeur, 2 : 2 + 3 = 5.
  3. Bonne réponse : 5Retour : Oui : for k in d parcourt les clés. s reçoit d["pomme"] = 2, puis d["mangue"] = 3 : 0 + 2 + 3 = 5.
  4. Distracteur : 0Retour : s change à chaque tour de boucle : s = s + d[k] lui ajoute une valeur.

18. [Dictionnaires] Un dictionnaire de listes

QCU, une seule réponse

Objectif : Lire une liste rangée dans un dictionnaire.

Sur une carte simplifiée, un dictionnaire associe à chaque village la liste des villages reliés directement par une route :

G = {"Sada": ["Chiconi", "Ouangani"], "Chiconi": ["Sada"]}

Quels villages sont reliés directement à Sada ?

Bonne réponse : C

  1. Distracteur : Seulement ChiconiRetour : G["Sada"] contient deux villages : Chiconi et Ouangani. Tu as peut-être lu seulement le premier élément de la liste.
  2. Distracteur : Seulement OuanganiRetour : G["Sada"] contient deux villages. Chiconi est le premier de la liste.
  3. Bonne réponse : Chiconi et OuanganiRetour : Oui : G["Sada"] est la liste ["Chiconi", "Ouangani"] : ce sont les deux villages reliés à Sada.
  4. Distracteur : Aucun villageRetour : La clé "Sada" existe, et sa valeur est une liste de deux villages.

19. [Dictionnaires] Des clés qui sont des nombres

QCU, une seule réponse

Objectif : Savoir qu'une clé peut être un nombre, et que 2 et "2" sont deux clés différentes.

Faouzia associe à chaque pièce de monnaie son nom :

pieces = {2: "2 euros", 1: "1 euro"}

Quelle expression donne le nom de la pièce de valeur 2 ?

Bonne réponse : D

  1. Distracteur : pieces["2"]Retour : "2" est un texte, et 2 est un nombre : ce sont deux clés différentes. Python répond KeyError: '2'.
  2. Distracteur : pieces[0]Retour : 0 n'est pas une position ici : c'est une clé, et elle n'existe pas (KeyError). Les clés sont 2 et 1.
  3. Distracteur : pieces.value(2)Retour : value n'existe pas pour un dictionnaire (AttributeError). On lit une valeur avec des crochets et la clé.
  4. Bonne réponse : pieces[2]Retour : Oui : la clé est le nombre 2, écrit sans guillemets. pieces[2] vaut "2 euros".

20. [Dictionnaires] Modifier, puis ajouter

QCU, une seule réponse

Objectif : Prévoir un dictionnaire après une modification et un ajout.

Nassim exécute ce programme :

d = {"A": 10}
d["A"] = 15
d["B"] = 20

Que contient d à la fin ?

Bonne réponse : D

  1. Distracteur : {"A": 10, "B": 20}Retour : d["A"] = 15 remplace la valeur de "A" : 10 n'existe plus.
  2. Distracteur : {"A": 15}Retour : d["B"] = 20 ajoute une clé : dans un dictionnaire, affecter une clé absente la crée.
  3. Distracteur : {"A": 25, "B": 20}Retour : d["A"] = 15 remplace la valeur, il n'ajoute pas : "A" vaut 15, pas 10 + 15.
  4. Bonne réponse : {"A": 15, "B": 20}Retour : Oui : d["A"] = 15 remplace 10 par 15 ; d["B"] = 20 ajoute une nouvelle clé.
