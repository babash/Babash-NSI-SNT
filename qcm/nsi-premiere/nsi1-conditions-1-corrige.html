1. [Conditions] Un if vrai

QCU, une seule réponse

Objectif : Suivre un if … else dont la condition est vraie.

x = 5
if x > 2:
    print("Vrai")
else:
    print("Faux")

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : FauxRetour : La condition x > 2 se lit 5 > 2 : elle est vraie. Le bloc du else ne s'exécute que si la condition est fausse.
  2. Bonne réponse : VraiRetour : Oui. x vaut 5 ; la condition 5 > 2 est vraie ; Python exécute le bloc du if et affiche Vrai. Le bloc du else est sauté.
  3. Distracteur : Une erreurRetour : Le programme est bien écrit : deux-points après la condition et après else, blocs indentés. Il s'exécute sans erreur.
  4. Distracteur : Vrai / FauxRetour : Une seule des deux branches s'exécute : le if quand la condition est vraie, sinon le else. Ici, c'est le if.

2. [Conditions] Un if faux : la branche else

QCU, une seule réponse

Objectif : Suivre un if … else dont la condition est fausse.

a = -1
if a >= 0:
    print("Positif")
else:
    print("Négatif")

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : NégatifRetour : Oui. a vaut -1 ; -1 >= 0 est faux ; Python saute le bloc du if et exécute celui du else : Négatif.
  2. Distracteur : PositifRetour : La condition se lit -1 >= 0 : elle est fausse, car -1 est plus petit que 0. C'est donc le bloc du else qui s'exécute.
  3. Distracteur : Rien ne s'afficheRetour : Chaque branche contient un print. L'une des deux s'exécute toujours : ici le else, qui affiche Négatif.
  4. Distracteur : -1Retour : Le programme n'affiche jamais a : il affiche le texte de la branche choisie. Ici, -1 >= 0 est faux : Négatif.

3. [Conditions] Comparer deux textes avec ==

QCU, une seule réponse

Objectif : Tester l'égalité de deux chaînes de caractères.

fruit = "mangue"
if fruit == "papaye":
    print(1)
else:
    print(0)

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 0Retour : Oui. "mangue" == "papaye" est faux, donc Python exécute le else et affiche 0.
  2. Distracteur : 1Retour : Les deux textes sont différents : "mangue" == "papaye" est faux. Le bloc du if (print(1)) est sauté.
  3. Distracteur : mangueRetour : Le programme n'affiche jamais la variable fruit : il affiche 1 ou 0 selon le résultat du test.
  4. Distracteur : FalseRetour : La condition vaut bien False, mais elle n'est pas affichée : elle sert à choisir la branche. C'est le else qui affiche 0.

4. [Conditions] L'opérateur or

QCU, une seule réponse

Objectif : Évaluer une condition avec or (« ou »).

a = 10
b = 5
if a > 15 or b < 8:
    print("OK")
else:
    print("KO")

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : KORetour : Tu as peut-être lu or comme and. Avec or (« ou »), une seule condition vraie suffit : ici, 5 < 8 est vrai.
  2. Distracteur : Rien ne s'afficheRetour : Il y a un print dans chaque branche, et l'une des deux s'exécute toujours. Ici, la condition est vraie : OK.
  3. Bonne réponse : OKRetour : Oui. a > 15 est faux, b < 8 est vrai. Avec or, il suffit qu'une condition soit vraie : faux or vrai donne vrai. Le if affiche OK.
  4. Distracteur : OK / KORetour : Une seule branche s'exécute. La condition entière (faux or vrai) vaut vrai : seul le bloc du if s'exécute.

5. [Conditions] L'opérateur and

QCU, une seule réponse

Objectif : Évaluer une condition avec and (« et »).

temperature = 25.5
humidite = 60
if temperature > 25 and humidite < 50:
    print("Alerte")
else:
    print("Normal")

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : AlerteRetour : Seule la première condition est vraie (25.5 > 25). Avec and, il faut que les deux soient vraies ; or 60 < 50 est faux.
  2. Distracteur : 25.5Retour : Seuls les print affichent quelque chose, et aucun n'affiche temperature. Ici, c'est Normal qui s'affiche.
  3. Distracteur : Rien ne s'afficheRetour : Une condition fausse n'arrête pas le programme : Python passe au else. Le else affiche Normal.
  4. Bonne réponse : NormalRetour : Oui. 25.5 > 25 est vrai, 60 < 50 est faux. Avec and (« et »), vrai and faux donne faux : le else affiche Normal.

6. [Conditions] if, elif, else : la première condition vraie

QCU, une seule réponse

Objectif : Trouver la branche exécutée dans un if … elif … else.

Dans les réponses, le signe « / » sépare deux lignes affichées.

note = 12
if note > 15:
    print("A")
elif note > 10:
    print("B")
else:
    print("C")

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : ARetour : 12 > 15 est faux : le premier bloc est sauté. Python teste alors le elif.
  2. Distracteur : CRetour : Le else ne s'exécute que si toutes les conditions au-dessus sont fausses. Ici, le elif (12 > 10) est vrai.
  3. Bonne réponse : BRetour : Oui. 12 > 15 est faux, puis 12 > 10 est vrai : Python exécute le bloc du elif et ignore le else.
  4. Distracteur : B / CRetour : Dans un if … elif … else, une seule branche s'exécute. Après le elif vrai, le else est sauté.

7. [Conditions] Pair ou impair avec %

QCU, une seule réponse

Objectif : Utiliser le reste de la division (%) dans une condition.

n = 11
if n % 2 == 0:
    print("Pair")
else:
    print("Impair")

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : PairRetour : n % 2 est le reste de la division de 11 par 2 : il vaut 1, pas 0. La condition 1 == 0 est fausse.
  2. Bonne réponse : ImpairRetour : Oui. 11 % 2 vaut 1 (11 = 2 × 5 + 1) ; 1 == 0 est faux ; le else affiche Impair.
  3. Distracteur : 11Retour : Le programme n'affiche pas n : il affiche le texte de la branche choisie.
  4. Distracteur : 1Retour : 1 est bien le reste de 11 % 2, mais il sert seulement au test, il n'est pas affiché. Le else affiche Impair.

8. [Conditions] L'opérateur not

QCU, une seule réponse

Objectif : Évaluer une condition avec not (« non »).

est_pret = False
if not est_pret:
    print("Attente")
else:
    print("Départ")

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : DépartRetour : not inverse la valeur : not False vaut True. La condition est vraie, c'est donc le if qui s'exécute.
  2. Distracteur : FalseRetour : Le programme n'affiche pas est_pret : il affiche Attente ou Départ, selon la condition.
  3. Distracteur : TrueRetour : not est_pret vaut bien True, mais cette valeur sert à choisir la branche ; elle n'est pas affichée.
  4. Bonne réponse : AttenteRetour : Oui. est_pret vaut False ; not False vaut True ; le bloc du if s'exécute et affiche Attente.

9. [Conditions] L'opérateur != (différent de)

QCU, une seule réponse

Objectif : Lire l'opérateur != dans une condition.

code = 404
if code != 200:
    print("Erreur")
else:
    print("Succès")

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : ErreurRetour : Oui. != veut dire « différent de ». 404 est différent de 200 : la condition est vraie, le if affiche Erreur.
  2. Distracteur : SuccèsRetour : Tu as peut-être lu != comme ==. Ici, 404 != 200 est vrai : c'est le bloc du if qui s'exécute.
  3. Distracteur : 200Retour : Le programme affiche un texte, Erreur ou Succès, jamais le nombre 200.
  4. Distracteur : 404Retour : Le programme n'affiche pas la variable code. La condition 404 != 200 est vraie : il affiche Erreur.

10. [Conditions] Un calcul dans la condition

QCU, une seule réponse

Objectif : Calculer une expression (puissance **) avant de la comparer.

p = 3
if p ** 2 > 8:
    print("Neuf")
else:
    print("Huit")

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : HuitRetour : Tu as peut-être calculé p * 2 = 6. Mais est la puissance : 3 2 = 9, et 9 > 8 est vrai.
  2. Bonne réponse : NeufRetour : Oui. p ** 2 est le carré de 3, soit 9 ; 9 > 8 est vrai ; le if affiche Neuf.
  3. Distracteur : Rien ne s'afficheRetour : Il y a un print dans chaque branche : le programme affiche forcément Neuf ou Huit.
  4. Distracteur : Une erreurRetour : est bien un opérateur de Python : la puissance. 3 2 vaut 9, et le programme affiche Neuf.

11. [Conditions] Des tests en cascade

QCU, une seule réponse

Objectif : Suivre plusieurs elif et trouver la seule branche exécutée.

Dans les réponses, le signe « / » sépare deux lignes affichées.

age = 18
if age < 10:
    etape = "École"
elif age < 18:
    etape = "Collège"
elif age >= 18:
    etape = "Lycée"
else:
    etape = "Autre"
print(etape)

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : CollègeRetour : 18 < 18 est faux : 18 n'est pas strictement plus petit que 18. Python passe au elif suivant.
  2. Distracteur : Collège / LycéeRetour : Une seule branche s'exécute : la première dont la condition est vraie. Ici, c'est age >= 18.
  3. Bonne réponse : LycéeRetour : Oui. 18 < 10 est faux, 18 < 18 est faux, 18 >= 18 est vrai : etape reçoit "Lycée", puis print l'affiche.
  4. Distracteur : AutreRetour : Le else ne s'exécute que si toutes les conditions sont fausses. Or 18 >= 18 est vrai.

12. [Conditions] Deux if indépendants

QCU, une seule réponse

Objectif : Distinguer deux if qui se suivent d'un if … elif.

score = 100
resultat = ""
if score > 50:
    resultat = resultat + "A"
if score > 80:
    resultat = resultat + "B"
print(resultat)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : ARetour : Ce sont deux if, pas un if et un elif : Python teste les deux. Le second (100 > 80) est vrai aussi.
  2. Bonne réponse : ABRetour : Oui. Les deux if sont indépendants et tous deux vrais : resultat vaut "A", puis "A" + "B" = "AB".
  3. Distracteur : BRetour : Le premier if (100 > 50) est vrai aussi : resultat vaut déjà "A" quand on ajoute "B".
  4. Distracteur : BARetour : resultat + "B" ajoute "B" à la fin du texte. "A" est déjà là : on obtient "AB".

13. [Conditions] Les instructions hors du bloc

QCU, une seule réponse

Objectif : Repérer par l'indentation ce qui est en dehors du if … else.

Dans les réponses, le signe « / » sépare deux lignes affichées.

t = 15
print("Début")
if t > 20:
    print("Chaud")
else:
    print("Froid")
print("Fin")

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : Début / Chaud / FinRetour : 15 > 20 est faux : c'est le else qui s'exécute, et il affiche Froid, pas Chaud.
  2. Distracteur : FroidRetour : print("Début") et print("Fin") ne sont pas indentés : ils sont hors de la condition et s'exécutent toujours.
  3. Bonne réponse : Début / Froid / FinRetour : Oui. Début s'affiche toujours ; 15 > 20 est faux, le else affiche Froid ; print("Fin") n'est pas indenté, il s'exécute toujours.
  4. Distracteur : Début / FroidRetour : print("Fin") n'est pas indenté : il ne fait pas partie du else. Il s'exécute après, dans tous les cas.

14. [Conditions] Une variable créée dans un bloc

QCU, une seule réponse

Objectif : Suivre les affectations faites dans un bloc if.

a = 1
if a > 0:
    a = 5
    b = 10
else:
    b = 0
print(a + b)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : 1Retour : a ne vaut plus 1 à la fin : le bloc du if lui donne la valeur 5. Et il faut ajouter b.
  2. Distracteur : 11Retour : Tu as gardé a = 1. Mais le bloc du if remplace la valeur de a par 5 : 5 + 10 = 15.
  3. Distracteur : Une erreur : b n'existe pasRetour : En Python, une variable créée dans un bloc if existe encore après le bloc. b vaut 10.
  4. Bonne réponse : 15Retour : Oui. 1 > 0 est vrai : a devient 5 et b reçoit 10. Le print, hors du bloc, affiche 5 + 10 = 15.

15. [Conditions] Plusieurs conditions vraies

QCU, une seule réponse

Objectif : Savoir qu'un if … elif s'arrête à la première condition vraie.

Dans les réponses, le signe « / » sépare deux lignes affichées.

x = 7
if x > 10:
    print("A")
elif x > 5:
    print("B")
elif x > 0:
    print("C")
else:
    print("D")

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : CRetour : x > 0 est vrai, mais Python ne le teste même pas : il s'est arrêté avant, au premier elif vrai (7 > 5).
  2. Distracteur : B / CRetour : Deux conditions sont vraies, mais une seule branche s'exécute : la première vraie, x > 5.
  3. Distracteur : ARetour : 7 > 10 est faux : le bloc du if est sauté. Python passe au elif.
  4. Bonne réponse : BRetour : Oui. 7 > 10 est faux, 7 > 5 est vrai : Python affiche B et ignore toute la suite, même x > 0, vrai aussi.

16. [Conditions] Division entière // et reste %

QCU, une seule réponse

Objectif : Utiliser // et % dans des conditions.

Dans les réponses, le signe « / » sépare deux lignes affichées.

a = 10
b = 3
c = a / b
if a % b == 0 and c == 3.0:
    print("R1")
elif a // b == 3:
    print("R2")
else:
    print("R3")

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : R2Retour : Oui. 10 % 3 vaut 1 : le if est faux. 10 // 3 (division entière) vaut 3 : le elif est vrai et affiche R2.
  2. Distracteur : R1Retour : 10 % 3 vaut 1, pas 0 : la première partie du and est fausse, donc toute la condition est fausse.
  3. Distracteur : R3Retour : Le elif est vrai : 10 // 3 est le quotient entier, 3. Le else n'est donc pas atteint.
  4. Distracteur : R1 / R2Retour : Une seule branche s'exécute. Et le if est faux : 10 % 3 vaut 1, pas 0.

17. [Conditions] Un if dans un if

QCU, une seule réponse

Objectif : Suivre deux conditions imbriquées.

Dans les réponses, le signe « / » sépare deux lignes affichées.

temp = 35
if temp > 30:
    print("A")
    if temp < 40:
        print("B")
    else:
        print("C")
else:
    print("D")

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : A / CRetour : 35 < 40 est vrai : le if intérieur affiche B. Le else intérieur (C) est sauté.
  2. Distracteur : DRetour : Le else extérieur ne s'exécute que si temp > 30 est faux. Ici, 35 > 30 est vrai.
  3. Bonne réponse : A / BRetour : Oui. 35 > 30 est vrai : A s'affiche. Puis, dans ce bloc, 35 < 40 est vrai : B s'affiche.
  4. Distracteur : BRetour : Avant le if intérieur, le bloc extérieur exécute print("A"). Les deux lignes s'affichent : A, puis B.

18. [Conditions] Réaffecter deux variables

QCU, une seule réponse

Objectif : Suivre la valeur de deux variables modifiées dans un if.

x = 10
y = 1
if x > 5:
    y = 2
    x = 5
else:
    y = 3
print(x + y)

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 7Retour : Oui. 10 > 5 est vrai : y devient 2 et x devient 5. Le print affiche 5 + 2 = 7.
  2. Distracteur : 11Retour : Tu as gardé les valeurs de départ (10 + 1). Mais le if est vrai : x devient 5 et y devient 2.
  3. Distracteur : 13Retour : 13 = 10 + 3 : x a gardé sa valeur de départ, et y a pris 3, la valeur du else. Mais le if est vrai : x devient 5, y devient 2, et le else est sauté.
  4. Distracteur : 12Retour : Tu as changé y mais gardé x = 10. Le bloc du if change aussi x : x = 5, donc 5 + 2 = 7.

cle = "A1"
if len(cle) == 2:

Qu'affiche ce programme ?

21. [Conditions] Deux elif identiques

QCU, une seule réponse

Objectif : Savoir qu'un elif n'est pas testé après une branche vraie.

m = "a"
if m == "b":
    m = m + "c"
elif m == "a":
    m = m + "d"
elif m == "a":
    m = m + "e"
print(m)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : adeRetour : Le second elif m == "a" n'est jamais testé : Python s'arrête à la première branche vraie.
  2. Bonne réponse : adRetour : Oui. "a" == "b" est faux ; "a" == "a" est vrai : m devient "ad". La suite des elif est ignorée.
  3. Distracteur : acRetour : La première condition m == "b" est fausse : "c" n'est pas ajouté.
  4. Distracteur : aRetour : Le premier elif est vrai : m = m + "d" donne une nouvelle valeur à m, "ad".
