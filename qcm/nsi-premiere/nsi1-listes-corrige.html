1. [Listes] Reconnaître un type à son écriture

QCU, une seule réponse

Objectif : Reconnaître le type d'une valeur à son écriture.

valeurs = [2, 4, 7, 34, 23]

Quel est le type de la valeur rangée dans valeurs ?

Bonne réponse : C

  1. Distracteur : Un dictionnaire (dict)Retour : Un dictionnaire s'écrit entre accolades { }, avec des couples clé : valeur, comme {'a': 1}.
  2. Distracteur : Un tupleRetour : Un tuple s'écrit entre parenthèses, comme (2, 4, 7). Les crochets désignent une liste.
  3. Bonne réponse : Une liste (list)Retour : Oui : des crochets [ ] et des éléments séparés par des virgules forment une liste. type(valeurs) affiche <class 'list'>.
  4. Distracteur : Un ensemble (set)Retour : Un ensemble s'écrit entre accolades, sans clés : {2, 4, 7}. Ici, ce sont des crochets : c'est une liste.

2. [Listes] Ajouter un élément à la fin

QCU, une seule réponse

Objectif : Ajouter un élément à la fin d'une liste.

Quelle instruction ajoute le nombre 3 à la fin d'une liste nommée L ?

Bonne réponse : A

  1. Bonne réponse : L.append(3)Retour : Oui : append (« ajouter à la fin ») modifie la liste elle-même et place 3 en dernière position.
  2. Distracteur : L.add(3)Retour : add est la méthode des ensembles (set). Une liste n'en a pas : Python répond AttributeError.
  3. Distracteur : L + 3Retour : On ne peut pas additionner une liste et un entier (TypeError). Et même L + [3] ne modifierait pas L : il fabrique une nouvelle liste.
  4. Distracteur : L[3]Retour : L[3] lit l'élément d'indice 3 ; il n'ajoute rien à la liste.

3. [Listes] Multiplier une liste par un entier

QCU, une seule réponse

Objectif : Prévoir l'effet de l'opérateur * sur une liste.

liste = [1, 3]
print(liste * 2)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : [2, 6]Retour : C'est l'erreur la plus fréquente : * ne multiplie pas chaque élément. Sur une liste, il la répète.
  2. Bonne réponse : [1, 3, 1, 3]Retour : Oui : liste * 2 fabrique une liste qui répète deux fois le contenu, à la suite : [1, 3, 1, 3].
  3. Distracteur : [1, 1, 3, 3]Retour : Les éléments ne sont pas doublés un à un : la liste entière est recopiée à la suite d'elle-même.
  4. Distracteur : [[1, 3], [1, 3]]Retour : On n'obtient pas une liste de listes : les éléments sont mis bout à bout dans une seule liste.

4. [Listes] Les entiers de 4 à 100 avec range

QCU, une seule réponse

Objectif : Écrire un range qui inclut la borne voulue.

Quelle instruction affiche la liste de tous les entiers de 4 à 100 inclus, dans l'ordre croissant ?

Bonne réponse : B

  1. Distracteur : print(list(range(4, 100)))Retour : La borne de fin de range est exclue : cette liste s'arrête à 99. Pour inclure 100, on écrit range(4, 101).
  2. Bonne réponse : print(list(range(4, 101)))Retour : Oui : range(4, 101) va de 4 à 100, car la borne de fin est exclue. list(...) en fait une liste qu'on peut afficher.
  3. Distracteur : print(range(4, 100))Retour : Deux problèmes : 100 est exclu, et print(range(...)) affiche seulement range(4, 100), pas les nombres. Il faut list(...).
  4. Distracteur : print(list(range4, 100))Retour : Il manque la parenthèse après range : Python cherche une variable range4 et répond NameError.

5. [Listes] Lire un élément par son indice

QCU, une seule réponse

Objectif : Lire un élément en comptant les indices à partir de 0.

liste = [1, 5, 4, 12, 7, 9, 10, 2]
print(liste[4])

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : 12Retour : 12 est le 4e élément, mais à l'indice 3 : les indices commencent à 0. liste[4] est le 5e élément.
  2. Distracteur : 9Retour : 9 est à l'indice 5. Compte depuis 0 : 1 (indice 0), 5 (1), 4 (2), 12 (3), 7 (4).
  3. Bonne réponse : 7Retour : Oui : les indices commencent à 0, donc liste[4] est le 5e élément, 7.
  4. Distracteur : 1Retour : 1 est le premier élément, d'indice 0. liste[4] désigne l'élément d'indice 4.

6. [Listes] Lire une tranche liste[3:5]

QCU, une seule réponse

Objectif : Prévoir une tranche, dont l'indice de fin est exclu.

liste = [1, 5, 4, 12, 7, 9, 10, 2]
print(liste[3:5])

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : [12, 7]Retour : Oui : liste[3:5] va de l'indice 3 inclus à l'indice 5 exclu, soit les indices 3 et 4 : [12, 7].
  2. Distracteur : [3, 5]Retour : 3 et 5 sont les indices de la tranche, pas des éléments de la liste. On affiche les éléments des indices 3 et 4.
  3. Distracteur : [12, 7, 9]Retour : L'indice de fin est exclu : l'élément d'indice 5 (9) n'est pas dans la tranche.
  4. Distracteur : [4, 12, 7]Retour : Les indices commencent à 0 : l'indice 3 est 12, pas 4. Et l'indice de fin, 5, est exclu.

7. [Listes] Écrire une tranche

QCU, une seule réponse

Objectif : Choisir les bornes d'une tranche pour obtenir des éléments donnés.

liste = [1, 5, 4, 12, 7, 9, 10, 2]
print(...)

Que faut-il écrire à la place des points pour afficher [7, 9, 10] ?

Bonne réponse : C

  1. Distracteur : liste[5:7]Retour : L'indice 5 est 9 : on oublierait 7, qui est à l'indice 4.
  2. Distracteur : liste[5:8]Retour : liste[5:8] donne [9, 10, 2] : l'indice 5 est 9. Le 7 est à l'indice 4, car les indices commencent à 0.
  3. Bonne réponse : liste[4:7]Retour : Oui : 7, 9 et 10 sont aux indices 4, 5 et 6 ; la tranche s'arrête juste avant l'indice 7.
  4. Distracteur : liste[4:6]Retour : L'indice de fin est exclu : liste[4:6] donne seulement [7, 9].

8. [Listes] Modifier un élément

QCU, une seule réponse

Objectif : Prévoir l'effet de l'affectation d'un élément par son indice.

liste = [1, 5, 4, 12, 7, 9, 10, 2]
liste[5] = 6
print(liste)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : [1, 5, 4, 12, 7, 9, 10, 2]Retour : La liste a bien changé : liste[5] = 6 remplace l'élément d'indice 5. Les listes sont modifiables.
  2. Bonne réponse : [1, 5, 4, 12, 7, 6, 10, 2]Retour : Oui : l'élément d'indice 5 (9) est remplacé par 6. Les autres éléments ne bougent pas.
  3. Distracteur : [1, 6, 4, 12, 7, 9, 10, 2]Retour : 6 n'est pas inséré à la place de 5 : c'est l'élément d'indice 5 (le 6e, ici 9) qui est remplacé.
  4. Distracteur : [1, 5, 4, 12, 7, 9, 5, 2]Retour : L'indice et la valeur sont inversés : liste[5] = 6 met la valeur 6 à l'indice 5.

9. [Listes] Trier une liste avec sort

QCU, une seule réponse

Objectif : Prévoir l'effet de la méthode sort sur une liste de nombres.

La méthode sort() trie une liste dans l'ordre croissant.

liste = [1, 5, 4, 12, 7, 9, 10, 2]
liste.sort()
print(liste)

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : [1, 5, 4, 12, 7, 9, 10, 2]Retour : sort() modifie la liste elle-même : après l'appel, elle est triée. Elle ne renvoie rien, mais elle change la liste.
  2. Distracteur : [1, 10, 12, 2, 4, 5, 7, 9]Retour : C'est l'ordre alphabétique des textes '1', '10', '12', '2'… Ici, ce sont des nombres : ils sont triés selon leur valeur.
  3. Bonne réponse : [1, 2, 4, 5, 7, 9, 10, 12]Retour : Oui : sort() range les éléments du plus petit au plus grand, dans la liste elle-même.
  4. Distracteur : [12, 10, 9, 7, 5, 4, 2, 1]Retour : C'est l'ordre décroissant, celui de liste.sort(reverse=True). Sans option, sort() trie dans l'ordre croissant.

10. [Listes] Tester l'appartenance avec in

Choix multiple

Objectif : Prévoir le résultat de x in liste selon le type des éléments.

liste = [1, 1 + 1, 'un', '2+3', 7, 23, '1', 'vingt trois']
print(23 in liste)             # ligne 2
print(2 in liste)              # ligne 3
print(5 in liste)              # ligne 4
print('7' in liste)            # ligne 5
print('vingt' in liste)        # ligne 6
print('23' in liste)           # ligne 7
print('vingt trois' in liste)  # ligne 8
print([7, 23] in liste)        # ligne 9

Quelles lignes affichent True ? Cocher toutes les bonnes réponses.

Bonnes réponses : A, B, G

  1. Bonne réponse : Ligne 2Retour : Oui : l'entier 23 est un élément de la liste.
  2. Bonne réponse : Ligne 3Retour : Oui : 1 + 1 est calculé à la création de la liste, qui contient donc l'entier 2.
  3. Distracteur : Ligne 4Retour : '2+3' est un texte entre guillemets : il n'est pas calculé. L'entier 5 n'est pas dans la liste.
  4. Distracteur : Ligne 5Retour : La liste contient l'entier 7, pas le texte '7' : pour Python, ce sont deux valeurs différentes.
  5. Distracteur : Ligne 6Retour : in compare des éléments entiers : 'vingt' n'est pas un élément, même s'il est le début de 'vingt trois'.
  6. Distracteur : Ligne 7Retour : La liste contient l'entier 23, pas le texte '23' : le type compte.
  7. Bonne réponse : Ligne 8Retour : Oui : le texte 'vingt trois' est un élément de la liste, écrit exactement pareil.
  8. Distracteur : Ligne 9Retour : in cherche un élément égal à [7, 23] : la liste contient 7 et 23 séparément, mais pas la liste [7, 23] comme élément.

11. [Listes] Parcourir avec enumerate

QCU, une seule réponse

Objectif : Prévoir les couples (indice, élément) donnés par enumerate.

Dans les réponses, le signe / sépare deux lignes d'affichage.

liste = ['T', 'e', 'x', 't', 'e']
for i, c in enumerate(liste):
    print(i, c)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : TexteRetour : print est appelé à chaque tour : il y a 5 lignes, et chacune contient aussi l'indice.
  2. Bonne réponse : 0 T / 1 e / 2 x / 3 t / 4 eRetour : Oui : enumerate donne à chaque tour l'indice (à partir de 0) et l'élément. print(i, c) les sépare par une espace.
  3. Distracteur : T / e / x / t / eRetour : Ce serait le cas avec for c in liste. Avec enumerate, i reçoit aussi l'indice, et print(i, c) l'affiche.
  4. Distracteur : 1 T / 2 e / 3 x / 4 t / 5 eRetour : Par défaut, enumerate commence à 0, comme les indices des listes.

12. [Listes] Lire une case d'une liste de listes

QCU, une seule réponse

Objectif : Lire un élément avec deux indices : ligne puis colonne.

grille = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(grille[2][1])

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 8Retour : Oui : grille[2] est la ligne [7, 8, 9], et son élément d'indice 1 est 8.
  2. Distracteur : 4Retour : 4 est grille[1][0] : c'est ce qu'on obtient en comptant les lignes et les cases à partir de 1 (2e ligne, 1re case). Les indices commencent à 0 : grille[2] est la 3e ligne, [7, 8, 9].
  3. Distracteur : 2Retour : 2 est grille[0][1], dans la première ligne. Le premier indice choisit la ligne : grille[2] est la 3e ligne, [7, 8, 9].
  4. Distracteur : 6Retour : 6 est grille[1][2] : les indices sont inversés. D'abord la ligne (2), puis la colonne (1).

13. [Listes] insert, del et append à la suite

QCU, une seule réponse

Objectif : Suivre l'état d'une liste après plusieurs modifications.

liste = [1, 2, 3, 4, 5]
liste.insert(1, 6)
del liste[0]
liste.append(1)
print(liste)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : [1, 6, 2, 3, 4, 1]Retour : del liste[0] supprime l'élément d'indice 0 (le 1), pas le dernier. Refais les étapes une par une.
  2. Distracteur : [6, 1, 2, 3, 4, 5]Retour : Suis les étapes une par une : insert(1, 6) place 6 à l'indice 1, après le 1 ; del liste[0] retire ensuite le premier élément ; append(1) ajoute un 1 à la fin.
  3. Distracteur : [6, 2, 3, 4, 5]Retour : C'est l'état après del : il reste append(1), qui ajoute 1 à la fin.
  4. Bonne réponse : [6, 2, 3, 4, 5, 1]Retour : Oui : [1, 6, 2, 3, 4, 5] après insert, [6, 2, 3, 4, 5] après del liste[0], puis [6, 2, 3, 4, 5, 1] après append.

14. [Listes] Des sommes cumulées

QCU, une seule réponse

Objectif : Suivre un accumulateur et la liste qu'il remplit.

liste = [1, 2, 3, 4, 5]
cumuls = []
total = 0
for nombre in liste:
    total = total + nombre
    cumuls.append(total)
print(cumuls)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : [1, 2, 3, 4, 5]Retour : On n'ajoute pas nombre, mais total, qui garde la somme des tours précédents.
  2. Distracteur : [15]Retour : append est dans la boucle : une valeur est ajoutée à chaque tour, pas seulement à la fin.
  3. Distracteur : [10, 20, 30, 40, 50]Retour : Aucune multiplication ici : total augmente de nombre à chaque tour. Suis la trace : 1, 3, 6…
  4. Bonne réponse : [1, 3, 6, 10, 15]Retour : Oui : total vaut 1, puis 1 + 2 = 3, 3 + 3 = 6, 6 + 4 = 10, 10 + 5 = 15 ; chaque valeur est ajoutée à cumuls.

15. [Listes] La longueur d'une liste qui contient une liste

QCU, une seule réponse

Objectif : Compter les éléments d'une liste dont un élément est une liste.

liste = [1, [2, 3], 4]
print(len(liste))

Qu'affiche ce programme ?

Bonne réponse : A

  1. Bonne réponse : 3Retour : Oui : la liste a 3 éléments : 1, la liste [2, 3] (un seul élément), et 4.
  2. Distracteur : 4Retour : len ne compte pas les éléments de la liste intérieure : [2, 3] compte pour un seul élément.
  3. Distracteur : 2Retour : 1 et 4 comptent, mais [2, 3] est aussi un élément : len donne 3.
  4. Distracteur : Une erreur de syntaxeRetour : Une liste peut contenir d'autres listes : c'est du Python valide.

16. [Listes] Lire l'élément qui est une liste

QCU, une seule réponse

Objectif : Lire un élément qui est lui-même une liste.

liste = [1, [2, 3], 4]
print(liste[1])

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : [2]Retour : liste[1] renvoie l'élément entier d'indice 1 : la liste [2, 3], pas seulement son début.
  2. Distracteur : 1Retour : 1 est l'élément d'indice 0. Les indices commencent à 0 : liste[1] est le 2e élément.
  3. Distracteur : [3]Retour : L'indice 1 de la grande liste ne va pas dans la petite : il désigne tout l'élément [2, 3].
  4. Bonne réponse : [2, 3]Retour : Oui : l'élément d'indice 1 est la liste [2, 3]. Pour obtenir 3, on écrirait liste[1][1].
