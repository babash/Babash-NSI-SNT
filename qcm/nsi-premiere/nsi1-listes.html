11. [Listes] Parcourir avec enumerate

QCU, une seule réponse

Objectif : Prévoir les couples (indice, élément) donnés par enumerate.

Dans les réponses, le signe / sépare deux lignes d'affichage.

liste = ['T', 'e', 'x', 't', 'e']
for i, c in enumerate(liste):
    print(i, c)

Qu'affiche ce programme ?

  1. Texte
  2. 0 T / 1 e / 2 x / 3 t / 4 e
  3. T / e / x / t / e
  4. 1 T / 2 e / 3 x / 4 t / 5 e

14. [Listes] Des sommes cumulées

    total = total + nombre

Qu'affiche ce programme ?

  1. [1, 2, 3, 4, 5]
  2. [15]
  3. [10, 20, 30, 40, 50]
  4. [1, 3, 6, 10, 15]
