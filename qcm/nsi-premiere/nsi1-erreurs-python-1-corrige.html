1. [Erreurs] NameError : une faute de frappe

QCU, une seule réponse

Objectif : Lire un NameError et trouver le nom mal écrit.

Le programme suivant est exécuté.

rayon = 5
pi = 3.14
surface = pii * rayon**2
print(surface)

Console :

NameError: name 'pii' is not defined. Did you mean: 'pi'?

Quelle correction faut-il faire ?

Bonne réponse : C

  1. Distracteur : Ajouter des guillemets autour de piiRetour : 'pii' deviendrait un texte : Python ne pourrait plus le multiplier par un nombre pour calculer la surface. Le message montre une faute de frappe.
  2. Distracteur : Supprimer la ligne pi = 3.14Retour : Cette ligne crée la variable qu'il faut utiliser. Sans elle, l'erreur resterait, et même pi n'existerait plus.
  3. Bonne réponse : Écrire pi au lieu de piiRetour : Oui : le message dit « le nom 'pii' n'est pas défini. Voulais-tu dire 'pi' ? ». La variable créée s'appelle pi : c'est une faute de frappe.
  4. Distracteur : Remplacer le symbole * par +Retour : Le signe * n'est pas en cause : NameError parle d'un nom inconnu, ici pii. Corrige le nom, le calcul sera bon.

2. [Erreurs] SyntaxError : les deux-points du if

QCU, une seule réponse

Objectif : Lire le message « expected ':' » et le corriger.

age = 16
if age >= 18
    print('Majeur')

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

Bonne réponse : C

  1. Distracteur : Mettre des parenthèses autour de la valeur 18Retour : Les parenthèses ne changent rien ici. Le message dit ce qui manque : « expected ':' », des deux-points à la fin de la ligne.
  2. Distracteur : Écrire IF en majusculesRetour : Python distingue majuscules et minuscules : les mots-clés s'écrivent en minuscules, comme if. IF serait une nouvelle erreur.
  3. Bonne réponse : Ajouter « : » à la fin de la ligne du ifRetour : Oui : « expected ':' » veut dire « deux-points attendus ». Toute ligne qui ouvre un bloc (if, else, for, while, def) se termine par deux-points.
  4. Distracteur : Retirer l'indentation devant printRetour : print doit justement être indenté, car il fait partie du bloc du if. Ce qui manque, ce sont les deux-points.

3. [Erreurs] IndentationError : le corps d'une boucle

QCU, une seule réponse

Objectif : Lire une IndentationError et corriger le corps d'une boucle.

for i in range(3):
print(i)

Console :

IndentationError: expected an indented block after 'for' statement on line 1

Quelle correction faut-il faire ?

Bonne réponse : A

  1. Bonne réponse : Indenter print(i) de 4 espacesRetour : Oui : le message dit « un bloc indenté était attendu après l'instruction for de la ligne 1 ». Le corps de la boucle se décale de 4 espaces.
  2. Distracteur : Supprimer les deux-points après range(3)Retour : Les deux-points sont obligatoires après for. Le message parle d'autre chose : « bloc indenté attendu après le for ».
  3. Distracteur : Remplacer i par xRetour : Le nom de la variable n'a pas d'importance. Le message demande un bloc indenté, c'est-à-dire décalé vers la droite.
  4. Distracteur : Supprimer la boucle forRetour : Le programme n'afficherait plus 0, 1 et 2. On garde la boucle et on décale print(i) pour qu'il soit dans son bloc.

4. [Erreurs] IndexError : lire après la fin d'une liste

QCU, une seule réponse

Objectif : Lire une IndexError et en trouver la cause.

couleurs = ['rouge', 'vert', 'bleu']
print(couleurs[3])

Console :

IndexError: list index out of range

Pourquoi cette erreur ?

Bonne réponse : D

  1. Distracteur : On ne peut pas mettre de texte dans une listeRetour : Une liste peut contenir des textes, des nombres, et même d'autres listes. Le message parle d'un indice « hors limites ».
  2. Distracteur : Il faut des parenthèses au lieu des crochetsRetour : couleurs(3) provoquerait une autre erreur : on lit un élément d'une liste avec des crochets. Le problème est la valeur 3.
  3. Distracteur : La liste doit d'abord être triée par ordre alphabétiqueRetour : L'ordre des éléments ne change rien à l'accès par indice. Ce qui compte, c'est que l'indice existe : ici, il va de 0 à 2.
  4. Bonne réponse : L'indice 3 n'existe pas : les indices vont de 0 à 2Retour : Oui : « list index out of range » veut dire « indice de liste hors limites ». Avec 3 éléments, les indices sont 0, 1 et 2.

5. [Erreurs] KeyError : une clé mal écrite

QCU, une seule réponse

Objectif : Lire une KeyError et respecter l'écriture exacte d'une clé.

capitales = {'France': 'Paris', 'Italie': 'Rome'}
print(capitales['italie'])

Console :

KeyError: 'italie'

Quelle correction faut-il faire ?

Bonne réponse : D

  1. Distracteur : Utiliser un indice numérique : capitales[1]Retour : Un dictionnaire n'a pas d'indices 0, 1, 2 : on y accède par ses clés. capitales[1] donnerait une nouvelle KeyError.
  2. Distracteur : Inverser les clés et les valeursRetour : Le dictionnaire est bien construit. KeyError signale seulement que la clé 'italie' n'existe pas : regarde son écriture.
  3. Distracteur : Remplacer les crochets par des accoladesRetour : Les accolades servent à écrire le dictionnaire. Pour lire une valeur, on garde les crochets, avec la clé exacte.
  4. Bonne réponse : Écrire capitales['Italie']Retour : Oui : KeyError: 'italie' signifie « clé introuvable ». Python distingue majuscules et minuscules : 'Italie' et 'italie' sont deux clés différentes.

6. [Erreurs] TypeError : ajouter un nombre à un texte

QCU, une seule réponse

Objectif : Lire une TypeError de concaténation et insérer un nombre dans un texte.

points = 50
bilan = 'Total : ' + points

Console :

TypeError: can only concatenate str (not "int") to str

Quelle correction donne à bilan la valeur 'Total : 50' ?

Bonne réponse : A

  1. Bonne réponse : bilan = f'Total : {points}'Retour : Oui : le message dit « on ne peut coller (concaténer) à un str qu'un autre str, pas un int ». La f-string convertit points en texte. str(points) marcherait aussi.
  2. Distracteur : bilan = 'Total : ' * pointsRetour : Multiplier un texte par 50 le répète 50 fois : « Total : Total : … ». Ce n'est pas le résultat voulu.
  3. Distracteur : bilan = int('Total : ') + pointsRetour : 'Total : ' ne contient pas de chiffres : int() ne peut pas le convertir (ValueError). C'est le nombre qu'il faut transformer en texte.
  4. Distracteur : bilan = 'Total : ' + 'points'Retour : Avec des guillemets, 'points' est le mot points, pas la valeur 50 : on obtiendrait 'Total : points'.

7. [Erreurs] TypeError : not subscriptable

QCU, une seule réponse

Objectif : Lire le message « not subscriptable » et en trouver la cause.

vitesse = 90
print(vitesse[0])

Console :

TypeError: 'int' object is not subscriptable

Que signifie ce message ?

Bonne réponse : B

  1. Distracteur : L'entier 90 est trop grand pour PythonRetour : Python accepte des entiers immenses. Le message dit qu'un int « n'accepte pas les indices » (not subscriptable).
  2. Bonne réponse : Des crochets sont utilisés sur un entierRetour : Oui : « subscriptable » veut dire « qui accepte des indices ». Seules les listes, les chaînes ou les tuples s'utilisent avec [ ].
  3. Distracteur : Il faut utiliser l'indice 1Retour : Aucun indice ne convient : un entier n'est pas une suite d'éléments. vitesse[1] donnerait la même erreur.
  4. Distracteur : La variable vitesse n'est pas définieRetour : Ce serait une NameError. Ici, vitesse existe et vaut 90 : c'est l'usage des crochets qui pose problème.

8. [Erreurs] ValueError : une conversion impossible

QCU, une seule réponse

Objectif : Lire une ValueError de int() et en trouver la cause.

saisie = 'abc'
nombre = int(saisie)

Console :

ValueError: invalid literal for int() with base 10: 'abc'

Pourquoi cette erreur ?

Bonne réponse : A

  1. Bonne réponse : int() n'accepte pas des lettresRetour : Oui : le message dit « écriture invalide pour int() en base 10 : 'abc' ». int() attend une chaîne de chiffres, comme '42'.
  2. Distracteur : Il faut utiliser float('abc') à la placeRetour : float() refuse aussi des lettres : il donnerait une ValueError du même genre. Le problème vient du contenu de la chaîne.
  3. Distracteur : La base 10 n'existe pas en PythonRetour : La base 10 est la base par défaut de int(). Le message cite la base pour dire que 'abc' n'est pas un nombre écrit en base 10.
  4. Distracteur : La variable saisie doit être une listeRetour : int() attend une chaîne ou un nombre, pas une liste. Ici, c'est le contenu de la chaîne, des lettres, qui pose problème.

9. [Erreurs] SyntaxError : une chaîne jamais fermée

QCU, une seule réponse

Objectif : Lire « unterminated string literal » et trouver ce qui manque.

message = "Bienvenue à tous
print(message)

Console :

SyntaxError: unterminated string literal (detected at line 1)

Quelle est l'erreur ?

Bonne réponse : C

  1. Distracteur : Il manque un point-virgule à la fin de la ligneRetour : En Python, on ne termine pas les lignes par un point-virgule. Le message parle d'une chaîne non terminée.
  2. Distracteur : Le mot message est réservé par PythonRetour : message est un nom de variable autorisé. L'erreur vient de la chaîne de la ligne 1, qui n'est jamais fermée.
  3. Bonne réponse : Il manque le guillemet fermant à la fin du texteRetour : Oui : « unterminated string literal » veut dire « chaîne de caractères non terminée », détectée à la ligne 1. Il faut fermer le guillemet après « tous ».
  4. Distracteur : L'accent du « à » provoque l'erreurRetour : Python accepte les accents dans les chaînes. Ce qui manque, c'est le guillemet de fin.

10. [Erreurs] ZeroDivisionError : éviter la division par zéro

QCU, une seule réponse

Objectif : Lire une ZeroDivisionError et la prévenir par un test.

total = 100
nb_personnes = 0
part = total / nb_personnes

Console :

ZeroDivisionError: division by zero

Comment éviter cet arrêt du programme ?

Bonne réponse : C

  1. Distracteur : Utiliser // au lieu de /Retour : La division entière par zéro est aussi impossible : Python s'arrêterait encore, avec le message « ZeroDivisionError: integer division or modulo by zero ».
  2. Distracteur : Multiplier par nb_personnes au lieu de diviserRetour : On obtiendrait 0, un résultat faux : partager 100 entre des personnes n'est pas multiplier. Il faut éviter le cas nb_personnes = 0.
  3. Bonne réponse : Tester avec un if que nb_personnes != 0Retour : Oui : « division by zero » veut dire « division par zéro ». On ne divise que si nb_personnes != 0, et on traite l'autre cas à part.
  4. Distracteur : Mettre nb_personnes entre guillemetsRetour : '0' serait un texte : diviser un nombre par un texte provoque une TypeError. Il faut tester la valeur avant de diviser.

11. [Erreurs] AttributeError : append sur un texte

QCU, une seule réponse

Objectif : Lire une AttributeError et savoir quelles méthodes a un type.

nom = 'Alice'
nom.append(' ')

Console :

AttributeError: 'str' object has no attribute 'append'

Pourquoi cette erreur ?

Bonne réponse : B

  1. Distracteur : Il faut écrire le nom de la méthode APPEND en majusculesRetour : Les noms de méthodes sont en minuscules, et append n'existe pour les chaînes ni en minuscules ni en majuscules.
  2. Bonne réponse : Les chaînes n'ont pas de méthode appendRetour : Oui : le message dit « un objet str n'a pas d'attribut append ». Pour un texte, on fabrique une nouvelle chaîne : nom = nom + ' '.
  3. Distracteur : La variable nom est videRetour : nom vaut 'Alice', elle n'est pas vide. Le message dit que le type str n'a pas de méthode append.
  4. Distracteur : Il manque une ligne import mathRetour : append ne vient d'aucun module. C'est une méthode des listes, que les chaînes n'ont pas.

12. [Erreurs] NameError : un nom pourtant bien écrit

QCU, une seule réponse

Objectif : Comprendre une NameError due à l'ordre des lignes.

print(valeur)
valeur = 20

Console :

NameError: name 'valeur' is not defined

Le nom valeur est pourtant bien écrit. Pourquoi l'erreur ?

Bonne réponse : B

  1. Distracteur : Il faut écrire valeur = '20'Retour : Le type de la valeur ne change rien : à la ligne 1, valeur n'existe pas encore, quelle que soit sa future valeur.
  2. Bonne réponse : La variable est utilisée avant d'avoir reçu une valeurRetour : Oui : « name 'valeur' is not defined » veut dire « le nom valeur n'est pas défini ». Python lit de haut en bas : il faut échanger les deux lignes.
  3. Distracteur : Python lit le programme de bas en hautRetour : C'est l'inverse : Python exécute les lignes de haut en bas. Quand il arrive à print, la ligne valeur = 20 n'a pas encore été exécutée.
  4. Distracteur : Python ne gère pas les entiers au début d'un programmeRetour : Un entier peut apparaître n'importe où. Le problème est l'ordre des lignes : la variable est utilisée avant d'être créée.

13. [Erreurs] ValueError : not enough values to unpack

QCU, une seule réponse

Objectif : Lire « not enough values to unpack » et en trouver la cause.

coords = (10, 20)
x, y, z = coords

Console :

ValueError: not enough values to unpack (expected 3, got 2)

Quel est le problème ?

Bonne réponse : A

  1. Bonne réponse : 3 variables à remplir, mais 2 valeurs seulementRetour : Oui : le message dit « pas assez de valeurs à répartir (3 attendues, 2 reçues) ». Il faut autant de variables que de valeurs.
  2. Distracteur : On ne peut pas nommer une variable zRetour : z est un nom de variable autorisé. Le message compte : 3 variables attendent une valeur, le tuple n'en a que 2.
  3. Distracteur : Il faut des crochets autour de (10, 20)Retour : Une liste [10, 20] a aussi 2 valeurs : l'erreur serait la même. Le problème est le nombre de valeurs.
  4. Distracteur : Les valeurs 10 et 20 doivent être écrites comme des textesRetour : Le type des valeurs ne compte pas ici : Python ne trouve que 2 valeurs pour remplir 3 variables.

14. [Erreurs] TypeError : boucler sur un entier

QCU, une seule réponse

Objectif : Lire « not iterable » et corriger la boucle pour faire 10 tours.

score = 10
for i in score:
    print(i)

Console :

TypeError: 'int' object is not iterable

Comment corriger pour répéter l'affichage 10 fois ?

Bonne réponse : B

  1. Distracteur : Écrire score = '10'Retour : La boucle parcourrait la chaîne '10' : elle afficherait 1 puis 0, soit 2 tours seulement.
  2. Bonne réponse : Écrire for i in range(score):Retour : Oui : « not iterable » veut dire « qu'on ne peut pas parcourir ». range(score) fabrique la suite 0, 1, …, 9 : 10 tours.
  3. Distracteur : Retirer l'indentation de printRetour : print sortirait de la boucle, et la boucle n'aurait plus de corps : Python afficherait « IndentationError: expected an indented block after 'for' statement on line 2 ».
  4. Distracteur : Écrire while i in score:Retour : i n'existe pas encore : Python s'arrêterait sur une NameError. Et, même avec i défini, le test in sur un entier provoque une TypeError. Pour répéter n fois, on écrit for i in range(n).

15. [Erreurs] SyntaxError : '(' was never closed

QCU, une seule réponse

Objectif : Lire « '(' was never closed » et trouver ce qui manque.

print('Début'
print('Fin')

Console :

SyntaxError: '(' was never closed

D'où vient l'erreur ?

Bonne réponse : D

  1. Distracteur : On ne peut pas écrire deux print l'un à la suite de l'autreRetour : On peut enchaîner autant de print qu'on veut, un par ligne. Le message parle d'une parenthèse ouverte jamais fermée.
  2. Distracteur : Il faut écrire Début et Fin en majusculesRetour : Le contenu des chaînes est libre. Le message dit « la parenthèse ( n'a jamais été fermée ».
  3. Distracteur : Il manque les deux-points à la finRetour : Les deux-points ne s'écrivent qu'après if, for, while, def… Un print n'en a pas besoin.
  4. Bonne réponse : La parenthèse fermante de la première ligne manqueRetour : Oui : « '(' was never closed » veut dire « la parenthèse ( n'a jamais été fermée ». Python montre la ligne où elle s'ouvre : la première.
