1. [Conditions] Un if vrai

QCU, une seule réponse · bonne réponse en B

Objectif : Suivre un if … else dont la condition est vraie.

x = 5
if x > 2:
    print("Vrai")
else:
    print("Faux")

Qu'affiche ce programme ?

  1. FauxLa condition x > 2 se lit 5 > 2 : elle est vraie. Le bloc du else ne s'exécute que si la condition est fausse.
  2. Juste · VraiOui. x vaut 5 ; la condition 5 > 2 est vraie ; Python exécute le bloc du if et affiche Vrai. Le bloc du else est sauté.
  3. Une erreurLe programme est bien écrit : deux-points après la condition et après else, blocs indentés. Il s'exécute sans erreur.
  4. Vrai / FauxUne seule des deux branches s'exécute : le if quand la condition est vraie, sinon le else. Ici, c'est le if.

2. [Conditions] Un if faux : la branche else

QCU, une seule réponse · bonne réponse en A

Objectif : Suivre un if … else dont la condition est fausse.

a = -1
if a >= 0:
    print("Positif")
else:
    print("Négatif")

Qu'affiche ce programme ?

  1. Juste · NégatifOui. a vaut -1 ; -1 >= 0 est faux ; Python saute le bloc du if et exécute celui du else : Négatif.
  2. PositifLa condition se lit -1 >= 0 : elle est fausse, car -1 est plus petit que 0. C'est donc le bloc du else qui s'exécute.
  3. Rien ne s'afficheChaque branche contient un print. L'une des deux s'exécute toujours : ici le else, qui affiche Négatif.
  4. -1Le programme n'affiche jamais a : il affiche le texte de la branche choisie. Ici, -1 >= 0 est faux : Négatif.

4. [Conditions] L'opérateur or

QCU, une seule réponse · bonne réponse en C

Objectif : Évaluer une condition avec or (« ou »).

a = 10
b = 5
if a > 15 or b < 8:
    print("OK")
else:
    print("KO")

Qu'affiche ce programme ?

  1. KOTu as peut-être lu or comme and. Avec or (« ou »), une seule condition vraie suffit : ici, 5 < 8 est vrai.
  2. Rien ne s'afficheIl y a un print dans chaque branche, et l'une des deux s'exécute toujours. Ici, la condition est vraie : OK.
  3. Juste · OKOui. a > 15 est faux, b < 8 est vrai. Avec or, il suffit qu'une condition soit vraie : faux or vrai donne vrai. Le if affiche OK.
  4. OK / KOUne seule branche s'exécute. La condition entière (faux or vrai) vaut vrai : seul le bloc du if s'exécute.

  4. Juste · NormalOui. 25.5 > 25 est vrai, 60 < 50 est faux. Avec and (« et »), vrai and faux donne faux : le else affiche Normal.

6. [Conditions] if, elif, else : la première condition vraie

Objectif : Trouver la branche exécutée dans un if … elif … else.

Dans les réponses, le signe « / » sépare deux lignes affichées.

note = 12
if note > 15:
    print("A")
elif note > 10:
    print("B")
else:
    print("C")

Qu'affiche ce programme ?

  1. A12 > 15 est faux : le premier bloc est sauté. Python teste alors le elif.
  2. CLe else ne s'exécute que si toutes les conditions au-dessus sont fausses. Ici, le elif (12 > 10) est vrai.
  3. Juste · BOui. 12 > 15 est faux, puis 12 > 10 est vrai : Python exécute le bloc du elif et ignore le else.
  4. B / CDans un if … elif … else, une seule branche s'exécute. Après le elif vrai, le else est sauté.

Qu'affiche ce programme ?
