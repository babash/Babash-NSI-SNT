1. [Types] Entier + flottant

QCU, une seule réponse

Objectif : Prévoir le type du résultat d'une opération entre un entier et un flottant.

Quel est le type de la valeur de l'expression 3 + 2.0 ?

Bonne réponse : D

  1. Distracteur : intRetour : 3 est un entier, mais 2.0 est un flottant (il a un point). Dès qu'un flottant est dans le calcul, le résultat est un flottant : 5.0.
  2. Distracteur : strRetour : Il n'y a pas de guillemets : ce sont des nombres, pas des textes. Le résultat est le nombre 5.0.
  3. Distracteur : boolRetour : Un bool vaut True ou False ; il vient d'une comparaison. Une addition donne un nombre.
  4. Bonne réponse : floatRetour : Oui : 3 + 2.0 vaut 5.0. Un calcul entre un int et un float donne un float (un nombre à virgule).

2. [Types] Entier × flottant

QCU, une seule réponse

Objectif : Prévoir le type du résultat d'une multiplication avec un flottant.

Quel est le type de la valeur de l'expression 3 * 1.0 ?

Bonne réponse : C

  1. Distracteur : intRetour : Le résultat a la même valeur que 3, mais il s'écrit 3.0 : c'est un float, car 1.0 est un float.
  2. Distracteur : strRetour : Il n'y a pas de guillemets : c'est un calcul sur des nombres.
  3. Bonne réponse : floatRetour : Oui : 3 * 1.0 vaut 3.0. Même si le résultat « tombe juste », il reste un float, car 1.0 est un float.
  4. Distracteur : boolRetour : Un bool vient d'une comparaison (comme 3 > 1). Une multiplication donne un nombre.

3. [Types] Le type de False

QCU, une seule réponse

Objectif : Reconnaître une valeur booléenne.

Quel est le type de la valeur False ?

Bonne réponse : C

  1. Distracteur : intRetour : False s'écrit sans guillemets et avec une majuscule : c'est une valeur de vérité, pas un nombre entier.
  2. Distracteur : strRetour : Sans guillemets, False n'est pas un texte. "False", avec des guillemets, serait un str.
  3. Bonne réponse : boolRetour : Oui : True et False sont les deux valeurs du type bool (booléen), le type des conditions.
  4. Distracteur : NoneTypeRetour : NoneType est le type de la seule valeur None, qui veut dire « rien ». False veut dire « faux ».

4. [Types] Un nombre entre guillemets

QCU, une seule réponse

Objectif : Savoir qu'une valeur entre guillemets est une chaîne de caractères.

Quel est le type de la valeur "42" ?

Bonne réponse : B

  1. Distracteur : intRetour : Les guillemets changent tout : "42" est un texte de deux caractères, 4 et 2. Sans guillemets, 42 serait un int.
  2. Bonne réponse : strRetour : Oui : tout ce qui est entre guillemets est une chaîne de caractères (str, pour string, « chaîne »).
  3. Distracteur : floatRetour : Un float s'écrit avec un point, sans guillemets, comme 42.0. Ici, les guillemets en font un texte.
  4. Distracteur : NoneTypeRetour : NoneType est le type de None seulement. "42" est un texte.

5. [Types] Convertir un nombre à virgule en entier

QCU, une seule réponse

Objectif : Savoir que int tronque un flottant (il ne l'arrondit pas).

Quelle est la valeur de l'expression int(7.9) ?

Bonne réponse : A

  1. Bonne réponse : 7Retour : Oui : int garde la partie entière et coupe le reste. int(7.9) vaut 7.
  2. Distracteur : 8Retour : int n'arrondit pas : il coupe la partie après la virgule. Pour arrondir, on utilise round(7.9), qui donne 8.
  3. Distracteur : 7.9Retour : int change le type : le résultat est un entier, sans virgule.
  4. Distracteur : Une erreurRetour : int accepte un flottant : la conversion est permise. Elle donne 7.

6. [Types] Convertir un texte en entier

QCU, une seule réponse

Objectif : Utiliser int pour calculer avec un nombre écrit dans un texte.

Quelle est la valeur de l'expression int("42") + 1 ?

Bonne réponse : B

  1. Distracteur : "421"Retour : "421" serait une concaténation de textes. Ici, int("42") donne le nombre 42 : on fait une vraie addition.
  2. Bonne réponse : 43Retour : Oui : int("42") transforme le texte en nombre 42, puis 42 + 1 = 43. C'est ce qu'on fait avec le résultat de input().
  3. Distracteur : 42Retour : Le + 1 n'est pas oublié : après la conversion, Python calcule 42 + 1 = 43.
  4. Distracteur : Une erreur TypeErrorRetour : Il n'y a pas d'erreur : int("42") est un nombre, et on peut lui ajouter 1. Sans int, "42" + 1 donnerait une TypeError.

7. [Opérateurs] La division entière //

QCU, une seule réponse

Objectif : Calculer un quotient entier avec //.

Quelle est la valeur de l'expression 7 // 2 ?

Bonne réponse : D

  1. Distracteur : 3.5Retour : 3.5 est le résultat de la division 7 / 2, avec une seule barre. Avec deux barres, // garde le quotient entier.
  2. Distracteur : 4Retour : // n'arrondit pas à l'entier le plus proche : il garde le quotient de la division euclidienne, 3.
  3. Distracteur : 7/2Retour : Python calcule l'expression : il n'affiche pas une fraction. 7 // 2 vaut 3.
  4. Bonne réponse : 3Retour : Oui : // donne le quotient entier. 7 = 2 × 3 + 1, donc 7 // 2 vaut 3.

8. [Opérateurs] La division / donne un flottant

QCU, une seule réponse

Objectif : Savoir que / donne toujours un float.

Quelle est la valeur de l'expression 6 / 2 ?

Bonne réponse : C

  1. Distracteur : 3Retour : La division tombe juste, mais / donne toujours un float : 3.0. Pour un entier, on écrirait 6 // 2.
  2. Distracteur : "3"Retour : Il n'y a pas de texte ici : c'est un calcul. Le résultat est le nombre 3.0.
  3. Bonne réponse : 3.0Retour : Oui : avec /, le résultat est toujours un float, même quand la division tombe juste.
  4. Distracteur : 6/2Retour : Python calcule l'expression : il n'affiche pas une fraction.

9. [Opérateurs] Le reste %

Réponse numérique

Objectif : Calculer le reste d'une division avec %.

On range 17 mangues dans des sacs de 5.

Quelle est la valeur de l'expression 17 % 5, le nombre de mangues qui restent hors des sacs ? Répondre par un nombre.

Réponse attendue : 2 (tolérance 0)

Retour : 17 % 5 vaut 2 : 17 = 5 × 3 + 2. On remplit 3 sacs (17 // 5 = 3) et il reste 2 mangues. % donne le reste, // le quotient.

10. [Opérateurs] La priorité des opérations

QCU, une seule réponse

Objectif : Appliquer la priorité de * sur +.

Quelle est la valeur de l'expression 2 + 3 * 4 ?

Bonne réponse : A

  1. Bonne réponse : 14Retour : Oui : comme en mathématiques, * passe avant + : 3 * 4 = 12, puis 2 + 12 = 14.
  2. Distracteur : 20Retour : Tu as calculé de gauche à droite : (2 + 3) × 4. Mais, comme en mathématiques, la multiplication passe avant l'addition.
  3. Distracteur : 9Retour : 9 serait 2 + 3 + 4. Le signe * est une multiplication : 3 * 4 = 12.
  4. Distracteur : 24Retour : 24 serait 2 × 3 × 4. Le premier signe est une addition.

11. [Opérateurs] La puissance **

QCU, une seule réponse

Objectif : Calculer une puissance avec **.

Quelle est la valeur de l'expression 2 ** 3 ?

Bonne réponse : A

  1. Bonne réponse : 8Retour : Oui : 2 ** 3 = 2 × 2 × 2 = 8. Le nombre de droite dit combien de fois on multiplie.
  2. Distracteur : 6Retour : 6 serait 2 * 3. Avec deux étoiles, ** est la puissance : 2 × 2 × 2.
  3. Distracteur : 9Retour : 9 serait 3 2. Le premier nombre est la base : 2 3 = 2 × 2 × 2.
  4. Distracteur : Une erreurRetour : ** est bien un opérateur de Python : la puissance.

12. [Opérateurs] Le sens de chaque opérateur

Appariement

Objectif : Associer chaque opérateur arithmétique à son sens.

Associer chaque opérateur à ce qu'il calcule.

ÉlémentAssociation attendue
%le reste de la division
**la puissance
//le quotient entier
/la division (résultat flottant)

Retour : Avec 7 et 2 : 7 / 2 = 3.5 ; 7 // 2 = 3 ; 7 % 2 = 1 ; 7 ** 2 = 49. Le quotient et le reste vont ensemble : 7 = 2 × 3 + 1.

13. [Comparaisons] Le résultat d'une comparaison

QCU, une seule réponse

Objectif : Prévoir la valeur d'une comparaison.

Quelle est la valeur de l'expression 5 > 3 ?

Bonne réponse : B

  1. Distracteur : FalseRetour : 5 est bien plus grand que 3 : la comparaison est vraie.
  2. Bonne réponse : TrueRetour : Oui : 5 > 3 est vrai. Une comparaison donne un booléen, True ou False.
  3. Distracteur : NoneRetour : Une comparaison donne toujours une valeur de vérité, True ou False, jamais None.
  4. Distracteur : 5Retour : Une comparaison ne renvoie pas le plus grand nombre : elle dit si c'est vrai ou faux.

14. [Comparaisons] Comparer un texte et un nombre avec ==

QCU, une seule réponse

Objectif : Savoir que == compare aussi les types.

Quelle est la valeur de l'expression "42" == 42 ?

Bonne réponse : B

  1. Distracteur : TrueRetour : Pour nous, c'est le même nombre ; pour Python, "42" est un texte et 42 un nombre : deux valeurs différentes.
  2. Bonne réponse : FalseRetour : Oui : un str et un int ne sont jamais égaux pour ==. Il faut convertir d'abord : int("42") == 42 vaut True.
  3. Distracteur : NoneRetour : Une comparaison donne toujours True ou False, jamais None.
  4. Distracteur : "False"Retour : Le résultat est la valeur False, sans guillemets : un booléen, pas un texte.

15. [Chaînes] + entre deux textes

QCU, une seule réponse

Objectif : Savoir que + met deux chaînes bout à bout (concaténation).

Quelle est la valeur de l'expression "3" + "4" ?

Bonne réponse : A

  1. Bonne réponse : "34"Retour : Oui : entre deux textes, + les met bout à bout (on dit « concaténer »). "3" + "4" donne "34".
  2. Distracteur : 7Retour : Les guillemets font de "3" et "4" des textes, pas des nombres : + ne fait pas d'addition ici.
  3. Distracteur : Une erreur TypeErrorRetour : Il n'y a pas d'erreur : + est permis entre deux textes. L'erreur viendrait d'un texte + un nombre, comme "3" + 4.
  4. Distracteur : "7"Retour : Python ne calcule pas avec des textes : il les met bout à bout, "3" puis "4".

16. [Chaînes] Texte × entier

QCU, une seule réponse

Objectif : Prévoir le type de la répétition d'une chaîne.

Quel est le type de la valeur de l'expression "3" * 2 ?

Bonne réponse : A

  1. Bonne réponse : strRetour : Oui : "3" * 2 répète le texte deux fois et donne "33", un str.
  2. Distracteur : intRetour : "3" est un texte : * le répète, il ne calcule pas 3 × 2. Le résultat est "33", un texte.
  3. Distracteur : listRetour : Il n'y a pas de crochets : le résultat n'est pas une liste, c'est le texte "33".
  4. Distracteur : Une erreur TypeErrorRetour : Un texte multiplié par un entier est permis : il est répété. "3" * 2 vaut "33".

17. [Erreurs] Coller un texte et un nombre

QCU, une seule réponse

Objectif : Lire une TypeError de concaténation et convertir le nombre en texte.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

age = 16
print("J'ai " + age + " ans")

Console :

TypeError: can only concatenate str (not "int") to str

Quelle correction faut-il faire ?

Bonne réponse : D

  1. Distracteur : Écrire int(age) au lieu de ageRetour : age est déjà un int : int(age) ne change rien, et l'erreur reste. Il faut le transformer en texte.
  2. Distracteur : Écrire age entre guillemets : "age"Retour : Le programme afficherait le mot age, pas la valeur 16 : « J'ai age ans ».
  3. Distracteur : Remplacer les + par des *Retour : Un texte multiplié par un texte provoque aussi une TypeError. C'est age qu'il faut convertir en texte.
  4. Bonne réponse : Écrire str(age) au lieu de ageRetour : Oui. Le message dit « on ne peut coller (concaténer) à un str qu'un str, pas un int ». str(age) donne "16".

18. [Affectation] Une variable qui reçoit un calcul

QCU, une seule réponse

Objectif : Comprendre qu'une affectation calcule à droite, puis range à gauche.

x = 3
x = x + 2
print(x)

Qu'affiche ce programme ?

Bonne réponse : D

  1. Distracteur : 3Retour : La ligne 2 change x : elle calcule x + 2 avec l'ancienne valeur (3 + 2), puis range 5 dans x.
  2. Distracteur : x + 2Retour : Une affectation ne garde pas le calcul : elle le fait tout de suite et range le résultat, 5.
  3. Distracteur : Une erreur : x ne peut pas valoir x + 2Retour : Ce n'est pas une équation de mathématiques : = veut dire « ranger dans ». x = x + 2 ajoute 2 à x.
  4. Bonne réponse : 5Retour : Oui : Python calcule d'abord la droite, 3 + 2 = 5, puis range le résultat dans x. L'ancienne valeur est remplacée.

19. [Affectation] Copier une valeur

QCU, une seule réponse

Objectif : Savoir qu'après b = a, changer a ne change pas b.

a = 5
b = a
a = 7
print(b)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : 7Retour : b = a copie la valeur de a à ce moment-là : 5. Ensuite, a change, mais b ne suit pas.
  2. Bonne réponse : 5Retour : Oui : b = a range dans b la valeur de a, 5. Changer a ensuite ne change pas b : les deux variables ne sont pas liées.
  3. Distracteur : aRetour : print(b) affiche la valeur de b, pas le nom a. b a reçu 5.
  4. Distracteur : Une erreurRetour : Chaque ligne est permise : on peut donner une nouvelle valeur à a après l'avoir copiée dans b.

20. [Affectation] Échanger deux variables

QCU, une seule réponse

Objectif : Suivre deux affectations successives et repérer la valeur perdue.

a = 1
b = 2
a = b
b = a
print(a, b)

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : 2 1Retour : C'est l'échange voulu, mais ces lignes ne le font pas : après a = b, a vaut 2, et l'ancienne valeur 1 est perdue.
  2. Distracteur : 1 2Retour : Les lignes 3 et 4 changent les variables : a reçoit 2, puis b reçoit la valeur de a.
  3. Bonne réponse : 2 2Retour : Oui : a = b donne 2 à a ; puis b = a donne à b la valeur actuelle de a, 2. La valeur 1 est perdue : il faudrait une variable de plus.
  4. Distracteur : 1 1Retour : La ligne 3, a = b, range la valeur de b (2) dans a : c'est la droite qui va dans la gauche.
