1. [Conditions] Un if … else dans un if

QCU, une seule réponse

Objectif : Suivre deux niveaux de blocs et l'instruction qui les suit.

a = 10
b = 1
if a > 5:
    a = a - 5
    if a < b:
        b = 100
    else:
        b = 20
    a = a + 1
else:
    a = 0
    b = 0
print(a + b)

Qu'affiche ce programme ?

  1. 26
  2. 101
  3. 25
  4. 7

13. [Erreurs] Corriger la condition d'un if

QCU, une seule réponse

Objectif : Lire le message d'une SyntaxError et corriger une condition.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

maree = "haute"
if maree = "haute":
    print("La barge accoste")

Console :

SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Quelle correction faut-il faire ?

  1. Mettre la condition entre parenthèses
  2. Retirer les guillemets autour de haute
  3. Écrire == au lieu de = dans la condition
  4. Ajouter un else à la fin

14. [Erreurs] Les deux-points oubliés

QCU, une seule réponse

note = 12
if note >= 10
    print("Admis·e")

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Écrire => au lieu de >=
  2. Ajouter : à la fin de la ligne if
  3. Ajouter un else après le print
  4. Retirer l'indentation du print

17. [Erreurs] Comparer un texte et un nombre

QCU, une seule réponse

La variable age contient un texte, comme ce que renvoie input(). Le programme suivant est exécuté.

if age >= 18:
    print("majeur·e")
else:
    print("mineur·e")

Console :

TypeError: '>=' not supported between instances of 'str' and 'int'

Quelle correction faut-il faire ?

  1. Écrire if int(age) >= 18:

  3. Écrire "18" entre guillemets
