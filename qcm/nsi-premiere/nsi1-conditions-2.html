1. [Conditions] Un if … else dans un if

QCU, une seule réponse · bonne réponse en A

Objectif : Suivre deux niveaux de blocs et l'instruction qui les suit.

a = 10
b = 1
if a > 5:
    a = a - 5
    if a < b:
        b = 100
    else:
        b = 20
    a = a + 1
else:
    a = 0
    b = 0
print(a + b)

Qu'affiche ce programme ?

  1. Juste · 26Oui. 10 > 5 : a devient 5. 5 < 1 est faux : b devient 20. Puis a = a + 1 : a vaut 6. Le print affiche 6 + 20 = 26.
  2. 101Tu as pris b = 100. Mais a vaut 5 à ce moment-là, et 5 < 1 est faux : c'est le else intérieur qui donne b = 20.
  3. 25Tu as oublié a = a + 1. Cette ligne est indentée au niveau du premier if : elle s'exécute après le if … else intérieur. a vaut 6.
  4. 7b change bien : le if intérieur est faux, donc son else s'exécute et b reçoit 20. Puis 6 + 20 = 26.

2. [Conditions] Le test in sur un texte

QCU, une seule réponse · bonne réponse en D

Objectif : Suivre un test in, puis un if … elif … else intérieur.

c = "rouge"
x = 0
if "r" in c:
    x = 1
    if c == "vert":
        x = x + 10
    elif c == "rouge":
        x = x * 2
    else:
        x = x + 100
else:
    x = 5
print(x)

Qu'affiche ce programme ?

  1. 1Après x = 1, le bloc intérieur s'exécute encore : c == "rouge" est vrai, et x = x * 2 change x.
  2. 101Le else intérieur n'est pas atteint : le elif c == "rouge" est vrai, la suite est ignorée.
  3. 5"r" in c ne demande pas si c vaut "r" : il demande si la lettre r apparaît dans le texte. Elle y est : on n'entre pas dans le else.
  4. Juste · 2Oui. "r" est dans "rouge" : x devient 1. Puis c == "vert" est faux, c == "rouge" est vrai : x = 1 × 2 = 2.

3. [Conditions] Un print dans le bloc, un autre après

QCU, une seule réponse · bonne réponse en C

Objectif : Suivre une variable modifiée dans un bloc et après lui.

Dans les réponses, le signe « / » sépare deux lignes affichées.

s = 10
if s > 5:
    s = s + 5
    if s > 15:
        print(s)
    else:
        print(s - 10)
s = s * 2
print(s)

Qu'affiche ce programme ?

  1. 15 / 30s vaut 15, et 15 > 15 est faux : c'est le else intérieur qui s'exécute. Il affiche s - 10, soit 5.
  2. 30Le bloc intérieur affiche déjà une ligne avant le dernier print : 5, puis 30.
  3. Juste · 5 / 30Oui. s devient 15 ; 15 > 15 est faux : le else affiche 15 - 10 = 5. Puis s = s * 2 (hors du bloc) : 30 s'affiche.
  4. 5 / 10print(s - 10) affiche un calcul mais ne change pas s : s vaut toujours 15. Puis s * 2 donne 30.

4. [Conditions] Un if … else dans un elif

QCU, une seule réponse · bonne réponse en D

Objectif : Suivre un bloc imbriqué dans une branche elif.

Dans les réponses, le signe « / » sépare deux lignes affichées.

h = 14
if h < 10:
    print("Matin")
elif h < 18:
    print("Jour")
    if h > 15:
        print("Fin")
    else:
        print("Milieu")
else:
    print("Soir")

Qu'affiche ce programme ?

  1. Jour / Fin14 > 15 est faux : le if intérieur est sauté et son else affiche Milieu.
  2. SoirLe else extérieur n'est pas atteint : le elif (14 < 18) est vrai.
  3. MilieuDans le bloc du elif, print("Jour") vient avant le if intérieur : il s'affiche d'abord.
  4. Juste · Jour / MilieuOui. 14 < 10 est faux, 14 < 18 est vrai : Jour s'affiche. Puis 14 > 15 est faux : le else intérieur affiche Milieu.

5. [Conditions] Des conditions avec and et or

QCU, une seule réponse · bonne réponse en D

Objectif : Évaluer une condition avec or, puis une avec and.

a = 15
b = 5
if a % 2 == 0 or b > 10:
    a = 1
    b = 1
elif a > 10 and b < 10:
    a = 2
    b = 2
else:
    a = 3
    b = 3
print(a * b)

Qu'affiche ce programme ?

  1. 115 % 2 vaut 1 et 5 > 10 est faux : faux or faux donne faux. Le premier bloc est sauté.
  2. 9Le else n'est pas atteint : 15 > 10 et 5 < 10 sont vrais tous les deux, donc le elif s'exécute.
  3. 2Le programme affiche a * b, le produit, pas a seul. a et b valent 2 : 2 × 2 = 4.
  4. Juste · 4Oui. Le if est faux (faux or faux). Le elif est vrai : 15 > 10 et 5 < 10. a et b valent 2 : 2 × 2 = 4.

resultat = ""
x = 10
if x > 20:
    resultat = "A"
else:
    resultat = "B"
    if x > 5:
        resultat = resultat + "C"
    else:
        resultat = resultat + "D"
resultat = resultat + "E"
print(resultat)

  3. A10 > 20 est faux : on passe dans le else, où resultat reçoit "B".
  4. BCresultat = resultat + "E" n'est pas indentée : elle s'exécute après les blocs, dans tous les cas.

7. [Conditions] Un test de divisibilité dans un if

QCU, une seule réponse · bonne réponse en A

Objectif : Suivre un if imbriqué qui teste un reste.

val = 15
res = 0
if val < 20:
    res = 1
    if val % 3 == 0:
        res = res + 2
    else:
        res = res + 5
elif val < 30:
    res = 10

print(res)

Qu'affiche ce programme ?

  1. Juste · 3Oui. 15 < 20 : res vaut 1. 15 % 3 vaut 0 (15 = 3 × 5) : res = 1 + 2 = 3.
  2. 10Le elif n'est pas testé : le premier if (15 < 20) est vrai.
  3. 615 est divisible par 3 : 15 % 3 vaut 0, la condition est vraie. C'est + 2, pas + 5.
  4. 1Après res = 1, le if intérieur s'exécute aussi : 15 % 3 == 0 est vrai, et res devient 3.

8. [Conditions] Une condition est une valeur

QCU, une seule réponse · bonne réponse en D

Objectif : Savoir qu'une comparaison donne un booléen, qu'on peut ranger dans une variable.

Le matin, il y a souvent un bouchon jusqu'à Mamoudzou.

heure = 7
bouchon = heure >= 6 and heure <= 9
print(bouchon)

Qu'affiche ce programme ?

  1. FalseLes deux comparaisons sont vraies pour heure = 7 : avec and, le résultat est True.
  2. Une erreur : il manque ifUne comparaison peut s'écrire sans if : elle donne True ou False, qu'on range dans une variable.
  3. 7bouchon ne reçoit pas heure : il reçoit le résultat de la condition, True ou False.
  4. Juste · TrueOui. 7 >= 6 est vrai, 7 <= 9 est vrai : vrai and vrai donne True. Une comparaison donne une valeur, rangée ici dans bouchon.

9. [Conditions] L'ordre des tests

QCU, une seule réponse · bonne réponse en B

Objectif : Comprendre pourquoi l'ordre des elif compte.

Ce programme doit classer une mangue selon son poids, en grammes : « grosse » au-dessus de 400 g, « moyenne » au-dessus de 200 g, « petite » sinon.

poids = 450
if poids > 200:
    print("moyenne")
elif poids > 400:
    print("grosse")
else:
    print("petite")

Qu'affiche-t-il pour une mangue de 450 g ?

  1. grosseC'est ce qu'on voudrait, mais Python teste dans l'ordre : 450 > 200 est vrai d'abord, il affiche moyenne et s'arrête.
  2. Juste · moyenneOui, et c'est une erreur du programme : 450 > 200 est vrai, le elif n'est jamais testé. Il faut tester poids > 400 en premier.
  3. moyenne / grosseUne seule branche s'exécute : la première vraie. Python ne teste pas le elif après le if vrai.
  4. petiteLe else ne s'exécute que si toutes les conditions sont fausses. Ici, 450 > 200 est vrai.

10. [Conditions] Un if sans else

QCU, une seule réponse · bonne réponse en A

Objectif : Savoir qu'une condition fausse sans else ne bloque pas le programme.

Dans les réponses, le signe « / » sépare deux lignes affichées.

maree = "basse"
if maree == "haute":
    print("Départ en pirogue")
print("Fin")

Qu'affiche ce programme ?

  1. Juste · FinOui. "basse" == "haute" est faux : le bloc est sauté. print("Fin") n'est pas indenté : il s'exécute toujours.
  2. Rien ne s'afficheUne condition fausse n'arrête pas le programme : Python saute le bloc et continue à la ligne suivante.
  3. Départ en pirogue / FinLa condition est fausse : maree vaut "basse". Le print indenté sous le if est sauté.
  4. Une erreur : il manque elseLe else n'est pas obligatoire. Sans else, si la condition est fausse, Python ne fait rien de plus et continue.

11. [Conditions] or au lieu de and

Dans cet exercice, le tarif de jour d'un taxi s'applique de 6 h à 20 h ; sinon, c'est le tarif de nuit.

heure = 22
if heure >= 6 or heure < 20:
    print("tarif de jour")
else:
    print("tarif de nuit")

Qu'affiche ce programme ?

  1. tarif de nuitC'est le bon tarif, mais pas ce qu'affiche ce programme : avec or, 22 >= 6 suffit à rendre la condition vraie.
  2. tarif de jour / tarif de nuitUne seule branche s'exécute. Ici, la condition est vraie : c'est le if.
  3. Juste · tarif de jourOui, et c'est une erreur : avec or, 22 >= 6 suffit, la condition est toujours vraie. Il faut and : heure >= 6 and heure < 20.
  4. Rien ne s'afficheChaque branche a un print : le programme affiche forcément un tarif.

13. [Erreurs] = au lieu de ==

QCU, une seule réponse · bonne réponse en C

Objectif : Lire le message d'une SyntaxError et corriger une condition.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

maree = "haute"
if maree = "haute":
    print("La barge accoste")

Console :

SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Quelle correction faut-il faire ?

  1. Mettre la condition entre parenthèsesLes parenthèses ne changent rien : Python affiche la même erreur. Le problème est le signe =, qui n'est pas une comparaison.
  2. Retirer les guillemets autour de hauteSans guillemets, haute serait un nom de variable inconnu. Les guillemets sont justes : "haute" est un texte.
  3. Juste · Écrire == au lieu de = dans la conditionOui. = range une valeur dans une variable (affectation) ; == compare deux valeurs. Le message le propose : « Maybe you meant '==' » (« voulais-tu dire == ? »).
  4. Ajouter un else à la finLe else n'est pas obligatoire. Le message « invalid syntax » (« syntaxe invalide ») vise le signe = de la ligne 2.

14. [Erreurs] Les deux-points oubliés

QCU, une seule réponse · bonne réponse en B

Objectif : Lire le message « expected ':' » et le corriger.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

note = 12
if note >= 10
    print("Admis·e")

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Écrire => au lieu de >==> n'existe pas en Python : « supérieur ou égal » s'écrit bien >=. Le message parle d'autre chose.
  2. Juste · Ajouter : à la fin de la ligne ifOui. « expected ':' » veut dire « deux-points attendus ». Une ligne if se termine toujours par deux-points, avant le bloc indenté.
  3. Ajouter un else après le printLe else n'est pas obligatoire, et il lui faudrait aussi ses deux-points. Lis le message : il manque « : ».
  4. Retirer l'indentation du printSans indentation, le print ne serait plus dans le bloc du if, et Python signalerait une autre erreur. L'indentation est juste.

15. [Erreurs] Le bloc non indenté

QCU, une seule réponse · bonne réponse en B

Objectif : Lire une IndentationError et indenter le bloc d'un if.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

n = 3
if n > 0:
print("positif")

Console :

IndentationError: expected an indented block after 'if' statement on line 2

Quelle correction faut-il faire ?

  1. Retirer les deux-points de la ligne 2Les deux-points sont obligatoires après un if : sans eux, Python signalerait « expected ':' ».

  3. Ajouter ; à la fin de la ligne 2Python n'utilise pas de point-virgule pour finir une ligne if : il afficherait une autre erreur de syntaxe.

16. [Erreurs] Un else avec une condition

QCU, une seule réponse · bonne réponse en C

Objectif : Savoir qu'un else n'a pas de condition : on écrit elif.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

x = -2
if x > 0:
    print("positif")
else x < 0:
    print("négatif")

Console :

SyntaxError: expected ':'

Quelle correction faut-il faire ?

  1. Écrire else if x < 0:else if existe dans d'autres langages, pas en Python : Python affiche la même erreur. Il attend « : » juste après else.
  2. Retirer les deux-points après x < 0Python attend justement « : » après else, et il en faut aussi à la fin d'une ligne elif. Retirer les deux-points ajoute une erreur.
  3. Juste · Écrire elif x < 0:Oui. Un else ne porte jamais de condition : Python attend « : » juste après else. Pour une deuxième condition, on écrit elif.
  4. Écrire else (x < 0):Les parenthèses ne changent rien : un else n'a pas de condition. Il faut un elif.

17. [Erreurs] Comparer un texte et un nombre

QCU, une seule réponse · bonne réponse en A

Objectif : Lire une TypeError dans une condition et convertir le texte en nombre.

La variable age contient un texte, comme ce que renvoie input(). Le programme suivant est exécuté.

age = "16"
if age >= 18:
    print("majeur·e")
else:
    print("mineur·e")

Console :

TypeError: '>=' not supported between instances of 'str' and 'int'

Quelle correction faut-il faire ?

  1. Juste · Écrire if int(age) >= 18:Oui. Le message dit « >= impossible entre un str (texte) et un int (entier) ». int(age) transforme "16" en 16 : la comparaison marche.
  2. Écrire elif au lieu de elseLe else est bien écrit. Le message parle de types : >= ne compare pas un texte (str) et un nombre entier (int).
  3. Écrire "18" entre guillemetsLe programme ne s'arrêterait plus, mais il comparerait deux textes, lettre par lettre : "9" >= "18" serait vrai ! Il faut comparer des nombres.
  4. Écrire => au lieu de >==> n'existe pas en Python. Le message vise les types : "16" est un texte, 18 est un nombre.
