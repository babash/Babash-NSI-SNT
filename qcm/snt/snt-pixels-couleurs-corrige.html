1. [Photographie] Le photosite du capteur

QCU, une seule réponse

Objectif : Distinguer le photosite du capteur et le pixel de l'image.

Sur le capteur d'un appareil photo, qu'est-ce qu'un photosite ?

Bonne réponse : C

  1. Distracteur : Un point de l'image enregistrée, avec sa couleurRetour : Ça, c'est un pixel : un élément de l'image enregistrée. Le photosite est sur le capteur, avant le calcul de l'image.
  2. Distracteur : Un point d'encre sur une photo impriméeRetour : Le photosite est dans l'appareil photo, pas sur le papier : c'est lui qui capte la lumière.
  3. Bonne réponse : Une minuscule cellule qui mesure la lumière reçueRetour : Oui : le capteur est couvert de photosites. Chacun mesure la quantité de lumière qu'il reçoit ; des algorithmes en tirent ensuite les pixels de l'image.
  4. Distracteur : Un petit fichier qui décrit la photoRetour : Les informations sur la photo (date, réglages, lieu) sont les métadonnées EXIF. Un photosite est une cellule du capteur.

2. [Pixels] La définition d'une image

QCU, une seule réponse

Objectif : Calculer la définition d'une image (nombre de pixels).

Une photo du lagon mesure 4 000 pixels de large et 3 000 pixels de haut. Quelle est sa définition ?

Bonne réponse : A

  1. Bonne réponse : 12 millions de pixelsRetour : Oui : 4 000 × 3 000 = 12 000 000 pixels, soit 12 mégapixels (12 Mpx).
  2. Distracteur : 7 000 pixelsRetour : Tu as additionné la largeur et la hauteur. L'image est un tableau : on multiplie, 4 000 × 3 000.
  3. Distracteur : 36 millions de pixelsRetour : Tu as multiplié aussi par 3, le nombre de couleurs R, V, B. Ce calcul donne la taille en octets, pas le nombre de pixels.
  4. Distracteur : 1,2 million de pixelsRetour : Vérifie les zéros : 4 000 × 3 000 = 12 000 000, soit 12 millions.

3. [Couleurs] Les lettres R, V, B

QCU, une seule réponse

Objectif : Connaître les trois couleurs du codage RVB.

Que signifient les lettres RVB (RGB en anglais), utilisées pour coder la couleur d'un pixel ?

Bonne réponse : C

  1. Distracteur : Résolution, Vitesse, Bande passanteRetour : Ces mots parlent de qualité d'image et de réseau. RVB désigne trois couleurs de lumière.
  2. Distracteur : Rapport, Volume, BinaireRetour : Ces mots ne désignent pas des couleurs. Chaque lettre de RVB est une couleur de lumière.
  3. Bonne réponse : Rouge, Vert, BleuRetour : Oui : chaque pixel d'un écran mélange ces trois lumières. En anglais : Red, Green, Blue.
  4. Distracteur : Rotation, Valeur, BrillanceRetour : Ce ne sont pas des termes du codage des couleurs. RVB : rouge, vert, bleu.

4. [Couleurs] Mélanger le rouge et le bleu

QCU, une seule réponse

Objectif : Trouver la couleur d'un pixel à partir de ses trois composantes.

Un pixel a les composantes R = 255, V = 0, B = 255. Quelle couleur affiche-t-il ?

Bonne réponse : D

  1. Distracteur : JauneRetour : Le jaune mélange le rouge et le vert : (255, 255, 0). Ici, c'est le vert qui vaut 0.
  2. Distracteur : VertRetour : Le vert seul serait (0, 255, 0). Ici, la composante verte vaut 0 : il n'y a pas de vert du tout.
  3. Distracteur : CyanRetour : Le cyan mélange le vert et le bleu : (0, 255, 255). Ici, c'est le rouge qui est à fond.
  4. Bonne réponse : MagentaRetour : Oui : rouge à fond et bleu à fond, sans vert. Sur un écran, la lumière rouge et la lumière bleue donnent le magenta (un rose violacé).

5. [Couleurs] Le code du blanc

QCU, une seule réponse

Objectif : Savoir que, sur un écran, toutes les lumières à fond donnent le blanc.

Quel triplet (R, V, B) code le blanc ?

Bonne réponse : C

  1. Distracteur : (0, 0, 0)Retour : Toutes les lumières éteintes : c'est le noir. Sur un écran, on ajoute de la lumière pour éclaircir.
  2. Distracteur : (1, 1, 1)Retour : 1 est une lumière presque éteinte : (1, 1, 1) est un noir. Chaque composante va de 0 à 255.
  3. Bonne réponse : (255, 255, 255)Retour : Oui : rouge, vert et bleu à fond donnent le blanc. Sur un écran, la lumière s'ajoute.
  4. Distracteur : (128, 128, 128)Retour : Trois composantes égales donnent bien un gris ; à 128, c'est un gris moyen. Le blanc demande le maximum, 255.

6. [Couleurs] Synthèse additive et soustractive

QCU, une seule réponse

Objectif : Distinguer la synthèse additive (écran) de la synthèse soustractive (encre).

Un écran mélange des lumières (RVB). Une imprimante mélange des encres (CMJN : cyan, magenta, jaune, noir). Quelle phrase est juste ?

Bonne réponse : D

  1. Distracteur : Écran : synthèse soustractive ; imprimante : synthèse additiveRetour : C'est l'inverse : l'écran part du noir et ajoute des lumières ; l'encre part du papier blanc et absorbe de la lumière.
  2. Distracteur : Écran et imprimante utilisent les mêmes couleurs primairesRetour : Les primaires sont différentes : rouge, vert, bleu pour l'écran ; cyan, magenta, jaune pour l'encre.
  3. Distracteur : Écran : couleurs en binaire ; imprimante : en décimalRetour : La façon d'écrire les nombres ne change rien aux couleurs. La différence est physique : ajouter ou retirer de la lumière.
  4. Bonne réponse : Écran : synthèse additive ; imprimante : synthèse soustractiveRetour : Oui : sur l'écran, on part du noir et on ajoute des lumières (tout à fond : blanc). L'encre retire de la lumière au papier blanc.

7. [Couleurs] La plus grande valeur d'un octet

QCU, une seule réponse

Objectif : Trouver la plus grande valeur d'une composante codée sur un octet.

Chaque composante R, V, B est codée sur un octet. Quel nombre décimal représente l'octet 11111111, la plus grande valeur possible ?

Bonne réponse : A

  1. Bonne réponse : 255Retour : Oui : 2⁸ - 1 = 255. C'est pourquoi chaque composante va de 0 à 255 : 256 valeurs sur un octet.
  2. Distracteur : 128Retour : 128 est le poids du seul bit de gauche (10000000). Ici, les huit bits sont à 1 : 128 + 64 + … + 1.
  3. Distracteur : 155Retour : Huit bits à 1 donnent la plus grande valeur d'un octet : 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.
  4. Distracteur : 256Retour : 256 est le nombre de valeurs possibles, de 0 à 255. La plus grande est 255.

8. [Données] La plus petite unité

QCU, une seule réponse

Objectif : Connaître l'unité de base de l'information.

Quelle est la plus petite unité d'information, qui vaut 0 ou 1 ?

Bonne réponse : B

  1. Distracteur : L'octetRetour : Un octet regroupe 8 bits : ce n'est pas la plus petite unité.
  2. Bonne réponse : Le bitRetour : Oui : un bit (de l'anglais binary digit, « chiffre binaire ») vaut 0 ou 1.
  3. Distracteur : Le hertzRetour : Le hertz mesure une fréquence (par exemple la vitesse d'un processeur), pas une quantité d'information.
  4. Distracteur : Le kilooctet (ko)Retour : Un kilooctet vaut 1 000 octets : c'est une grande unité.

9. [Données] L'octet

QCU, une seule réponse

Objectif : Connaître la relation entre l'octet et le bit.

Quelle relation lie l'octet et le bit ?

Bonne réponse : A

  1. Bonne réponse : 1 octet = 8 bitsRetour : Oui : un octet, c'est 8 bits. Il code 2⁸ = 256 valeurs, de 0 à 255 : exactement une composante R, V ou B.
  2. Distracteur : 1 octet = 4 bitsRetour : 4 bits forment un quartet, la moitié d'un octet.
  3. Distracteur : 1 octet = 10 bitsRetour : On pense souvent à 10 comme en décimal, mais un octet regroupe 8 bits.
  4. Distracteur : 1 bit = 8 octetsRetour : C'est l'inverse : le bit est la plus petite unité, et l'octet en contient 8.

10. [Pixels] Un pixel en niveaux de gris

QCU, une seule réponse

Objectif : Calculer la place d'un pixel en niveaux de gris.

Un pixel en niveaux de gris n'a qu'une composante, de 0 (noir) à 255 (blanc). Combien d'octets faut-il pour le coder ?

Bonne réponse : A

  1. Bonne réponse : 1 octetRetour : Oui : 256 valeurs, de 0 à 255, tiennent dans un octet (8 bits). Un pixel en couleur RVB en demande 3.
  2. Distracteur : 2 octetsRetour : Un octet code déjà 256 valeurs, de 0 à 255 : c'est assez pour une seule composante.
  3. Distracteur : 3 octetsRetour : 3 octets, c'est un pixel en couleur : un pour R, un pour V, un pour B. En gris, il n'y a qu'une composante.
  4. Distracteur : 8 octetsRetour : Tu confonds peut-être avec les 8 bits d'un octet. Une valeur de 0 à 255 tient dans 1 octet.

11. [Pixels] La taille d'une image sans compression

QCU, une seule réponse

Objectif : Calculer la taille d'une image : définition × octets par pixel.

Une image de 1 000 × 500 pixels est codée en RVB, un octet par composante, sans compression. Quelle est sa taille ?

Bonne réponse : D

  1. Distracteur : 500 000 octetsRetour : C'est le nombre de pixels. Chaque pixel prend 3 octets (R, V, B) : il faut multiplier par 3.
  2. Distracteur : 3 octetsRetour : C'est la taille d'un seul pixel. L'image en a 1 000 × 500 = 500 000.
  3. Distracteur : 12 000 000 octetsRetour : Tu as multiplié par 8 en plus : c'est le nombre de bits. 1 500 000 octets = 12 000 000 bits.
  4. Bonne réponse : 1 500 000 octetsRetour : Oui : 1 000 × 500 = 500 000 pixels, × 3 octets = 1 500 000 octets, soit 1,5 Mo environ.

12. [Pixels] La profondeur de couleur

QCU, une seule réponse

Objectif : Calculer le nombre de couleurs codées sur 24 bits.

Un pixel RVB est codé sur 24 bits : 8 bits par composante. Combien de couleurs différentes peut-il prendre ?

Bonne réponse : B

  1. Distracteur : 768Retour : Tu as additionné (256 × 3). Mais chaque valeur de R se combine avec chaque valeur de V et de B : on multiplie, 256 × 256 × 256.
  2. Bonne réponse : 16 777 216Retour : Oui : 256 × 256 × 256 = 2²⁴ = 16 777 216 couleurs, plus de 16 millions.
  3. Distracteur : 24Retour : 24 est le nombre de bits. Avec 24 bits, on a 2²⁴ combinaisons possibles.
  4. Distracteur : 765Retour : 765 = 255 × 3 : c'est la somme des trois valeurs maximales, pas le nombre de couleurs.

13. [Pixels] La résolution

QCU, une seule réponse

Objectif : Comprendre la résolution d'une image imprimée, en pixels par pouce.

Une image est imprimée avec une résolution de 300 ppp (pixels par pouce ; un pouce mesure 2,54 cm). Que veut dire ce nombre ?

Bonne réponse : B

  1. Distracteur : L'image contient 300 pixels en toutRetour : Le nombre total de pixels, c'est la définition. La résolution les rapporte à une longueur.
  2. Bonne réponse : On aligne 300 pixels sur 2,54 cmRetour : Oui : la résolution compte les pixels par unité de longueur. Plus elle est grande, plus l'image imprimée est fine.
  3. Distracteur : Chaque pixel peut prendre 300 couleursRetour : Le nombre de couleurs dépend de la profondeur de couleur (en bits), pas de la résolution.
  4. Distracteur : Le fichier pèse 300 octetsRetour : La taille du fichier dépend de la définition et du codage, pas directement de la résolution.

14. [Traitement] Un pixel dans une grille

QCU, une seule réponse

Objectif : Repérer un pixel par sa ligne et sa colonne, en comptant à partir de 0.

Une image est rangée dans une grille : grille[ligne][colonne], les indices commencent à 0. Quelle instruction colore en bleu pur le pixel de la 3ᵉ ligne et de la 10ᵉ colonne ?

Bonne réponse : C

  1. Distracteur : grille[3][10] = (255, 0, 0)Retour : Deux erreurs : (255, 0, 0) est le rouge, et les indices 3 et 10 visent la 4ᵉ ligne, 11ᵉ colonne.
  2. Distracteur : grille[3][10] = (0, 0, 255)Retour : La couleur est juste, mais les indices commencent à 0 : la 3ᵉ ligne est la ligne 2.
  3. Bonne réponse : grille[2][9] = (0, 0, 255)Retour : Oui : la 3ᵉ ligne a l'indice 2, la 10ᵉ colonne l'indice 9, et (0, 0, 255) est le bleu pur.
  4. Distracteur : grille[2][9] = (0, 255, 0)Retour : La position est juste, mais (0, 255, 0) est le vert : le bleu est la troisième composante.

15. [Traitement] Une boucle qui dessine

QCU, une seule réponse

Objectif : Prévoir ce que dessine une boucle sur une grille de pixels.

Une image carrée de N × N pixels est rangée dans grille[ligne][colonne].

for i in range(N):
    grille[i][i] = (0, 0, 0)

Que dessine ce programme ?

Bonne réponse : D

  1. Distracteur : Une ligne horizontale noireRetour : Une ligne horizontale garde le même indice de ligne, par exemple grille[5][i]. Ici, la ligne change à chaque tour.
  2. Distracteur : Une colonne noireRetour : Une colonne garde le même indice de colonne, par exemple grille[i][5]. Ici, la colonne change aussi.
  3. Distracteur : Le bord de l'image en noirRetour : Pour le bord, il faudrait noircir la première et la dernière ligne, et la première et la dernière colonne.
  4. Bonne réponse : Une diagonale noireRetour : Oui : la ligne et la colonne valent toutes deux i : (0, 0), (1, 1), (2, 2)… On noircit la diagonale.

16. [Traitement] Le négatif d'un pixel

QCU, une seule réponse

Objectif : Calculer le négatif d'un pixel : 255 moins chaque composante.

# un pixel orange, couleur de mangue
r, v, b = 200, 150, 0
r, v, b = 255 - r, 255 - v, 255 - b
print(r, v, b)

Qu'affiche ce programme ?

Bonne réponse : C

  1. Distracteur : -200 -150 0Retour : Le programme ne change pas seulement le signe : il calcule 255 moins chaque valeur.
  2. Distracteur : 0 150 200Retour : Le négatif n'inverse pas l'ordre des composantes : il calcule 255 - r, 255 - v, 255 - b.
  3. Bonne réponse : 55 105 255Retour : Oui : 255 - 200 = 55, 255 - 150 = 105, 255 - 0 = 255. L'orange devient un bleu : c'est le négatif.
  4. Distracteur : 55 105 0Retour : Attention à la dernière composante : 255 - 0 vaut 255, pas 0.

17. [Traitement] Passer en niveaux de gris

QCU, une seule réponse

Objectif : Calculer le gris d'un pixel comme la moyenne de ses composantes.

r, v, b = 90, 180, 30
gris = (r + v + b) // 3
print(gris)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : 300Retour : 300 est la somme. Le programme la divise ensuite par 3 : c'est une moyenne.
  2. Bonne réponse : 100Retour : Oui : (90 + 180 + 30) // 3 = 300 // 3 = 100. Le pixel devient (100, 100, 100), un gris.
  3. Distracteur : 180Retour : Le programme ne garde pas la plus grande composante : il fait la moyenne des trois.
  4. Distracteur : 90Retour : Le programme ne garde pas la première composante : il calcule la moyenne des trois.

18. [Traitement] Éclaircir sans dépasser 255

QCU, une seule réponse

Objectif : Éclaircir une composante en la gardant entre 0 et 255.

r = 230
r = min(255, r + 50)
print(r)

Qu'affiche ce programme ?

Bonne réponse : B

  1. Distracteur : 280Retour : 230 + 50 = 280, mais min(255, 280) garde la plus petite des deux valeurs : 255. Une composante ne dépasse jamais 255.
  2. Bonne réponse : 255Retour : Oui : min garde la plus petite valeur entre 255 et 280. La composante reste dans les limites, 0 à 255.
  3. Distracteur : 230Retour : La ligne 2 change r : r + 50 donne 280, et min le ramène à 255.
  4. Distracteur : 50Retour : min compare 255 et r + 50, soit 280 : il ne renvoie pas 50.

19. [Erreurs] Modifier un pixel rangé dans un tuple

QCU, une seule réponse

Objectif : Lire une TypeError : un tuple ne se modifie pas.

Le programme suivant est exécuté. Python s'arrête sur l'erreur affichée dans la console.

pixel = (255, 0, 0)
pixel[0] = 0

Console :

TypeError: 'tuple' object does not support item assignment

Quelle correction permet d'obtenir un pixel noir ?

Bonne réponse : A

  1. Bonne réponse : Créer un nouveau triplet : pixel = (0, 0, 0)Retour : Oui. Le message dit « un tuple ne permet pas de modifier un élément ». On range un nouveau triplet dans la variable.
  2. Distracteur : Écrire pixel(0) = 0Retour : Les parenthèses servent à appeler une fonction : Python affiche une SyntaxError. Le problème est le tuple.
  3. Distracteur : Écrire pixel[0] == 0Retour : Il n'y a plus d'erreur, mais == compare sans rien changer : le pixel reste (255, 0, 0).
  4. Distracteur : Écrire pixel[1] = 0Retour : On ne peut modifier aucun élément d'un tuple : Python afficherait la même erreur.
