1. Repérer les fonctions

Voici des extraits du code de la bibliothèque Python « openai » (openai-python 0.x, © OpenAI, licence MIT). Sans chercher à comprendre chaque fonction, repère les définitions et les appels de fonctions, puis leurs paramètres et leurs valeurs de retour.

def _console_log_level():
    if openai.log in ["debug", "info"]:
        return openai.log
    elif OPENAI_LOG in ["debug", "info"]:
        return OPENAI_LOG
    else:
        return None

def logfmt(props):
    def fmt(key, val):
        # Handle case where val is a bytes or bytesarray
        if hasattr(val, "decode"):
            val = val.decode("utf-8")
        # Check if val is already a string to avoid re-encoding into ascii.
        if not isinstance(val, str):
            val = str(val)
        if re.search(r"\s", val):
            val = repr(val)
        # key should already be a string
        if re.search(r"\s", key):
            key = repr(key)
        return "{key}={val}".format(key=key, val=val)

    return " ".join([fmt(key, val) for key, val in sorted(props.items())])


def get_object_classes():
    # This is here to avoid a circular dependency
    from openai.object_classes import OBJECT_CLASSES

    return OBJECT_CLASSES


def convert_to_openai_object(
    resp,
    api_key=None,
    api_version=None,
    organization=None,
    engine=None,
    plain_old_data=False,
):
    # If we get a OpenAIResponse, we'll want to return a OpenAIObject.

    response_ms: Optional[int] = None
    if isinstance(resp, openai.openai_response.OpenAIResponse):
        organization = resp.organization
        response_ms = resp.response_ms
        resp = resp.data

    if plain_old_data:
        return resp
    elif isinstance(resp, list):
        return [
            convert_to_openai_object(
                i, api_key, api_version, organization, engine=engine
            )
            for i in resp
        ]
    elif isinstance(resp, dict) and not isinstance(
        resp, openai.openai_object.OpenAIObject
    ):
        resp = resp.copy()
        klass_name = resp.get("object")
        if isinstance(klass_name, str):
            klass = get_object_classes().get(
                klass_name, openai.openai_object.OpenAIObject
            )
        else:
            klass = openai.openai_object.OpenAIObject

        return klass.construct_from(
            resp,
            api_key=api_key,
            api_version=api_version,
            organization=organization,
            response_ms=response_ms,
            engine=engine,
        )
    else:
        return resp

def merge_dicts(x, y):
    z = x.copy()
    z.update(y)
    return z

Une définition commence par def. Un appel, c'est un nom suivi de parenthèses, ailleurs.

Six définitions (def) : _console_log_level, logfmt, fmt (définie dans logfmt), get_object_classes, convert_to_openai_object et merge_dicts. sorted, repr, str, isinstance… sont seulement appelées.

Combien de paramètres a chaque fonction ?

_console_log_level = [[0]]
logfmt = [[1]]
fmt = [[2]]
get_object_classes = [[0]]
convert_to_openai_object = [[6]]
merge_dicts = [[2]]

Compte les noms entre les parenthèses de chaque def ; des parenthèses vides : 0.

convert_to_openai_object a ses paramètres sur plusieurs lignes ; ceux qui ont une valeur par défaut comptent aussi.

0, 1 (props), 2 (key, val), 0, 6 (resp, api_key, api_version, organization, engine, plain_old_data) et 2 (x, y).

Que peut renvoyer _console_log_level() ?

  • openai.log, OPENAI_LOG ou None.
  • La liste ["debug", "info"].
  • Rien : elle n'a pas de paramètre.
  • Seulement openai.log.

Repère chaque return de la fonction.

Trois return, un par branche : openai.log, OPENAI_LOG, ou None sinon. Une fonction peut ne pas avoir de paramètre et renvoyer une valeur.

Que renvoie merge_dicts(x, y) ?

  • Le dictionnaire x, modifié.
  • Un nouveau dictionnaire z : une copie de x, complétée par y.
  • La valeur renvoyée par z.update(y).
  • Rien : elle ne fait qu'afficher.

Suis z : d'où vient-il, et que lui arrive-t-il ?

z est une copie de x ; z.update(y) y ajoute les paires de y (et remplace les clés communes) ; la fonction renvoie z. Ni x ni y ne changent.

Après une ligne qui finit par deux-points (if, for, def…), il faut un bloc en retrait.

Ligne 3 : le message doit être dans le bloc du if, donc en retrait de 8 espaces.

Une fois la ligne 3 en retrait, le programme se lance. Mais decompte(5) affiche le message d'erreur, puis 10, 9, 8, 7, 6. Que faut-il encore corriger ? Coche tout.

  • L'affichage : print(n-i) au lieu de print(10-i).
  • Après le message, sortir de la fonction avec return.
  • La boucle : range(n+1) au lieu de range(n).

3. Comprendre un algorithme

Pour chaque fonction : déroule l'exécution pas à pas, puis dis ce qu'elle fait.

def mystere(n):
    a = 1
    for i in range(1, n+1):
        a = a*i
    return a

mystere(5)

Complète le déroulé de mystere(5) : les valeurs de i et de a à la fin de chaque tour.

#        (i, a)

tour_3 = ([[3]], [[6]])
tour_4 = ([[4]], [[24]])
tour_5 = ([[5]], [[120]])
renvoie = [[120]]

range(1, n+1) donne 1, 2, 3, 4, 5.

À chaque tour, a est multiplié par i.

a vaut 1, 1×2 = 2, 2×3 = 6, 6×4 = 24, 24×5 = 120. mystere(5) renvoie 120.

Que fait cette fonction mystere(n) ?

  • Elle calcule la somme des entiers de 1 à n.
  • Elle calcule le produit 1 × 2 × … × n (la factorielle de n).
  • Elle calcule n puissance n.
  • Elle affiche les nombres de 1 à n.

Relis le déroulé : 1, 2, 6, 24, 120.

Elle renvoie 1 × 2 × … × n : c'est la factorielle de n, notée n!.

Que fait cette fonction mystere(n) ?

Elle renvoie le produit 1 × 2 × … × n, la factorielle de n.

Qu'affiche ce programme ?

def mystere(a, b):
    if a > b :
        temp = a
        a = b
        b = temp
    return a, b

print(mystere(46, 12))
(12, 46)

46 > 12 : on entre dans le if. Suis temp, a et b ligne par ligne.

temp = 46, puis a = 12, puis b = 46 : le programme affiche (12, 46).

Que fait cette fonction mystere(a, b) ?

  • Elle renvoie les deux nombres rangés du plus petit au plus grand.
  • Elle échange toujours les deux nombres.
  • Elle renvoie le plus petit des deux.
  • Elle renvoie la différence des deux nombres.

Que renvoie mystere(3, 8) ?

Si a > b, elle échange a et b (avec la variable temp). Elle renvoie donc toujours (le plus petit, le plus grand).

Que fait cette fonction mystere(a, b) ?

Elle renvoie les deux nombres dans l'ordre croissant : si a > b, elle les échange.

def mystere(tab, n):
    for i in range(len(tab)) :
        tab[i] = tab[i] * n
    return tab

print(mystere([3, 6, 10, 1, 0], 5))
[15, 30, 50, 5, 0]

Chaque case du tableau est multipliée par 5.

La fonction multiplie chaque élément du tableau par n (et modifie le tableau lui-même) : [15, 30, 50, 5, 0].

Qu'affiche ce programme ?

def mystere(tab):
    for i in range(1, len(tab)+1) :
        if tab[i-1] != tab[-i]:
            return False
    return True

print(mystere([3, 6, 10, 1, 0, 4, 10, 6, 3]))
False

Pour i = 1, on compare tab[0] et tab[-1] ; pour i = 2, tab[1] et tab[-2]…

3 = 3, 6 = 6, 10 = 10, puis pour i = 4 : tab[3] vaut 1 et tab[-4] vaut 4. Ils sont différents : la fonction renvoie False.

Que fait cette fonction mystere(tab) ?

  • Elle vérifie que le tableau est trié.
  • Elle vérifie que le tableau se lit pareil dans les deux sens (un palindrome).
  • Elle vérifie que le premier et le dernier éléments sont égaux.
  • Elle renverse le tableau.

Que renvoie mystere([1, 2, 1]) ?

Elle compare chaque élément à son symétrique (tab[i-1] et tab[-i]) : True si le tableau est un palindrome, False dès qu'une paire diffère.

Que fait cette fonction mystere(tab) ?

Elle renvoie True si le tableau se lit pareil dans les deux sens (un palindrome), False sinon.

from math import sqrt # import de la fonction racine carrée

def mystere(point1, point2):
    return sqrt((point1[0] - point2[0])**2 + (point1[1] - point2[1])**2)

def mystere2(tab, depart):
    point = tab[0]
    min_dist = mystere(point, depart)
    for i in range (1, len(tab)):
        if mystere(tab[i], depart) < min_dist:
            point = tab[i]
            min_dist = mystere(tab[i], depart)
    return point

print(mystere2([[7, 9], [2, 5], [5, 2]], [0, 0]))
[2, 5]

mystere calcule la distance entre deux points. Calcule-la pour chaque point, depuis [0, 0].

[2, 5] et [5, 2] sont à la même distance : la comparaison < est stricte.

Distances à [0, 0] : environ 11,4 pour [7, 9], et racine de 29 (environ 5,39) pour [2, 5] comme pour [5, 2]. Le premier plus proche est gardé : [2, 5].

Que fait la fonction mystere2(tab, depart) ?

  • Elle renvoie le point de tab le plus proche de depart.
  • Elle renvoie le point le plus éloigné de depart.
  • Elle renvoie la plus petite distance.
  • Elle trie les points par distance.

mystere est la distance entre deux points ; mystere2 cherche un minimum.

mystere calcule la distance entre deux points ; mystere2 cherche le minimum de ces distances et renvoie le point le plus proche de depart.

Que font les fonctions mystere et mystere2 ?

mystere calcule la distance entre deux points ; mystere2 renvoie le point de tab le plus proche de depart.
