5. Avec des paramètres

Écris une fonction factorielle(n) qui renvoie le produit 1 × 2 × … × (n-1) × n, pour un entier n passé en paramètre. Des tests, cachés, la vérifient quand tu cliques sur « Lancer et vérifier ».

def factorielle(n):
    ...

C'est factorielle10, avec n à la place de 10, et return à la place de print.

def factorielle(n):
    produit = 1
    for i in range(1, n + 1):
        produit = produit * i
    return produit

Test : factorielle(5) doit valoir 120.

Écris une fonction nombre_de(n, tab) qui compte combien de fois la valeur n apparaît dans le tableau tab, et affiche ce nombre.

def nombre_de(n, tab):
    ...

nombre_de(3, [3, 1, 3, 3, 2])
nombre_de(7, [1, 2, 4])

3
0

Un compteur qui part de 0 ; on ajoute 1 à chaque case égale à n.

def nombre_de(n, tab):
    compteur = 0
    for valeur in tab:
        if valeur == n:
            compteur = compteur + 1
    print(compteur)

nombre_de(3, [3, 1, 3, 3, 2])
nombre_de(7, [1, 2, 4])

Le 3 apparaît trois fois ; le 7 n'apparaît pas : 0.

6. Avec une valeur de retour

Écris une fonction puissance(x, n) qui calcule xn (x multiplié n fois par lui-même) et le renvoie au programme principal. Des tests, cachés, la vérifient quand tu cliques sur « Lancer et vérifier ».

def puissance(x, n):
    ...

Comme une factorielle, mais on multiplie toujours par x, n fois.

def puissance(x, n):
    resultat = 1
    for _ in range(n):
        resultat = resultat * x
    return resultat

Python a aussi l'opérateur x ** n : la boucle montre ce qu'il calcule.

Rappel : l'équation du second degré a x² + b x + c = 0 (avec a non nul). On calcule d'abord le discriminant delta = b² - 4ac. Si delta < 0 : pas de solution. Si delta > 0 : deux solutions, (-b + racine(delta)) / 2a et (-b - racine(delta)) / 2a. Si delta = 0 : une seule solution, -b / 2a.

Calcule delta = b**2 - 4*a*c, puis trois cas : if, elif, else.

Attention aux parenthèses : (-b + sqrt(delta)) / (2*a).

from math import sqrt


def solutions(a, b, c):
    delta = b**2 - 4*a*c
    if delta < 0:
        return []
    elif delta == 0:
        return [-b / (2*a)]
    else:
        return [(-b + sqrt(delta)) / (2*a), (-b - sqrt(delta)) / (2*a)]

Sans les parenthèses autour de 2*a, Python diviserait par 2 puis multiplierait par a : solutions(2, 1, -1) le montre.

Mémo

print affiche, pour la personne qui regarde l'écran ; return renvoie une valeur au programme, qui peut s'en servir.
