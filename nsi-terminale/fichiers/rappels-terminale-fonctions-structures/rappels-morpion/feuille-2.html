5. Listes et dictionnaires

Voici une structure de données qui donne le nombre de médailles gagnées par 10 pays aux Jeux olympiques de Paris 2024.

Quelle est la structure de données choisie ?

  • Une liste de tuples.
  • Une seule liste de 44 éléments.

Regarde les crochets : ceux de l'ensemble, et ceux de chaque ligne.

Une liste de listes : chaque ligne est une liste, et la première ligne est un en-tête qui nomme les colonnes.

Donne l'instruction qui affiche le premier pays de la liste.

JO_2024[0] est la ligne d'en-tête : JO_2024[0][0] vaut "pays".

Cette instruction affiche toute la ligne de l'Italie. On veut seulement le nom du pays.

La ligne 0 est l'en-tête. Le nom est dans la colonne 0.

print(JO_2024[1][0]) affiche Italie : ligne 1 (la ligne 0 est l'en-tête), colonne 0.

Donne l'instruction qui affiche le dernier pays de la liste.

La liste a 11 lignes : la dernière a l'indice 10 (ou -1). JO_2024[11] provoque une erreur IndexError.

L'indice -1 désigne le dernier élément.

print(JO_2024[-1][0]) affiche Grande-Bretagne. On peut aussi écrire JO_2024[10][0] ou JO_2024[len(JO_2024) - 1][0].

Donne l'instruction qui affiche le nombre de pays contenus dans la liste.

len(JO_2024) vaut 11 : la ligne d'en-tête est comptée, mais ce n'est pas un pays.

len compte toutes les lignes… même la première.

print(len(JO_2024) - 1) affiche 10 : 11 lignes, moins la ligne d'en-tête.

def gagnant(tableau):
    meilleur = tableau[1]
    for ligne in tableau[2:]:
        if ligne[1] > meilleur[1]:
            meilleur = ligne
    return meilleur[0], meilleur[1]

def plus_medailles(tableau):
    meilleur, total_max = None, -1
    for ligne in tableau[1:]:
        total = ligne[1] + ligne[2] + ligne[3]
        if total > total_max:
            meilleur, total_max = ligne[0], total
    return meilleur, total_max

def gagnant_dict(d):
    meilleur, or_max = None, -1
    for pays, (o, a, b) in d.items():
        if o > or_max:
            meilleur, or_max = pays, o
    return meilleur, or_max


def plus_medailles_dict(d):
    meilleur, total_max = None, -1
    for pays, medailles in d.items():
        if sum(medailles) > total_max:
            meilleur, total_max = pays, sum(medailles)
    return meilleur, total_max
