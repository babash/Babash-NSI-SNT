On étudie le programme d'un morpion. Chaque joueur·euse joue à son tour. Le programme demande où jouer, puis met la grille à jour. Le jeu s'arrête si la grille est pleine ou si quelqu'un a gagné.

Voici la fonction qui affiche la grille du morpion :

# La fonction qui affiche la grille dans le terminal
def afficherGrille(g, gagnant=None):
    print(" " + g[0][0] + " | " + g[0][1] + " | " + g[0][2] + " ")
    print("---+---+---")
    print(" " + g[1][0] + " | " + g[1][1] + " | " + g[1][2] + " ")
    print("---+---+---")
    print(" " + g[2][0] + " | " + g[2][1] + " | " + g[2][2] + " \n")

    if gagnant:
        print("* Partie terminée : le joueur", gagnant, "a gagné. *")


grille = [[" " for _ in range(3)] for _ in range(3)]  # 9 espaces " "

Les indices commencent à 0 : le deuxième élément a l'indice 1.

Un élément d'un tuple se lit comme dans une liste : joueurs[indice].

print(joueurs[1]) affiche O.

Peux-tu modifier le symbole du deuxième joueur, avec joueurs[1] = "Z" ?

  • Oui, comme dans une liste.
  • Non : un tuple ne se modifie pas (il est immuable).
  • Non : seule la valeur "O" est interdite.
  • Non : l'indice 1 n'existe pas.

Liste et tuple se lisent de la même façon. Mais l'un des deux ne se modifie pas.

Non. Un tuple est immuable : Python répond TypeError: 'tuple' object does not support item assignment. Pour changer de symbole, il faut créer un nouveau tuple : joueurs = ("X", "Z").

Peux-tu modifier le symbole du deuxième joueur ? Justifie.

Non : un tuple est immuable. joueurs[1] = "Z" provoque TypeError: 'tuple' object does not support item assignment.

La fonction tourJoueur demande le numéro d'une case, de 0 à 8 (de gauche à droite, puis de haut en bas), et y place le symbole du joueur. Complète-la.

def tourJoueur(joueur, grille):
    tour = [[int]](input("Sur quelle case veux-tu jouer ? (0 à 8) "))
    grille[[[tour // 3|tour//3]]][[[tour % 3|tour%3]]] = joueur

input renvoie toujours un texte : il faut le changer en nombre entier.

La case 5 est sur la ligne 1, colonne 2 : 5 // 3 = 1 et 5 % 3 = 2.

def tourJoueur(joueur, grille):
    tour = int(input("Sur quelle case veux-tu jouer ? (0 à 8) "))
    grille[tour // 3][tour % 3] = joueur

int change le texte saisi en nombre. La grille est une liste de listes : il faut deux indices, la ligne (tour // 3) et la colonne (tour % 3). Avec la saisie 5, le X va en grille[1][2].

Complète les trous : chaque fonction renvoie le symbole gagnant s'il y en a un, sinon False.

def ligneGagnante(grille, ligne):

        return grille[0][colonne]

def diagonalGagnante(grille):
    if [[grille[0][0] |grille[2][2] ]] == [[grille[1][1] ]] == [[grille[2][2] |grille[0][0] ]]:
        return grille[0][0]

Pour la colonne, c'est le premier indice (la ligne) qui change : 0, 1, 2.

Les deux diagonales passent par le centre, grille[1][1].

Que se passe-t-il pour une ligne encore vide : " " == " " == " " ?

"X" ou "O" si la ligne est gagnante, False sinon… et " " pour une ligne encore vide, car trois espaces sont égaux ! Le programme doit donc vérifier que le symbole renvoyé n'est pas une case vide.

À quoi sert la fonction len ?

  • Elle renvoie le dernier élément d'une liste.
  • Elle renvoie le nombre d'éléments d'une liste (sa longueur).
  • Elle renvoie le dernier indice d'une liste.
  • Elle ajoute une case à une liste.

4. Rappels sur les dictionnaires

joueurs = {"Lagon": (4, 15),
           "Corail": (6, 15),
           "Manta": (11, 20),
           "Tortue": (19, 30)}

def meilleurRatio(joueurs):
    meilleur = None
    rmax = 0
    for n, (v, j) in joueurs.items():
        if v/j > rmax:
            rmax = v/j
            meilleur = n
    return meilleur

Le dictionnaire joueurs a pour clé le pseudo d'un·e joueur·euse et pour valeur un tuple (nombre de parties gagnées, nombre de parties jouées). La fonction meilleurRatio cherche le meilleur ratio de victoires.

Quelles sont les clés du dictionnaire joueurs ?

  • "Lagon", "Corail", "Manta" et "Tortue"
  • Les tuples (4, 15), (6, 15)…
  • Les nombres 4, 6, 11 et 19
  • joueurs

Dans {clé: valeur}, la clé est avant les deux-points.

Les clés sont les quatre pseudos : "Lagon", "Corail", "Manta", "Tortue".

Que vaut joueurs["Tortue"][0], et à quoi cela correspond-il ?

  • 30 : le nombre de parties jouées par Tortue.
  • 19 : le nombre de parties gagnées par Tortue.
  • (4, 15) : la valeur du premier joueur.
  • "T" : la première lettre de la clé.

joueurs["Tortue"] vaut (19, 30) ; puis [0] prend son premier élément.

joueurs["Tortue"] vaut (19, 30), et [0] donne 19 : Tortue a gagné 19 parties.

À quoi correspond joueurs["Lagon"][1] + joueurs["Corail"][1] + joueurs["Manta"][1] + joueurs["Tortue"][1] ?

  • Au nombre total de victoires (40).
  • Au total des parties jouées par les quatre (80).
  • Au plus grand nombre de parties jouées (30).
  • Aux parties du deuxième joueur, Corail (15).

Pour chaque pseudo, [1] est le deuxième nombre du tuple.

15 + 15 + 20 + 30 = 80 parties jouées en tout, en additionnant celles de chacun·e. (Une partie à deux y compte deux fois, une fois pour chaque joueur·euse.)

À quoi correspondent les variables n, v et j de la fonction meilleurRatio ?

  • n : le pseudo ; v : les parties gagnées ; j : les parties jouées.
  • n : un numéro ; v : la valeur ; j : le joueur.
  • n : le pseudo ; v : les parties jouées ; j : les parties gagnées.
  • n : le dictionnaire ; v et j : deux joueurs.

joueurs.items() donne des paires (clé, valeur), et la valeur est un tuple.

for n, (v, j) in joueurs.items() : n reçoit la clé (le pseudo) ; le tuple valeur est découpé en v (parties gagnées) et j (parties jouées). v/j est donc le ratio de victoires.

Que renvoie meilleurRatio(joueurs) ?

Manta a gagné 11 parties sur 20 (0,55). Compare avec 19 sur 30.

Calcule le ratio de chacun·e : victoires divisées par parties jouées.

Lagon : 4/15, environ 0,27 ; Corail : 6/15 = 0,4 ; Manta : 11/20 = 0,55 ; Tortue : 19/30, environ 0,63. La fonction renvoie "Tortue".

En cas d'égalité de ratio, quel·le joueur·euse la fonction renvoie-t-elle ?

  • Le premier ou la première rencontré·e dans le dictionnaire.
  • Le dernier ou la dernière rencontré·e.
  • Tous les ex æquo, dans une liste.
  • Celui ou celle qui a joué le plus de parties.

La comparaison est v/j > rmax : strictement plus grand.

Avec >, un ratio égal ne remplace pas le meilleur : la fonction garde le premier ou la première rencontré·e, dans l'ordre du dictionnaire. Avec >=, ce serait le dernier ou la dernière.

Un tuple ne se modifie pas : on remplace toute la valeur, joueurs["Tortue"] = (…, …).

Tortue : une victoire et une partie de plus. Lagon : une partie de plus seulement.

joueurs = {"Lagon": (4, 15),
           "Corail": (6, 15),
           "Manta": (11, 20),
           "Tortue": (19, 30)}

# Tortue gagne une partie contre Lagon
v, j = joueurs["Tortue"]
joueurs["Tortue"] = (v + 1, j + 1)
v, j = joueurs["Lagon"]
joueurs["Lagon"] = (v, j + 1)
print(joueurs)

On ne peut pas écrire joueurs["Tortue"][0] += 1 : le tuple est immuable. On remplace donc la valeur par un nouveau tuple. Écrire directement joueurs["Tortue"] = (20, 31) marche aussi, mais seulement pour ces nombres-là.

Mémo

Liste [ ] : modifiable, deux indices pour une liste de listes, grille[ligne][colonne]. Tuple ( ) : immuable.

Dictionnaire {clé: valeur} : for cle, valeur in d.items() le parcourt ; d[cle] = … remplace une valeur.
