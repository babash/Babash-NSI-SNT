Exercice 3 (6 points) : simuler un ordonnanceur

Sujet du bac 2024, Amérique du Nord, jour 1 (24-NSIJ1AN1), exercice 1, 6 points. Le sujet d'origine (PDF).

Cet exercice porte sur la programmation Python, la programmation orientée objet, les structures de données (file), l'ordonnancement et l'interblocage.

On s'intéresse aux processus et à leur ordonnancement au sein d'un système d'exploitation. On considère ici qu'on utilise un monoprocesseur.

1. Citer les trois états dans lesquels un processus peut se trouver.

  • prêt
  • élu
  • compilé
  • bloqué
  • enregistré

Un processus attend son tour, s'exécute, ou attend une ressource.

Prêt (il attend le processeur), élu (il s'exécute), bloqué (il attend une ressource).

1. Citer les trois états dans lesquels un processus peut se trouver.

On veut simuler cet ordonnancement avec des objets. Pour ce faire, on dispose déjà de la classe Processus dont voici la documentation :

  • p = Processus(nom: str, duree: int) : crée un processus de nom <nom> et de durée <duree> (exprimée en cycles d'ordonnancement) ;
  • p.execute_un_cycle() : exécute le processus donné pendant un cycle ;
  • p.est_fini() : renvoie True si le processus est terminé, False sinon.

Pour simplifier, on ne s'intéresse pas aux ressources qu'un processus pourrait acquérir ou libérer.

2. Citer les deux seuls états possibles pour un processus dans ce contexte.

  • prêt
  • élu
  • bloqué

Qu'est-ce qui fait passer un processus à l'état bloqué ? Est-ce possible ici ?

Prêt et élu : on ne s'occupe pas des ressources, donc aucun processus n'attend une ressource, donc aucun n'est bloqué.

Pour mettre en place l'ordonnancement, on décide d'utiliser une file, instance de la classe File ci-dessous.

class File:
    def __init__(self):
        """ Crée une file vide """
        self.contenu = []

    def enfile(self, element):
        """ Enfile element dans la file """
        self.contenu.append(element)

    def defile(self):
        """ Renvoie le premier élément de la file et l'enlève de la file """
        return self.contenu.pop(0)

    def est_vide(self):
        """ Renvoie True si la file est vide, False sinon """
        return self.contenu == []

On se propose d'ordonnancer les processus avec une méthode du type tourniquet telle qu'à chaque cycle :

  • si un nouveau processus est créé, il est mis dans la file d'attente ;
  • ensuite, on défile un processus de la file d'attente et on l'exécute pendant un cycle ;
  • si le processus exécuté n'est pas terminé, on le replace dans la file.

class Ordonnanceur:

    def __init__(self):
        self.temps = 0
        self.file = File()

    def ajoute_nouveau_processus(self, proc):
        '''Ajoute un nouveau processus dans la file de
        l'ordonnanceur. '''
        [[self.file.enfile(proc)]]

    def tourniquet(self):
        '''Effectue une étape d'ordonnancement et renvoie le nom
        du processus élu.'''
        self.temps += 1
        if not self.file.est_vide():
            proc = [[self.file.defile()]]
            [[proc.execute_un_cycle()]]
            if not proc.est_fini():
                [[self.file.enfile(proc)|self.ajoute_nouveau_processus(proc)]]
            return proc.nom
        else:
            return None

L'ordonnanceur range ses processus dans self.file : utilise les méthodes de la classe File.

Dans tourniquet : on défile, on exécute un cycle, et on renfile si le processus n'est pas fini.

Ligne 10 : self.file.enfile(proc) ; ligne 17 : proc = self.file.defile() ; ligne 18 : proc.execute_un_cycle() ; ligne 20 : self.file.enfile(proc).

7. Montrer que l'ordre d'exécution donné en exemple aboutit à une situation d'interblocage.

Pour vérifier ici : coche les processus qui s'attendent mutuellement. L'explication complète va sur ta feuille.

  • A
  • B
  • C
  • D

Suis la figure 1 : à chaque fois qu'un processus est élu, il fait l'instruction suivante de sa colonne. Note qui détient le fichier et le clavier.

Cycle 0 : D acquiert le fichier. Cycle 2 : B acquiert le clavier. Que se passe-t-il au cycle 3 pour D, puis au cycle 5 pour B ?

D acquiert le fichier (cycle 0) et calcule (cycle 1). B acquiert le clavier (cycle 2). Au cycle 3, D demande le clavier, détenu par B : D est bloqué. Au cycle 5, B demande le fichier, détenu par D : B est bloqué. B et D s'attendent mutuellement : chacun détient la ressource dont l'autre a besoin et ne la libérera jamais. C'est un interblocage. Mots attendus : détient, attend, bloqué, attente circulaire.

7. Montrer que l'ordre d'exécution donné en exemple aboutit à une situation d'interblocage.

Mémo

Processus : un programme en cours d'exécution, avec un PID. États : prêt, élu, bloqué. ps les liste, kill en arrête un.

Ordonnancement : par priorité, le plus prioritaire s'exécute (et peut en suspendre un autre) ; par tourniquet, chacun son tour pendant un quantum, puis retour au bout de la file. Fais toujours un tableau : cycle, file, élu.

Interblocage : une attente en cercle. X détient R1 et attend R2, Y détient R2 et attend R1. Pour l'éviter : demander les ressources toujours dans le même ordre.
