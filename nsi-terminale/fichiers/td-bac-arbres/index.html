Exercice 1 : la somme d'un arbre (4 points)

Bac 2022, Métropole, jour 1 (sujet 22-NSIJ1ME1), exercice 4, 4 points. Sujet d'origine (PDF).

Cet exercice, composé de deux parties A et B, porte sur le parcours des arbres binaires, le principe “diviser pour régner” et la récursivité.

Cet exercice traite du calcul de la somme d’un arbre binaire. Cette somme consiste à additionner toutes les valeurs numériques contenues dans les nœuds de l’arbre.

L’arbre utilisé dans les parties A et B est le suivant :

Partie A : Parcours d’un arbre

1. Donner la somme de l’arbre précédent. Justifier la réponse en explicitant le calcul qui a permis de l’obtenir.

Calcul : …………………………………………………………………………

Tu as oublié la racine : elle compte aussi.

Tu n'as additionné que les feuilles. La somme prend tous les nœuds.

L'arbre a 7 nœuds. Additionne les 7 valeurs, niveau par niveau.

Racine : 3. Niveau 1 : 6 et 2. Niveau 2 : 7, 4, 9 et 1.

3 + 6 + 2 + 7 + 4 + 9 + 1 = 32. Pour justifier, on écrit le calcul avec toutes les valeurs.

2. Indiquer la lettre correspondante aux noms ‘racine’, ‘feuille’, ‘nœud’, ‘SAG’ (Sous Arbre Gauche) et ‘SAD’ (Sous Arbre Droit). Chaque lettre A, B, C, D et E devra être utilisée une seule fois.

Écris une lettre dans chaque case.

racine  = "[[A|a]]"
feuille = "[[C|c]]"
noeud   = "[[B|b]]"
SAG     = "[[D|d]]"
SAD     = "[[E|e]]"

La racine est le nœud du haut. Une feuille n'a pas d'enfant.

D et E entourent chacun tout un groupe de nœuds : ce sont des sous-arbres. Lequel est à gauche ?

Racine : A (le 3). Feuille : C (le 7 n'a pas d'enfant). Nœud : B (le 6, qui a des enfants). SAG : D. SAD : E.

3. Parmi les quatre propositions A, B, C et D ci-dessous, donnant un parcours en largeur d’abord de l’arbre, une seule est correcte. Indiquer laquelle.

  • Proposition A : 7 - 6 - 4 - 3 - 9 - 2 - 1
  • Proposition B : 3 - 6 - 7 - 4 - 2 - 9 - 1
  • Proposition C : 3 - 6 - 2 - 7 - 4 - 9 - 1
  • Proposition D : 7 - 4 - 6 - 9 - 1 - 2 – 3

En largeur, on lit l'arbre niveau par niveau, de haut en bas.

Dans chaque niveau, on lit de gauche à droite : 3, puis 6 et 2, puis…

Proposition C : niveau 0 (3), niveau 1 (6, 2), niveau 2 (7, 4, 9, 1). Les autres propositions sont des parcours en profondeur : A infixe, B préfixe, D suffixe.

4. Écrire en langage Python la fonction somme qui prend en paramètre une liste de nombres et qui renvoie la somme de ses éléments.

Exemple : somme([1, 2, 3, 4]) est égale à 10.

def somme(liste):
    ...

Utilise un accumulateur : une variable qui vaut 0 au départ.

Parcours la liste avec for x in liste: et ajoute chaque élément à l'accumulateur. Renvoie-le après la boucle.

def somme(liste):
    total = 0
    for x in liste:
        total = total + x
    return total

Le return est après la boucle, sans décalage : sinon la fonction s'arrête au premier tour.

5. La fonction parcourir(arbre) pourrait se traduire en langage naturel par :

parcourir(A):
    L = liste_vide
    F = file_vide
    enfiler A dans F
    Tant que F n’est pas vide
        défiler S de F
        ajouter la valeur de la racine de S dans L
        Pour chaque sous arbre SA non vide de S
            enfiler SA dans F
    renvoyer L

Donner le type de parcours obtenu grâce à la fonction parcourir.

Regarde la structure utilisée : une file (premier entré, premier sorti), pas la récursivité.

Quelle structure de données utilise l'algorithme ? Une pile ou une file ?

Avec une file, on traite les nœuds dans l'ordre où on les a rencontrés : niveau par niveau.

Un parcours en largeur (d'abord). La file fait sortir les nœuds dans l'ordre où ils sont entrés : la racine, puis ses enfants, puis ses petits-enfants… Sur l'arbre de l'exercice, on obtient la proposition C de la question 3.

Partie B : Méthode ‘diviser pour régner’

6. Parmi les quatre propositions A, B, C et D ci-dessous, indiquer la seule proposition correcte. En informatique, le principe diviser pour régner signifie :

  • Proposition A : diviser une fonction en deux fonctions plus petites
  • Proposition B : utiliser plusieurs modules
  • Proposition C : séparer les informations en fonction de leur types
  • Proposition D : diviser un problème en deux problèmes plus petits et indépendants.

Pense au tri fusion : on coupe la liste en deux, on trie chaque moitié, puis on fusionne.

Proposition D. On divise le problème en sous-problèmes plus petits et indépendants, on les résout (souvent par récursivité), puis on combine leurs résultats.

7. L’arbre présenté dans le problème peut être décomposé en racine et sous arbres :

Indiquer dans l’esprit de ‘diviser pour régner’ l’égalité donnant la somme d’un arbre en fonction de la somme des sous arbres et de la valeur numérique de la racine.

Pour t'aider, complète d'abord l'égalité avec les nombres de cet arbre :

somme_SAG = [[17]]
somme_SAD = [[12]]
somme_arbre = [[3]] + somme_SAG + somme_SAD
print(somme_arbre)
32

Égalité générale : somme(arbre) = ……………………………………………………

Le SAG contient 6, 7 et 4. Le SAD contient 2, 9 et 1.

Il reste la racine : sa valeur s'ajoute aux deux sommes.

Ici : 32 = 3 + 17 + 12. En général :

somme(arbre) = valeur de la racine + somme(SAG) + somme(SAD)

Le problème « somme de l'arbre » est divisé en deux problèmes plus petits et indépendants : la somme du SAG et celle du SAD.

8. Écrire en langage Python une fonction récursive calcul_somme(arbre). Cette fonction calcule la somme de l’arbre passé en paramètre.

Les fonctions suivantes sont disponibles :

  • est_vide(arbre) : renvoie True si arbre est vide et renvoie False sinon ;
  • valeur_racine(arbre) : renvoie la valeur numérique de la racine de arbre ;
  • arbre_gauche(arbre) : renvoie le sous arbre gauche de arbre ;
  • arbre_droit(arbre) : renvoie le sous arbre droit de arbre.

Sur machine, ces fonctions sont déjà écrites dans l'éditeur, avec la classe ArbreBinaire du cours (l'arbre vide est None). Le sujet ne dit pas comment l'arbre est construit : tu n'as besoin que des quatre fonctions.

# Fourni pour tester sur machine (ce n'est pas dans le sujet) :
class ArbreBinaire:
    def __init__(self, valeur, gauche=None, droit=None):
        self.valeur = valeur
        self.gauche = gauche
        self.droit = droit

def est_vide(arbre):
    return arbre is None

def valeur_racine(arbre):
    return arbre.valeur

def arbre_gauche(arbre):
    return arbre.gauche

def arbre_droit(arbre):
    return arbre.droit

# L'arbre de l'exercice :
arbre = ArbreBinaire(3, ArbreBinaire(6, ArbreBinaire(7), ArbreBinaire(4)),
                        ArbreBinaire(2, ArbreBinaire(9), ArbreBinaire(1)))

# À toi :
def calcul_somme(arbre):
    ...

print(calcul_somme(arbre))

Cas de base : que vaut la somme d'un arbre vide ?

Sinon, utilise l'égalité de la question 7 : la valeur de la racine, plus deux appels récursifs.

Les appels : calcul_somme(arbre_gauche(arbre)) et calcul_somme(arbre_droit(arbre)).

def calcul_somme(arbre):
    if est_vide(arbre):
        return 0
    return (valeur_racine(arbre)
            + calcul_somme(arbre_gauche(arbre))
            + calcul_somme(arbre_droit(arbre)))

Le cas de base (l'arbre vide, somme 0) arrête la récursivité. Chaque appel se fait sur un sous-arbre plus petit : la fonction se termine.

Mémo

Une fonction récursive sur un arbre : un cas de base (l'arbre vide), puis des appels sur les deux sous-arbres, puis on combine leurs résultats avec la racine.

somme(arbre) = valeur de la racine + somme(SAG) + somme(SAD), et 0 pour l'arbre vide.

Parcours en largeur : une file, niveau par niveau. Parcours en profondeur (préfixe, infixe, suffixe) : la récursivité.
