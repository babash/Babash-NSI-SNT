Convention du cours : un nœud seul a une hauteur de 0, l'arbre vide de −1. Ce sujet appelle cette mesure le « niveau » et donne aussi 0 à une feuille.

Ce TD a 2 feuilles, une par exercice de bac, du plus guidé au plus proche de l'épreuve : 1. la somme d'un arbre ; 2. la plus grande somme racine-feuille (ici).

Exercice 2 : la plus grande somme racine-feuille (4 points)

Bac 2022, Amérique du Sud, jour 2 (sujet 22-NSIJ2AS1), exercice 5, 4 points. Sujet d'origine (PDF).

Cet exercice porte sur les arbres binaires, la programmation orienté objet et la récursivité

Dans un arbre binaire, chaque nœud admet au plus deux enfants, appelés sous-arbre gauche et sous-arbre droit. On considère dans cet exercice des arbres binaires étiquetés avec des nombres entiers.

On définit un chemin racine-feuille dans un tel arbre comme une liste ordonnée de nœuds telle que

  • le premier nœud est la racine ;
  • chaque nœud suivant est enfant du précédent ;
  • le dernier nœud est une feuille.

On appellera somme d’un chemin racine-feuille la somme des étiquettes des nœuds du chemin.

Enfin, la plus grande somme racine-feuille d'un arbre est la plus grande somme qu’il est possible d’obtenir en considérant tous les chemins racine-feuille de l'arbre.

1. Déterminer la plus grande somme racine-feuille de l’arbre représenté ci-dessous.

15 est la somme de plusieurs chemins, mais il y en a un plus grand. As-tu essayé tous les chemins ?

C'est la somme de tous les nœuds. Un chemin va de la racine à une seule feuille.

Un chemin s'arrête à une feuille : 2, 7, 4 n'est pas un chemin complet.

L'arbre a 5 feuilles, donc 5 chemins racine-feuille. Calcule la somme de chacun.

Par exemple, le chemin 2, 5, 8 a pour somme 15. Et le chemin qui passe par 7, puis 4 ?

Les 5 chemins : 2+7+4+2 = 15 ; 2+7+4+3 = 16 ; 2+7+1+5 = 15 ; 2+5+3+1 = 11 ; 2+5+8 = 15. La plus grande somme vaut 16.

La classe Noeud ci-dessous implémente le type abstrait d’arbre binaire.

class Noeud:
    def __init__(self, v):
        self.etiquette = v
        self.sag = None
        self.sad = None
    def niveau(self):
        if self.sag!=None and self.sad!=None:
            hg = self.sag.niveau()
            hd = self.sad.niveau()
            return 1+max(hg, hd)
        if self.sag!=None:
            return self.sag.niveau()+1
        if self.sad!=None:
            return self.sad.niveau()+1
        return 0
    def modifier_sag(self, nsag) :
        self.sag = nsag
    def modifier_sad(self, nsad) :
        self.sad = nsad

# À toi : la racine dans la variable arbre

Pour construire, on crée chaque nœud, puis on le relie à son parent. L'ordre de création ne compte pas, tant que chaque nœud existe avant d'être relié.

2. b. Que renvoie l’appel de la méthode niveau sur l’arbre ci-dessus ?

La méthode compte les arêtes du plus long chemin : une feuille renvoie 0, pas 1.

6 est le nombre de nœuds (la taille). Le niveau mesure la longueur du plus long chemin.

Une feuille (4, 1 ou 8) renvoie 0.

Le nœud 7 a deux enfants de niveau 0 : il renvoie 1 + max(0, 0). Continue jusqu'à la racine.

Feuilles : 0. Nœud 7 : 1 + max(0, 0) = 1. Nœud 5 (un seul enfant, 8) : 0 + 1 = 1. Racine 2 : 1 + max(1, 1) = 2. C'est la hauteur de l'arbre, avec la convention du cours.

Reprends les quatre cas de niveau : deux enfants, seulement un enfant gauche, seulement un enfant droit, aucun enfant (une feuille).

Une feuille renvoie sa propre étiquette. Dans les autres cas, on ajoute l'étiquette du nœud à la plus grande somme de ses enfants.

Avec deux enfants : self.etiquette + max(self.sag.pgde_somme(), self.sad.pgde_somme()).

def pgde_somme(self):
    if self.sag!=None and self.sad!=None:
        return self.etiquette + max(self.sag.pgde_somme(), self.sad.pgde_somme())
    if self.sag!=None:
        return self.etiquette + self.sag.pgde_somme()
    if self.sad!=None:
        return self.etiquette + self.sad.pgde_somme()
    return self.etiquette

Même structure que niveau : on remplace « 1 + » par « l'étiquette + », et une feuille renvoie son étiquette au lieu de 0.

Le corrigé de l'AEIF compte 0 pour un enfant absent : self.etiquette + max(somg, somd). C'est juste quand les étiquettes sont positives, comme dans le sujet ; avec des étiquettes négatives, un chemin pourrait alors s'arrêter avant une feuille.

On appelle arbre magique un arbre binaire dont toutes les sommes des chemins racine-feuille sont égales.

Un chemin est déjà complet : 5, 5, 3, 1. Sa somme donne la somme de tous les chemins.

Tous les chemins valent 14. Commence par le chemin 5, a, 4, 2 : il n'a qu'une inconnue.

Le chemin 5, 5, 3, 1 vaut 14. Donc : 5 + a + 4 + 2 = 14 donne a = 3 ; 5 + 3 + 4 + d = 14 donne d = 2 ; 5 + 3 + b + 3 = 14 donne b = 3 ; 5 + 5 + c = 14 donne c = 4.

Commence par le cas simple : une feuille est-elle magique ?

Avec deux enfants : les deux doivent être magiques et avoir la même pgde_somme().

Avec un seul enfant : l'arbre est magique si cet enfant l'est (il n'y a qu'un sous-arbre).

def est_magique(self):
    if self.sag!=None and self.sad!=None:
        return (self.sag.est_magique() and self.sad.est_magique()
                and self.sag.pgde_somme() == self.sad.pgde_somme())
    if self.sag!=None:
        return self.sag.est_magique()
    if self.sad!=None:
        return self.sad.est_magique()
    return True

Une feuille est magique (un seul chemin). Le sujet ne dit pas ce qui se passe avec un seul enfant : comme pour le corrigé de l'AEIF, l'arbre est magique si cet enfant l'est.

Mémo

Une méthode récursive dans la classe Noeud : on teste self.sag != None et self.sad != None avant d'appeler une méthode sur un enfant.

Quatre cas : deux enfants, seulement un enfant gauche, seulement un enfant droit, une feuille.

niveau = 1 + max des niveaux des enfants, et 0 pour une feuille : c'est la hauteur du cours (−1 pour l'arbre vide).
