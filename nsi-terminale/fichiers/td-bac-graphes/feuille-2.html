Exercice 2 · Visiter toutes les villes (6 points)

Sujet : baccalauréat 2024, Polynésie, jour 2 (24-NSIJ2PO1), exercice 1, partie B (questions 3 à 11), pages 2 à 5. Sujet officiel (PDF) · version de l'AEIF · corrigé de l'AEIF · second corrigé de l'AEIF.

Cet exercice porte sur les structures de données file et pile, sur les graphes et sur les algorithmes de parcours. La partie A (questions 1 et 2 : plus court chemin dans le graphe pondéré des distances) est dans le PDF d'origine : elle n'est pas reprise ici.

Une agence de voyages veut proposer un itinéraire qui permet de visiter toutes les villes. On utilise le graphe G ci-dessous, non pondéré. On l'implémente par listes d'adjacence, avec un dictionnaire : les clés sont les sommets (de type str), la valeur associée à une clé est la liste de ses voisins. Dans ce TD, on écrit les voisins dans l'ordre alphabétique (le sujet ne fixe pas l'ordre ; il en faut un pour corriger les parcours).

Écris le dictionnaire représentant le graphe de la figure 2, stocké dans la variable G. Écris chaque couple clé : valeur sur une nouvelle ligne.

G = {'Ar': [[ ['Ax', 'Mp', 'Mr', 'Ni'] ]],
     'Av': [[ ['Ax', 'Mr', 'Ni'] ]],
     'Ax': [[ ['Ar', 'Av', 'Di', 'Mr', 'Nc', 'To'] ]],
     'Di': [[ ['Ax', 'Nc'] ]],

     'Mr': [[ ['Ar', 'Av', 'Ax', 'Nc', 'To'] ]],
     'Nc': [[ ['Ax', 'Di', 'Mr', 'To'] ]],
     'Ni': [[ ['Ar', 'Av', 'Mp'] ]],
     'To': [[ ['Ax', 'Mr', 'Nc'] ]]}

Pour chaque ville, suis les arêtes qui partent de son cercle. Range les voisins dans l'ordre alphabétique : Ar, Av, Ax, Di, Mp, Mr, Nc, Ni, To.

Le graphe est non orienté : si Mp est dans la liste de Ar, alors Ar est dans la liste de Mp. Au total, les listes contiennent 32 noms (16 arêtes, comptées deux fois).

Ax a le plus de voisins (6). Les deux corrigés de l'AEIF donnent les mêmes listes, dans des ordres différents : les deux sont justes pour le sujet.

On considère une file, avec : creerFile() qui renvoie une file vide ; estVide(F) qui renvoie True si la file F est vide, False sinon ; enfiler(F, e) qui ajoute e dans la file ; defiler(F) qui renvoie l'élément en tête de la file et le retire.

On considère une pile, avec : creerPile() ; estVide(P) ; empiler(P, e) qui ajoute e au sommet de la pile ; depiler(P) qui renvoie le sommet de la pile et le retire.

Donne la signification des lettres des acronymes LIFO et FIFO.

  • LIFO : Last In, First Out (dernier entré, premier sorti) ; FIFO : First In, First Out (premier entré, premier sorti).
  • LIFO : First In, Last Out ; FIFO : Last In, First Out.
  • LIFO : Last Input, Final Output ; FIFO : First Input, Final Output.

LIFO : Last In, First Out, le dernier entré est le premier sorti. FIFO : First In, First Out, le premier entré est le premier sorti.

Donne l'acronyme désignant la structure de file.

  • FIFO
  • LIFO

Une file d'attente (à la barge, au taxi) : le premier arrivé est le premier servi. C'est FIFO.

On donne la fonction parcours :

def parcours(graphe, sommet):
    f = creerFile()
    enfiler(f, sommet)
    visite = [sommet]
    while not estVide(f):
        s = defiler(f)
        for v in graphe[s]:
            if not (v in visite):
                visite.append(v)
                enfiler(f, v)
    return visite

Donne le résultat de l'appel parcours(G, 'Av').

C'est la réponse du corrigé de l'AEIF, qui écrit les voisins dans un autre ordre. Ici, les voisins sont dans l'ordre alphabétique : ceux de Av sont Ax, Mr, Ni.

Tu as suivi un chemin le plus loin possible (profondeur). Avec une file, on visite d'abord tous les voisins de Av, puis les voisins de ces voisins.

Écris l'état de la file et de la liste visite à chaque tour. Au départ : file = [Av], visite = [Av].

Tour 1 : on défile Av, on enfile ses voisins Ax, Mr, Ni. Tour 2 : on défile Ax, on enfile ses voisins pas encore vus (Ar, Di, Nc, To)…

['Av', 'Ax', 'Mr', 'Ni', 'Ar', 'Di', 'Nc', 'To', 'Mp'] : d'abord Av, puis ses voisins (distance 1 : Ax, Mr, Ni), puis les sommets à distance 2. Tous les sommets du graphe sont visités.

Indique si la fonction parcours réalise un parcours en largeur ou en profondeur.

  • Proposition A : parcours en largeur.
  • Proposition B : parcours en profondeur.

Parcours en largeur : la file fait traiter les sommets par distance croissante depuis le départ.

La distance entre deux sommets est le nombre minimal d'arêtes d'un chemin qui les relie. Par exemple, la distance entre Mp et Nc vaut 3.

Modifie la fonction parcours pour écrire une fonction distance(graphe, sommet) : graphe est un dictionnaire en listes d'adjacence, sommet une chaîne de caractères. Elle renvoie un dictionnaire dont les clés sont les sommets du graphe, et la valeur de chaque clé la distance entre ce sommet et sommet.

# La file est fournie (ne la modifie pas).
def creerFile(): return []
def estVide(F): return len(F) == 0
def enfiler(F, e): F.append(e)
def defiler(F): return F.pop(0)

def distance(graphe, sommet):

Remplace la liste visite par un dictionnaire : au départ, {sommet: 0}. « Être visité » devient « être une clé du dictionnaire ».

Quand on découvre un voisin v du sommet s qu'on vient de défiler, sa distance est celle de s plus 1.

def distance(graphe, sommet):
    f = creerFile()
    enfiler(f, sommet)
    dist = {sommet: 0}
    while not estVide(f):
        s = defiler(f)
        for v in graphe[s]:
            if not (v in dist):
                dist[v] = dist[s] + 1
                enfiler(f, v)
    return dist

Le parcours en largeur découvre les sommets par distance croissante : la première fois qu'on atteint v, c'est par un plus court chemin. Piège : augmenter un compteur à chaque sommet défilé ne donne pas la distance.

Donne le résultat de l'appel distance(G, 'Av').

Les sommets visités par parcours(G, 'Av') à la question 14 arrivent par distance croissante.

Av est à distance 0 ; ses voisins à distance 1 ; tous les autres sommets sont voisins d'un voisin de Av.

{'Av': 0, 'Ax': 1, 'Mr': 1, 'Ni': 1, 'Ar': 2, 'Di': 2, 'Nc': 2, 'To': 2, 'Mp': 2}. Les distances ne dépendent pas de l'ordre des voisins (seul l'ordre des clés en dépend).

On considère l'algorithme suivant, écrit en pseudo-code :

créer une pile p
empiler s dans p
créer une liste visite vide
tant que p n'est pas vide
    x = dépiler p
    si x n'est pas dans la liste visite
        ajouter x à la liste visite
        pour chaque voisin v de x
            empiler v dans p
renvoyer visite

def depiler(P): return P.pop()

« Tant que p n'est pas vide » se traduit par while not estVide(p):. « x n'est pas dans la liste visite » : if not (x in visite):.

Les voisins de x sont dans G[x]. Respecte l'indentation du pseudo-code : chaque bloc décalé est un bloc Python.

def parcours2(G, s):
    p = creerPile()
    empiler(p, s)
    visite = []
    while not estVide(p):
        x = depiler(p)
        if not (x in visite):
            visite.append(x)
            for v in G[x]:
                empiler(p, v)
    return visite

Ici, on teste « déjà visité » au moment où l'on dépile : un sommet peut être empilé plusieurs fois, mais il n'est ajouté qu'une fois à visite.

Donne un résultat possible renvoyé par l'appel parcours2(G, 'Av').

Avec une pile, le dernier empilé sort en premier : après Av, on empile Ax, Mr, Ni ; c'est Ni qui est dépilé d'abord.

C'est le parcours en largeur de la question 14. Avec une pile, on part loin avant de revenir.

Écris la pile à chaque tour, le sommet à droite. Après le premier tour : pile = [Ax, Mr, Ni], visite = [Av].

On dépile Ni, on empile ses voisins Ar, Av, Mp : pile = [Ax, Mr, Ar, Av, Mp]. On dépile Mp…

['Av', 'Ni', 'Mp', 'Ar', 'Mr', 'To', 'Nc', 'Di', 'Ax'] : un parcours en profondeur. Le sujet dit « un résultat possible » car l'ordre dépend de celui des voisins : avec l'ordre du premier corrigé de l'AEIF, on obtient ['Av', 'Ax', 'Di', 'Nc', 'To', 'Mr', 'Ar', 'Mp', 'Ni'].

Mémo

Représenter : matrice d'adjacence (m[i][j] vaut 1 si i et j sont voisins) ou dictionnaire {sommet: liste des voisins}. Non orienté : chaque arête dans les deux sens.

Parcourir : en largeur avec une file (FIFO), qui donne les distances ; en profondeur avec une pile (LIFO) ou la récursivité. Toujours marquer les sommets visités.

À l'épreuve : déroule le parcours dans l'ordre des voisins donné, en écrivant la file ou la pile à chaque tour.
