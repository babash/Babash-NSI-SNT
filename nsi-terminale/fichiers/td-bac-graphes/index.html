Exercice 1 · Un groupe d'amis (6 points)

Sujet : baccalauréat 2024, Amérique du Nord, jour 1 (24-NSIJ1AN1), exercice 2, pages 6 à 8. Sujet officiel (PDF) · version de l'AEIF · corrigé de l'AEIF.

Cet exercice porte sur les graphes.

On modélise un groupe de huit ami·es par un graphe : chaque personne est un sommet, chaque amitié une arête. Les personnes sont Anas, Emma, Gabriel, Jade, Lou, Milo, Nina et Yanis. Leurs amitiés :

  • Gabriel est ami avec Jade, Yanis, Nina et Milo ;
  • Jade est amie avec Gabriel, Yanis, Emma et Lou ;
  • Yanis est ami avec Gabriel, Jade, Emma, Nina, Milo et Anas ;
  • Emma est amie avec Jade, Yanis et Nina ;
  • Nina est amie avec Gabriel, Yanis et Emma ;
  • Milo est ami avec Gabriel, Yanis et Anas ;
  • Anas est ami avec Yanis et Milo ;
  • Lou est amie avec Jade.

Partie A : matrice d'adjacence

Dessine sur ta copie ce graphe, en représentant chaque personne par la première lettre de son prénom entourée d'un cercle. Pour vérifier ton dessin : combien d'arêtes compte-t-il ?

Chaque amitié est comptée deux fois dans la liste (Gabriel avec Jade, puis Jade avec Gabriel). Une arête relie deux sommets : divise par 2.

Additionne les nombres d'ami·es de chaque personne : 4 + 4 + 6 + 3 + 3 + 3 + 2 + 1.

Chaque arête a deux extrémités : elle est comptée deux fois dans cette somme.

La somme des nombres d'ami·es vaut 26 : chaque arête est comptée deux fois, il y a donc 13 arêtes. Un dessin possible :

La matrice d'adjacence est un tableau à deux entrées : les lignes et les colonnes correspondent aux sommets, dans l'ordre de la liste sommets. La case vaut 1 si les deux personnes sont amies, 0 sinon.

sommets = ['G', 'J', 'Y', 'E', 'N', 'M', 'A', 'L']

Recopie et complète la déclaration de la matrice d'adjacence du graphe.

# sommets : G, J, Y, E, N, M, A, L
matrice_adj = [[0, 1, 1, 0, 1, 1, 0, 0],   # G
               [ [[1, 0, 1, 1, 0, 0, 0, 1]] ],   # J
               [ [[1, 1, 0, 1, 1, 1, 1, 0]] ],   # Y
               [ [[0, 1, 1, 0, 1, 0, 0, 0]] ],   # E
               [ [[1, 0, 1, 1, 0, 0, 0, 0]] ],   # N
               [ [[1, 0, 1, 0, 0, 0, 1, 0]] ],   # M
               [ [[0, 0, 1, 0, 0, 1, 0, 0]] ],   # A
               [ [[0, 1, 0, 0, 0, 0, 0, 0]] ]]   # L

Ligne J : pour chaque sommet G, J, Y, E, N, M, A, L (dans cet ordre), écris 1 si Jade est amie avec cette personne, 0 sinon. Sépare les nombres par des virgules.

Personne n'est ami avec soi-même : la case de la diagonale vaut 0. Le graphe est non orienté : la matrice est symétrique (la colonne G est égale à la ligne G).

Chaque ligne contient autant de 1 que la personne a d'ami·es. Vérification : la matrice est symétrique, et la somme de tous ses nombres vaut 26 (2 × 13 arêtes).

La fonction position(l, s) renvoie la position du sommet s dans la liste l s'il est présent, et None sinon. Le sujet ne donne pas son code.

Indique ce que renvoie chacune des instructions suivantes.

position(sommets, 'G')
position(sommets, 'Z')

Une seule des deux personnes est dans la liste. Laquelle ?

'G' est le premier élément de sommets. 'Z' n'y est pas.

position(sommets, 'G') renvoie 0 (l'indice du premier élément en Python) et position(sommets, 'Z') renvoie None.

Le sujet ne précise pas si la position commence à 0 ou à 1 : le corrigé de l'AEIF répond 1 (première position) et écrit ensuite m[pos_s-1][i]. Les deux sont acceptés, à condition d'être cohérent·e à la question suivante.

Recopie et complète le code de la fonction nb_amis(L, m, s). Elle prend en paramètres une liste L de noms de sommets, une matrice d'adjacence m et un nom de sommet s. Elle renvoie le nombre d'ami·es de s s'il est dans L, et None sinon.

def nb_amis(L, m, s):
    pos_s = [[position(L, s)]]
    if pos_s == None:
        return [[None]]
    amis = 0
    for i in range(len(m)):
        amis += [[ m[pos_s][i]|m[i][pos_s]|m[pos_s - 1][i] ]]
    return [[amis]]

Commence par chercher la ligne de s dans la matrice : c'est le rôle de position.

Le nombre d'ami·es est la somme des nombres de la ligne de s : on ajoute la case de la ligne pos_s et de la colonne i.

def nb_amis(L, m, s):
    pos_s = position(L, s)
    if pos_s == None:
        return None
    amis = 0
    for i in range(len(m)):
        amis += m[pos_s][i]
    return amis

Avec une position comptée à partir de 1 (comme dans le corrigé de l'AEIF), la ligne 7 devient amis += m[pos_s - 1][i]. La colonne m[i][pos_s] marche aussi : la matrice est symétrique.

Indique ce que renvoie l'instruction suivante.

nb_amis(sommets, matrice_adj, 'G')

C'est la somme de la ligne G de la matrice : [0, 1, 1, 0, 1, 1, 0, 0].

4 : Gabriel est ami avec Jade, Yanis, Nina et Milo.

Partie B : dictionnaire de listes d'adjacence

Dans un dictionnaire Python {c: v}, indique ce que représentent c et v.

  • c est une clé et v la valeur associée à cette clé.
  • c est une valeur et v sa clé.
  • c est un indice (0, 1, 2…) et v un élément.
  • Toujours un sommet et une arête.

c est une clé et v la valeur associée. Pour un graphe : la clé est un sommet, la valeur la liste de ses voisins.

Recopie et complète le dictionnaire de listes d'adjacence graphe pour qu'il modélise complètement le groupe d'ami·es. Écris les voisins dans l'ordre de la liste sommets, comme pour 'G'.

graphe = {'G': ['J', 'Y', 'N', 'M'],
          'J': [[ ['G', 'Y', 'E', 'L'] ]],
          'Y': [[ ['G', 'J', 'E', 'N', 'M', 'A'] ]],
          'E': [[ ['J', 'Y', 'N'] ]],
          'N': [[ ['G', 'Y', 'E'] ]],
          'M': [[ ['G', 'Y', 'A'] ]],
          'A': [[ ['Y', 'M'] ]],
          'L': [[ ['J'] ]]}

Chaque valeur est une liste entre crochets, avec les noms entre guillemets : ['G', 'Y', 'E', 'L'].

Tu peux aussi lire les 1 de chaque ligne de la matrice de la question 2.

Chaque liste contient les ami·es de la clé, dans l'ordre G, J, Y, E, N, M, A, L. Vérification : chaque amitié apparaît dans les deux listes (Lou est dans la liste de Jade, Jade dans celle de Lou).

Écris le code de la fonction nb_amis(d, s), qui prend en paramètres un dictionnaire de listes d'adjacence d et un nom de sommet s, et renvoie le nombre d'ami·es de s. On suppose que s est bien dans d.

La valeur d[s] est la liste des ami·es de s.

La fonction len donne la longueur d'une liste.

def nb_amis(d, s):
    return len(d[s])

Avec un dictionnaire, plus besoin de parcourir une ligne : la liste des voisins est déjà là, sa longueur est le nombre d'ami·es.

Milo, Gabriel et Yanis se sont fâché·es, tandis qu'Anas s'est fâché avec Yanis. Le réseau devient :

graphe = {'G': ['J', 'N'],
          'J': ['G', 'Y', 'E', 'L'],
          'Y': ['J', 'E', 'N'],
          'E': ['J', 'Y', 'N'],
          'N': ['G', 'Y', 'E'],
          'M': ['A'],
          'A': ['M'],
          'L': ['J']}

On appelle cercle d'amis d'une personne toute personne atteignable dans le graphe à partir d'elle.

Donne la liste du cercle d'amis de Lou : coche toutes les personnes qui en font partie.

  • Jade
  • Gabriel
  • Yanis
  • Emma
  • Nina
  • Milo
  • Anas

Pars de Lou : son seul voisin est Jade. Puis ajoute les voisins de Jade, puis leurs voisins…

Milo et Anas ne sont plus reliés qu'entre eux.

Lou → Jade → Gabriel, Yanis, Emma → Nina. Le cercle d'amis de Lou : Jade, Gabriel, Yanis, Emma, Nina. Milo et Anas forment un autre morceau du graphe : il n'est plus connexe.

Recopie et complète le code de la fonction parcours_en_profondeur(d, s), qui renvoie la liste des sommets issue du parcours en profondeur du graphe modélisé par d à partir du sommet s.

def parcours_en_profondeur(d, s, visites = []):
    [[visites.append(s)|visites += [s] ]]
    for v in d[s]:
        [[if v not in visites:|if not v in visites:|if not (v in visites):]]
            parcours_en_profondeur(d, v, visites)
    [[return visites]]

Ligne 2 : on marque le sommet s comme visité, en l'ajoutant à la liste.

Ligne 4 : on ne relance le parcours que sur un voisin qui n'a pas encore été visité. Ligne 6 : la fonction renvoie la liste.

def parcours_en_profondeur(d, s, visites = []):
    visites.append(s)
    for v in d[s]:
        if v not in visites:
            parcours_en_profondeur(d, v, visites)
    return visites

Depuis Lou, l'appel donne ['L', 'J', 'G', 'N', 'Y', 'E'] : on va le plus loin possible (L, J, G, N, Y, E), puis on revient en arrière.

Attention, piège classique : la valeur par défaut visites = [] est créée une seule fois. Un second appel sans troisième paramètre repart de la liste du premier. On écrit plutôt visites=None, puis if visites is None: visites = [].

Mémo

Représenter : matrice d'adjacence (m[i][j] vaut 1 si i et j sont voisins) ou dictionnaire {sommet: liste des voisins}. Non orienté : chaque arête dans les deux sens.

Parcourir : en largeur avec une file (FIFO), qui donne les distances ; en profondeur avec une pile (LIFO) ou la récursivité. Toujours marquer les sommets visités.

À l'épreuve : déroule le parcours dans l'ordre des voisins donné, en écrivant la file ou la pile à chaque tour.
