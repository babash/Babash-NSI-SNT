1. Un arbre en programmation objet

On peut écrire un arbre binaire en Python avec la programmation objet. On crée une classe ArbreBinaire :

class ArbreBinaire:
    def __init__(self, valeur, gauche = None, droit = None):
        self.valeur = valeur  # Étiquette
        self.gauche = gauche  # Sous-arbre gauche
        self.droit = droit    # Sous-arbre droit

Dans toute la suite, on garde cette classe. Un sous-arbre vide vaut None.

3. Parcours infixe et suffixe

Complète la méthode du parcours infixe. Sur l'arbre I, elle doit afficher B-D-I-K-C-E-Z-.

class ArbreBinaire:
    def __init__(self, valeur, gauche = None, droit = None):
        self.valeur = valeur
        self.gauche = gauche
        self.droit = droit

    def parcours_infixe(self):
        if self.gauche is not None:
            self.gauche.parcours_infixe()
        print(self.valeur, end='-')
        if [[self.droit is not None|self.droit != None]]:
            [[self.droit.parcours_infixe()]]

A = ArbreBinaire
I = A("I", A("D", A("B")), A("E", A("K", None, A("C")), A("Z")))
I.parcours_infixe()
B-D-I-K-C-E-Z-

La partie droite est le miroir de la partie gauche.

        if self.droit is not None:
            self.droit.parcours_infixe()

Infixe : sous-arbre gauche, puis le nœud, puis sous-arbre droit.

Que faut-il changer pour transformer ce code en parcours suffixe ?

  • Placer le print après les deux appels récursifs.
  • Placer le print avant les deux appels.
  • Échanger gauche et droit.
  • Remplacer end='-' par end=''.

Suffixe : on visite les deux sous-arbres, puis le nœud.

    def parcours_suffixe(self):
        if self.gauche is not None:
            self.gauche.parcours_suffixe()
        if self.droit is not None:
            self.droit.parcours_suffixe()
        print(self.valeur, end='-')

On déplace le print à la fin (et on renomme la méthode et ses appels). Sur I : B-D-C-K-Z-E-I-.

Que faut-il changer pour transformer le code ci-dessus en parcours suffixe ?

Placer print(self.valeur, end='-') après les deux appels récursifs (gauche puis droit), et renommer la méthode et ses appels parcours_suffixe. Sur I : B-D-C-K-Z-E-I-.
