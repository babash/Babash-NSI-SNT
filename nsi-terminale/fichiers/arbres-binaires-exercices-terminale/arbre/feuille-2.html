1. Code mystère

Convention : la profondeur de la racine est 0 ; un arbre réduit à un seul nœud a une hauteur de 0.

def mystere(self):
    if self.gauche is None and self.droit is None:
        return 0
    elif self.gauche is None and self.droit is not None:
        return 1 + self.droit.mystere()
    elif self.gauche is not None and self.droit is None:
        return 1 + self.gauche.mystere()
    else:
        return 1 + max(self.droit.mystere(), self.gauche.mystere())

Que renvoie la méthode mystere pour l'arbre dessiné ci-dessus (de racine 20) ?

Une feuille renvoie 0, pas 1 : compte les arêtes du plus long chemin, pas les nœuds.

C'est le nombre de nœuds. Ici, on prend le max des deux côtés : on ne suit qu'un chemin.

Une feuille renvoie 0. Un nœud renvoie 1 de plus que le plus grand résultat de ses enfants.

2 renvoie 0, donc 4 renvoie 1, donc 7 renvoie 2…

Le plus long chemin de la racine à une feuille est 20 → 7 → 4 → 2 (ou 20 → 53 → 46 → 29…) : 3 arêtes. La méthode renvoie 3.

Cet algorithme est-il récursif ?

  • Oui : mystere s'appelle elle-même sur les sous-arbres.
  • Non : il n'y a pas de boucle for ni de boucle while.
  • Oui : il utilise max, qui compare les deux sous-arbres.
  • Non : une méthode d'une classe ne peut pas être récursive.

Cherche le nom mystere à l'intérieur de la méthode.

Oui. self.droit.mystere() et self.gauche.mystere() appellent la même méthode sur un sous-arbre plus petit ; le cas de base est la feuille, qui renvoie 0.

Quel nouveau nom donnerais-tu à la méthode mystere ?

  • hauteur : la longueur du plus long chemin de la racine à une feuille.
  • taille : le nombre de nœuds de tout l'arbre, racine et feuilles comprises.
  • nb_feuilles : le nombre de nœuds sans enfant, au bout des branches.
  • profondeur_racine : la profondeur de la racine de l'arbre.

hauteur : une feuille a une hauteur 0, et un nœud a une hauteur de 1 de plus que le plus haut de ses sous-arbres.

La taille d'un arbre, c'est 1 (le nœud lui-même) plus la taille du sous-arbre gauche plus celle du sous-arbre droit.

Attention aux sous-arbres vides : on n'appelle .taille() que si le sous-arbre n'est pas None.

class ArbreBinaire:
    def __init__(self, valeur, gauche = None, droit = None):
        self.valeur = valeur
        self.gauche = gauche
        self.droit = droit

    def taille(self):
        t = 1
        if self.gauche is not None:
            t = t + self.gauche.taille()
        if self.droit is not None:
            t = t + self.droit.taille()
        return t

Contrairement à mystere, on additionne les deux côtés au lieu de prendre le plus grand.

class ArbreBinaire:
    def __init__(self, valeur, gauche = None, droit = None):
        self.valeur = valeur
        self.gauche = gauche
        self.droit = droit

    def somme(self):
        s = self.valeur
        if self.gauche is not None:
            s = s + self.gauche.somme()
        if self.droit is not None:
            s = s + self.droit.somme()
        return s

Pour l'arbre de racine 20 : arbre.droit.somme() vaut 53 + 46 + 29 + 80 + 74 = 282.

Mémo

Hauteur : 1 + max des deux côtés. Taille : 1 + somme des deux côtés.

Méthode récursive sur un arbre : un cas de base (la feuille ou le vide), puis un appel sur chaque sous-arbre non vide.
