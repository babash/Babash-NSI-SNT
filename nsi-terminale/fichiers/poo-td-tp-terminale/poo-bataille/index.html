La classe CarteBataille

Exercice préparatoire

Cours-quiz

Nom et prénom :Classe :

Objectif : créer une classe CarteBataille qui simule l'affrontement direct de deux cartes.

Je sais :

  • écrire une classe et son constructeur __init__ ;
  • écrire une méthode qui compare l'objet self à un autre objet ;
  • créer des objets (instancier) dans le programme principal ;
  • afficher les attributs d'un objet et le résultat d'une méthode.

30 minutes · 7 questions · seul·e ou en binôme

Au jeu de la bataille, chaque joueur ou joueuse retourne une carte : la plus forte l'emporte. Une carte a une valeur, un entier de 2 à 14 (11 pour le valet, 12 pour la dame, 13 pour le roi, 14 pour l'as), et un symbole, une chaîne de caractères parmi "Coeur", "Carreau", "Trèfle" et "Pique".

1. Définir la classe et son constructeur

Écris la première ligne, celle qui crée une classe nommée CarteBataille.

Il manque les deux-points à la fin de la ligne : le bloc de la classe suit.

Le mot-clé def crée une fonction. Pour une classe, c'est un autre mot-clé.

Le mot-clé est class, suivi du nom de la classe.

class CarteBataille:

Comme pour def ou if, la ligne finit par : et le contenu de la classe est décalé de 4 espaces.

Écris le constructeur __init__ de la classe. Il prend deux paramètres, valeur et symbole, et les range dans deux attributs du même nom.

class CarteBataille:
    # le constructeur
    ...

Le constructeur s'écrit comme une méthode : def __init__(self, valeur, symbole):.

Dans son bloc, on range chaque paramètre dans un attribut : self.valeur = valeur.

class CarteBataille:
    # le constructeur
    def __init__(self, valeur, symbole):
        self.valeur = valeur
        self.symbole = symbole

valeur seul est le paramètre, qui disparaît à la fin de __init__ ; self.valeur est l'attribut, gardé dans l'objet.

2. La méthode de comparaison

Écris la méthode battre(self, autre_carte) : elle renvoie True si la valeur de la carte self est strictement supérieure à celle de autre_carte, et False sinon.

class CarteBataille:
    def __init__(self, valeur, symbole):
        self.valeur = valeur
        self.symbole = symbole

    def battre(self, autre_carte):
        ...

La valeur de la carte est self.valeur ; celle de l'autre carte, autre_carte.valeur.

« Strictement supérieure » : >, pas >=.

class CarteBataille:
    def __init__(self, valeur, symbole):
        self.valeur = valeur
        self.symbole = symbole

    def battre(self, autre_carte):
        return self.valeur > autre_carte.valeur

La comparaison donne déjà True ou False : on la renvoie directement. Un if … else avec deux return est juste aussi.

3. Le programme principal

Écris l'instruction qui crée (instancie) une carte joueur1 : le 10 de trèfle.

L'ordre compte : le constructeur attend d'abord la valeur, puis le symbole.

Le symbole est une chaîne de caractères : il faut des guillemets.

On appelle la classe avec les deux valeurs : CarteBataille(valeur, symbole).

joueur1 = CarteBataille(10, "Trèfle")

Écris l'instruction qui crée une carte joueur2 : le 13 de cœur (un roi).

La valeur est un entier : le roi vaut 13. Et la valeur vient en premier.

Le roi vaut 13 ; le symbole s'écrit "Coeur".

joueur2 = CarteBataille(13, "Coeur")

Pour afficher la carte, Lina écrit print(joueur1). Qu'affiche Python ?

  • Une ligne comme <__main__.CarteBataille object at 0x7fcb3f1370e0>
  • 10 de Trèfle
  • joueur1
  • Une erreur TypeError

Python ne connaît pas la façon d'écrire une carte : il décrit l'objet comme il peut (sa classe et son adresse en mémoire).

Python affiche la classe de l'objet et son adresse en mémoire (elle change à chaque lancement). Pour afficher la carte, on affiche ses attributs : print(joueur1.valeur, "de", joueur1.symbole).

Sous la classe, écris le programme principal : il crée joueur1 et joueur2, affiche les deux cartes, puis utilise la méthode battre pour afficher Joueur 1 gagne ! ou Joueur 2 gagne !. On doit voir exactement :

10 de Trèfle13 de CoeurJoueur 2 gagne !
class CarteBataille:
    def __init__(self, valeur, symbole):
        self.valeur = valeur
        self.symbole = symbole

    def battre(self, autre_carte):
        return self.valeur > autre_carte.valeur

# programme principal

10 de Trèfle
13 de Coeur
Joueur 2 gagne !

Pour afficher une carte : print(joueur1.valeur, "de", joueur1.symbole).

joueur1.battre(joueur2) vaut True si le joueur 1 gagne : utilise-le dans un if … else.

class CarteBataille:
    def __init__(self, valeur, symbole):
        self.valeur = valeur
        self.symbole = symbole

    def battre(self, autre_carte):
        return self.valeur > autre_carte.valeur

# programme principal
joueur1 = CarteBataille(10, "Trèfle")
joueur2 = CarteBataille(13, "Coeur")
print(joueur1.valeur, "de", joueur1.symbole)
print(joueur2.valeur, "de", joueur2.symbole)
if joueur1.battre(joueur2):
    print("Joueur 1 gagne !")
else:
    print("Joueur 2 gagne !")

Le message dépend de ce que renvoie battre : avec deux autres cartes, le même programme donnerait le bon gagnant. (Pour deux cartes de même valeur, il y a « bataille » : ce programme simple ne le gère pas.)

Mémo

class Nom: crée la classe ; le constructeur __init__(self, …) range les paramètres dans les attributs : self.valeur = valeur.

Une méthode compare self à un autre objet : self.valeur > autre_carte.valeur. print(objet) n'affiche pas ses attributs.
