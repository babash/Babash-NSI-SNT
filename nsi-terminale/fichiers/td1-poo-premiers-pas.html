Bienvenue dans une nouvelle façon de programmer : la programmation orientée objet (POO). Au lieu de donner des instructions pas à pas, on organise le code en objets qui interagissent entre eux, comme dans le monde réel.

Paradigme de programmation : une manière de structurer et d'écrire un programme. La POO est un paradigme, tout comme la programmation que tu as utilisée jusqu'à présent.

L'essentiel 1 · Classes et objets : le plan et la voiture

À vos smartphones ! Vidéo « Les paradigmes » (NOVELCLASS) : youtube.com/watch?v=D26k0EaoyNI

Imagine que tu veux acheter une voiture.

  • Classe = le plan : pas une voiture réelle, mais le document qui dit qu'une voiture a des roues, une couleur, un moteur…
  • Objet = une voiture concrète du parking, une instance unique du plan. Toutes les voitures suivent le même plan ; chacune est un objet.
  • Une classe contient des attributs (les caractéristiques de l'objet, son état : couleur, vitesse) et des méthodes (ses comportements, des fonctions qui agissent sur l'objet, comme accelerer() ou freiner()).
  • Instanciation = créer un objet à partir du plan.

Eurêka ! La POO, c'est l'art d'organiser son code en regroupant les données (les attributs) et les actions (les méthodes) qui leur sont liées.

L'essentiel 2 · La POO en Python

À vos smartphones ! Vidéo « Le mot-clé self » (Docstring) : youtube.com/watch?v=pzxDxOD-gmw

class Voiture:                              # le plan
    # Le constructeur : les « instructions de fabrication » du plan
    def __init__(self, marque, modele, couleur):
        # Les attributs
        self.marque = marque
        self.modele = modele
        self.couleur = couleur
        self.vitesse = 0    # attribut avec une valeur par défaut

    # Une méthode
    def accelerer(self, augmentation):
        self.vitesse += augmentation
        print(f"La voiture roule à {self.vitesse} km/h.")
  • On écrit une classe avec le mot-clé class. __init__ est le constructeur : une méthode spéciale, appelée automatiquement quand on crée un objet.
  • self désigne l'objet lui-même. C'est le premier paramètre de chaque méthode ; il permet d'accéder aux attributs de l'objet (par exemple self.couleur).

        self.en_marche = True

L'essentiel 3 · Créer et utiliser des objets

Créer un objet : on appelle la classe comme une fonction.

# Création de deux objets (deux voitures)
voiture_de_ludovic = Voiture("Renault", "Clio", "bleue")
voiture_de_marine = Voiture("Peugeot", "208", "rouge")

Accès et modification : le point « . » donne accès aux attributs et aux méthodes de l'objet : voiture_de_marine.couleur (objet, point, attribut), voiture_de_ludovic.accelerer(50) (objet, point, méthode).

# Lire un attribut
print(voiture_de_ludovic.marque)    # affiche Renault
# Modifier un attribut (la rayure !)
voiture_de_marine.couleur = "rose"  # la voiture de Marine est rose
print(voiture_de_marine.couleur)    # affiche rose
# Appeler une méthode
voiture_de_ludovic.accelerer(50)    # affiche La voiture roule à 50 km/h.

Eurêka ! Chaque objet est indépendant : si tu rayes la voiture de Marine (en modifiant son attribut couleur), celle de Ludovic n'est pas touchée.

Exercice 2 · La Pascaline de Blaise Pascal (XVIIe siècle)

Suivre le code et le type de retour. Blaise Pascal a conçu une machine à calculer mécanique pour aider son père dans son travail : les machines pouvaient faire des calculs complexes.

class MachineACalculer:
    def __init__(self, createur):
        self.createur = createur
        self.compteur = 0  # le cadran d'affichage

    def ajouter(self, nombre):
        self.compteur += nombre

    def lire_resultat(self):
        return self.compteur

pascaline = MachineACalculer("Pascal")

On exécute ensuite ces lignes. Complète les commentaires : la valeur, après chaque ligne.

pascaline.ajouter(10)                       # compteur : [[10]]
pascaline.ajouter(5)                        # compteur : [[15]]
resultat_final = pascaline.lire_resultat()  # resultat_final : [[15]]
compteur_actuel = pascaline.compteur        # compteur_actuel : [[15]]

Au départ, pascaline.compteur vaut 0 ; ajouter lui ajoute le nombre reçu.

lire_resultat() renvoie la valeur de self.compteur, sans la changer.

Le compteur passe de 0 à 10, puis à 15. resultat_final reçoit ce que renvoie lire_resultat() : 15. compteur_actuel lit directement l'attribut : 15 aussi.

Quel est le type de resultat_final et de compteur_actuel ?

  • les deux sont des entiers (int)
  • un int et une méthode
  • les deux sont des chaînes (str)
  • un NoneType et un int

On a additionné 10 et 5 : quel type de nombre obtient-on ?

Les deux valent 15, un entier : int. La méthode renvoie la valeur de l'attribut, et l'attribut se lit aussi directement avec le point.

Quel est le type de resultat_final ? Et celui de compteur_actuel ?

Les deux valent 15, un entier : int. La méthode renvoie la valeur de l'attribut, et l'attribut se lit aussi directement avec le point.

Mémo

Une classe est un plan ; un objet en est une instance. __init__ crée les attributs ; self désigne l'objet. On écrit objet.attribut et objet.methode().
