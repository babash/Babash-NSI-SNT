Bienvenue dans un nouveau mode de pensée pour la programmation : la Programmation Orientée Objet (POO). Fini de donner des instructions pas à pas ! Avec la POO, on organise notre code en créant des « objets » qui interagissent entre eux, comme dans le monde réel.

Définition — Paradigme de programmation

Un paradigme de programmation est une manière de structurer et d'écrire un programme. La POO est un paradigme, tout comme la programmation que vous avez utilisée jusqu'à présent.

L'essentiel 1 Classes et objets : le plan et la voitureImaginez que vous voulez acheter une voiture…
  • Classe = le plan : pas une voiture réelle, mais le document qui définit qu'une voiture a des roues, une couleur, un moteur…
  • Objet = la voiture concrète du parking, une instance unique du plan. Toutes les voitures suivent le même plan, chacune est un objet.
  • Que contient une classe ?
  • des attributs : les caractéristiques de l'objet (son état), par exemple couleur ou vitesse ;
  • des méthodes : ses comportements, des fonctions qui agissent sur l'objet, comme accelerer() ou freiner().
  • Instanciation = créer un objet à partir du plan.
Vous avez dit Eurêka ?

La POO, c'est l'art d'organiser son code en regroupant les données (les attributs) et les actions (les méthodes) qui leur sont liées.

L'essentiel 2 La POO en Python
class Voiture:le plan    # Le constructeur : la section "Instructions de fabrication" du plan    def __init__(self, marque, modele, couleur):constructeur        # Les attributs        self.marque = marqueattributs        self.modele = modele        self.couleur = couleur        self.vitesse = 0 # Attribut avec une valeur par défaut    # Une méthode    def accelerer(self, augmentation):méthode        self.vitesse += augmentation        print(f"La voiture roule à {self.vitesse} km/h.")

On écrit une classe avec le mot-clé class. __init__ est le constructeur, une méthode spéciale appelée automatiquement quand on crée un objet.

self : désigne l'objet lui-même. C'est le premier paramètre de chaque méthode ; il permet d'accéder aux attributs de l'objet (ex. : self.couleur).
