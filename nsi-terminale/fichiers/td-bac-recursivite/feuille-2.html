Exercice : construire des chaînes avec des règles (4 points)

Bac 2022, Polynésie, jour 1 (sujet 22-NSIJ1PO1), exercice 1, 4 points. Sujet d'origine (PDF).

Cet exercice traite du thème «programmation», et principalement de la récursivité.

On rappelle qu'une chaîne de caractères peut être représentée en Python par un texte entre guillemets "" et que :

  • la fonction len renvoie la longueur de la chaîne de caractères passée en paramètre ;
  • si une variable ch désigne une chaîne de caractères, alors ch[0] renvoie son premier caractère, ch[1] le deuxième, etc. ;
  • l'opérateur + permet de concaténer deux chaînes de caractères.

Exemples :

>>> texte = "bricot"
>>> len(texte)
6
>>> texte[0]
"b"
>>> texte[1]
"r"
>>> "a" + texte
"abricot"

On s'intéresse dans cet exercice à la construction de chaînes de caractères suivant certaines règles de construction.

Règle A : une chaîne est construite suivant la règle A dans les deux cas suivants :

  • soit elle est égale à "a" ;
  • soit elle est de la forme "a"+chaine+"a", où chaine est une chaîne de caractères construite suivant la règle A.

Règle B : une chaîne est construite suivant la règle B dans les deux cas suivants :

  • soit elle est de la forme "b"+chaine+"b", où chaine est une chaîne de caractères construite suivant la règle A ;
  • soit elle est de la forme "b"+chaine+"b", où chaine est une chaîne de caractères construite suivant la règle B.

On a reproduit ci-dessous l'aide de la fonction choice du module random.

>>>from random import choice
>>>help(choice)
Help on method choice in module random:
choice(seq) method of random.Random instance
    Choose a random element from a non-empty sequence.

Traduction : « Choisit un élément au hasard dans une séquence non vide. »

La fonction A() ci-dessous renvoie une chaîne de caractères construite suivant la règle A, en choisissant aléatoirement entre les deux cas de figure de cette règle.

def A():
    if choice([True, False]):
        return "a"
    else:
        return "a" + A() + "a"

1. a. Cette fonction est-elle récursive ? Justifier.

Sur la copie, on écrit la justification. Ici, choisis-la.

  • Oui : à la ligne 5, la fonction A s'appelle elle-même.
  • Oui : elle appelle la fonction choice.
  • Non : elle n'a pas de paramètre.
  • Non : elle ne contient pas de boucle.

Lis la ligne 5 : quelle fonction y est appelée ?

Oui : la fonction A s'appelle elle-même ("a" + A() + "a"), elle est donc récursive.

1. b. La fonction choice([True, False]) peut renvoyer False un très grand nombre de fois consécutives. Expliquer pourquoi ce cas de figure amènerait à une erreur d'exécution.

Sur la copie, on rédige l'explication. Ici, choisis-la.

  • La chaîne devient trop longue pour tenir en mémoire.
  • Chaque False lance un nouvel appel de A, avant que les précédents soient finis. Les appels s'empilent ; au-delà d'environ 1 000 appels, Python s'arrête : c'est une erreur de récursion.
  • La fonction choice ne peut pas renvoyer False deux fois de suite.
  • La fonction renvoie None, et on ne peut pas ajouter None à une chaîne.

Avec False, que fait la fonction avant de renvoyer son résultat ? Combien d'appels sont alors en attente ?

Python garde chaque appel en attente dans la pile d'exécution, dont la taille est limitée (environ 1 000 appels).

Chaque False provoque un appel récursif de plus, en attente. La pile des appels dépasse sa limite : Python s'arrête. Voici le vrai message, obtenu en forçant choice à renvoyer toujours False :

Traceback (most recent call last):
  File "regles.py", line 10, in <module>
    A()
    ~^^
  File "regles.py", line 8, in A
    return "a" + A() + "a"
                 ~^^
  File "regles.py", line 8, in A
    return "a" + A() + "a"
                 ~^^
  File "regles.py", line 8, in A
    return "a" + A() + "a"
                 ~^^
  [Previous line repeated 994 more times]
  File "regles.py", line 5, in A
    if choice([True, False]):
       ~~~~~~^^^^^^^^^^^^^^^
RecursionError: maximum recursion depth exceeded

RecursionError : la profondeur maximale de récursion est dépassée (« maximum recursion depth exceeded »).

Dans la suite, on considère une deuxième version de la fonction A. À présent, la fonction prend en paramètre un entier n tel que, si la valeur de n est négative ou nulle, la fonction renvoie "a". Si la valeur de n est strictement positive, elle renvoie une chaîne de caractères construite suivant la règle A avec un n décrémenté de 1, en choisissant aléatoirement entre les deux cas de figure de cette règle.

2. a. Recopier sur la copie et compléter aux emplacements des points de suspension ... le code de cette nouvelle fonction A.

def A(n):
    if [[n <= 0|n<=0|n < 1|n<1|0 >= n|0>=n]] or choice([True, False]) :
        return "a"
    else:
        return "a" + [[A(n - 1)|A(n-1)]] + "a"

Première case : la condition « n est négatif ou nul ».

Deuxième case : un appel récursif avec n décrémenté de 1.

def A(n):
    if n <= 0 or choice([True, False]) :
        return "a"
    else:
        return "a" + A(n - 1) + "a"

2. b. Justifier le fait qu'un appel de la forme A(n) avec n un nombre entier positif inférieur à 50, termine toujours.

Sur la copie, on rédige la justification. Ici, choisis-la.

  • Parce que choice finit toujours par renvoyer True.
  • À chaque appel, n diminue de 1. Au pire, après n appels, n vaut 0 et la fonction renvoie "a" sans s'appeler : moins de 51 appels, loin de la limite de Python.
  • Parce que la fonction s'arrête dès que n vaut 50.
  • Parce que la fonction n'est plus récursive.

Comment évolue n d'un appel au suivant ? Que se passe-t-il quand n atteint 0 ?

Soit choice renvoie True et l'appel s'arrête ; soit on rappelle A avec n - 1. Au plus n + 1 appels (51 au plus), car quand n <= 0, le cas de base renvoie "a". On reste loin de la limite d'environ 1 000 appels.

On donne ci-après le code de la fonction récursive B qui prend en paramètre un entier n et qui renvoie une chaîne de caractères construite suivant la règle B.

def B(n):
    if n <= 0 or choice([True, False]):
        return "b" + A(n-1) + "b"
    else:
        return "b" + B(n-1) + "b"

On admet que :

  • les appels A(-1) et A(0) renvoient la chaîne "a" ;
  • l’appel A(1) renvoie la chaîne "a" ou la chaîne "aaa" ;
  • l’appel A(2) renvoie la chaîne "a", la chaîne "aaa" ou la chaîne "aaaaa".

3. Donner toutes les chaînes possibles renvoyées par les appels B(0), B(1) et B(2).

3. L'appel B(0).

Avec la règle B, la chaîne commence et finit par "b".

N'oublie pas le "b" de la fin et ce qu'il y a entre les deux : A(n-1).

Avec n = 0, la condition n <= 0 est vraie : on calcule "b" + A(-1) + "b".

B(0) renvoie toujours "b" + A(-1) + "b", soit "bab".

3. L'appel B(1) : coche toutes les chaînes possibles.

  • "bab"
  • "bbabb"
  • "baaab"
  • "bbbabbb"

Deux cas : choice renvoie True (on calcule "b" + A(0) + "b") ou False (on calcule "b" + B(0) + "b").

Cas True : "b" + A(0) + "b" = "bab". Cas False : "b" + B(0) + "b" = "bbabb". Vérifié en énumérant les deux cas par programme.

3. L'appel B(2) : coche toutes les chaînes possibles.

  • "bab"
  • "baaab"
  • "baaaaab"
  • "bbabb"
  • "bbbabbb"
  • "bbbb"

Cas True : "b" + A(1) + "b", et A(1) a deux résultats possibles.

Cas False : "b" + B(1) + "b", et tu connais les deux résultats de B(1).

Cas True : "bab" ou "baaab". Cas False : "b" + "bab" + "b" = "bbabb" ou "b" + "bbabb" + "b" = "bbbabbb". Quatre chaînes en tout (vérifié par programme).

On suppose maintenant qu'on dispose d'une fonction raccourcir qui prend comme paramètre une chaîne de caractères de longueur supérieure ou égale à 2, et renvoie la chaîne de caractères obtenue à partir de la chaîne initiale en lui ôtant le premier et le dernier caractère.

Par exemple :

>>> raccourcir("abricot")
"brico"
>>> raccourcir("ab")
""

4. a. Recopier sur la copie et compléter les points de suspension ... du code de la fonction regleA ci-dessous pour qu'elle renvoie True si la chaîne passée en paramètre est construite suivant la règle A, et False sinon.

def regleA(chaine):
    n = len(chaine)
    if n >= 2:
        return chaine[0] == "a" and chaine[n-1] == "a" and regleA([[raccourcir(chaine)]])
    else:
        return chaine == [["a"|'a']]

Pour une chaîne longue, on vérifie le premier et le dernier caractère, puis on vérifie ce qu'il reste au milieu, avec la même fonction.

Pour une chaîne de 0 ou 1 caractère, une seule chaîne suit la règle A.

        return chaine[0] == "a" and chaine[n-1] == "a" and regleA(raccourcir(chaine))
    else:
        return chaine == "a"

Remarque sur le sujet : la ligne du return y est coupée après and. En Python, une ligne coupée ainsi provoque une erreur de syntaxe : on l'écrit sur une seule ligne, ou entre parenthèses.

4. b. Écrire le code d’une fonction regleB, prenant en paramètre une chaîne de caractères et renvoyant True si la chaîne est construite suivant la règle B, et False sinon.

Sur machine, raccourcir et regleA sont déjà écrites dans l'éditeur.

def raccourcir(chaine):
    return chaine[1:len(chaine) - 1]

def regleA(chaine):
    n = len(chaine)
    if n >= 2:
        return chaine[0] == "a" and chaine[n-1] == "a" and regleA(raccourcir(chaine))
    else:
        return chaine == "a"

def regleB(chaine):
    ...

print(regleB("bbabb"), regleB("bba"))

Inspire-toi de regleA : premier et dernier caractères égaux à "b", puis on regarde le milieu raccourcir(chaine).

D'après la règle B, le milieu doit suivre la règle A ou la règle B : regleA(...) or regleB(...), entre parenthèses.

Une chaîne de moins de 2 caractères ne peut pas suivre la règle B (il faut au moins un "b" au début et à la fin, plus un milieu).

def regleB(chaine):
    n = len(chaine)
    if n >= 2:
        return (chaine[0] == "b" and chaine[n-1] == "b"
                and (regleA(raccourcir(chaine)) or regleB(raccourcir(chaine))))
    else:
        return False

Les parenthèses autour du or sont nécessaires : sans elles, and passe avant or.

Mémo

Terminaison : un paramètre qui diminue à chaque appel et un cas de base atteint à coup sûr.

Trop d'appels en attente (environ 1 000) : Python s'arrête avec RecursionError: maximum recursion depth exceeded.

Récursivité sur une chaîne : on traite le premier et le dernier caractère, puis on rappelle la fonction sur le milieu, plus court.
