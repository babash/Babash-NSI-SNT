Exercice : compte à rebours, factorielle et somme (4 points)

Bac 2023, sujet 0.B (sujet zéro publié pour la session 2023), exercice 2, 4 points. Sujet d'origine (PDF).

Cet exercice est consacré à l’analyse et à l’écriture de programmes récursifs.

1. a. Expliquer en quelques mots ce qu’est une fonction récursive.

Sur la copie, on l'écrit en une phrase. Ici, choisis la bonne explication.

  • Une fonction qui contient une boucle for ou while pour répéter ses instructions.
  • Une fonction qui appelle une autre fonction, déjà définie plus haut dans le programme.
  • Une fonction qui s'appelle elle-même dans sa propre définition.
  • Une fonction qui renvoie une autre fonction au lieu de renvoyer une valeur.

Regarde la fonction compte_rebours ci-dessous : quelle fonction appelle-t-elle à la ligne 5 ?

Une fonction récursive est une fonction qui s'appelle elle-même. Pour qu'elle s'arrête, elle a un cas de base, où elle ne s'appelle plus.

1. a. Expliquer en quelques mots ce qu’est une fonction récursive.

1. b. On considère la fonction Python suivante :

def compte_rebours(n):
    """ n est un entier positif ou nul """
    if n >= 0:
        print(n)
        compte_rebours(n - 1)

1. b. L’appel compte_rebours(3) affiche successivement les nombres 3, 2, 1 et 0. Expliquer pourquoi le programme s’arrête après l’affichage du nombre 0.

Sur la copie, on rédige l'explication. Ici, choisis-la.

  • Parce que la fonction renvoie 0 quand elle arrive à 0, et qu'un return arrête tous les appels en cours.
  • Parce qu'après 0, la fonction s'appelle avec n = -1 : la condition n >= 0 est fausse, elle n'affiche rien et ne s'appelle plus.
  • Parce que Python arrête toujours une fonction récursive quand son paramètre atteint 0, sans qu'il faille une condition.
  • Parce qu'une erreur se produit quand n devient négatif : l'appel avec n = -1 est refusé et le programme s'arrête.

Après avoir affiché 0, la fonction s'appelle avec quelle valeur de n ?

Pour cette valeur, la condition de la ligne 3 est-elle vraie ?

Après l'affichage de 0, on appelle compte_rebours(-1). Comme -1 >= 0 est faux, cet appel ne fait rien : il n'y a plus d'appel récursif. Le cas n < 0 est le cas de base.

1. b. L’appel compte_rebours(3) affiche successivement les nombres 3, 2, 1 et 0. Expliquer pourquoi le programme s’arrête après l’affichage du nombre 0.

2. En mathématiques, la factorielle d'un entier naturel n est le produit des nombres entiers strictement positifs inférieurs ou égaux à n. Par convention, la factorielle de 0 est 1. Par exemple :

  • la factorielle de 1 est 1
  • la factorielle de 2 est 2 x 1 =2
  • la factorielle de 3 est 3 x 2 x 1 = 6
  • la factorielle de 4 est 4 x 3 x 2 x 1 = 24…

2. Recopier et compléter sur votre copie le programme donné ci-dessous afin que la fonction récursive fact renvoie la factorielle de l’entier passé en paramètre de cette fonction.

Exemple : fact(4) renvoie 24.

def fact(n):
    """ Renvoie le produit des nombres entiers
    strictement positifs inférieurs à n """
    if n == 0:
        return [[1]]
    else:
        return [[n * fact(n - 1)|n*fact(n-1)|fact(n - 1) * n|fact(n-1)*n|n * fact(n-1)|fact(n-1) * n]]

Que vaut la factorielle de 0 ? Relis la convention de l'énoncé.

4 x 3 x 2 x 1, c'est 4 x (la factorielle de 3). En général : n fois la factorielle de n - 1.

    if n == 0:
        return 1
    else:
        return n * fact(n - 1)

Cas de base : fact(0) vaut 1. Sinon, fact(n) = n × fact(n − 1), avec un appel sur un nombre plus petit : on finit par atteindre 0. Vérifié : fact(4) renvoie 24.

Remarque sur le sujet : la documentation de la fonction dit « inférieurs à n » ; il faut lire « inférieurs ou égaux à n », comme dans l'énoncé (4 fait partie du produit de fact(4)).

3. La fonction somme_entiers_rec ci-dessous permet de calculer la somme des entiers, de 0 à l'entier naturel n passé en paramètre.

Par exemple :

  • Pour n = 0, la fonction renvoie la valeur 0.
  • Pour n = 1, la fonction renvoie la valeur 0 + 1 = 1.
  • …
  • Pour n = 4, la fonction renvoie la valeur 0 + 1 + 2 + 3 + 4 = 10.

3. a. Écrire ce qui sera affiché dans la console après l'exécution de la ligne suivante : res = somme_entiers_rec(3)

def somme_entiers_rec(n):
    """ Permet de calculer la somme des entiers,
    de 0 à l'entier naturel n """
    if n == 0:
        return 0
    else:
        print(n) #pour vérification
        return n + somme_entiers_rec(n - 1)

res = somme_entiers_rec(3)

L'instruction print(n) de la ligne 7 dans le code précédent a été insérée afin de mettre en évidence le mécanisme en œuvre au niveau des appels récursifs.

3
2
1

Quand n vaut 0, la fonction renvoie 0 sans passer par le print de la ligne 7.

La ligne res = … n'affiche pas la valeur renvoyée : seuls les print(n) affichent quelque chose.

Suis les appels : somme_entiers_rec(3) affiche 3, puis appelle somme_entiers_rec(2)…

Que se passe-t-il pour l'appel avec n = 0 ? Passe-t-il par la ligne 7 ?

Les appels 3, 2 et 1 affichent leur n avant de s'appeler. L'appel avec 0 renvoie 0 directement, sans rien afficher. On lit donc 3, 2, 1, un nombre par ligne.

3. b. Quelle valeur sera alors affectée à la variable res ?

3 est le premier nombre affiché. res reçoit la valeur renvoyée par l'appel : la somme.

0 est renvoyé par le dernier appel seulement. Chaque appel ajoute son n en remontant.

Remonte les appels : somme_entiers_rec(0) renvoie 0, donc somme_entiers_rec(1) renvoie 1 + 0…

3 + (2 + (1 + 0)) = 6. Vérifié par exécution : res vaut 6.

4. Écrire en Python une fonction somme_entiers non récursive : cette fonction devra prendre en argument un entier naturel n et renvoyer la somme des entiers de 0 à n compris. Elle devra donc renvoyer le même résultat que la fonction somme_entiers_rec définie à la question 3.

Exemple : somme_entiers(4) renvoie 10.

def somme_entiers(n):
    ...

print(somme_entiers(4))

Non récursive : la fonction ne s'appelle pas. Utilise une boucle et un accumulateur qui vaut 0 au départ.

for i in range(n + 1): donne 0, 1, …, n : la fin n + 1 est exclue.

def somme_entiers(n):
    somme = 0
    for i in range(n + 1):
        somme = somme + i
    return somme

Attention à range(n + 1) : avec range(n), on oublierait n. Autre réponse juste : return n * (n + 1) // 2.

Mémo

Une fonction récursive s'appelle elle-même. Elle a un cas de base, où elle ne s'appelle plus, et chaque appel se rapproche de ce cas : c'est ce qui garantit qu'elle se termine.

Suivre une récursion : on descend les appels (ce qui est affiché avant l'appel s'affiche à l'aller), puis on remonte les valeurs renvoyées.

fact(n) = n × fact(n − 1), avec fact(0) = 1 ; somme(n) = n + somme(n − 1), avec somme(0) = 0.
