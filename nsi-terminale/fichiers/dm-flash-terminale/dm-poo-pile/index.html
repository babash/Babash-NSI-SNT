[5, 8, 6, 5, 3] : on dépile 3, puis on dépile 5. Que reste-t-il ?

Le premier depiler() renvoie 3, il reste [5, 8, 6, 5] ; le second renvoie 5, il reste [5, 8, 6] ; tete() renvoie 6, sans l'enlever. Total : 3 + 5 + 6 = 14.

La méthode append d'une liste ajoute un élément à la fin.

class Pile:
    def __init__(self, tab):
        self.pile = tab

    def est_vide(self):
        return len(self.pile) == 0

    def empiler(self, x):
        self.pile.append(x)

    def tete(self):
        return self.pile[-1]

append modifie la liste de l'objet : la méthode n'a rien à renvoyer.

La méthode pop() d'une liste enlève le dernier élément et le renvoie.

class Pile:
    def __init__(self, tab):
        self.pile = tab

    def est_vide(self):
        return len(self.pile) == 0

    def empiler(self, x):
        self.pile.append(x)

    def depiler(self):
        return self.pile.pop()

    def tete(self):
        return self.pile[-1]

self.pile[-1] renverrait la tête sans l'enlever ; pop(0) enlèverait le bas de la pile.

class Pile:
    def __init__(self, tab):
        self.pile = tab

    def est_vide(self):
        return len(self.pile) == 0

    def empiler(self, x):
        self.pile.append(x)

    def depiler(self):
        return self.pile.pop()

    def tete(self):
        return self.pile[-1]

# 1. Crée une pile p vide.
p = Pile([])
# 2. Empile 2 dans p.
p.empiler(2)
# 3. Teste si p est vide.
vide = p.est_vide()
# 4. Empile dans p une copie de l'élément en tête de p.
p.empiler(p.tete())
# 5. Dépile p.
x = p.depiler()

On se sert de la pile par son interface, sans toucher à p.pile. Sans parenthèses, p.est_vide serait la méthode elle-même, pas sa réponse.

Mémo

Ici, la tête de la pile est le dernier élément de la liste : append empile, pop() dépile et renvoie la tête.

On crée une pile avec Pile([]) et on s'en sert par ses méthodes : p.empiler(2), p.est_vide().
