1. La structure des données

On veut calculer, en Python, le nombre total d'oreilles d'une personne et de tous ses descendant·e·s. Chaque personne est un dictionnaire ; sa clé 'enfants' donne la liste de ses enfants, et chaque enfant est lui-même un dictionnaire de personne.

famille = {
    'nom': 'Grand-Père',
    'oreilles': 2,
    'enfants': [
        {
            'nom': 'Père',
            'oreilles': 2,
            'enfants': [
                {'nom': 'Moi', 'oreilles': 2, 'enfants': []},
                {'nom': 'Ma Sœur', 'oreilles': 2, 'enfants': []}
            ]
        },
        {
            'nom': 'Tante',
            'oreilles': 2,
            'enfants': [
                {'nom': 'Cousin', 'oreilles': 2, 'enfants': []}
            ]
        }
    ]
}

Quel est le type de la variable famille ?

  • Une liste (list).
  • Un dictionnaire (dict).
  • Une chaîne de caractères (str).
  • Un tuple (tuple).

Regarde le premier caractère après le signe =, et ce qu'il y a avant chaque :.

Des accolades et des couples clé: valeur : famille est un dictionnaire, avec trois clés, 'nom', 'oreilles' et 'enfants'.

Quel est le type de famille['enfants'] ?

  • Un dictionnaire (dict).
  • Un entier (int).
  • Une chaîne de caractères (str).
  • Une liste (list) de dictionnaires.

Quel caractère suit 'enfants': ?

La valeur commence par [ : c'est une liste, dont chaque élément est un dictionnaire de personne. Une liste vide, [], veut dire « pas d'enfant ».

Écris l'instruction Python qui donne le nom du premier enfant de « Grand-Père ».

On va chercher la liste des enfants, puis son premier élément (indice 0), puis sa clé 'nom'.

famille['enfants'][0]['nom'] vaut 'Père'. On lit de gauche à droite : la liste des enfants, le premier, son nom.

Écris l'instruction Python qui donne le nombre d'oreilles de « Cousin », en partant de la variable famille.

« Cousin » est l'enfant de « Tante », qui est le deuxième enfant de « Grand-Père » : indice 1.

Deux fois ['enfants'], avec un indice après chacun, puis ['oreilles'].

famille['enfants'][1]['enfants'][0]['oreilles'] vaut 2 : « Tante » (indice 1), puis son premier enfant, « Cousin » (indice 0), puis ses oreilles.

2. Une fonction récursive

La fonction calcule le total des oreilles d'une personne et de tous ses descendant·e·s. Complète-la.

def calculer_oreilles_famille(personne):
    # Cas 1 : la personne n'a pas d'enfant (cas de base).
    if personne['enfants'] == []:
        return [[personne['oreilles'] ]]
    # Cas 2 : la personne a des enfants (cas récursif).
    # 1. On compte les oreilles de la personne elle-même.
    total = personne['oreilles']
    # 2. On ajoute les oreilles de chaque enfant et de ses descendant·e·s.
    for enfant in personne['enfants']:
        total += calculer_oreilles_famille(enfant)
    return [[total]]

Sans enfant, le total, ce sont les oreilles de la personne seule. Écris-le avec le dictionnaire personne, pas avec un nombre : toutes les personnes n'ont pas forcément 2 oreilles.

À la fin du cas 2, la variable total contient la réponse.

def calculer_oreilles_famille(personne):
    if personne['enfants'] == []:
        return personne['oreilles']
    total = personne['oreilles']
    for enfant in personne['enfants']:
        total += calculer_oreilles_famille(enfant)
    return total

Appelée sur famille, six personnes de 2 oreilles, la fonction renvoie 12.

Quel est le rôle principal du cas 1, le cas de base ?

  • Arrêter les appels : sans enfant, la réponse est connue sans rappeler la fonction.
  • Parcourir les enfants de la personne.
  • Afficher un message d'erreur.
  • Additionner les oreilles de toute la famille.

Que se passerait-il si la fonction s'appelait toujours elle-même ?

Le cas de base donne une réponse directe, sans nouvel appel. C'est lui qui garantit que la suite d'appels s'arrête.

Quel est le rôle principal du cas 2, le cas récursif ? Comment ramène-t-il le problème à un problème plus simple ?

  • Il rappelle la fonction sur la même personne jusqu'à trouver le total.
  • Il compte seulement les enfants directs.
  • Il appelle la fonction sur chaque enfant, une famille plus petite, et additionne les résultats.
  • Il trie les enfants avant de les compter.

Sur qui porte l'appel calculer_oreilles_famille(enfant) ?

Chaque enfant est la « racine » d'une famille plus petite. Le cas 2 confie chacune de ces petites familles à un nouvel appel, puis additionne : oreilles de la personne + total de chaque enfant.

3. Le déroulé

On considère cette petite famille :

petit_arbre = {'nom': 'A', 'oreilles': 2,
    'enfants': [
        {'nom': 'B', 'oreilles': 2, 'enfants': []},
        {'nom': 'C', 'oreilles': 2, 'enfants': []}
    ]
}

Combien de fois, au total, la fonction calculer_oreilles_famille est-elle appelée quand on l'appelle sur petit_arbre ? Les personnes concernées sont A, B et C.

Tu as compté les appels sur B et C. N'oublie pas le tout premier appel, sur A.

Chaque personne déclenche exactement un appel.

3 appels : un sur A, qui appelle la fonction sur B, puis sur C. B et C n'ont pas d'enfant : ce sont des cas de base.

Quel résultat la fonction renvoie-t-elle quand on l'appelle sur petit_arbre ?

C'est ce que renvoient les appels sur B et sur C. L'appel sur A ajoute ses propres oreilles à ces deux résultats.

Tu as additionné B et C. Il manque les oreilles de A.

Remonte l'arbre d'appels : B renvoie 2, C renvoie 2, et A ajoute ses 2 oreilles.

2 (A) + 2 (renvoyé par B) + 2 (renvoyé par C) = 6. Les résultats remontent dans l'arbre d'appels, des feuilles vers la racine.

Mémo

Une fonction récursive a un cas de base, qui répond sans s'appeler, et un cas récursif, qui s'appelle sur un problème plus petit.

L'arbre d'appels a un nœud par appel ; les résultats remontent des feuilles vers la racine.
