Objectif : lire et modifier une donnée rangée dans une liste de dictionnaires.

Je sais :

  • donner le type de chaque niveau d'une structure imbriquée (liste, dictionnaire, tuple) ;
  • enchaîner les indices et les clés pour atteindre une valeur ;
  • modifier une valeur dans un dictionnaire rangé dans une liste ;
  • parcourir une liste de dictionnaires pour trouver un maximum.

2. Atteindre et modifier une valeur

Écris une instruction qui donne l'attaque spéciale de pikachu.

pokemons est une liste : on y entre par un indice (un nombre), pas par un nom.

L'attaque spéciale n'est pas directement dans le dictionnaire de pikachu : elle est rangée sous la clé 'stats'.

Trois étapes : la liste (quel indice pour pikachu ?), puis la clé 'stats', puis la clé de l'attaque spéciale.

On enchaîne les crochets : pokemons[…][…][…].

pokemons[0]['stats']['special-attack'] vaut 50. On lit de gauche à droite : le premier Pokémon, puis ses statistiques, puis l'attaque spéciale.

Écris une instruction qui donne le deuxième type de dracolosse.

Les indices commencent à 0 : le deuxième élément a l'indice 1.

dracolosse est le deuxième Pokémon de la liste : son indice est 1.

dracolosse est le deuxième élément de la liste : indice 1. Ses types sont sous la clé 'types'.

Dans un tuple aussi, le deuxième élément a l'indice 1.

pokemons[1]['types'][1] vaut 'flying'. On peut aussi écrire [-1] : le dernier élément du tuple.

Écris une instruction qui change l'attaque de ronflex : elle passe à 1000.

Deux signes == comparent. Pour donner une nouvelle valeur, un seul signe = suffit.

Cette instruction crée une nouvelle clé 'attack' à côté de 'stats' : l'attaque de ronflex est rangée sous la clé 'stats'.

D'abord le chemin jusqu'à l'attaque de ronflex (troisième Pokémon), puis une affectation avec =.

pokemons[2]['stats']['attack'] = 1000. Un dictionnaire se modifie : la valeur 110 est remplacée par 1000. (Un tuple, lui, ne se modifie pas.)

pk est un dictionnaire : son poids est pk["weight"], son nom pk["name"].

On garde ce Pokémon s'il est plus lourd que le meilleur trouvé jusqu'ici : pk["weight"] > meilleur_poids.

La fonction renvoie le nom, pas le poids.

def plus_lourd(pokemons):
    # initialisation
    meilleur = ""
    meilleur_poids = 0
    for pk in pokemons:
        if pk["weight"] > meilleur_poids:
            meilleur = pk["name"]
            meilleur_poids = pk["weight"]
    return meilleur

À chaque tour, pk est le dictionnaire d'un Pokémon. Quand il est plus lourd que le meilleur, on retient son nom et son poids. Avec la liste de la feuille, la fonction renvoie 'ronflex' (4600).

Mémo

Une structure imbriquée se lit de gauche à droite : pokemons[1]['stats']['hp'] = l'élément d'indice 1 de la liste, puis la clé 'stats', puis la clé 'hp'.

Liste [ ] et dictionnaire { } se modifient ; un tuple ( ), non.
