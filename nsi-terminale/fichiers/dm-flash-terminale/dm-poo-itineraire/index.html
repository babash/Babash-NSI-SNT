45 minutes · 7 questions · devoir maison

Un itinéraire est noté par une suite de lettres : D pour un déplacement d'une case vers la droite, B pour un déplacement d'une case vers le bas. Le nombre de D est la longueur de l'itinéraire ; le nombre de B est sa largeur.

Ainsi, l'itinéraire 'DDBDBBDDDDB' a pour longueur 7 et pour largeur 4. Sa représentation graphique est :

S * *    * *      *      * * * * *              E

avec S la case de départ (start), de coordonnées (0 ; 0), * les cases visitées, et E la case d'arrivée (end).

class Chemin:

1. Lire les attributs

On exécute ce code, sous la classe :

chemin_1 = Chemin("DDBDBBDDDDB")  # on crée une instance de Chemin
a = chemin_1.largeur
b = chemin_1.longueur

Quelle valeur contient la variable a ?

7, c'est la longueur : le nombre de D. a reçoit la largeur.

La largeur est le nombre de B dans l'itinéraire. Compte-les.

a vaut 4 : il y a 4 lettres B dans "DDBDBBDDDDB".

Quelle valeur contient la variable b ?

4, c'est la largeur. b reçoit la longueur : le nombre de D.

11, c'est le nombre total de lettres (longueur + largeur).

La longueur est le nombre de D dans l'itinéraire.

b vaut 7 : il y a 7 lettres D. Le constructeur les a comptées dans sa boucle.

2. Compléter et écrire les méthodes

Complète la méthode remplir_grille. i est le numéro de la ligne, j celui de la colonne. Les trois dernières lignes affichent la grille, pour vérifier.

class Chemin:
    def __init__(self, itineraire):
        self.itineraire = itineraire
        longueur, largeur = 0, 0
        for direction in self.itineraire:
            if direction == "D":
                longueur = longueur + 1
            if direction == "B":
                largeur = largeur + 1
        self.longueur = longueur
        self.largeur = largeur
        self.grille = [['.' for i in range(longueur + 1)]
                       for j in range(largeur + 1)]

    def remplir_grille(self):
        i, j = 0, 0  # position initiale
        self.grille[0][0] = 'S'  # case de départ marquée d'un S
        for direction in [[self.itineraire]]:
            if direction == 'D':
                [[j]] = [[j + 1|1 + j]]  # vers la droite
            elif direction == 'B':
                [[i]] = [[i + 1|1 + i]]  # vers le bas
            self.grille[i][j] = '*'  # marquer le chemin avec '*'
        self.grille[self.largeur][self.longueur] = 'E'  # case E

chemin_1 = Chemin("DDBDBBDDDDB")
chemin_1.remplir_grille()
for ligne in chemin_1.grille: print("".join(ligne))

On parcourt les lettres de l'itinéraire : c'est l'attribut self.itineraire.

Aller à droite, c'est changer de colonne : j augmente de 1. Aller en bas, c'est changer de ligne : i augmente de 1.

La grille est une liste de lignes : une boucle sur self.grille, et un print par ligne.

Pour chaque case d'une ligne, on construit un texte : un espace si la case vaut '.', sinon la case, chaque fois suivie d'un espace.

    def __init__(self, itineraire):

        for direction in self.itineraire:
            if direction == "D":

            if direction == "B":
                largeur = largeur + 1
        self.longueur = longueur
        self.largeur = largeur
        self.grille = [['.' for i in range(longueur + 1)]
                       for j in range(largeur + 1)]

    def remplir_grille(self):
        i, j = 0, 0
        self.grille[0][0] = 'S'
        for direction in self.itineraire:
            if direction == 'D':
                j = j + 1
            elif direction == 'B':
                i = i + 1
            self.grille[i][j] = '*'
        self.grille[self.largeur][self.longueur] = 'E'

    def tracer_chemin(self):
        for ligne in self.grille:
            texte = ''
            for case in ligne:
                if case == '.':
                    texte = texte + '  '
                else:
                    texte = texte + case + ' '
            print(texte.rstrip())

Chaque case prend deux caractères : la case (ou un espace) et un espace. Sans espaces entre les cases, l'affichage est juste aussi.

    def get_dimensions(self):

Inutile de recompter les lettres : on renvoie les attributs. Les parenthèses sont facultatives : return self.longueur, self.largeur renvoie le même tuple.

3. Un itinéraire au hasard

Complète la fonction itineraire_aleatoire : elle crée un itinéraire aléatoire de taille taille (la taille est longueur + largeur, le nombre de lettres). La dernière ligne vérifie la taille.

from random import choice

def itineraire_aleatoire(taille):
    itineraire = ''
    i = 0
    while [[i < taille|i != taille|i <= taille - 1|len(itineraire) < taille]]:
        direction = choice(["D", "B"])
        itineraire += [[direction]]
        [[i = i + 1|i += 1|i = 1 + i]]
    return itineraire

print(len(itineraire_aleatoire(10)))
10

i compte les lettres déjà ajoutées : on continue tant qu'il en manque.

Dans la boucle : on ajoute la lettre tirée au hasard, puis on n'oublie pas de faire avancer i, sinon la boucle ne s'arrête jamais.

    while i < taille:
        direction = choice(["D", "B"])
        itineraire += direction
        i = i + 1

choice(["D", "B"]) tire une des deux lettres au hasard. Après taille tours, l'itinéraire a taille lettres.

Combien y a-t-il de chemins possibles de taille N ? Écris le nombre en fonction de N (par exemple avec ** pour la puissance).

Chaque lettre multiplie par 2 le nombre de chemins : on ne l'ajoute pas. Essaie avec N = 1, 2, 3.

Attention à l'ordre : 2 choix par lettre, N lettres. Pour N = 3, il y a 8 chemins, pas 9.

Pour N = 1 : D ou B, 2 chemins. Pour N = 2 : DD, DB, BD, BB. Et pour N = 3 ?

À chaque lettre ajoutée, chaque chemin donne deux chemins : un qui finit par D, un qui finit par B.

Il y a 2N chemins (en Python, 2 ** N). Un chemin de taille N est une suite de N lettres, et chaque lettre a 2 valeurs possibles, D ou B, sans contrainte : 2 × 2 × … × 2 (N fois) = 2N. Pour N = 11, comme "DDBDBBDDDDB", il y en a 2048.

Combien y a-t-il de chemins possibles de taille N ? Justifie ta réponse.

Mémo

Un attribut se lit avec objet.attribut ; une méthode qui renvoie utilise return, une méthode qui affiche utilise print.

Dans une grille (liste de listes), grille[i][j] : ligne i, puis colonne j.
