Trouver le maximum

Cours-quiz

Nom et prénom :Classe :

Objectif : dérouler une recherche de maximum, y trouver les erreurs, puis la corriger.

Je sais :

  • distinguer la valeur du maximum et sa position (son indice) ;
  • suivre un parcours par indice dans un tableau d'avancement ;
  • trouver un exemple qui montre qu'une fonction est fausse ;
  • écrire une recherche de maximum juste, même avec des nombres négatifs.

30 minutes · 7 questions · seul·e ou en binôme

1. Lire la fonction

La fonction recherche_max prend en paramètre un tableau non vide de nombres. Elle doit renvoyer la plus grande valeur du tableau et la position (l'indice) où elle se trouve.

def recherche_max(tab):
    vmax, imax = 0, None
    for i in range(len(tab)-1):
        if tab[i] > vmax:
            vmax = tab[i]
            imax = i
    return vmax, imax

Quel type de parcours est utilisé à la ligne 3 de la fonction ?

  • Un parcours par valeur.
  • Un parcours par indice.
  • Une boucle non bornée.
  • Un parcours récursif.

Que contient i : un élément du tableau, ou une position ?

for i in range(...) : i prend des indices (0, 1, 2…), et on lit l'élément avec tab[i]. C'est un parcours par indice.

Que représente la variable imax ?

  • La plus grande valeur vue jusqu'ici.
  • Le nombre de tours de boucle.
  • L'indice du dernier élément du tableau.
  • L'indice de la plus grande valeur vue jusqu'ici.

Regarde la ligne imax = i : quand est-elle exécutée ?

imax est la position du maximum : on la met à jour en même temps que vmax, quand tab[i] dépasse le maximum provisoire.

Écris l'appel de la fonction recherche_max avec la liste [9, 100, 8, 48, 73].

Le nom de la fonction, puis l'argument entre parenthèses.

recherche_max([9, 100, 8, 48, 73]). On peut aussi garder le résultat : vmax, imax = recherche_max([9, 100, 8, 48, 73]).

Complète le tableau d'avancement de cet appel. Chaque ligne donne, à la fin du tour, i, tab[i], tab[i] > vmax, vmax et imax. Puis écris ce que renvoie l'appel.

#       (i, tab[i], tab[i] > vmax, vmax, imax)
tour_0 = (None, None, None, 0, None)
tour_1 = ([[0]], [[9]], [[True|true|vrai|Vrai]], [[9]], [[0]])
tour_2 = ([[1]], [[100]], [[True|true|vrai|Vrai]], [[100]], [[1]])
tour_3 = ([[2]], [[8]], [[False|false|faux|Faux]], [[100]], [[1]])
tour_4 = ([[3]], [[48]], [[False|false|faux|Faux]], [[100]], [[1]])
renvoie = [[(100, 1)|100, 1]]

len(tab) vaut 5, donc range(len(tab)-1) donne 0, 1, 2, 3 : quatre tours.

La comparaison se fait avec le vmax du début du tour.

#       (i, tab[i], tab[i] > vmax, vmax, imax)
tour_0 = (None, None, None, 0, None)
tour_1 = (0, 9, True, 9, 0)
tour_2 = (1, 100, True, 100, 1)
tour_3 = (2, 8, False, 100, 1)
tour_4 = (3, 48, False, 100, 1)
renvoie = (100, 1)

La fonction renvoie (100, 1), la bonne réponse. Mais regarde : la boucle s'arrête à i = 3. Le dernier élément, 73, n'est jamais regardé.

2. La fonction est-elle correcte ?

Écris la valeur renvoyée par chaque appel.

# recherche_max([10, 4, 8, 88, 10]) renvoie :
r1 = [[(88, 3)|88, 3]]
# recherche_max([-10, -2, -10]) renvoie :
r2 = [[(0, None)|0, None]]

Une fonction qui renvoie deux valeurs renvoie un tuple : (valeur, indice).

Pour le deuxième appel : un nombre négatif est-il plus grand que 0, la valeur de départ de vmax ?

r1 = (88, 3)
r2 = (0, None)

Le premier résultat est juste. Le second est faux : 0 n'est même pas dans le tableau, et None n'est pas une position. Le vrai maximum est -2, à l'indice 1.

La fonction n'est pas correcte. Coche toutes ses erreurs.

  • La comparaison devrait être < au lieu de >.
  • vmax commence à 0 : faux si tous les nombres sont négatifs.
  • Une fonction ne peut pas renvoyer deux valeurs.
  • range(len(tab)-1) oublie le dernier élément.

Essaie la fonction de tête avec [1, 2, 3] : que renvoie-t-elle ?

Deux erreurs. Avec [-10, -2, -10], on obtient (0, None) : vmax doit partir d'un élément du tableau. Avec [1, 2, 3], on obtient (2, 1) : le dernier élément est oublié, il faut range(len(tab)).

Réécris la fonction en corrigeant les deux erreurs. Des tests, cachés, la vérifient quand tu cliques sur « Lancer et vérifier ».

def recherche_max(tab):
    vmax, imax = 0, None
    for i in range(len(tab)-1):
        if tab[i] > vmax:
            vmax = tab[i]
            imax = i
    return vmax, imax

Pour le départ, prends le premier élément du tableau : il existe, puisque le tableau n'est pas vide. Quel est alors son indice ?

range(len(tab)) donne tous les indices, du premier au dernier.

def recherche_max(tab):
    vmax, imax = tab[0], 0
    for i in range(len(tab)):
        if tab[i] > vmax:
            vmax = tab[i]
            imax = i
    return vmax, imax

On part du premier élément (tab[0], indice 0) : le maximum provisoire est toujours une vraie valeur du tableau. Puis on regarde tous les indices. On peut aussi écrire range(1, len(tab)), puisque l'indice 0 est déjà pris en compte.

Mémo

Maximum : partir du premier élément (jamais d'une valeur inventée comme 0), puis regarder tous les indices, range(len(tab)).

Pour montrer qu'une fonction est fausse, un seul contre-exemple suffit.
