Recherche linéaire

DM flash : dans un dictionnaire

Cours-quiz

Nom et prénom :Classe :

Objectif : dérouler une recherche linéaire dans un dictionnaire, puis corriger sa valeur « pas trouvé ».

Je sais :

  • reconnaître un dictionnaire parcouru avec items() ;
  • suivre une boucle qui s'arrête dès qu'elle trouve ;
  • prévoir ce que renvoie la fonction, clé présente ou absente ;
  • choisir une valeur « pas trouvé » qui ne peut pas être une vraie valeur.

25 minutes · 5 questions et 1 bonus ★ · seul·e ou en binôme

1. Lire la fonction

La fonction recherche cherche la clé x dans d, et renvoie la valeur associée.

def recherche(d, x):
    for k, v in d.items():
        if k == x:
            return v
    return -1

Quel est le type du paramètre d ? Choisis la réponse et sa justification.

  • Une liste : on la parcourt avec for.
  • Un dictionnaire : il s'écrit entre crochets.
  • Un tuple : k, v est un couple.
  • Un dictionnaire : d.items() donne des couples (clé, valeur).

Quelle structure de Python a une méthode items() ?

d est un dictionnaire (dict) : d.items() donne ses couples (clé, valeur), que la boucle range dans k et v.

On appelle recherche({9: 2, 7: 1, 11: 11, 6: 7, 0: 2}, 6). Complète le tableau d'avancement : chaque ligne donne k, v et k == x pendant le tour. Puis écris ce que renvoie l'appel.

#       (k, v, k == x)
tour_1 = ([[9]], [[2]], [[False|false|faux|Faux]])
tour_2 = ([[7]], [[1]], [[False|false|faux|Faux]])
tour_3 = ([[11]], [[11]], [[False|false|faux|Faux]])
tour_4 = ([[6]], [[7]], [[True|true|vrai|Vrai]])
renvoie = [[7]]

Un dictionnaire se parcourt dans l'ordre où ses clés ont été écrites : 9, puis 7, puis 11…

Dès que k == x est vrai, return v arrête la fonction : il n'y a pas de cinquième tour.

#       (k, v, k == x)
tour_1 = (9, 2, False)
tour_2 = (7, 1, False)
tour_3 = (11, 11, False)
tour_4 = (6, 7, True)
renvoie = 7

Au quatrième tour, la clé 6 est trouvée : la fonction renvoie sa valeur, 7, et s'arrête. La clé 0 n'est jamais regardée.

Écris la valeur renvoyée par chaque appel.

# recherche({9: 2, 7: 1, 11: 11}, 7) renvoie :
r1 = [[1]]
# recherche({}, 3) renvoie :
r2 = [[-1]]
# recherche({3: 1, 1: 0}, 5) renvoie :
r3 = [[-1]]
# recherche({5: 6, 7: 1, 11: -1}, 11) renvoie :
r4 = [[-1]]

Quand la boucle va jusqu'au bout sans trouver la clé, la fonction exécute la dernière ligne.

Avec le dictionnaire vide {}, la boucle ne fait aucun tour.

r1 = 1
r2 = -1
r3 = -1
r4 = -1

La clé 7 est présente : on obtient sa valeur, 1. Les clés 3 (dans {}) et 5 sont absentes : on obtient -1. La clé 11 est présente… et sa valeur est -1.

2. Une valeur « pas trouvé » ambiguë

recherche({3: 1, 1: 0}, 5) et recherche({5: 6, 7: 1, 11: -1}, 11) renvoient le même résultat. Pourquoi n'est-ce pas satisfaisant ?

  • La fonction se trompe pour la clé 11.
  • Avec -1, on ne sait pas si la clé est absente ou si sa valeur vaut -1.
  • Une valeur ne doit jamais être négative.
  • La fonction ne regarde pas toutes les clés.

Si tu reçois -1, peux-tu dire si la clé était dans le dictionnaire ?

Le résultat -1 a deux sens : « clé absente » et « la valeur associée est -1 ». Celui ou celle qui appelle la fonction ne peut pas les distinguer.

Quelle solution règle ce problème ?

  • Renvoyer 0 quand la clé est absente.
  • Renvoyer False quand la clé est absente.
  • Renvoyer None quand la clé est absente.
  • Renvoyer -2 quand la clé est absente.

Il faut une valeur à part, qui veut dire « rien ».

None veut dire « aucune valeur ». On le teste avec is None. (Si une valeur du dictionnaire peut elle-même être None, on teste d'abord la présence de la clé avec x in d.)

Modifie la fonction pour qu'elle renvoie None quand la clé est absente. Des tests, cachés, la vérifient quand tu cliques sur « Lancer et vérifier ».

def recherche(d, x):
    for k, v in d.items():
        if k == x:
            return v
    return -1

Une seule ligne change : la dernière.

def recherche(d, x):
    for k, v in d.items():
        if k == x:
            return v
    return None

Le return None reste après la boucle : on ne conclut « absente » qu'après avoir regardé toutes les clés.

Mémo

Recherche linéaire : on regarde les clés une par une ; return arrête la fonction dès qu'on trouve.

« Pas trouvé » se dit avec une valeur qui ne peut pas être une vraie réponse : None.
