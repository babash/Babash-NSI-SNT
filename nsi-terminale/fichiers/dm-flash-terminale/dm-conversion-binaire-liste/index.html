1. Un peu de binaire

Dans tout le devoir, le bit de poids fort est à gauche. Sur un octet, les bits valent, de gauche à droite : 2**7 = 128, 64, 32, 16, 8, 4, 2 et 2**0 = 1.

Écris la représentation binaire sur un octet (8 bits) de 2, de 156 et de 89.

octet_2 = "[[00000010]]"
octet_156 = "[[10011100]]"
octet_89 = "[[01011001]]"

Sur un octet, on écrit toujours 8 chiffres : on complète à gauche par des 0.

Pour 156 : cherche la plus grande puissance de 2 qui tient dans 156 (c'est 128), retire-la, puis recommence avec le reste (28).

156 = 128 + 16 + 8 + 4 : les bits de 128, 16, 8 et 4 valent 1, les autres 0.

octet_2 = "00000010"     # 2 = 2^1
octet_156 = "10011100"   # 156 = 128 + 16 + 8 + 4
octet_89 = "01011001"    # 89 = 64 + 16 + 8 + 1

On décompose l'entier en somme de puissances de 2. Chaque puissance utilisée donne un bit à 1. Les 0 de gauche comptent : sur un octet, il y a toujours 8 bits.

Donne la représentation binaire sur un octet des nombres suivants. Justifie tes réponses par un calcul : 2 ; 156 ; 89.

2 = 2**1, donc 00000010.

156 = 128 + 16 + 8 + 4 = 2**7 + 2**4 + 2**3 + 2**2, donc 10011100.

89 = 64 + 16 + 8 + 1 = 2**6 + 2**4 + 2**3 + 2**0, donc 01011001.

On accepte aussi les divisions successives par 2 (les restes, lus de bas en haut).

Écris la valeur décimale de chaque écriture binaire : 1000001, 101 et 111111110.

valeur_1000001 = [[65]]
valeur_101 = [[5]]
valeur_111111110 = [[510]]

Le bit le plus à droite vaut 1, le suivant 2, puis 4, 8, 16… Additionne les valeurs des bits à 1.

1000001 a 7 bits : le premier vaut 2**6 = 64. 111111110 a 9 bits : le premier vaut 2**8 = 256.

1000001 = 2**6 + 2**0 = 64 + 1 = 65.

101 = 2**2 + 2**0 = 4 + 1 = 5.

111111110 = 256 + 128 + 64 + 32 + 16 + 8 + 4 + 2 = 510 (ou 511 − 1 : neuf 1 font 2**9 − 1 = 511, et le dernier bit est 0).

Donne la représentation décimale des nombres suivants, écrits en binaire. Justifie tes réponses par un calcul : 1000001 ; 101 ; 111111110.

1000001 = 2**6 + 2**0 = 65 ; 101 = 2**2 + 2**0 = 5 ; 111111110 = 2**8 + 2**7 + … + 2**1 = 510.

Le bit d'indice i vaut 2 puissance (len(tab) - 1 - i) : le premier bit est celui de poids fort.

Pars d'une variable resultat = 0. Pour chaque indice i de range(len(tab)), ajoute tab[i] * 2 ** (len(tab) - 1 - i). Puis renvoie resultat.

def convertir(tab):
    n = len(tab)
    resultat = 0
    for i in range(n):
        resultat = resultat + tab[i] * 2 ** (n - 1 - i)
    return resultat

print(convertir([1, 0, 1, 0, 0, 1, 1]))

Avec 7 bits, le bit d'indice 0 vaut 2**6 et le bit d'indice 6 vaut 2**0 = 1. On n'ajoute que les bits à 1 (un bit à 0 ajoute 0).

Autre méthode juste : resultat = resultat * 2 + tab[i] à chaque tour (on « décale » le résultat d'un rang vers la gauche avant d'ajouter le bit).

Mémo

Binaire vers décimal : on additionne les puissances de 2 des bits à 1 (le bit de droite vaut 2**0 = 1).

Décimal vers binaire : on retire la plus grande puissance de 2 possible, et on recommence avec le reste.
