Le signe + ne sait pas additionner deux objets Fraction : Python s'arrêterait sur TypeError: unsupported operand type(s) for +: 'Fraction' and 'Fraction'. Utilise la méthode somme.

C'est une méthode : on l'appelle sur un objet, avec un point.

Le premier objet est devant le point : on ne le redonne pas entre les parenthèses.

La méthode somme(self, fraction) a deux paramètres : self, l'objet devant le point, et fraction, l'autre fraction.

f1.somme(f2)

self est f1, et fraction est f2. La méthode renvoie un nouvel objet Fraction.

Complète la méthode somme : elle renvoie une nouvelle fraction r, égale à la somme de self et de fraction. Elle ne modifie ni self ni fraction.

D'abord, crée un nouvel objet pour r, par exemple Fraction(0, 1) : ses attributs seront changés ensuite.

Les deux dénominateurs sont self.b et fraction.b. S'ils sont différents, on multiplie : a/b + c/d = (a × d + c × b) / (b × d).

S'ils sont égaux : a/b + c/b = (a + c) / b.

class Fraction:
    def __init__(self, a, b):
        self.a = a
        assert b != 0
        self.b = b

    def somme(self, fraction):
        r = Fraction(0, 1)
        # mise sur le même dénominateur
        if self.b != fraction.b:
            r.b = self.b * fraction.b
            r.a = (self.a * fraction.b) + (fraction.a * self.b)
        else:
            r.a = self.a + fraction.a
            r.b = self.b
        return r

r = Fraction(0, 1) crée un nouvel objet : self et fraction ne changent pas. Écrire r = self modifierait f1 !

Le résultat n'est pas simplifié : 5/9 + 9/12 donne 141/108, une fraction égale à 47/36.

Mémo

Un attribut est une donnée de l'objet (self.a) ; une méthode est une fonction de la classe (def somme(self, …)).

On crée un objet avec Fraction(5, 9) et on appelle une méthode avec f1.somme(f2) : f1 devient self.
