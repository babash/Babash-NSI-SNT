1. La pile des nombres pairs

La fonction tri_pair prend en paramètre une pile de nombres entiers. Elle renvoie une pile qui ne contient que les nombres pairs de cette pile.

Comme dans le cours, la pile est une liste Python : [] est la pile vide, p.append(v) empile v, p.pop() dépile et renvoie le sommet. Le sommet est le dernier élément de la liste, à droite.

def tri_pair(p):
    p_pair = []
    while p != []:
        v = p.pop()
        if v % 2 == 0:
            p_pair.append(v)
    return p_pair

Quelle politique d'accès suit une pile ?

  • Premier entré, premier sorti (FIFO).
  • Accès direct à n'importe quel élément.
  • Dernier entré, premier sorti (LIFO).
  • Du plus petit au plus grand.

Pense à une pile d'assiettes : laquelle prends-tu en premier ?

Une pile est LIFO (Last In, First Out) : le dernier élément empilé est le premier dépilé. Tout se passe au sommet.

p != [] est vrai tant que p contient au moins un élément : la boucle dépile jusqu'à ce que p soit vide. C'est est_vide(p) de l'interface, à l'envers.

p.pop() retire le dernier élément de la liste : au premier tour, v vaut 1.

Il y a autant de tours que d'éléments dans p : 5. Un nombre est pair quand le reste de sa division par 2 vaut 0.

#       (v, p, v % 2 == 0, p_pair)
tour_0 = (None, [5, 2, 6, 7, 1], None, [])
tour_1 = (1, [5, 2, 6, 7], False, [])
tour_2 = (7, [5, 2, 6], False, [])
tour_3 = (6, [5, 2], True, [6])
tour_4 = (2, [5], True, [6, 2])
tour_5 = (5, [], False, [6, 2])

On dépile 1, 7, 6, 2, puis 5. Seuls 6 et 2 sont pairs : ils sont empilés dans p_pair, dans cet ordre. La fonction renvoie [6, 2].

2. L'ordre des piles renvoyées

Écris la pile renvoyée par chaque appel (le sommet à droite).

# tri_pair([-1, 144, -10, 23]) renvoie :
r1 = [[[-10, 144]|[-10, 144] ]]
# tri_pair([233, 677, 99, 3, 73, 75, 91]) renvoie :
r2 = [[[]|[] ]]
# tri_pair([12, 5, 8, 6, 2]) renvoie :
r3 = [[[2, 6, 8, 12]|[2, 6, 8, 12] ]]

Dépile depuis la droite : pour le premier appel, v vaut 23, puis -10, puis 144, puis -1.

En Python, -1 % 2 vaut 1 : -1 est impair. Et si aucun nombre n'est pair, la pile renvoyée reste vide.

r1 = [-10, 144]
r2 = []
r3 = [2, 6, 8, 12]

Le nombre pair le plus haut dans p est empilé le premier : il se retrouve au fond de p_pair.

Que contient la pile p à la fin de chacun de ces appels ?

  • La pile de départ, inchangée.
  • Les nombres impairs.
  • Le dernier nombre dépilé.
  • Rien : p est vide.

Relis la condition de la boucle : quand s'arrête-t-elle ?

La boucle tourne tant que p n'est pas vide : à la fin, p vaut []. La fonction a détruit la pile reçue : c'est la même liste que celle de l'appel.

Que remarques-tu sur l'ordre des nombres dans les piles renvoyées ?

  • Ils sont dans l'ordre inverse de celui de p.
  • Ils sont dans le même ordre que dans p.
  • Ils sont rangés du plus petit au plus grand.
  • Ils sont dans un ordre au hasard.

Compare [12, 5, 8, 6, 2] et [2, 6, 8, 12] : où est passé le sommet ?

On dépile le sommet de p en premier, et on l'empile en premier dans p_pair : il finit au fond. Vider une pile dans une autre inverse l'ordre.

3. Les pairs et les impairs

On modifie la fonction : elle renvoie la pile des nombres pairs et une pile p_impair des nombres impairs. Complète le code.

def tri_pair(p):
    p_pair = []
    [[p_impair = []|p_impair=[] ]]
    while p != []:
        v = p.pop()
        if v % 2 == 0:
            p_pair.append(v)
        [[else:|elif v % 2 != 0:|elif v % 2 == 1:|elif not v % 2 == 0:|elif v % 2:]]
            [[p_impair.append(v)]]
    return [[p_pair, p_impair|(p_pair, p_impair)|[p_pair, p_impair] ]]

print(tri_pair([5, 2, 6, 7, 1]))
([6, 2], [1, 7, 5])

La nouvelle pile se crée vide, comme p_pair.

Un nombre qui n'est pas pair est impair : un else suffit. Une fonction renvoie deux valeurs en les séparant par une virgule.

def tri_pair(p):
    p_pair = []
    p_impair = []
    while p != []:
        v = p.pop()
        if v % 2 == 0:
            p_pair.append(v)
        else:
            p_impair.append(v)
    return p_pair, p_impair

Avec [5, 2, 6, 7, 1], la fonction renvoie ([6, 2], [1, 7, 5]) : les deux piles sont encore dans l'ordre inverse.

Mémo

Pile : dernier entré, premier sorti. En liste Python : append empile, pop() dépile le sommet, [] est la pile vide.

Vider une pile dans une autre inverse l'ordre ; la vider deux fois le rétablit.
