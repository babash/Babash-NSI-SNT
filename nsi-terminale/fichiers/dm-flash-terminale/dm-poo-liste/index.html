Complète la méthode liste_course. Le cellier est un dictionnaire : à chaque ingrédient qu'on a déjà, il associe sa quantité (dans l'unité de la recette). La méthode renvoie la liste de courses : une liste de tuples (ingrédient, quantité), dans l'ordre de la recette. Un ingrédient est dans la liste de courses si :

  • il n'est pas dans le cellier : on prend la quantité de la recette ;
  • sa quantité dans le cellier est inférieure à celle de la recette : on prend la différence.

Exemple : pour le muffin et le cellier {"farine": 500, "chocolat": 20, "oeuf": 2}, on renvoie [("chocolat", 30), ("lait", 200)].

Parcours les ingrédients avec leur position : for i in range(len(self.ingredients)):. Commence avec une liste vide.

Pour savoir si un ingrédient est dans le cellier : if ingredient not in cellier:.

Sinon, la quantité du cellier est cellier[ingredient] : si elle est plus petite (strictement) que celle de la recette, on ajoute (ingredient, besoin - cellier[ingredient]).

class Recette:

    def __init__(self, nom, ingredients, quantites, unites):
        self.ingredients = ingredients
        self.quantites = quantites
        self.unites = unites
        self.nom = nom

    def liste_course(self, cellier):
        ''' Renvoie une liste de tuples (ingredient, quantite). '''
        courses = []
        for i in range(len(self.ingredients)):
            ingredient = self.ingredients[i]
            besoin = self.quantites[i]
            if ingredient not in cellier:
                courses.append((ingredient, besoin))
            elif cellier[ingredient] < besoin:
                courses.append((ingredient, besoin - cellier[ingredient]))
        return courses

Les doubles parenthèses de append((…, …)) sont nécessaires : on ajoute un tuple. Avec <=, un ingrédient déjà en quantité suffisante serait acheté pour 0.

Mémo

Un attribut peut être une liste : on la complète avec self.ingredients.append(…) et on modifie un élément avec tartiflette.quantites[0] = 1000.

Des listes alignées se parcourent par position : for i in range(len(self.ingredients)):.
