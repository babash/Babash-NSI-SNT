Exercice 3 · L'interprétation de Grace Hopper (années 1950)

Le rôle du point « . » et des méthodes qui modifient self. Grace Hopper, amirale et informaticienne, fut la pionnière du premier compilateur, un programme qui traduit le code source (lisible par l'humain) en langage machine (exécutable par l'ordinateur). Une tâche cruciale du compilateur est de décoder les instructions : à quel objet on s'adresse, et quelle action on lui demande.

Ton rôle : tu es le compilateur. Décode les instructions de la classe Code et détermine leur effet.

class Code:
    def __init__(self, lignes):
        self.lignes = lignes
        self.est_nettoye = False  # état initial : non nettoyé

    def preparer_compilation(self):
        # La méthode .upper() transforme le texte en MAJUSCULES.
        self.lignes = self.lignes.upper()
        self.est_nettoye = True

    def afficher_etat(self):
        return (self.lignes, self.est_nettoye)

mon_code = Code("while True:"
                "    print('Mouhahah !')")

La méthode upper() est une méthode de quelle classe ?

  • de la classe str : on l'appelle sur self.lignes, une chaîne de caractères
  • de la classe Code, puisqu'elle est appelée dans une de ses méthodes
  • de la classe bool
  • d'aucune classe : c'est une fonction de Python

Une méthode appartient à la classe de l'objet écrit avant le point.

self.lignes.upper() : on appelle upper sur self.lignes, qui contient une chaîne. C'est une méthode de la classe str.

La méthode upper() est une méthode de quelle classe ? Justifie.

De la classe str : on l'appelle sur self.lignes, une chaîne de caractères.

Si l'on crée l'objet mon_code = Code("while true"), quelle est la valeur de l'attribut lignes après l'appel mon_code.preparer_compilation() ?

  • "while true"
  • "While True"
  • "WHILE TRUE"
  • True

La ligne self.lignes = self.lignes.upper() remplace l'ancienne valeur.

lignes vaut "WHILE TRUE" : tout le texte est passé en majuscules, et l'attribut est_nettoye vaut True.

Quel est le type de la valeur renvoyée par la méthode afficher_etat() ?

  • un tuple (tuple)
  • une liste (list)
  • une chaîne (str)
  • un booléen (bool)

Regarde ce qui suit return : deux valeurs, entre parenthèses, séparées par une virgule.

(self.lignes, self.est_nettoye) est un tuple de deux éléments : une chaîne et un booléen.

Eurêka ! Tu utilises déjà des objets : les listes (l.append()), les dictionnaires (d.keys()) et les chaînes de caractères sont des objets en Python.

Exercice 4 · Les données universelles d'Alan Turing (1936)

Le point : méthode ou accès ? En 1936, Alan Turing décrit la machine universelle, capable de traiter toute information. En Python, le point (.) est l'opérateur universel pour atteindre cette information, qu'elle soit dans une liste, une chaîne ou un nombre flottant.

Ton rôle : pour chaque ligne, détermine si le point appelle une action sur un objet (une méthode) ou s'il donne accès à une donnée.

# Données universelles :
ma_liste = [10, 20, 30]
mon_dict = {'a': 1, 'b': 2}
mon_texte = "TURING"
mon_chiffre = 3.14

# Instructions à décoder :
A = ma_liste.append(40)
B = mon_dict.keys()
C = mon_texte.lower()
D = mon_chiffre.is_integer()
E = mon_dict['a']

Dans quelles lignes le point (.) sert-il à appeler une méthode ?

  • A
  • B
  • C
  • D
  • E

Une méthode s'appelle avec un point, son nom, puis des parenthèses.

A, B, C et D appellent une méthode : append, keys, lower, is_integer. La ligne E n'utilise pas le point.

Laquelle de ces instructions modifie l'objet sur lequel elle est appelée ?

  • A
  • B
  • C
  • D
  • E

Après ces lignes, regarde si ma_liste, mon_dict, mon_texte ou mon_chiffre ont changé.

Seule A modifie son objet : append(40) ajoute 40 à la fin de ma_liste.

Complète les commentaires : le type de A, B, C, D et E.

A = ma_liste.append(40)       # type de A : [[NoneType]]
B = mon_dict.keys()           # type de B : [[dict_keys]]
C = mon_texte.lower()         # type de C : [[str]]
D = mon_chiffre.is_integer()  # type de D : [[bool]]
E = mon_dict['a']             # type de E : [[int]]

La variable de gauche reçoit ce que renvoie l'instruction. Une méthode qui modifie l'objet ne renvoie pas forcément quelque chose : elle renvoie alors None, dont le type s'appelle NoneType.

keys() renvoie un objet spécial, de type dict_keys ; is_integer() répond par oui ou non.

A : NoneType (append ne renvoie rien) ; B : dict_keys ; C : str ; D : bool ; E : int. On le vérifie avec type(A), type(B)…

Une seule instruction a modifié son objet (question précédente).

Seule la liste a changé : [10, 20, 30, 40]. lower() a renvoyé une nouvelle chaîne sans changer mon_texte, qui vaut toujours "TURING".

L'instruction E utilise-t-elle le point pour accéder à une valeur ? Pour quels types les crochets [] sont-ils courants ?

  • Non : les crochets donnent accès à un élément par sa clé ou son indice ; c'est courant pour les dictionnaires, les listes, les tuples et les chaînes
  • Oui : le point est caché dans les crochets ; c'est courant pour tous les objets
  • Non : les crochets ne servent qu'aux dictionnaires
  • Non : les crochets sont courants pour les nombres entiers et flottants

Pense à ma_liste[0] et à mon_texte[0].

E n'utilise pas le point : mon_dict['a'] lit la valeur associée à la clé 'a'. Les crochets donnent accès à un élément d'une collection : une clé pour un dictionnaire, un indice pour une liste, un tuple ou une chaîne.

L'instruction E utilise-t-elle le point pour accéder à une valeur ? Explique brièvement pourquoi les crochets ([]) sont une autre manière d'accéder aux données, et pour quels types ils sont courants.

Non. Les crochets donnent accès à un élément d'une collection : par sa clé (dictionnaire) ou par son indice (liste, tuple, chaîne).

Mémo

Une méthode appartient à la classe de l'objet écrit avant le point. Elle peut modifier l'objet (et renvoyer None) ou renvoyer une valeur sans le modifier. Listes, dictionnaires et chaînes sont des objets.
