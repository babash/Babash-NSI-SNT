À retenir

  • Un processus est un programme en cours d'exécution ; le système lui donne un numéro, son PID.
  • Chaque processus est créé par un autre, son parent : son PPID est le PID du parent. Le processus 1 est lancé par le noyau au démarrage : c'est l'ancêtre de tous les autres.
  • ps -ef liste tous les processus, avec leur PID et leur PPID.
  • kill PID demande à un processus de s'arrêter ; kill -9 PID l'arrête de force, sans lui laisser le temps de sauvegarder.
  • Le tube | envoie ce qu'affiche la commande de gauche à la commande de droite : ps -ef | grep cron ne garde que les lignes qui contiennent cron.

1. Les commandes

Pour chaque commande, dis ce qu'elle fait. Exemple : man ps affiche le manuel d'une commande.

Que fait ps -ef ? Exemple : ps -ef

  • Lister les fichiers du dossier
  • Arrêter les processus en cours
  • Afficher la place libre du disque
  • Lister les processus en cours
ps (process status) liste les processus ; ps -ef les montre tous, avec leur PID et leur PPID.

« Lister les fichiers du dossier » : non. C'est ls.

« Arrêter les processus en cours » : non. Arrêter un processus, c'est kill : ps affiche seulement.

« Afficher la place libre du disque » : non. ps parle des processus, pas du disque.

ps -ef · exemple : ps -ef

Que fait kill [PID] ? Exemple : kill 450

  • Demander l'arrêt d'un processus
  • Supprimer le fichier numéro 450
  • Éteindre l'ordinateur tout de suite
  • Afficher les infos du processus
kill envoie un signal au processus dont on donne le PID, pour qu'il s'arrête ; kill -9 le force.

« Supprimer le fichier numéro 450 » : non. 450 est un PID : le numéro d'un processus.

« Éteindre l'ordinateur tout de suite » : non. kill vise un seul processus, celui du PID.

« Afficher les infos du processus » : non. Afficher les processus, c'est ps.

Que fait le tube | ? Exemple : ps -ef | grep cron

  • Lancer les deux commandes ensemble
  • Enregistrer la sortie dans un fichier
  • Envoyer la sortie de gauche à droite
  • Lancer la droite si la gauche réussit
Le tube | envoie ce qu'affiche la commande de gauche à la commande de droite : ici, grep cron ne garde que les lignes de ps -ef qui contiennent cron.

« Lancer les deux commandes ensemble » : non. Elles ne sont pas indépendantes : celle de droite lit ce qu'affiche celle de gauche.

« Enregistrer la sortie dans un fichier » : non. Enregistrer dans un fichier, c'est >.

« Lancer la droite si la gauche réussit » : non. C'est &&.

Que fait ping [machine] ? Exemple : ping 8.8.8.8

  • Afficher ses propres adresses IP
  • Envoyer un message à la machine
  • Tester si une machine répond
  • Télécharger un fichier de la machine
ping envoie de petits paquets à une machine et attend leur retour : il dit si elle répond, et en combien de millisecondes.

« Afficher ses propres adresses IP » : non. C'est ip addr.

« Envoyer un message à la machine » : non. ping n'envoie aucun message lisible : un petit paquet, qui revient.

« Télécharger un fichier de la machine » : non. ping ne transfère aucun fichier.

2. Lire une liste de processus

eleve s'est connecté·e au serveur lycee à distance (par ssh), a lancé un calcul des marées (python3 marees.py), puis la commande ps -ef. En voici un extrait (les colonnes STIME, TTY et TIME sont retirées) :

eleve@lycee:~$ ps -ef
UID     PID  PPID  C CMD
root      1     0  0 /sbin/init
root     98     1  0 /usr/sbin/cron
root    105     1  0 /usr/sbin/sshd
eleve   118   105  0 sshd: eleve@pts/0
eleve   120   118  0 -bash
eleve   450   120 97 python3 marees.py
eleve   451   120  0 ps -ef

Exemple : la ligne de cron a pour PPID 1 : cron a été créé par le processus 1, /sbin/init.

À ton tour : quel est le processus parent de python3 marees.py ? Donne son nom ou son PID.

Le processus 1 est un ancêtre. Quel nombre lis-tu dans la colonne PPID de la ligne du calcul ?

Ce nombre est un PID de la liste : celui du calcul, ou celui de son parent ? Dans quelle colonne lit-on le parent ?

C'est un ancêtre plus lointain : quel processus porte le PID écrit dans la colonne PPID du calcul ?

C'est le calcul lui-même : qui l'a lancé ?

-bash (PID 120) : la ligne de python3 marees.py a pour PPID 120. C'est le shell depuis lequel eleve a lancé le calcul.

À ton tour : donne les PID de tous les processus créés par -bash (PID 120).

Y a-t-il une seule ligne dont le PPID vaut 120 ? Regarde toutes les lignes.

Ce sont les enfants du processus 1. Quelles lignes ont 120 dans la colonne PPID ?

Le PID 120 est le parent lui-même. Lesquels ont 120 comme PPID ?

450 et 451 : ce sont les deux lignes dont le PPID vaut 120 (le calcul, et ps -ef lui-même).

On relie chaque ligne à son PPID : 98 et 105 à 1 ; 118 à 105 ; 120 à 118 ; 450 et 451 à 120.

Les autres arbres relient un processus à un ancêtre (118 et 120 à 1, ou à 105), ou font de ps -ef un enfant du calcul (son PPID est 120).

Pourquoi la commande ps -ef apparaît-elle dans sa propre liste ?

  • C'est un processus elle aussi, lancé par -bash
  • C'est une erreur d'affichage de la commande
  • Elle reste lancée en permanence, comme cron
  • Elle a été lancée par le processus 1, au démarrage
Pendant qu'elle construit la liste, ps -ef est un programme en cours d'exécution : un processus, créé par -bash (PPID 120). Elle s'arrête juste après.

« C'est une erreur d'affichage de la commande » : non. Pendant qu'elle s'exécute, ps est un processus comme les autres.

« Elle reste lancée en permanence, comme cron » : non. ps s'arrête dès que la liste est affichée.

« Elle a été lancée par le processus 1, au démarrage » : non. Son PPID est 120 : elle a été lancée par -bash.

Qu'écrit-on après kill : un nom, ou un numéro ?

Les majuscules comptent, et kill attend le vrai numéro du processus.

Ta commande arrête bien le calcul, mais elle essaie aussi d'arrêter le processus 9 : pour forcer, comment s'écrit l'option ?

kill 450 : kill envoie au processus 450 le signal de s'arrêter. S'il ne répond plus, kill -9 450 l'arrête de force.

3. Le tube

Exemple : cat tp1.py | grep barge : cat envoie tout le fichier dans le tube, et grep n'en garde que les lignes qui contiennent barge.

À ton tour : complète la commande pour n'afficher, dans la liste des processus, que les lignes qui contiennent marees.

Après le tube, grep lit ce qui arrive de la gauche : faut-il lui donner autre chose que le mot cherché ?

Quelle commande garde seulement les lignes qui contiennent un mot ?

Les majuscules comptent : comment s'écrit le mot dans la liste ?

ps -ef | grep marees : ps -ef envoie la liste dans le tube, grep garde les lignes qui contiennent marees. (La ligne du grep lui-même apparaît souvent aussi : elle contient le mot cherché.)
