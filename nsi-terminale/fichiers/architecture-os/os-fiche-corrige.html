1. Définition et Concept

Qu'est-ce qu'un Système d'Exploitation ?

L'OS est un ensemble de programmes qui fait l'interface entre l'utilisateur, les applications et le matériel. Il gère les ressources (CPU, RAM, périphériques) et fournit un environnement stable pour l'exécution des logiciels.

Le Kernel (Noyau) : Quel est son rôle précis vis-à-vis du matériel ?

C'est le cœur de l'OS. Il gère la communication directe entre le logiciel et le matériel (gestion de la mémoire, accès processeur et pilotes) en mode "superviseur" pour garantir la sécurité.

Dual Boot : Expliquez la possibilité de faire cohabiter deux systèmes sur une machine :

Il s'agit d'installer deux OS sur des partitions différentes d'un même disque. Au démarrage, un programme appelé "Bootloader" (ex: GRUB) permet de choisir quel système lancer.

2. Les 4 Rôles Majeurs de l'OS

FonctionDescription détaillée des mécanismes
Gestion des ProcessusL'ordonnanceur (scheduler) répartit le temps processeur entre les différents programmes en cours d'exécution.
Gestion de la MémoireIl alloue des zones de RAM à chaque application et assure le cloisonnement pour éviter qu'un programme n'écrase les données d'un autre.
Gestion des FichiersIl organise le stockage sur le disque via une structure hiérarchique (système de fichiers comme NTFS, ext4) et gère les droits d'accès.
Gestion des Entrées/SortiesIl sert d'intermédiaire pour les périphériques (clavier, écran, réseau) en utilisant des pilotes (drivers) spécifiques.

4. Interfaces de contrôle

  • GUI (Graphical User Interface) : Interface visuelle avec fenêtres, icônes et menus(ex: Bureau Windows).
  • CLI (Command Line Interface) : Interface textuelle (Terminal) où l'on saisit des commandes (ex: Bash).
  • API (Application Programming Interface) : Ensemble de fonctions prêtes à l'emploi que l'OS offre aux développeurs pour interagir avec le système.

Exercice 1 : Hiérarchie du système

Structure en "couches" (de l'extérieur vers l'intérieur) :

1. Utilisateur
2. Applications
3. Noyau (Kernel)
4. Pilotes (Drivers)
5. Matériel (Hardware)

Exercice 2 : Logiciel libre vs propriétaire

Les 4 libertés fondamentales définies par la FSF :

  • Liberté 0 : Liberté d'utiliser le programme pour tous les usages.
  • Liberté 1 : Liberté d'étudier le fonctionnement du programme (accès au code source).
  • Liberté 2 : Liberté de redistribuer des copies du programme pour aider autrui.
  • Liberté 3 : Liberté d'améliorer le programme et de publier ses améliorations.

Exercice 3 : Analyse de scénario

1. Comment l'OS empêche-t-il le jeu de couper le son de la musique ?

Grâce à l'ordonnancement (Time Sharing). L'OS alterne l'exécution des processus si rapidement qu'ils semblent s'exécuter en même temps. De plus, le noyau gère un mixeur audio logiciel qui centralise les flux sonores de toutes les applications avant de les envoyer à la carte son.

2. Que se passe-t-il au niveau de la RAM si vous ouvrez 100 onglets ? Quel est le rôle de l'OS ?

La RAM sature. L'OS utilise alors la "Mémoire Virtuelle" : il déplace les données des onglets inactifs de la RAM vers une zone du disque dur (Swap). Si cela continue, l'OS peut décider de fermer les processus les plus gourmands (OOM Killer sur Linux) pour éviter le plantage total.
