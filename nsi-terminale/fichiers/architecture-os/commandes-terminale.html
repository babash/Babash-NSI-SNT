1. Naviguer dans l'arborescence

Concepts clés : . représente le répertoire courant ; .. représente le répertoire parent (au-dessus) ; * est un joker qui remplace n'importe quelle suite de caractères (*.txt : tous les fichiers texte).

Complète la colonne « Action » : ce que fait chaque commande.

CommandeAction à compléterExemple
pwdpwd
lsls -la
cd [dir]cd Documents/
historyhistory
clearclear

pwd : afficher le chemin du répertoire de travail actuel. Exemple : pwd.

ls : lister les fichiers et dossiers d'un répertoire. Exemple : ls -la.

cd [dir] : changer de répertoire (se déplacer). Exemple : cd Documents/.

history : afficher la liste des dernières commandes saisies. Exemple : history.

clear : effacer le contenu de l'écran du terminal. Exemple : clear.

Quelle commande sert à afficher le chemin du répertoire de travail actuel ?

cd change de répertoire, il n'affiche pas où tu es.

print working directory : « affiche le répertoire de travail ».

pwd : afficher le chemin du répertoire de travail actuel. Exemple : pwd.

Sous Linux, la commande s'écrit en deux lettres (dir est la commande de Windows).

list, en deux lettres.

ls : lister les fichiers et dossiers d'un répertoire. Exemple : ls -la.

Le mot anglais pour « vider, dégager ».

clear : effacer le contenu de l'écran du terminal. Exemple : clear.

2. Manipuler des fichiers et des dossiers

touch notes.txt crée un fichier vide (ou met à jour sa date).

Complète la colonne « Action » : ce que fait chaque commande.

CommandeAction à compléterExemple
touch [file]Créer un objet / fichier videtouch notes.txt
mkdir [nom]mkdir NSI_TP
cp [src] [dest]cp doc.txt /tmp/
mv [src] [dest]mv ancien.txt nouveau.txt
rm [file]rm fichier.temp
rmdir [nom]rmdir dossier_vide
unzip [file]unzip archive.zip

mkdir [nom] : créer un nouveau répertoire (dossier). Exemple : mkdir NSI_TP.

cp [src] [dest] : copier un fichier ou un répertoire. Exemple : cp doc.txt /tmp/.

mv [src] [dest] : déplacer ou renommer un fichier ou un répertoire. Exemple : mv ancien.txt nouveau.txt.

rm [file] : supprimer un fichier. Exemple : rm fichier.temp.

rmdir [nom] : supprimer un répertoire vide. Exemple : rmdir dossier_vide.

unzip [file] : extraire les fichiers d'une archive compressée .zip. Exemple : unzip archive.zip.

Quelle commande sert à créer un nouveau répertoire (dossier) ?

touch crée un fichier, pas un dossier.

make directory.

mkdir [nom] : créer un nouveau répertoire (dossier). Exemple : mkdir NSI_TP.

Quelle commande sert à copier un fichier ou un répertoire ?

mv déplace : l'original disparaît. Pour garder l'original, on copie.

copy, en deux lettres.

cp [src] [dest] : copier un fichier ou un répertoire. Exemple : cp doc.txt /tmp/.

Quelle commande sert à déplacer ou renommer un fichier ou un répertoire ?

cp garde l'original : ici, l'ancien nom disparaît.

move, en deux lettres. La même commande sert à renommer.

mv [src] [dest] : déplacer ou renommer un fichier ou un répertoire. Exemple : mv ancien.txt nouveau.txt.

Quelle commande sert à supprimer un fichier ?

rmdir supprime un dossier vide, pas un fichier.

remove, en deux lettres. Attention : pas de corbeille.

rm [file] : supprimer un fichier. Exemple : rm fichier.temp.

Quelle commande sert à supprimer un répertoire vide ?

rm seul refuse de supprimer un dossier : il existe une commande pour les dossiers vides.

remove directory.

rmdir [nom] : supprimer un répertoire vide. Exemple : rmdir dossier_vide.

Quelle commande sert à extraire les fichiers d'une archive compressée .zip ?

zip crée une archive ; on veut l'inverse.

Le contraire de zip.

unzip [file] : extraire les fichiers d'une archive compressée .zip. Exemple : unzip archive.zip.

4. Gérer les droits et les utilisateurs

U (User) : le propriétaire ; G (Group) : les membres du groupe du fichier ; O (Others) : tous les autres. Mode octal : on additionne r = 4, w = 2, x = 1 (7 = rwx, 5 = r-x). Mode relatif : + ou - ajoute ou retire un droit (g+x rend le fichier exécutable pour le groupe). sudo [cmd] lance une commande en tant que super-utilisateur (sudo apt update).

Complète la colonne « Action » : ce que fait chaque commande.

CommandeAction à compléterExemple
chmod [mode]chmod 755 script.sh
chown [user]chown prof devoirs.py
sudo [cmd]Lancer une commande en tant que super-utilisateursudo apt update
passwdpasswd

chmod [mode] : modifier les permissions d'accès d'un fichier. Exemple : chmod 755 script.sh.

chown [user] : changer le propriétaire d'un fichier. Exemple : chown prof devoirs.py.

passwd : modifier le mot de passe de l'utilisateur. Exemple : passwd.

Quelle commande sert à modifier les permissions d'accès d'un fichier ?

chown change le propriétaire, pas les droits.

change mode.

chmod [mode] : modifier les permissions d'accès d'un fichier. Exemple : chmod 755 script.sh.

Quelle commande sert à changer le propriétaire d'un fichier ?

chmod change les droits (r, w, x), pas le propriétaire.

change owner.

chown [user] : changer le propriétaire d'un fichier. Exemple : chown prof devoirs.py.

Quelle commande sert à modifier le mot de passe de l'utilisateur ?

Presque : la commande est plus courte, sans « o » ni « r ».

password, en abrégé : six lettres.

passwd : modifier le mot de passe de l'utilisateur. Exemple : passwd.

5. Gérer les processus et le système

Un processus est un programme en cours d'exécution, identifié par son PID. kill [PID] demande au processus de s'arrêter ; s'il est bloqué, kill -9 [PID] (le signal SIGKILL) le fait arrêter tout de suite par le noyau, sans lui laisser le temps de sauvegarder.

Complète la colonne « Action » : ce que fait chaque commande.

CommandeAction à compléterExemple
psps -ef
toptop
kill [PID]kill 1234
df -hdf -h
ip addrip addr
ping [host]ping google.com

ps : lister les processus en cours d'exécution. Exemple : ps -ef.

top : afficher les processus en temps réel (comme un gestionnaire de tâches). Exemple : top.

kill [PID] : envoyer un signal pour arrêter un processus. Exemple : kill 1234.

df -h : afficher l'espace disque disponible, dans un format lisible. Exemple : df -h.

ip addr : afficher les adresses IP et les interfaces réseau. Exemple : ip addr.

ping [host] : tester la connexion réseau vers une machine. Exemple : ping google.com.

Quelle commande sert à lister les processus en cours d'exécution ?

ls liste des fichiers, pas des processus.

process status, en deux lettres.

ps : lister les processus en cours d'exécution. Exemple : ps -ef.

Quelle commande sert à afficher les processus en temps réel (comme un gestionnaire de tâches) ?

ps donne une photo, à un instant : pour suivre en temps réel, c'est une autre commande.

Elle montre en haut les processus qui consomment le plus.

top : afficher les processus en temps réel (comme un gestionnaire de tâches). Exemple : top.

Quelle commande sert à envoyer un signal pour arrêter un processus ?

rm supprime un fichier ; un processus s'arrête avec un signal.

Le mot anglais pour « tuer ».

kill [PID] : envoyer un signal pour arrêter un processus. Exemple : kill 1234.

Quelle commande sert à afficher l'espace disque disponible, dans un format lisible ?

du mesure la place prise par des fichiers ; l'espace libre des disques, c'est df.

disk free ; l'option -h : human-readable.

df -h : afficher l'espace disque disponible, dans un format lisible. Exemple : df -h.

Quelle commande sert à afficher les adresses IP et les interfaces réseau ?

ping teste une autre machine ; on veut les adresses de son propre ordinateur.

La commande ip, suivie de addr.

ip addr : afficher les adresses IP et les interfaces réseau. Exemple : ip addr.

Quelle commande sert à tester la connexion réseau vers une machine ?

ip addr affiche tes propres adresses ; elle ne teste pas une autre machine.

Comme une balle de ping-pong : un aller, un retour.

ping [host] : tester la connexion réseau vers une machine. Exemple : ping google.com.

6. Chemins absolus et chemins relatifs

D'où part toujours un chemin absolu ?

  • Du sommet de l'arborescence : la racine /.
  • Du répertoire courant, là où l'on se trouve.
  • Du répertoire personnel de l'utilisateur, noté ~.
  • Du répertoire parent, noté ...

Un chemin absolu marche quel que soit l'endroit où l'on est.

Un chemin absolu part toujours de la racine, / : par exemple /home/nsi/TP1.

Complète la phrase : « Un chemin absolu part toujours … / »

… de la racine, /.

D'où part un chemin relatif ?

  • De la racine /, comme un chemin absolu.
  • Du répertoire courant, où l'on se trouve.
  • Toujours du dossier /home, où que l'on soit.
  • Du dossier qui contient le fichier cherché.

../Projets n'a pas le même sens selon l'endroit où l'on tape la commande.

Un chemin relatif part du répertoire courant (celui que donne pwd). Astuce : la touche Tabulation complète les noms tout seule.

Complète la phrase : « Un chemin relatif part … »

… du répertoire courant, là où l'on se trouve (celui que donne pwd).
