1. Rappels : se déplacer, copier, créer

L'arborescence du TD (la même qu'en première), telle que l'affiche la commande tree (les dossiers finissent par /). L'utilisateur·rice eleve et l'enseignant·e prof font partie du même groupe, nsi.

/
|-- bin/
|-- home/
|   |-- eleve/
|   |   |-- devoirs/
|   |   |   `-- nsi/
|   |   |       `-- tp1.py
|   |   |-- photos/
|   |   |   `-- lagon.png
|   |   `-- projets/
|   |       `-- site.html
|   `-- prof/
|       |-- examens/
|       `-- notes.csv
`-- tmp/

Pour t'entraîner dans un vrai terminal (facultatif) : ouvre le terminal d'entraînement d'Opération MIRAGE (rien à installer) ou JSLinux (un vrai Linux dans le navigateur), puis recrée l'arborescence du TD avec ces trois commandes :

mkdir -p /home/eleve/devoirs/nsi /home/eleve/photos /home/eleve/projets /home/prof/examens
touch /home/eleve/devoirs/nsi/tp1.py /home/eleve/photos/lagon.png /home/eleve/projets/site.html /home/prof/notes.csv
cd /home/eleve/devoirs/nsi

Là-bas, tu es root (l'administrateur·rice) : ~ y désigne /root, et sudo n'y existe pas.

Un chemin absolu part toujours de la racine /, d'où que l'on soit : /home/eleve/devoirs/nsi. Un chemin relatif part du répertoire courant et remonte avec .. : depuis /home/eleve, devoirs/nsi ou ../prof.

Exemples résolus (à ton tour ensuite, en dessous) :

De nsi à photos (relatif) : cd ../../photos
De photos à projets (absolu) : cd /home/eleve/projets
De projets, lister nsi : ls ../devoirs/nsi
De nsi, copier tp1.py dans projets : cp tp1.py ../../projets/
De eleve, créer brouillons dans photos : mkdir photos/brouillons

Exemples : depuis nsi, aller dans photos en relatif : cd ../../photos · depuis photos, aller dans projets en absolu : cd /home/eleve/projets · depuis projets, lister nsi : ls ../devoirs/nsi · depuis nsi, copier tp1.py dans projets : cp tp1.py ../../projets/ · depuis eleve, créer brouillons dans photos : mkdir photos/brouillons.

Depuis /home/eleve/devoirs, va dans projets (chemin relatif).

cd ../projets : .. remonte dans eleve, puis on descend dans projets.

Erreur fréquente : cd projets : projets n'est pas dans devoirs : il faut d'abord remonter au parent.

Erreur fréquente : cd /home/eleve/projets : ce chemin part de la racine (ou de ~) : on demande un chemin relatif, qui part de devoirs.

Depuis /home/eleve/projets, va dans /home/eleve (chemin absolu).

cd /home/eleve : le chemin part de la racine. (cd .. et cd ~ y mènent aussi, mais ce ne sont pas des chemins absolus écrits en entier.)

Erreur fréquente : cd .. : c'est juste, mais .. est un chemin relatif. On demande un chemin absolu, qui part de /.

Erreur fréquente : cd ~ : c'est juste, mais ~ est un raccourci : écris le chemin absolu en entier.

Depuis /home/eleve/devoirs, liste le contenu de photos.

ls ../photos (ou, en chemin absolu, ls /home/eleve/photos) : la commande affiche lagon.png.

Erreur fréquente : ls photos : photos n'est pas dans devoirs : il faut remonter d'un cran.

Erreur fréquente : cd ../photos : cette commande te déplace, sans rien afficher. Pour voir le contenu, c'est une autre commande.

Depuis /home/eleve/projets, copie site.html dans devoirs.

cp site.html ../devoirs/ : la source est dans le répertoire courant ; la destination, devoirs, est à côté de projets.

Erreur fréquente : mv site.html ../devoirs/ : mv déplace : site.html disparaîtrait de projets. On veut une copie.

Erreur fréquente : cp site.html devoirs : devoirs n'est pas dans projets : cette commande crée, dans projets, une copie nommée devoirs.

Depuis /home/eleve, crée un dossier archives dans devoirs.

mkdir devoirs/archives : chemin relatif, depuis eleve.

Erreur fréquente : mkdir archives : ce dossier serait créé dans eleve, pas dans devoirs.

Erreur fréquente : touch devoirs/archives : touch crée un fichier ; pour un dossier, c'est mkdir.

2. Rappels : la bonne commande

Exemple : la commande qui affiche le chemin absolu du répertoire courant est pwd.

Quelle commande affiche tout le contenu d'un fichier ?

cat (more et less le montrent aussi, page par page).

Erreur fréquente : ls : ls affiche le nom des fichiers, pas ce qu'ils contiennent.

Quelle commande supprime un dossier vide ?

rmdir : il refuse un dossier qui n'est pas vide, c'est le plus sûr.

Erreur fréquente : rm : rm seul refuse de supprimer un dossier (« Is a directory »).

Erreur fréquente : rm -r : rm -r marche, mais il efface aussi tout ce que contient le dossier : pour un dossier vide, rmdir est plus sûr.

Quelle commande affiche les lignes d'un fichier qui contiennent un mot ?

grep : grep print tp1.py.

Erreur fréquente : find : find cherche des fichiers par leur nom, pas dans leur contenu.

Erreur fréquente : cat : cat affiche tout le fichier, sans trier les lignes.

Quelle commande affiche le manuel d'une commande ?

man : man ls (on en sort avec la touche q).

Erreur fréquente : help : help donne une aide courte sur quelques commandes du shell ; le manuel complet, c'est man.

3. Rappels : les droits

Exemple : chmod 755 tp1.py donne rwxr-xr-x ; chmod g-w tp1.py retire l'écriture au groupe.

À ton tour : quels droits le groupe nsi a-t-il sur tp1.py ?

eleve@lycee:~/devoirs/nsi$ ls -l tp1.py
-rwxrw-r-- 1 eleve nsi 155 Nov 25 10:00 tp1.py
  • Lire et écrire (rw-)
  • Lire, écrire et exécuter (rwx)
  • Lire seulement (r--)
  • Lire et exécuter (r-x)

- (un fichier), rwx (propriétaire eleve), rw- (groupe nsi), r-- (autres) : le groupe peut lire et écrire, pas exécuter.

« Lire, écrire et exécuter (rwx) » : non. rwx sont les droits du propriétaire, eleve : les trois premiers après le tiret.

« Lire seulement (r--) » : non. r-- sont les droits des autres : les trois derniers.

« Lire et exécuter (r-x) » : non. le groupe n'a pas x : sa troisième lettre est un tiret.

À ton tour : quels droits le groupe nsi a-t-il sur tp1.py ?

eleve@lycee:~/devoirs/nsi$ ls -l tp1.py
-rwxrw-r-- 1 eleve nsi 155 Nov 25 10:00 tp1.py

- (un fichier), rwx (propriétaire eleve), rw- (groupe nsi), r-- (autres) : le groupe peut lire et écrire, pas exécuter.

À ton tour : tu es dans nsi. En octal, donne tous les droits à tout le monde sur tp1.py.

chmod 777 tp1.py : 7 = 4 + 2 + 1 = rwx, pour le propriétaire, le groupe et les autres.

Erreur fréquente : chmod 666 tp1.py : 666 donne lire et écrire, sans exécuter : il manque x = 1.

Erreur fréquente : chmod a+rwx tp1.py : c'est juste, mais en symbolique. On demande l'octal.

À ton tour : en symbolique, ajoute le droit d'exécution aux autres (others) sur tp1.py.

chmod o+x tp1.py : o (les autres), + (ajouter), x (exécuter). Les droits deviennent -rwxrw-r-x.

Erreur fréquente : chmod +x tp1.py : sans lettre (ou avec a), le droit est ajouté à tout le monde. Les autres, c'est o.

Erreur fréquente : chmod g+x tp1.py : g désigne le groupe. Les autres, c'est o.

history : afficher les commandes déjà tapées.

ps (process status) : lister les processus en cours d'exécution.

top : afficher les processus en temps réel, ceux qui consomment le plus en haut.

kill : envoyer un signal à un processus, pour l'arrêter.

Exemple : find [dossier] -name [nom] cherche des fichiers par leur nom : find ~ -name "*.py" affiche /home/eleve/devoirs/nsi/tp1.py. À ton tour, pour les autres commandes.

Que fait la commande history ?

  • Afficher les commandes déjà tapées
  • Afficher le contenu des fichiers récents
  • Annuler la dernière commande tapée
  • Afficher les fichiers modifiés aujourd'hui

history affiche la liste des commandes déjà tapées, numérotées.

« Afficher le contenu des fichiers récents » : non. history ne lit aucun fichier de l'utilisateur·rice : elle liste les commandes tapées.

« Annuler la dernière commande tapée » : non. Il n'y a pas d'annulation dans le terminal : history affiche seulement.

« Afficher les fichiers modifiés aujourd'hui » : non. Pour des fichiers, on utiliserait ls ou find : history parle des commandes.

Que fait la commande ps ? Exemple : ps -ef

  • Lister les processus en cours d'exécution
  • Lister les fichiers du répertoire courant
  • Afficher la place libre sur le disque
  • Arrêter tous les processus de l'utilisateur·rice

ps (process status) liste les processus en cours d'exécution ; ps -ef les montre tous, avec leur PID et leur PPID.

« Lister les fichiers du répertoire courant » : non. Lister des fichiers, c'est ls.

« Afficher la place libre sur le disque » : non. La place libre, c'est df -h.

« Arrêter tous les processus de l'utilisateur·rice » : non. Arrêter un processus, c'est kill : ps ne fait qu'afficher.

Que fait la commande top ?

  • Afficher les processus en temps réel
  • Afficher les fichiers les plus gros
  • Afficher le haut d'un fichier texte
  • Remonter à la racine de l'arborescence

top affiche les processus en temps réel, ceux qui consomment le plus en haut (comme un gestionnaire de tâches) ; on en sort avec q.

« Afficher les fichiers les plus gros » : non. top parle des processus, pas des fichiers.

« Afficher le haut d'un fichier texte » : non. Le début d'un fichier, c'est head.

« Remonter à la racine de l'arborescence » : non. Remonter à la racine, c'est cd /.

Que fait la commande kill [PID] ? Exemple : kill 450

  • Envoyer un signal d'arrêt au processus
  • Supprimer le fichier numéro 450
  • Éteindre l'ordinateur tout de suite
  • Afficher les informations du processus

kill envoie un signal au processus dont on donne le PID, pour lui demander de s'arrêter.

« Supprimer le fichier numéro 450 » : non. kill ne touche pas aux fichiers : 450 est le numéro (PID) d'un processus.

« Éteindre l'ordinateur tout de suite » : non. kill vise un seul processus, celui dont on donne le PID.

« Afficher les informations du processus » : non. Afficher les processus, c'est ps ou top.

Que fait la commande df -h ?

  • Afficher la place libre sur les disques
  • Effacer les fichiers inutiles du disque
  • Afficher l'aide d'une commande
  • Afficher la mémoire vive libre

df (disk free) affiche la place libre sur les disques ; -h l'écrit en Go et Mo.

« Effacer les fichiers inutiles du disque » : non. df ne supprime rien : il affiche.

« Afficher l'aide d'une commande » : non. L'aide, c'est man (ou --help). Ici -h veut dire human-readable, « lisible ».

« Afficher la mémoire vive libre » : non. La mémoire vive se lit avec top (ou free) ; df parle des disques.

Que fait la commande ip addr ?

  • Afficher les adresses IP de la machine
  • Tester si une autre machine répond
  • Changer l'adresse IP de la machine
  • Afficher le nom de l'utilisateur·rice

ip addr affiche les adresses IP de la machine et ses cartes réseau.

« Tester si une autre machine répond » : non. Tester une autre machine, c'est ping.

« Changer l'adresse IP de la machine » : non. ip addr seul ne change rien : il affiche.

« Afficher le nom de l'utilisateur·rice » : non. Le nom de l'utilisateur·rice, c'est whoami.

Que fait la commande ping [machine] ? Exemple : ping 192.168.1.1

  • Tester si une machine répond sur le réseau
  • Afficher les adresses IP de sa machine
  • Envoyer un message à l'utilisateur·rice
  • Télécharger un fichier depuis la machine

ping envoie un petit paquet à une machine et attend sa réponse : elle dit si la machine est joignable, et en combien de millisecondes.

« Afficher les adresses IP de sa machine » : non. Ses propres adresses, c'est ip addr.

« Envoyer un message à l'utilisateur·rice » : non. ping n'envoie aucun message lisible : seulement un petit paquet, et attend la réponse.

« Télécharger un fichier depuis la machine » : non. ping ne transfère aucun fichier.
