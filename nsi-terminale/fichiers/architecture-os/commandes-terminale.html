4. Gestion des Droits et Utilisateurs

U : User (Propriétaire)
L'utilisateur qui possède le fichier.
G : Group (Groupe)
Les utilisateurs membres du groupe du fichier.
O : Others (Autres)
Tous les autres utilisateurs du système.
Modifier les droits (chmod) :
• Mode Octal : On additionne les valeurs r=4, w=2, x=1. (Ex: 7 = rwx, 5 = r-x).
• Mode Relatif : On utilise + ou - pour ajouter/retirer un droit. (Ex: g+x rend le fichier exécutable pour le groupe).
CommandeAction à compléterExemple
chmod [mode]chmod 755 script.sh
chown [user]chown prof devoirs.py
sudo [cmd]Lancer une commande en tant que super-utilisateur sudo apt update
passwdpasswd

5. Gestion des Processus et Système

Un processus est un programme en cours d'exécution identifié par son PID.

Focus sur kill :
La commande kill [PID] demande gentiment au processus de s'arrêter. Si le processus est bloqué, on utilise kill -9 [PID]. Le -9 (SIGKILL) force l'arrêt immédiat et brutal par le noyau, sans laisser au programme le temps de sauvegarder.
CommandeAction à compléterExemple
psps -ef
toptop
kill [PID]kill 1234
df -hdf -h
ip addrip addr
ping [host]ping google.com
