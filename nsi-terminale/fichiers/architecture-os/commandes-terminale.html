  • cp copie (l'original reste) ; mv déplace ou renomme (l'original quitte sa place).

1. Les commandes de base

Pour chaque commande, dis ce qu'elle fait. Exemple : la commande whoami affiche le nom de l'utilisateur·rice connecté·e (ici, eleve).

Que fait ls [dossier] ? Exemple : ls · ls ..

  • Afficher le contenu d'un fichier
  • Lister le contenu d'un dossier
  • Afficher le chemin du dossier
  • Effacer l'écran du terminal
ls (list) liste le contenu du répertoire courant, ou du dossier indiqué : ls .. liste le parent.

« Afficher le contenu d'un fichier » : non. Afficher un fichier, c'est cat.

« Afficher le chemin du dossier » : non. Afficher le chemin, c'est pwd.

« Effacer l'écran du terminal » : non. ls n'efface rien : il affiche une liste de noms.

Que fait cd [chemin] ? Exemple : cd projets

  • Aller dans le dossier indiqué
  • Créer le dossier indiqué, vide
  • Copier le dossier indiqué
  • Lister le contenu du dossier indiqué
cd (change directory) change de répertoire courant : on se déplace dans l'arborescence.

« Créer le dossier indiqué, vide » : non. Créer un dossier, c'est mkdir.

« Copier le dossier indiqué » : non. Copier, c'est cp.

« Lister le contenu du dossier indiqué » : non. Lister, c'est ls.

Que fait cat [fichier] ? Exemple : cat tp1.py

  • Afficher le nom des fichiers du dossier
  • Chercher un mot à l'intérieur d'un fichier
  • Créer un fichier, puis l'ouvrir
  • Afficher tout le contenu d'un fichier
cat affiche tout le contenu d'un fichier dans le terminal.

« Afficher le nom des fichiers du dossier » : non. Les noms, c'est ls.

« Chercher un mot à l'intérieur d'un fichier » : non. Chercher un mot, c'est grep.

« Créer un fichier, puis l'ouvrir » : non. Créer un fichier vide, c'est touch ; cat n'ouvre aucun éditeur.

Que fait man [commande] ? Exemple : man ls

  • Afficher le manuel d'une commande
  • Exécuter une commande en tant que root
  • Afficher l'utilisateur·rice connecté·e
  • Interrompre une commande bloquée
man affiche le manuel d'une commande (on en sort avec la touche q).

« Exécuter une commande en tant que root » : non. C'est sudo.

« Afficher l'utilisateur·rice connecté·e » : non. C'est whoami.

« Interrompre une commande bloquée » : non. C'est la touche Ctrl+C.

Que fait mkdir [dossier] ? Exemple : mkdir archives

  • Créer un fichier vide
  • Supprimer un dossier
  • Créer un dossier
  • Aller dans un dossier
mkdir (make directory) crée un dossier.

« Créer un fichier vide » : non. Un fichier vide, c'est touch.

« Supprimer un dossier » : non. Supprimer un dossier vide, c'est rmdir.

« Aller dans un dossier » : non. Se déplacer, c'est cd.

mkdir (make directory) crée un dossier.

Que fait cp [source] [destination] ? Exemple : cp notes.csv projets/

  • Copier, en gardant l'original
  • Déplacer, sans garder l'original
  • Renommer le fichier indiqué
  • Comparer les deux fichiers
cp (copy) copie la source vers la destination : l'original reste à sa place.

« Déplacer, sans garder l'original » : non. Si l'original disparaît, c'est mv.

« Renommer le fichier indiqué » : non. Renommer, c'est mv.

« Comparer les deux fichiers » : non. cp ne compare rien : il fabrique une copie.

Que fait mv [source] [destination] ? Exemple : mv nsi ../archives/

  • Copier, en gardant l'original
  • Supprimer un fichier
  • Déplacer ou renommer
  • Créer la destination
mv (move) déplace ou renomme : l'original quitte sa place.

« Copier, en gardant l'original » : non. Garder l'original, c'est cp.

« Supprimer un fichier » : non. C'est rm.

« Créer la destination » : non. Créer un dossier, c'est mkdir.

Que fait rm [fichier] ? Exemple : rm brouillon.txt

  • Mettre un fichier à la corbeille
  • Vider un fichier, sans le supprimer
  • Renommer un fichier
  • Supprimer un fichier, pour de bon
rm (remove) supprime un fichier, définitivement.

« Mettre un fichier à la corbeille » : non. Il n'y a pas de corbeille dans le terminal : le fichier est perdu.

« Vider un fichier, sans le supprimer » : non. rm ne garde rien : le fichier disparaît.

« Renommer un fichier » : non. C'est mv.

rm [fichier] · exemple : rm brouillon.txt

Que fait rm -r [dossier] ? Exemple : rm -r archives

  • Supprimer un dossier, s'il est vide
  • Supprimer un dossier et son contenu
  • Renommer un dossier et son contenu
  • Vider un dossier, en le gardant
rm -r (récursif) supprime un dossier et tout ce qu'il contient, sans corbeille.

« Supprimer un dossier, s'il est vide » : non. Un dossier vide seulement, c'est rmdir.

« Renommer un dossier et son contenu » : non. Renommer, c'est mv.

« Vider un dossier, en le gardant » : non. rm -r supprime aussi le dossier lui-même.

2. Chemins

L'arborescence du TD (D : dossier ; F : fichier). L'utilisateur·rice connecté·e est eleve ; son dossier personnel est /home/eleve. eleve et l'enseignant·e prof sont dans le même groupe, info : prof lui a donné le droit de lire notes.csv et d'écrire dans examens.

/ (racine)
|-- bin/ (D)
|-- home/ (D)
|   |-- eleve/ (D)
|   |   |-- devoirs/ (D)
|   |   |   `-- nsi/ (D)
|   |   |       `-- tp1.py (F)
|   |   `-- projets/ (D)
|   `-- prof/ (D)
|       |-- examens/ (D)
|       `-- notes.csv (F)
`-- tmp/ (D)

Exemple : depuis /home/eleve, cd projets, cd ./projets et cd /home/eleve/projets mènent toutes dans projets ; cd /projets, non : il n'y a pas de dossier projets sous la racine.

3. Les droits

eleve@lycee:~$ ls -l /home/prof
total 8
drwxrwx--- 2 prof info 4096 Nov 25 10:00 examens
-rw-r----- 1 prof info   38 Nov 25 10:00 notes.csv

Exemple : dans la ligne de examens, d : un dossier ; rwx pour le propriétaire, prof ; rwx pour le groupe, info ; --- pour les autres.

À ton tour : quels droits le groupe info a-t-il sur notes.csv ?

  • Lire seulement (r--)
  • Lire et écrire (rw-)
  • Aucun droit (---)
  • Lire et exécuter (r-x)
- (un fichier), rw- (le propriétaire, prof), r-- (le groupe, info), --- (les autres) : le groupe peut lire le fichier, pas le modifier.

« Lire et écrire (rw-) » : non. rw- sont les droits du propriétaire, prof : les trois premières lettres après le tiret.

« Aucun droit (---) » : non. --- sont les droits des autres : les trois dernières lettres.

« Lire et exécuter (r-x) » : non. Il n'y a aucun x dans -rw-r----- : personne ne peut l'exécuter.

À ton tour : quels droits le groupe info a-t-il sur notes.csv ?

- (un fichier), rw- (le propriétaire, prof), r-- (le groupe, info), --- (les autres) : le groupe peut lire le fichier, pas le modifier.

Exemple : chmod 750 tp1.py donne rwxr-x--- : 7 = 4 + 2 + 1 (rwx), 5 = 4 + 1 (r-x), 0 (---).

À ton tour : tu es dans nsi. En octal, rends tp1.py lisible et modifiable par son propriétaire (toi), sans aucun droit ni pour le groupe ni pour les autres.

On demande lire et écrire : combien vaut r ? et w ? Faut-il x ?

Dans quel ordre se lisent les trois chiffres ?

Le groupe et les autres doivent-ils garder un droit ?

Qu'écrit-on après chmod : les droits, puis quoi ?

C'est du symbolique : on demande l'octal, avec des chiffres.

chmod 600 tp1.py : 6 = 4 + 2 (rw-) pour le propriétaire, 0 (---) pour le groupe et pour les autres.

Exemple : chmod g+w notes.csv ajoute l'écriture au groupe : -rw-r----- devient -rw-rw----.

À ton tour : en symbolique, ajoute le droit d'exécution au propriétaire de tp1.py (tu es dans nsi), sans changer les autres droits.

À qui ton +x donne-t-il le droit ? Avec quelle lettre désigne-t-on le seul propriétaire ?

Quelle lettre désigne le propriétaire : o, g ou u ?

Dans quel ordre écrit-on : qui, le signe, le droit ?

C'est de l'octal, et il change aussi d'autres droits : on demande le symbolique.

Les majuscules comptent : comment s'écrivent u et x ?

chmod u+x tp1.py : u (user, le propriétaire), + (ajouter), x (exécution).

Exemple : pour donner tp1.py à prof : sudo chown prof tp1.py.

À ton tour : tu es prof, dans /home/prof. Donne notes.csv à direction.

Changer le propriétaire est réservé à root : que faut-il ajouter devant ta commande ?

Dans chown, qu'écrit-on d'abord : le nouveau propriétaire, ou le fichier ?

chmod change les droits. Quelle commande change le propriétaire ?

Les majuscules comptent : comment s'écrivent la commande et le nom ?

sudo chown direction notes.csv : chown (change owner) change le propriétaire, et sudo lui donne les droits de root.
