Exercice 1 · Une file avec deux piles (4 points)

Sujet : baccalauréat 2021, Métropole (mars), jour 2, exercice 5 (4 points). Le sujet d'origine (PDF).

Cet exercice porte sur les structures de données linéaires.

Une méthode simple pour gérer l'ordonnancement des processus est d'exécuter les processus en une seule fois et dans leur ordre d'arrivée.

1. Parmi les propositions suivantes, quelle est la structure de données la plus appropriée pour mettre en œuvre le mode FIFO (First In First Out) ?

  • a) liste
  • b) dictionnaire
  • c) pile
  • d) file

Traduis First In First Out : « premier entré, premier sorti ». Quelle structure de la fiche fonctionne comme une file d'attente ?

d) file. Dans une file, on enfile à la queue et on défile à la tête : le premier arrivé est le premier servi (FIFO). Une pile est LIFO.

2. On choisit de stocker les données des processus en attente à l'aide d'une liste Python lst. On dispose déjà d'une fonction retirer(lst) qui renvoie l'élément lst[0] puis le supprime de la liste lst. Écrire en Python le code d'une fonction ajouter(lst, proc) qui ajoute à la fin de la liste lst le nouveau processus en attente proc.

def ajouter(lst, proc):
    [[lst.append(proc)|lst += [proc]|lst.insert(len(lst), proc)]]

Quelle méthode des listes Python ajoute un élément à la fin ?

La fonction ne renvoie rien : elle modifie la liste lst qu'elle reçoit.

def ajouter(lst, proc):
    lst.append(proc)

append ajoute à la fin et modifie la liste elle-même. Attention : lst = lst + [proc] crée une nouvelle liste, et la liste de départ ne change pas.

On choisit maintenant d'implémenter une file file à l'aide d'un couple (p1,p2) où p1 et p2 sont des piles. Ainsi file[0] et file[1] sont respectivement les piles p1 et p2.

Pour enfiler un nouvel élément elt dans file, on l'empile dans p1.

Pour défiler file, deux cas se présentent.

  • La pile p2 n'est pas vide : on dépile p2.
  • La pile p2 est vide : on dépile les éléments de p1 en les empilant dans p2 jusqu'à ce que p1 soit vide, puis on dépile p2.

Illustration du fonctionnement des fonctions enfiler et défiler (redessinée d'après le sujet).

3. On considère la situation représentée ci-dessous.

On exécute la séquence d'instructions suivante :

enfiler(file,ps6)
defiler(file)
defiler(file)
defiler(file)
enfiler(file,ps7)

Représenter le contenu final des deux piles à la suite de ces instructions. Ici, d'abord la pile p1.

Regarde la dernière instruction : enfiler empile toujours dans p1.

Au 3e defiler, p2 est vide : tout p1 (ps6 compris) est versé dans p2.

Avance instruction par instruction et dessine les deux piles à chaque fois.

Les deux premiers defiler retirent ps1 puis ps2 de p2. Au troisième, p2 est vide : que fait-on ?

p1 ne contient que ps7 : le 3e defiler a vidé p1 dans p2, puis enfiler(file,ps7) a empilé ps7 dans p1.

3 (suite). Même question pour la pile p2 : son contenu final, de haut en bas.

C'est l'ordre inverse. On verse p1 en dépilant : ps6, le sommet de p1, est versé en premier, il se retrouve donc au fond de p2.

Presque : le 3e defiler verse p1 dans p2, puis dépile p2. Il retire donc ps3.

Après enfiler(file,ps6), p1 contient, de haut en bas : ps6 ps5 ps4 ps3.

Verser p1 dans p2 retourne l'ordre : le sommet de p1 va au fond de p2.

Au 3e defiler, on dépile ps6, ps5, ps4, ps3 de p1 et on les empile dans p2 : ps3 arrive au sommet et il est défilé (c'était le plus ancien). Il reste dans p2, de haut en bas : ps4 ps5 ps6. Les processus sortent bien dans leur ordre d'arrivée.

4. On dispose des fonctions :

  • empiler(p,elt) qui empile l'élément elt dans la pile p,
  • depiler(p) qui renvoie le sommet de la pile p si p n'est pas vide et le supprime,
  • pile_vide(p) qui renvoie True si la pile p est vide, False si la pile p n'est pas vide.

4.a. Écrire en Python une fonction est_vide(f) qui prend en argument un couple de piles f et qui renvoie True si la file représentée par f est vide, False sinon.

def est_vide(f):
    return [[pile_vide(f[0]) and pile_vide(f[1])|pile_vide(f[1]) and pile_vide(f[0])]]

La file est vide quand il n'y a plus rien ni dans p1, ni dans p2.

f[0] est la pile p1 et f[1] la pile p2. Utilise pile_vide deux fois.

def est_vide(f):
    return pile_vide(f[0]) and pile_vide(f[1])

Les deux piles doivent être vides : on relie les deux tests par and. Attention, ici pile_vide(p) teste si une pile est vide : lis toujours l'interface donnée par l'énoncé.

4.b. Écrire en Python une fonction enfiler(f,elt) qui prend en arguments un couple de piles f et un élément elt et qui ajoute elt en queue de la file représentée par f.

def enfiler(f, elt):
    [[empiler(f[0], elt)]]

Relis la règle : « Pour enfiler un nouvel élément elt dans file, on l'empile dans p1. »

def enfiler(f, elt):
    empiler(f[0], elt)

On empile dans p1, c'est-à-dire f[0]. On n'utilise que la fonction empiler de l'énoncé, pas append.

4.c. Écrire en Python une fonction defiler(f) qui prend en argument un couple de piles f et qui renvoie l'élément en tête de la file représentée par f en le retirant. Ici, les trois fonctions de l'énoncé sont déjà programmées ; lance ton code pour le tester.

# Déjà programmé : ici, une pile est une liste Python.
def empiler(p, elt):
    p.append(elt)

def depiler(p):
    return p.pop()

def pile_vide(p):
    return p == []


# À toi : f est un couple (p1, p2) de piles.
def defiler(f):
    ...

Deux cas, comme dans l'énoncé : un if qui teste si p2 (c'est-à-dire f[1]) est vide.

Si p2 est vide : une boucle while not pile_vide(f[0]): qui dépile p1 et empile dans p2. Dans les deux cas, on finit par return depiler(f[1]).

def defiler(f):
    if pile_vide(f[1]):
        while not pile_vide(f[0]):
            empiler(f[1], depiler(f[0]))
    return depiler(f[1])

Si p2 est vide, on y verse tout p1 : l'ordre est retourné et le plus ancien élément arrive au sommet. Ensuite, dans tous les cas, on dépile p2. On ne verse jamais p1 dans une pile p2 qui n'est pas vide : l'ordre d'arrivée serait perdu.

Mémo

Pile : dernier entré, premier sorti (LIFO), tout se passe au sommet. File : premier entré, premier sorti (FIFO), on enfile à la queue et on défile à la tête.

Verser une pile dans une autre retourne l'ordre. Avec deux piles, on fait une file : on enfile dans p1 ; on défile dans p2, après y avoir versé p1 si p2 est vide.

On n'utilise que l'interface donnée par l'énoncé : les noms changent d'un sujet à l'autre (empiler ou empile, pile_vide qui teste ou qui crée…).
