Exercice 1 · Chiffrer avec un dictionnaire (4 points)

Sujet : baccalauréat 2022, Centres étrangers, jour 2 (22-NSIJ2G11), exercice 2, pages 4 et 5. Sujet officiel (PDF) · version de l'AEIF.

Cet exercice porte sur les structures de données (dictionnaires).

Le chiffrement par substitution consiste à mélanger les lettres d'un alphabet, puis à réécrire le message en remplaçant chaque lettre par sa correspondante. Un dictionnaire de chiffrement associe chaque lettre à sa lettre mélangée. Par exemple, avec le dictionnaire alpha = {"A": "B", "B": "D", "C": "A", "D": "C"}, le mot "BAC" est chiffré en "DBA".

Dans les questions 1 à 3, on utilise le dictionnaire :

alpha = {"A": "B", "B": "D", "C": "A", "D": "C", "E": "F", "F": "G", "G": "E"}

[1. a] Donne la valeur associée à la clé "D" dans le dictionnaire alpha…

C'est la clé associée à la valeur "D". On cherche l'inverse : ce qui est écrit après "D":.

Cherche la paire qui commence par "D":.

La paire est "D": "C" : la valeur associée à "D" est "C".

[1. a, suite] … et indique comment l'obtenir en Python.

On lit une valeur grâce à sa clé, pas grâce à une position : la clé est "D".

On écrit le nom du dictionnaire, puis la clé entre crochets.

alpha["D"] renvoie "C". Un dictionnaire n'a pas d'indices : alpha[3] provoquerait une erreur KeyError.

[1. b] Chiffre le mot "BAGAGE" avec ce dictionnaire.

Tu as lu le dictionnaire à l'envers : on part de la lettre du mot (la clé) pour trouver sa lettre chiffrée (la valeur).

Remplace chaque lettre par sa valeur : B devient D, A devient B…

B → D, A → B, G → E, A → B, G → E, E → F : DBEBEF.

[2] Écris une fonction chiffrer qui prend en paramètres un mot mot (une chaîne de caractères formée seulement des 26 lettres majuscules, sans accent, sans espace ni ponctuation) et un dictionnaire de chiffrement alpha, et qui renvoie le mot chiffré.

>>> chiffrer("BAC", {"A": "B", "B": "D", "C": "A", "D": "C"})
'DBA'
def chiffrer(mot, alpha):

Pars d'une chaîne vide, puis parcours le mot lettre par lettre.

Pour chaque lettre, ajoute à la fin du résultat sa valeur alpha[lettre].

def chiffrer(mot, alpha):
    resultat = ""
    for lettre in mot:
        resultat = resultat + alpha[lettre]
    return resultat

On parcourt la chaîne et on concatène les lettres chiffrées. La chaîne de départ n'est pas modifiée (une chaîne ne se modifie pas en Python).

[3. a] Pour un mot chiffré avec alpha, donne un dictionnaire qui permet de le déchiffrer.

dechiffrement = {"B": [["A"]], "D": [["B"]], "A": [["C"]], "C": [["D"]],
                 "F": [["E"]], "G": [["F"]], "E": [["G"]]}

Pour déchiffrer, on part de la lettre chiffrée (la valeur de alpha) pour retrouver la lettre d'origine (sa clé).

Dans alpha, "A": "B" : la lettre chiffrée B se déchiffre en A.

On échange clés et valeurs : {"B": "A", "D": "B", "A": "C", "C": "D", "F": "E", "G": "F", "E": "G"}. C'est possible car deux lettres différentes ne sont jamais chiffrées par la même lettre.

[3. b] Recopie et complète la fonction dico_dechiffrement, qui prend en paramètre un dictionnaire de chiffrement dico et renvoie le dictionnaire de déchiffrement.

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico :
        code = dico[ [[lettre]] ]
        nouveau[ [[code]] ] = [[lettre]]
    return nouveau

alpha = {"A": "B", "B": "D", "C": "A", "D": "C", "E": "F", "F": "G", "G": "E"}
print(dico_dechiffrement(alpha))
{'B': 'A', 'D': 'B', 'A': 'C', 'C': 'D', 'F': 'E', 'G': 'F', 'E': 'G'}

La boucle parcourt les clés de dico : lettre est une lettre d'origine, code sa lettre chiffrée.

Dans le nouveau dictionnaire, la clé est la lettre chiffrée et la valeur la lettre d'origine.

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico :
        code = dico[lettre]
        nouveau[code] = lettre
    return nouveau

nouveau[code] = lettre ajoute une paire au dictionnaire : la clé code n'existait pas encore.

[3. c] Écris une fonction dechiffre qui prend en paramètres un mot chiffré mot et le dictionnaire de chiffrement dico qui a servi à le chiffrer, et qui renvoie le mot déchiffré. Utilise les fonctions précédentes (elles sont déjà écrites ci-dessous).

def chiffrer(mot, alpha):
    resultat = ""
    for lettre in mot:
        resultat = resultat + alpha[lettre]
    return resultat

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico:
        nouveau[dico[lettre]] = lettre
    return nouveau

def dechiffre(mot, dico):

Déchiffrer, c'est chiffrer avec le dictionnaire de déchiffrement.

Une seule ligne suffit : return chiffrer(mot, …).

def dechiffre(mot, dico):
    return chiffrer(mot, dico_dechiffrement(dico))

On réutilise les deux fonctions : on construit le dictionnaire inverse, puis on chiffre avec lui.

On pourra utiliser la fonction shuffle du module random, qui mélange en place un tableau :

>>> tab = ["A", "B", "C", "D"]
>>> shuffle(tab)
>>> tab
['B', 'A', 'D', 'C']

[4] Écris une fonction dico_chiffrement qui prend en paramètre un tableau de lettres alphabet et qui renvoie un dictionnaire de chiffrement : ses clés sont les lettres de alphabet, ses valeurs ces mêmes lettres mélangées.

from random import shuffle

def dico_chiffrement(alphabet):

shuffle ne renvoie rien : elle modifie le tableau qu'on lui donne. Mélange donc une copie du tableau, par exemple melange = list(alphabet).

Ensuite, pour chaque indice i, la clé alphabet[i] reçoit la valeur melange[i].

from random import shuffle

def dico_chiffrement(alphabet):
    melange = list(alphabet)
    shuffle(melange)
    dico = {}
    for i in range(len(alphabet)):
        dico[alphabet[i]] = melange[i]
    return dico

Deux pièges : melange = shuffle(alphabet) donne None ; et si l'on mélange alphabet lui-même, on associe chaque lettre à elle-même.

Exercice 2 · Le stock de la scierie (8 points, partie A)

Sujet : baccalauréat 2026, Antilles-Guyane, jour 2 (26-NSIJ2AG1), exercice 3, partie A (questions 1 à 6), pages 11 à 15. Sujet (version de l'AEIF). Les parties B et C (récursivité, programmation dynamique) sont dans le PDF : elles relèvent d'un autre chapitre.

Cet exercice traite de tableaux, de dictionnaires, de récursivité et de programmation dynamique.

Une scierie possède un stock de planches. Chaque planche a une longueur entière, en mètres, comprise entre 1 et 10, et un prix entier, en euros, qui dépend de sa longueur. La variable globale prix est une liste telle que prix[n] est le prix de vente d'une planche de longueur n (l'élément d'indice 0 n'est jamais utilisé) :

prix = [0, 1, 5, 8, 9, 10, 17, 17, 20, 24, 30]

Le dictionnaire effectif associe à chaque longueur de planche présente dans le stock son effectif, c'est-à-dire le nombre de planches de cette longueur. Par exemple, s'il y a 3 planches de 2 m, effectif[2] vaut 3 ; s'il n'y a aucune planche de 3 m, effectif n'a pas de clé 3.

[1] Le stock contient trois planches de 1 m, quatre planches de 2 m et une planche de 4 m. Donne une instruction Python qui déclare et initialise effectif pour ce stock.

Une longueur absente du stock n'est pas une clé du dictionnaire : pas de 3: 0.

Les clés sont les longueurs, les valeurs les nombres de planches.

Clé : la longueur. Valeur : le nombre de planches de cette longueur.

effectif = {1: 3, 2: 4, 4: 1}. L'ordre des paires n'a pas d'importance.

[2] Donne une expression Python qui calcule la valeur totale, en euros, des planches de 10 m d'un stock qui en contient au moins une. Utilise la liste prix.

Il faut le prix d'une planche multiplié par le nombre de planches de 10 m.

Le prix d'une planche de 10 m est prix[10] ; le nombre de ces planches est effectif[10].

prix[10] * effectif[10] : un indice de liste (prix[10]) et une clé de dictionnaire (effectif[10]) s'écrivent de la même façon, mais ne sont pas la même chose.

[3] Donne une expression Python qui vaut True si le stock contient des planches de 5 m, et False sinon.

S'il n'y a pas de planche de 5 m, la clé 5 n'existe pas : effectif[5] provoque une erreur KeyError.

La liste prix donne les prix de toutes les longueurs : elle ne dit rien du stock.

Une longueur est en stock si, et seulement si, elle est une clé du dictionnaire.

5 in effectif teste si 5 est une clé du dictionnaire.

[4] Recopie et complète les lignes 2, 3 et 4 de la fonction valeur_stock, qui renvoie la valeur en euros du stock si toutes ses planches sont vendues au prix de la liste prix.

def valeur_stock(effectif):
    valeur_totale = [[0]]
    for longueur in [[effectif|effectif.keys()]] :
        valeur_totale = valeur_totale + [[ prix[longueur] * effectif[longueur]|effectif[longueur] * prix[longueur] ]]
    return valeur_totale

prix = [0, 1, 5, 8, 9, 10, 17, 17, 20, 24, 30]
print(valeur_stock({1: 3, 2: 4, 4: 1}))
32

La boucle parcourt les clés du dictionnaire : les longueurs présentes dans le stock.

Pour chaque longueur, on ajoute le prix d'une planche multiplié par le nombre de planches. Vérification : le stock de la question 1 vaut 3 × 1 + 4 × 5 + 1 × 9 = 32 €.

def valeur_stock(effectif):
    valeur_totale = 0
    for longueur in effectif :
        valeur_totale = valeur_totale + prix[longueur] * effectif[longueur]
    return valeur_totale

for longueur in effectif parcourt les clés. On aurait aussi pu écrire for longueur, n in effectif.items().

[5] Un camion livre de nouvelles planches, décrites par le dictionnaire autre_effectif. Écris la fonction mise_a_jour(effectif, autre_effectif), qui met à jour le dictionnaire effectif avec le stock du camion.

Exemple : si, avant l'appel, effectif = {1: 3, 5: 5} et autre_effectif = {1: 2, 2: 2}, alors après l'appel mise_a_jour(effectif, autre_effectif), l'expression effectif == {1: 5, 2: 2, 5: 5} vaut True.

def mise_a_jour(effectif, autre_effectif):

Parcours les longueurs du camion. Pour chacune, deux cas : la longueur est déjà une clé de effectif, ou non.

Si elle y est, on ajoute les effectifs ; sinon, on crée la clé avec l'effectif du camion. La fonction ne renvoie rien : elle modifie effectif.

def mise_a_jour(effectif, autre_effectif):
    for longueur in autre_effectif:
        if longueur in effectif:
            effectif[longueur] = effectif[longueur] + autre_effectif[longueur]
        else:
            effectif[longueur] = autre_effectif[longueur]

Un dictionnaire est mutable : modifié dans la fonction, il l'est aussi pour l'appelant. Autre écriture : effectif[longueur] = effectif.get(longueur, 0) + autre_effectif[longueur].

[6] Un client achète une planche dont la longueur est présente dans le stock. Écris la fonction vendre(effectif, longueur), qui modifie effectif en conséquence. Si le stock de cette longueur devient nul, la clé doit être supprimée (tu peux utiliser del).

Exemple : si, avant l'appel, effectif = {1: 3, 5: 1}, alors après vendre(effectif, 1), effectif == {1: 2, 5: 1} vaut True ; puis après vendre(effectif, 5), effectif == {1: 2} vaut True.

def vendre(effectif, longueur):

Commence par retirer 1 à l'effectif de cette longueur.

Puis, si l'effectif vaut 0, supprime la clé : del effectif[longueur].

def vendre(effectif, longueur):
    effectif[longueur] = effectif[longueur] - 1
    if effectif[longueur] == 0:
        del effectif[longueur]

On garde ainsi la règle de l'énoncé : une longueur absente du stock n'est pas une clé. C'est ce qui rend juste le test 5 in effectif de la question 3.

Mémo

Lire : d[cle] (erreur KeyError si la clé n'existe pas) ; tester : cle in d ; parcourir : for cle in d (les clés), d.items() (les paires).

Modifier : d[cle] = v ajoute ou remplace ; del d[cle] supprime. Un dictionnaire passé à une fonction est modifié pour de bon.

Liste ou dictionnaire ? prix[10] lit l'indice 10 d'une liste ; effectif[10] lit la clé 10 d'un dictionnaire.
