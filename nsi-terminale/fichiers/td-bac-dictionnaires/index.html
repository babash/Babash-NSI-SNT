Exercice 1 · Chiffrer avec un dictionnaire (4 points)

Sujet : baccalauréat 2022, Centres étrangers, jour 2 (22-NSIJ2G11), exercice 2, pages 4 et 5. Sujet officiel (PDF) · version de l'AEIF.

Cet exercice porte sur les structures de données (dictionnaires).

La cryptographie est un ensemble de techniques permettant de chiffrer un message.

Une technique de cryptographie consiste à mélanger les lettres d'un alphabet et à réécrire le message avec ces permutations. En Python, on peut créer un dictionnaire dans lequel les clés sont les lettres de l'alphabet et les valeurs sont celles de l'alphabet mélangé.

Par exemple, si l'alphabet contient les 4 lettres A, B, C et D, et si le dictionnaire de l'alphabet mélangé est alpha = {"A": "B", "B": "D", "C": "A", "D": "C"}, la chaîne de caractères "BAC" sera chiffrée "DBA".

Un tel dictionnaire sera appelé dictionnaire de chiffrement.

1. On souhaite chiffrer un message écrit avec l'alphabet A, B, C, D, E, F, G à l'aide du dictionnaire :

alpha = {"A": "B", "B": "D", "C": "A", "D": "C", "E": "F", "F": "G", "G": "E"}

1. a. Quelle est la valeur associée à la clé "D" ?

C'est la clé associée à la valeur "D". On cherche l'inverse : ce qui est écrit après "D":.

Cherche la paire qui commence par "D":.

La paire est "D": "C" : la valeur associée à "D" est "C".

1. a. (suite) En Python, comment l'obtenir ?

Un dictionnaire n'a pas de positions : on lit une valeur grâce à sa clé, ici "D".

"C" est la valeur trouvée en 1.a, pas la clé : entre crochets, on écrit la clé "D", et Python renvoie la valeur "C".

On écrit le nom du dictionnaire, puis la clé entre crochets.

alpha["D"] renvoie "C". Un dictionnaire n'a pas d'indices : alpha[3] provoquerait une erreur KeyError.

1. b. Chiffrer la chaîne de caractères "BAGAGE" avec le dictionnaire alpha.

Tu as lu le dictionnaire à l'envers : on part de la lettre du mot (la clé) pour trouver sa lettre chiffrée (la valeur).

Remplace chaque lettre par sa valeur : B devient D, A devient B…

B → D, A → B, G → E, A → B, G → E, E → F : DBEBEF.

2. On considère qu'un mot est une chaîne de caractères (un objet de type str) écrite uniquement avec les 26 lettres de l'alphabet en majuscule. Par exemple, "ARBRE" est un mot et "L'ARBRE !" n'est pas un mot à cause des caractères : "'", " " (espace) et "!".

2. Écrire une fonction chiffrer(mot, alpha) qui prend en paramètres mot un mot et alpha un dictionnaire de chiffrement, et qui renvoie une chaîne de caractères chiffrée avec le dictionnaire de chiffrement alpha.

Pour répondre ici : un exemple d'appel.

>>> chiffrer("BAC", {"A": "B", "B": "D", "C": "A", "D": "C"})
'DBA'
def chiffrer(mot, alpha):

Pars d'une chaîne vide, puis parcours le mot lettre par lettre.

Pour chaque lettre, ajoute à la fin du résultat sa valeur alpha[lettre].

def chiffrer(mot, alpha):
    resultat = ""
    for lettre in mot:
        resultat = resultat + alpha[lettre]
    return resultat

On parcourt la chaîne et on concatène les lettres chiffrées. La chaîne de départ n'est pas modifiée (une chaîne ne se modifie pas en Python).

3. On souhaite déchiffrer un mot chiffré avec cette méthode.

3. a. Si un mot est chiffré avec le dictionnaire de chiffrement alpha = {"A": "B", "B": "D", "C": "A", "D": "C", "E": "F", "F": "G", "G": "E"}, donner un dictionnaire permettant de le déchiffrer.

dechiffrement = {"B": [["A"]], "D": [["B"]], "A": [["C"]], "C": [["D"]],
                 "F": [["E"]], "G": [["F"]], "E": [["G"]]}

Pour déchiffrer, on part de la lettre chiffrée (la valeur de alpha) pour retrouver la lettre d'origine (sa clé).

Dans alpha, "A": "B" : la lettre chiffrée B se déchiffre en A.

On échange clés et valeurs : {"B": "A", "D": "B", "A": "C", "C": "D", "F": "E", "G": "F", "E": "G"}. C'est possible car deux lettres différentes ne sont jamais chiffrées par la même lettre.

3. b. Écrire une fonction en Python appelée dico_dechiffrement(dico) qui prend en paramètre dico un dictionnaire de chiffrement et qui renvoie un dictionnaire permettant le déchiffrement. On pourra s'inspirer du code incomplet ci-dessous ou proposer une autre solution :

Pour répondre ici : complète le code ; les deux dernières lignes, ajoutées pour le TD, l'exécutent.

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico :
        code = dico[ [[lettre]] ]
        nouveau[ [[code]] ] = [[lettre]]
    return nouveau

alpha = {"A": "B", "B": "D", "C": "A", "D": "C", "E": "F", "F": "G", "G": "E"}
print(dico_dechiffrement(alpha))
{'B': 'A', 'D': 'B', 'A': 'C', 'C': 'D', 'F': 'E', 'G': 'F', 'E': 'G'}

La boucle parcourt les clés de dico : lettre est une lettre d'origine, code sa lettre chiffrée.

Dans le nouveau dictionnaire, la clé est la lettre chiffrée et la valeur la lettre d'origine.

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico :
        code = dico[lettre]
        nouveau[code] = lettre
    return nouveau

nouveau[code] = lettre ajoute une paire au dictionnaire : la clé code n'existait pas encore.

3. c. Écrire une fonction dechiffre(mot, dico) qui reçoit un mot chiffré et un dictionnaire de chiffrement et renvoie le mot décodé. On utilisera les fonctions écrites dans les questions précédentes.

Pour répondre ici : elles sont déjà écrites ci-dessous.

def chiffrer(mot, alpha):
    resultat = ""
    for lettre in mot:
        resultat = resultat + alpha[lettre]
    return resultat

def dico_dechiffrement(dico):
    nouveau = {}
    for lettre in dico:
        nouveau[dico[lettre]] = lettre
    return nouveau

def dechiffre(mot, dico):

Déchiffrer, c'est chiffrer avec le dictionnaire de déchiffrement.

Une seule ligne suffit : return chiffrer(mot, …).

def dechiffre(mot, dico):
    return chiffrer(mot, dico_dechiffrement(dico))

On réutilise les deux fonctions : on construit le dictionnaire inverse, puis on chiffre avec lui.

4. On souhaite à présent créer un dictionnaire de chiffrement.

On pourra utiliser la fonction shuffle du module random qui mélange en place un tableau. Par exemple, on a :

>>> tab = ["A", "B", "C", "D"]
>>> shuffle(tab)
>>> tab
["B", "A", "D", "C"]

4. Écrire une fonction dico_chiffrement(alphabet) qui prend en paramètre alphabet un tableau de lettres et qui renvoie un dictionnaire de chiffrement dont les clés sont les lettres du tableau alphabet et les valeurs sont les lettres du tableau alphabet mélangées.

from random import shuffle

shuffle ne renvoie rien : elle modifie le tableau qu'on lui donne. Mélange donc une copie du tableau, par exemple melange = list(alphabet).

Ensuite, pour chaque indice i, la clé alphabet[i] reçoit la valeur melange[i].

from random import shuffle

def dico_chiffrement(alphabet):
    melange = list(alphabet)
    shuffle(melange)
    dico = {}
    for i in range(len(alphabet)):
        dico[alphabet[i]] = melange[i]
    return dico

Deux pièges : melange = shuffle(alphabet) donne None ; et si l'on mélange alphabet lui-même, on associe chaque lettre à elle-même.

Mémo

Lire : d[cle] (erreur KeyError si la clé n'existe pas) ; tester : cle in d ; parcourir : for cle in d (les clés), d.items() (les paires).

Modifier : d[cle] = v ajoute ou remplace ; del d[cle] supprime. Un dictionnaire passé à une fonction est modifié pour de bon.

Liste ou dictionnaire ? prix[10] lit l'indice 10 d'une liste ; effectif[10] lit la clé 10 d'un dictionnaire.
