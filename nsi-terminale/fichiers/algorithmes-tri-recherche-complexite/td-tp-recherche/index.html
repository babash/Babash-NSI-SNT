2. Analyse du code

Principe : si le tableau est trié, on regarde au milieu. Si la cible est plus grande, on ignore la moitié gauche ; si elle est plus petite, la moitié droite. On divise ainsi la zone de recherche par deux à chaque étape.

def recherche_dichotomique(tab, valeur):
    # Attention : tab doit être trié
    gauche = 0
    droite = len(tab) - 1
    while gauche <= droite:
        # On cible le centre de la zone de recherche
        milieu = (gauche + droite) // 2
        if tab[milieu] == valeur:
            return milieu  # Cible trouvée !
        elif tab[milieu] > valeur:
            # Cible plus petite : on ignore la partie droite
            droite = milieu - 1
        else:
            # Cible plus grande : on ignore la partie gauche
            gauche = milieu + 1
    return None  # Cible NON trouvée !

Exemple : recherche de 36 dans [3, 8, 11, 15, 19, 24, 30, 36, 41]. Le milieu est en trait épais ; les cases écartées sont en pointillés.

  1. gauche = 0, droite = 8, milieu = 4 : 19 < 36, on garde la partie droite.
  2. gauche = 5, droite = 8, milieu = 6 : 30 < 36, on garde la partie droite.
  3. gauche = 7, droite = 8, milieu = 7 : 36 trouvé, à l'indice 7.

  • Pour vérifier que le tableau est trié.

En dichotomie, chaque étape divise la zone par 2 : 100, 50, 25, 12, 6, 3, 1… Compte les étapes.

Linéaire : 100 étapes, et n pour une liste de taille n. Dichotomie : 7 étapes pour 100 (mesuré ; log2(100) ≈ 6,6), et environ log2(n) pour une liste de taille n.
