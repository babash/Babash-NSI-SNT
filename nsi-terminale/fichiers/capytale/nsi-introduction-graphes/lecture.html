📘 Activité NSI : Introduction aux Graphes¶

Objectif : Découvrir comment modéliser un réseau social et manipuler ses données avec Python.

Dans ce notebook, nous allons travailler sur un réseau d'amis fictif. En informatique, cette structure s'appelle un Graphe.

  • Les personnes sont des Sommets.
  • Les amitiés sont des Arêtes.

1️⃣ La structure de données¶

Pour représenter ce réseau en Python, nous utilisons un dictionnaire.

  • Les clés sont les prénoms des personnes.
  • Les valeurs sont des listes contenant les prénoms de leurs amis (leurs voisins).

Exécutez la cellule ci-dessous pour charger les données.

In [ ]:
from graphtools import *
# Données du réseau social "NSI-Book"
# Ce dictionnaire représente les relations d'amitié (Graphe non orienté)
reseau = {
    "Alice": ["Bob", "Charlie"],
    "Bob": ["Alice", "Denis", "Eve"],
    "Charlie": ["Alice", "Denis"],
    "Denis": ["Bob", "Charlie", "Fred"],
    "Eve": ["Bob"],

6️⃣ BONUS : Suggestion d'amis (Distance 2) 🎁¶

Dans un réseau social, on définit la distance 2 comme les personnes qui sont amies avec vos amis directs (sans être vos amis directs). Ces personnes sont les candidates idéales pour une suggestion d'amitié.
