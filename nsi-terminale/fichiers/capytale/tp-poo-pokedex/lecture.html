Création d'une classe Pokemon

L'objectif de ce TP est de créer un programme en objet dans lequel nous allons créer des Pokémons et les fair interagir entre eux. Pour commencer, nous créons la classe pokémon ci-dessous.

👇 Exécuter la cellule ci-dessous pour continuer. 👇

class Pokemon:
    
    # constructeur
    def __init__(self, name, pid, height, weight, types, stats, sprite, cry):
        self.name = name
        self.pid = pid
        self.height = height
        self.weight = weight
        self.types = tuple(types)
        self.stats = stats
        self.sprite = sprite
        self.cry = cry
        
    # les méthodes
    def show(self):
        # Fetch the image data from the URL using requests
        response = requests.get(self.sprite)
        #response.raise_for_status()  # Raise an exception if the request fails

        # Open the image data with Pillow
        image = Image.open(io.BytesIO(response.content))

        # Convert the Pillow image to a NumPy array for matplotlib
        image_np = img.pil_to_array(image)
        plt.figure(str(self))
        plt.imshow(image_np)
        plt.axis('off')
        plt.show()
        if self.cry:
            response = requests.get(self.cry)
            if response.status_code == 200:
                audio = Audio(response.content, autoplay=True)
                display(audio)
            else:
                print("Error retrieving cry audio.")
        else:
            print("No cry available for this Pokémon.")

    def __str__(self):
        txt = self.name.capitalize()
        if hasattr(self, "level"):
            txt += f"[lvl {self.level}]"
        return txt
    
    def __rpr__(self):
        return str(self)

Exercice 5 :

Améliorons la fonction attaque tenir compte de l'efficacité des attaques, de leur type, de leur catégorie et de leur puissance.

Dégat = ((\frac{(2× Niveau / 5+2)× Puissance × Attaque / Defense}{50})+2)× Random × Type1 × Type2 × Stab Avec :

Niveau : Le niveau de l'attaquant

Puissance : La puissance de l'attaque par exemple 120 pour Close Combat et 40 pour Eclair.

Attaque : L'attaque du pokémon attaquant si la capacite est physique, l'attaque speciale du pokemon attaquant si la capacite est speciale

Random : Un nombre aléatoire entre 0.85 et 1, on pourra utiliser python random.uniform(0.85, 1).

Type1 : L'éfficacite du type de l'attaque sur le premier type du pokemon défenseur. Cela peut être 0,5 (pas très efficace), 1 (normalement efficace) ou 2 (super efficace) ou 0 (si imunité). Voir la table des types ci-dessous.

Type2 : L'éfficacite du type de l'attaque sur le deuxième type du pokemon defenseur. Cela peut être 0,5 (pas très efficace), 1 (normalement efficace) ou 2 (super efficace) ou 0 (si imunité. Voir la table des types ci-dessous.

Stab: Stab est de 1.5 si le pokémon attaquant à le type de l'attaque 0 sinon.
