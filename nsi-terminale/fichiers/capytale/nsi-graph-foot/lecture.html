def compter_victoires(matrice, index_equipe):
    ligne_equipe = matrice[index_equipe]
    victoires = 0
    for score in ligne_equipe:
        if score > 0:
            victoires += 1
    return victoires

Partie 3 : Le Ratio (Attaque / Défense)¶

On veut favoriser les équipes qui marquent beaucoup et encaissent peu.

$$ Score = \frac{\text{Buts Marqués}}{\text{Buts Encaissés}} $$

⚠️ Attention : Si Buts Encaissés vaut 0, on ne peut pas diviser ! Le score doit être très grand (ex: 1000).

  • Grosse Équipe = Une équipe qui a 3 victoires ou plus.
  • Points gagnés = La différence de buts du match.

# --- CORRECTION FONCTION IA ---
def score_influence_des_adversaires(matrice, index_gagneur):
    score_influence = 0
    N = len(matrice)
    for index_perdant in range(N):
        poids_victoire = matrice[index_gagneur][index_perdant]
        if poids_victoire > 0:
            victoires_adversaire = compter_victoires(matrice, index_perdant)
            if victoires_adversaire >= 3:
                score_influence += poids_victoire
    return score_influence
