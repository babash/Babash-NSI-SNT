Exercice 1 · Le stock de la briocherie (4 points)

Sujet : baccalauréat 2022, Asie, jour 1, sujet 22-NSIJ1JA1, exercice 4 (4 points). Le sujet d'origine (PDF).

Thème abordé : programmation objet en langage Python.

Un fabricant de brioches décide d'informatiser sa gestion des stocks. Il écrit pour cela un programme en langage Python. Une partie de son travail consiste à développer une classe Stock dont la première version est la suivante :

class Stock:
    def __init__(self):
        self.qt_farine = 0         # quantité de farine initialisée à 0 g
        self.nb_oeufs = 0          # nombre d’œufs (0 à l’initialisation)
        self.qt_beurre = 0         # quantité de beurre initialisée à 0 g

La quantité de beurre est l'attribut self.qt_beurre.

On ajoute : la nouvelle quantité, c'est l'ancienne plus qt.

class Stock:
    def __init__(self):
        self.qt_farine = 0         # quantité de farine initialisée à 0 g
        self.nb_oeufs = 0          # nombre d’œufs (0 à l’initialisation)
        self.qt_beurre = 0         # quantité de beurre initialisée à 0 g

    def ajouter_beurre(self, qt):
        self.qt_beurre = self.qt_beurre + qt

La méthode modifie l'attribut de l'objet avec self. Elle ne renvoie rien.

On admet que l'on a écrit deux autres méthodes ajouter_farine et ajouter_oeufs qui ont des fonctionnements analogues.

3. Pour faire une brioche, il faut 350 g de farine, 175 g de beurre et 4 œufs. Écrire une méthode stock_suffisant_brioche(self) qui renvoie un booléen : VRAI s'il y a assez d'ingrédients dans le stock pour faire une brioche et FAUX sinon.

class Stock:
    def __init__(self):
        self.qt_farine = 0         # quantité de farine initialisée à 0 g
        self.nb_oeufs = 0          # nombre d’œufs (0 à l’initialisation)
        self.qt_beurre = 0         # quantité de beurre initialisée à 0 g

    def stock_suffisant_brioche(self):
        ...

Il faut les trois ingrédients en quantité suffisante : trois comparaisons reliées par and.

« Assez », c'est « au moins » : >=. Avec exactement 350 g de farine, on peut faire la brioche.

class Stock:
    def __init__(self):
        self.qt_farine = 0         # quantité de farine initialisée à 0 g
        self.nb_oeufs = 0          # nombre d’œufs (0 à l’initialisation)
        self.qt_beurre = 0         # quantité de beurre initialisée à 0 g

    def stock_suffisant_brioche(self):
        return self.qt_farine >= 350 and self.qt_beurre >= 175 and self.nb_oeufs >= 4

On peut renvoyer directement l'expression booléenne, sans if. Écrire > au lieu de >= est l'erreur la plus fréquente.

4. On considère la méthode supplémentaire produire(self) de la classe Stock donnée par le code suivant :

    def produire(self):
        res = 0
        while self.stock_suffisant_brioche():
            self.qt_beurre = self.qt_beurre - 175
            self.qt_farine = self.qt_farine - 350
            self.nb_oeufs = self.nb_oeufs - 4
            res = res + 1
        return res

5. L'industriel possède n lieux de production distincts et donc n stocks distincts. On suppose que ces stocks sont dans une liste dont chaque élément est un objet de type Stock. Écrire une fonction Python nb_brioches(liste_stocks) possédant pour unique paramètre la liste des stocks et renvoie le nombre total de brioches produites.

class Stock:
    def __init__(self):
        self.qt_farine = 0         # quantité de farine initialisée à 0 g
        self.nb_oeufs = 0          # nombre d’œufs (0 à l’initialisation)
        self.qt_beurre = 0         # quantité de beurre initialisée à 0 g

    def ajouter_beurre(self, qt):
        self.qt_beurre = self.qt_beurre + qt

    def ajouter_farine(self, qt):
        self.qt_farine = self.qt_farine + qt

    def ajouter_oeufs(self, qt):
        self.nb_oeufs = self.nb_oeufs + qt

    def stock_suffisant_brioche(self):
        return self.qt_farine >= 350 and self.qt_beurre >= 175 and self.nb_oeufs >= 4

    def produire(self):
        res = 0
        while self.stock_suffisant_brioche():
            self.qt_beurre = self.qt_beurre - 175
            self.qt_farine = self.qt_farine - 350
            self.nb_oeufs = self.nb_oeufs - 4
            res = res + 1
        return res

Parcours la liste : for stock in liste_stocks:. Chaque stock est un objet Stock.

Pour chaque stock, stock.produire() renvoie le nombre de brioches de ce lieu : additionne-les dans un accumulateur.

def nb_brioches(liste_stocks):
    total = 0
    for stock in liste_stocks:
        total = total + stock.produire()
    return total

nb_brioches est une fonction (en dehors de la classe), qui appelle la méthode produire de chaque objet de la liste.

Mémo

Une classe (Region) est un modèle ; un objet ou instance (ge = Region("Grand Est")) est fabriqué par le constructeur __init__.

Les attributs sont les variables de chaque objet : self.nom. Les méthodes sont les fonctions de la classe : leur premier paramètre est self, mais on ne l'écrit pas à l'appel (ge.renvoie_nb_voisines()).

Une méthode qui affiche utilise print ; une méthode qui renvoie utilise return. Une méthode peut modifier les attributs : c'est un effet de bord.
