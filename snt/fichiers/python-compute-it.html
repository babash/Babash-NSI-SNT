Règle fondamentale

L'INDENTATION : LA PORTÉE DU CODE

En Python, l'indentation (décalage de 4 espaces ou 1 touche Tab) définit le bloc d'instructions rattaché à une structure.

Toute ligne indentée fait partie du bloc. Dès qu'on revient vers la gauche, on sort du bloc !

N'oubliez jamais les deux-points : en fin de ligne de commande !

for i in range(2):
│    droite() # DANS la boucle
│    bas() # DANS la boucle
haut() # HORS de la boucle !

1. Conditions : if / elif / else

Exécute un bloc SI une condition est vraie. Sinon, passe à la suite ou au else.

if rouge():
    bas()
elif bleu():
    haut()
else:
    droite()

Dès qu'une condition est vraie, les suivantes sont ignorées.

2. Opérateurs logiques

Combine ou inverse des conditions pour affiner les tests.

not rouge() : Vrai si la case n'est PAS rouge.
rouge() and bleu() : Vrai si les DEUX conditions sont vraies.
rouge() or bleu() : Vrai si AU MOINS UNE condition est vraie.

Exemple : while not rouge(): (Avancer tant qu'on n'est pas sur du rouge).

3. Boucle non-bornée : while

Répète le bloc TANT QUE la condition reste vraie. Le nombre de tours est inconnu au départ.

while rouge():
    droite()
    bas()
⚠️ Point-Clé Compute-it : La condition n'est testée qu'au début de chaque tour, jamais au milieu du bloc !

4. Boucle bornée : for

Répète le bloc un nombre de fois fixe et connu à l'avance grâce à range(N).

for i in range(3):
    droite()
    haut()

Ici, la séquence (droite puis haut) sera exécutée exactement 3 fois.

Focus : Fonctionnement détaillé des 3 structures de contrôle

Structure Conditionnelle
  • if : Teste la condition 1. Si elle est vraie, son bloc s'exécute et tout le reste du bloc d'aiguillage est ignoré.
  • elif (Sinon Si) : Utilisé si la condition 1 est fausse. On peut en mettre autant que nécessaire.
  • else (Sinon) : Optionnel. S'exécute uniquement si toutes les conditions précédentes sont fausses.
Boucle Répétitive (FOR)
  • Nombre de tours connu : On sait à l'avance combien de fois le bloc va tourner grâce à range(N).
  • Compteur interne : La variable i prend automatiquement les valeurs de 0 à N-1.
  • Utilisation : Idéal pour parcourir une grille sur une distance fixe ou effectuer une action un nombre précis de fois.
Boucle Conditionnelle (WHILE)
  • Nombre de tours inconnu : Le programme répète le bloc tant que l'état du plateau/jeu satisfait la condition.
  • Test à l'entrée : Si la condition est fausse dès le début, le bloc n'est jamais exécuté.
  • ⚠️ Risque de boucle infinie : Si la condition reste toujours vraie, le programme ne s'arrête jamais !
