SNT - Enigmes

Chaque lien plus bas renvoie vers une énigme.
Chaque énigme résolue donne un chiffre ou un nombre.
Résoudre toutes les énigmes permet d'obtenir un code d'accès à une page validant la réussite.
Pour accéder à cette page de validation, se connecter à l'adresse suivante : http://..........html, en remplaçant les pointillés par les 4 réponses obtenues, dans l'ordre des énigmes, et en laissant un point (".") avant html.
Pour obtenir les commentaires de cette page allez dans l'explorateur de code de votre navigateur :-))
