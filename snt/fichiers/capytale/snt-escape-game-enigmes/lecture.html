Sixième énigme

Cette image contient un message.

  • Elle contient un texte masqué dans une distribution aléatoire de couleurs.
  • Ce texte est écrit en bleu.
  • Ce bleu est codé par le triplet rvb (0,0,117).
  • Quand le texte a été masqué, sa composante bleue (117) a été conservée.
  • L’image texte_decode.png obtenue après exécution du code contiendra le nombre à trouver.

On peut décoder l’image et obtenir le texte en utilisant le code qui suit, après avoir complété les zones ... :
