Exercice 3. Guider l'alien

C'est à toi maintenant de guider le robot pour essayer de lui trouver une sortie. Donne les instructions pour aller en O15.

# L'alien (ne modifie pas ces lignes) : il part de H8.
x, y = 8, 8    # colonne (1 à 15), ligne (1 = A, 15 = O)
def droite(n=1): global x; x = x + n
def gauche(n=1): global x; x = x - n
def bas(n=1): global y; y = y + n
def haut(n=1): global y; y = y - n

Exercice 4. Pour aller plus loin

La fonction colonne() donne le numéro de la colonne où se trouve l'alien. Pour chacun des scripts suivants, donne la position finale du robot.

a = 13
b = 10

gauche(6)
haut(3)
for loop in range(5):
    droite()
    b = b + 1
    if a == b:
        haut(4)
    else:
        bas()
    droite()
bas(2)

Attention au sens : haut va vers la ligne A, bas vers la ligne O.

Attention au sens : gauche va vers la colonne 1, droite vers la colonne 15.

H8, c'est la case de départ : l'alien a bougé depuis.

Le bloc décalé sous for loop in range(n): se répète n fois. Sans nombre, droite() avance d'une case.

Dans la boucle, b vaut 11, 12, 13, 14 puis 15 : a == b n'est vrai qu'au 3e tour.

L'alien finit en G12. Son chemin, instruction par instruction : H8 → H2 → E2 → E3 → F3 → F4 → F5 → G5 → G6 → G7 → C7 → C8 → C9 → D9 → D10 → D11 → E11 → E12 → G12.

gauche(6)
bas(5)
for loop in range(8):
    droite()
    if colonne() < 7:
        bas()
        droite()
    haut()

Attention au sens : haut va vers la ligne A, bas vers la ligne O.

Attention au sens : gauche va vers la colonne 1, droite vers la colonne 15.

H8, c'est la case de départ : l'alien a bougé depuis.

colonne() donne le numéro de la colonne où se trouve l'alien, au moment où on l'appelle.

Note la colonne au début de chaque tour : 2 au départ de la boucle.

L'alien finit en G12. Son chemin, instruction par instruction : H8 → H2 → M2 → M3 → N3 → N4 → M4 → M5 → N5 → N6 → M6 → M7 → L7 → L8 → K8 → K9 → J9 → J10 → I10 → I11 → H11 → H12 → G12.

gauche(6)
haut(5)
if colonne() < 3:
    droite(4)
if colonne() < 5:
    droite(2)
if colonne() > 9:
    bas(4)
droite(4)
if colonne() > 9:
    bas(4)
for loop in range(3):
    gauche()
    haut()

Attention au sens : haut va vers la ligne A, bas vers la ligne O.

Attention au sens : gauche va vers la colonne 1, droite vers la colonne 15.

H8, c'est la case de départ : l'alien a bougé depuis.

colonne() donne le numéro de la colonne où se trouve l'alien, au moment où on l'appelle.

Après gauche(6) et haut(5), l'alien est en C2 : colonne() vaut 2.

L'alien finit en D7. Son chemin, instruction par instruction : H8 → H2 → C2 → C6 → C10 → G10 → G9 → F9 → F8 → E8 → E7 → D7.

Mémo

Pour guider l'alien, on compte les lignes (de A à O) et les colonnes (de 1 à 15) qui séparent le départ de l'arrivée. Une fonction comme colonne() donne une valeur au moment où on l'appelle.
