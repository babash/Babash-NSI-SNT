Exercice 2. Trouver le robot (et appliquer les conditions en Python, et découvrir les boucles)

Les boucles en Python permettent de répéter un même bloc d'instructions (des lignes de code) plusieurs fois. Ainsi, l'instruction for loop in range(3): signifie que le bloc d'instructions sera répété 3 fois. Pour chacun des scripts suivants, donne la position finale du robot.

a = 10
b = 7

haut(4)
if a > b:
    droite(6)
    bas(3)
gauche(3)
if a < b:
    haut(2)
gauche(2)

Attention au sens : haut va vers la ligne A, bas vers la ligne O.

Mémo

Le bloc décalé sous un if ne s'exécute que si la condition est vraie (sinon, celui du else). Le bloc décalé sous for loop in range(n): se répète n fois.
