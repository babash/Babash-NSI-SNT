📦 L'Emballage Structuré
Le HTML sans <div>, c'est comme des ingrédients posés en vrac sur une table. Les "div" servent à créer des cartons de rangement. En leur donnant une classe (nom), on permet au CSS de savoir quel carton décorer. Le "container" est la grande boîte qui garde tout bien aligné au centre pour éviter que le texte ne touche les bords de l'écran.

🛠️ Pourquoi utiliser un Framework comme Bootstrap ?
Imagine que tu doives ouvrir une pâtisserie : vas-tu fabriquer tes propres moules, construire ton four et inventer chaque recette ? Non, tu vas utiliser des outils professionnels pour gagner du temps. C'est exactement le rôle de Bootstrap.

1. L'Importation de Styles (La mise en forme immédiate)
Au début de ton fichier HTML, nous avons lié une copie de Bootstrap, rangée dans le dossier vendor (on peut aussi la charger depuis un CDN, un site qui distribue ces fichiers). C'est comme si tu connectais ton site à une immense bibliothèque de design. • Avantage : Tu n'as plus besoin d'écrire 50 lignes de CSS pour créer un bouton arrondi avec une ombre. En ajoutant simplement class="btn btn-primary", ton bouton devient instantanément bleu, réactif au clic et esthétique. C'est le principe du "Standard" : ton site ressemble à une application moderne dès la première seconde.

2. L'Importation de Composants (Les structures prêtes à l'emploi)
Un "Composant", c'est un objet web complexe (comme un carrousel ou une barre de navigation) que des experts ont déjà codé pour toi. • Le Carrousel : C'est l'un des plus sophistiqués. Bootstrap fournit la "recette" HTML précise. Si tu respectes l'emboîtement (la grande boîte .carousel qui contient une boîte .carousel-inner qui contient chaque image .carousel-item), le framework s'occupe de tout le calcul mathématique pour faire défiler les images de manière fluide.

3. Le Responsive : Un site "Élastique"
L'un des plus gros avantages de Bootstrap est le Responsive Design. Le framework est conçu pour que ton site soit aussi beau sur un écran géant que sur le petit écran d'un smartphone. Grâce à son système de grille (Grid), les éléments se rangent ou se redimensionnent automatiquement sans que tu aies à coder chaque version.

⚡ Rendre le site vivant (UX & JS)
L'UX (User Experience) est l'art de rendre la visite du site agréable et logique.

• Le Feedback Visuel : Le :hover n'est pas juste "joli". Il confirme à l'utilisateur·rice que l'élément est cliquable. C'est une réponse du site à l'action humaine.
• Le JavaScript (JS) : C'est le langage qui gère l'intelligence du site. Un popover ne peut pas s'ouvrir "tout seul" en HTML. Il faut un script qui surveille le clic. Bootstrap nous offre ces scripts (fichiers .js) : il nous suffit d'ajouter des attributs "data-bs" pour les activer.
• L'équilibre : Trop d'animations perdent le·la lecteur·rice. On utilise les finitions (lettrines, popovers) avec parcimonie, comme le sucre glace sur un gâteau.
• Professionnalisme : La Favicon est le petit logo de 16x16 pixels dans l'onglet. C'est le détail qui transforme un projet scolaire en un véritable site web crédible.
• Popover vs Tooltip : Le popover est fait pour du texte plus long (descriptions), tandis que le tooltip est une simple étiquette rapide. • L'accessibilité : Ces interactions codées par des pros permettent aussi aux personnes utilisant des claviers ou des lecteurs d'écran de naviguer sans encombre dans tes menus.
