Opération GHOST

TP Linux, protocole v1.1

Nom et prénom :Classe :

Objectif : naviguer dans une arborescence et manipuler des fichiers en ligne de commande, régler des droits, rechercher et filtrer.

Je sais :

  • me déplacer avec cd et voir les fichiers cachés ;
  • créer, copier, renommer et supprimer avec mkdir, touch, cp, mv, rmdir ;
  • protéger un fichier avec chmod ;
  • chercher un fichier avec find et une ligne avec grep.

1 heure · 13 questions et 4 bonus ★ · sur ordinateur, avec un terminal

[QG] Ghost, tu es infiltré·e sur le serveur AVALON. 10 missions t'attendent.
[QG] Utilise la commande check pour valider tes actions et obtenir tes ordres.
[QG] En cas d'échecs répétés, le QG te donnera des indices de plus en plus précis.

Comment ça marche : les missions se font sur l'ordinateur, dans le terminal ; c'est la commande check qui les valide. Sur cette feuille, après chaque mission, écris la commande que tu as utilisée et réponds aux questions : elles se corrigent en ligne.

1. Initialisation du terminal (sur l'ordinateur)

  1. Lance JSLinux Alpine et attends l'invite ~ #.
  2. Charge ton environnement : importe d'abord le fichier init_hacker.sh avec la flèche ↑ sous le terminal, puis tape : 
    ~ # . ./init_hacker.sh
  3. Lance le protocole : 
    ~ # check

2. Commandes vitales

  • check : analyse ta position, valide la mission et affiche l'objectif suivant.
  • tree : affiche l'arborescence du serveur (la carte du terrain).
  • ls / cd : explorer les répertoires et se déplacer.

Système d'indices progressifs : si check échoue, pas de panique, relance-le. Essai 1 : un indice logique · essai 2 : une aide technique · essai 3 : la solution (code). Pour les missions bonus, le QG te laisse en autonomie.

3. Phase I : infiltration et secrets

Après le chargement, tu es dans /tmp/avalon_server.

Mission 1 (cd, accès SQL). Infiltre le dossier SQL, qui est dans donnees. Quelle commande as-tu tapée ?

Le dossier SQL n'est pas directement dans avalon_server : il est dans donnees.

Tu es dans donnees : encore un niveau à descendre. On peut aussi tout faire en une seule commande.

Utilise l'outil de changement de répertoire.

Tu dois entrer dans donnees, puis dans SQL : un seul chemin, avec un / entre les deux.

cd donnees/SQL (ou, en chemin absolu, cd /tmp/avalon_server/donnees/SQL).

Mission 2 (ls -a, dossier caché). Le QG détecte un dossier fantôme à la racine de avalon_server. Depuis SQL, quelle commande affiche tout le contenu de avalon_server, dossiers cachés compris ?

Sans option, ls ne montre pas les fichiers cachés. Une option permet de tout voir (all).

Cette commande liste le contenu de SQL. Le dossier fantôme est deux niveaux plus haut.

Les dossiers dont le nom commence par un point sont masqués.

Utilise l'option -a de ls, avec le chemin de avalon_server (depuis SQL : ../..).

ls -a ../.. (ou ls -a /tmp/avalon_server) affiche . .. .secret donnees.

Comment reconnaît-on un fichier ou un dossier caché sous Linux ?

  • Son nom commence par un point
  • Il n'a aucun droit de lecture
  • Son nom finit par .hide
  • Il est rangé dans le dossier /hidden

Regarde le nom du dossier que ls -a a fait apparaître.

Un nom qui commence par un point (.secret) est caché : ls ne le montre qu'avec l'option -a.

Depuis SQL, entre dans le dossier caché. Quelle commande as-tu tapée ?

Le dossier s'appelle .secret (avec le point), et il est deux niveaux au-dessus de SQL.

Depuis SQL, .. mène à donnees : il faut remonter encore d'un niveau.

Le nom exact du dossier caché, point compris, est dans la réponse de ls -a.

cd ../../.secret (ou cd /tmp/avalon_server/.secret).

Mission 3 (cat, lecture du code). Un fichier pass.txt se trouve ici. Il contient le code d'accès au serveur de fichiers. Quelle commande affiche son contenu ? (Tape ensuite check et donne le code.)

ls montre le nom du fichier, pas ce qu'il contient.

Consulte le contenu du fichier pass.txt.

L'outil cat affiche le contenu.

cat pass.txt affiche le code d'accès, à donner à check.

4. Phase II : manipulation et camouflage

Mission 4 (mkdir / touch). Retourne dans donnees (tu es dans .secret). Quelle commande as-tu tapée ?

donnees n'est pas dans .secret : il faut d'abord remonter d'un niveau.

donnees et .secret sont tous les deux dans avalon_server : on remonte d'un niveau, puis on descend.

cd ../donnees (ou cd /tmp/avalon_server/donnees).

Il te faut un dossier backdoor pour travailler. Quelle commande le crée ?

touch crée un fichier vide, pas un dossier.

Utilise l'outil de création de dossier (MaKe DIRectory).

mkdir backdoor

Crée maintenant un fichier vide logs.txt dans backdoor, sans changer de dossier.

Le fichier serait créé dans donnees. Donne le chemin : d'abord le dossier, puis le nom du fichier.

mkdir créerait un dossier nommé logs.txt. Il faut un fichier vide.

L'outil de création de fichier vide est touch.

touch backdoor/logs.txt

Mission 5 (cp, duplication). Tu es dans donnees. Fais une copie de system_id vers backdoor/id_backup.txt. Quelle commande as-tu tapée ?

L'ordre compte : d'abord la source (ce qu'on copie), puis la destination.

mv déplace : l'original disparaîtrait. Ici, on veut une copie.

Utilise l'outil de duplication.

Indique la source (system_id) et la cible (backdoor/id_backup.txt).

cp system_id backdoor/id_backup.txt

Mission 6 (mv, renommer). Renomme l'original system_id en evidence.txt et cache-le dans ton dossier backdoor, en une seule commande.

cp laisse l'original en place : check le verra encore. Il doit disparaître.

Le fichier est renommé, mais il reste dans donnees : il doit aller dans backdoor.

L'outil de déplacement permet aussi de renommer.

Déplace l'original vers ta planque, avec son nouveau nom : backdoor/evidence.txt.

mv system_id backdoor/evidence.txt

Mission 7 (chmod, droits). Sécurise tes logs : modifie les permissions de logs.txt pour être la seule personne à pouvoir le lire et l'écrire. Tu es toujours dans donnees.

logs.txt n'est pas dans donnees : il est dans backdoor.

Presque : 7 donne aussi le droit d'exécuter. On ne demande que lire et écrire.

Le premier chiffre est pour le·la propriétaire, le dernier pour les autres : tu as inversé.

Modifie les droits (chmod) avec trois chiffres : propriétaire, groupe, autres.

Le mode 600 réserve tout au propriétaire.

chmod 600 backdoor/logs.txt

Après chmod 600, quels droits affiche ls -l backdoor/logs.txt ?

  • -rw-r--r--
  • -rw-------
  • -rwxrwxrwx
  • -------rw-

6 = 4 + 2 = lecture (r) + écriture (w). 0 = aucun droit.

-rw------- : lecture et écriture pour le·la propriétaire (6), rien pour le groupe (0) ni pour les autres (0).

5. Phase III : nettoyage et lanceur d'alerte

Mission 8 (rmdir, effacement). Le travail est presque fini. Supprime le dossier vide archives (dans donnees) pour masquer ton passage.

rm seul refuse de supprimer un dossier (« Is a directory »). Une commande est faite pour les dossiers vides.

Ça marche, mais c'est risqué : rm -r efface aussi tout ce qu'il y a dedans. Pour un dossier vide, il y a plus sûr.

Supprime le dossier archives.

L'outil de suppression de répertoire vide est requis : ReMove DIRectory.

rmdir archives : il ne supprime qu'un dossier vide, sans risque d'effacer autre chose.

Mission 9 (find, recherche). Utilise find pour localiser le fichier rapport_fraude.txt, caché profondément dans le serveur. Quelle commande as-tu tapée ?

Donne d'abord à find le dossier où commencer la recherche (par exemple /tmp), puis -name et le nom du fichier.

find a besoin d'un point de départ et d'un critère : -name suivi du nom cherché.

find /tmp -name rapport_fraude.txt répond /tmp/avalon_server/donnees/SQL/archives/2024/temp/rapport_fraude.txt.

Rends-toi dans le dossier parent de rapport_fraude.txt, avec son chemin absolu.

cd entre dans un dossier, pas dans un fichier : arrête-toi au dossier qui contient le rapport.

Reprends le chemin donné par find, sans le nom du fichier.

cd /tmp/avalon_server/donnees/SQL/archives/2024/temp

Mission 10 (grep, extraction). Avec grep, extrais la ligne qui contient le mot DETOURNEMENT et enregistre-la dans lanceur_alerte.txt, en une seule commande.

La ligne s'affiche à l'écran, mais n'est pas enregistrée. Le symbole > envoie l'affichage dans un fichier.

Le symbole > envoie ce qu'affiche une commande dans un fichier.

grep "DETOURNEMENT" rapport_fraude.txt > lanceur_alerte.txt

Déplace ensuite lanceur_alerte.txt dans le dossier /tmp/avalon_server.

check l'accepterait, mais la mission demande de déplacer le fichier, pas de le copier.

L'outil de déplacement, avec la source puis le dossier de destination.

mv lanceur_alerte.txt /tmp/avalon_server/ : un dernier check, et le monde saura la vérité sur Avalon.

Mémo

ls -a montre les fichiers cachés (leur nom commence par un point) · cp copie, mv déplace ou renomme · chmod 600 : lecture et écriture pour le·la propriétaire seulement · rmdir supprime un dossier vide · find cherche un fichier, grep une ligne, > l'enregistre.
