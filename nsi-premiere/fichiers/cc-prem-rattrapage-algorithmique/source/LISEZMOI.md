# Sources LaTeX

Sujets d'évaluation de NSI, par Babash - NSI Tani Malandi et Johanne Bakalara (CC BY-SA 4.0).

Compilation : `latexmk -pdf -shell-escape <fichier>.tex` (pdfLaTeX ; `-shell-escape` seulement si le fichier charge `minted`).
Les fichiers sont réglés en mode sujet (`noanswers`). Pour obtenir le corrigé quand le fichier en contient, remplacer `noanswers` par `answers` dans `\documentclass`.
