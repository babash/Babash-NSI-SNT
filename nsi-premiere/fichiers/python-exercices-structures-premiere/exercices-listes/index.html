1. Recherche linéaire

def recherche(l, x):
    for i in range(len(l)):
        if l[i] == x:
            return i
    return -1

l = [2, 1, 11, 7, 2, 6]
x = int(input("Donner une valeur : "))
print(recherche(l, x))

Quel est le type de la variable l ? Choisis la bonne justification.

  • Une liste (list) : ses valeurs sont entre crochets, séparées par des virgules.
  • Un entier (int) : elle contient des nombres entiers.
  • Un texte (str) : elle contient des caractères.
  • Un tuple : elle regroupe plusieurs valeurs.

Regarde les symboles qui entourent les valeurs, à la ligne 7.

l est une liste (list) : on le reconnaît aux crochets [ ] qui entourent des valeurs séparées par des virgules.

Quel est le type de la variable l ? Justifie ta réponse.

Complète le tableau d'avancement de la fonction pour l'appel recherche(l, 7), avec la liste l du programme. Pour chaque tour, écris la valeur de i et celle du test (True ou False).

# tour 0 : i = [[0]]   l[i] == x : [[False|false|faux|Faux]]
# tour 1 : i = [[1]]   l[i] == x : [[False|false|faux|Faux]]
# tour 2 : i = [[2]]   l[i] == x : [[False|false|faux|Faux]]
# tour 3 : i = [[3]]   l[i] == x : [[True|true|vrai|Vrai]]
# la fonction renvoie [[3]]

Au tour 0, i vaut 0 et l[0] vaut 2 : est-ce égal à 7 ?

Dès que l[i] == x est vrai, return i arrête la fonction : il n'y a plus de tour après.

l[0] = 2, l[1] = 1, l[2] = 11 : différents de 7. Au tour 3, l[3] = 7 : le test est vrai et la fonction renvoie 3 aussitôt. Le programme affiche 3 (vérifié en l'exécutant).

Que renvoie la fonction recherche pour chacun de ces appels ?

# recherche([2, 1, 11], 7)   renvoie [[-1]]
# recherche([], 3)           renvoie [[-1]]
# recherche([1, 0], 5)       renvoie [[-1]]
# recherche([6, 1, 11], 11)  renvoie [[2]]

Si la valeur n'est pas dans la liste, la boucle se termine sans return i : on arrive à la dernière ligne de la fonction.

Les indices commencent à 0 : dans [6, 1, 11], 11 est à l'indice 2.

7, 3 et 5 ne sont pas dans leur liste : la fonction renvoie -1 (une liste vide ne fait aucun tour). 11 est à l'indice 2 de [6, 1, 11].

Quelle phrase décrit l'objectif et le fonctionnement de ce programme ?

  • Il parcourt la liste et renvoie l'indice de la première case égale à la valeur saisie, ou -1 si elle n'y est pas.
  • Il renvoie la valeur saisie si elle est dans la liste.
  • Il compte combien de fois la valeur saisie est dans la liste.
  • Il cherche la plus grande valeur de la liste.

Que renvoie return i : une valeur de la liste, ou une position ?

C'est une recherche linéaire : on regarde les cases une à une ; à la première case égale à x, on renvoie son indice ; si on ne trouve rien, on renvoie -1.

Explique l'objectif et le fonctionnement de ce programme en une phrase.

2. Trouver un maximum

tab = [9, 100, 8, 48, 73]
imax, vmax = 0, tab[0]
for i in range(len(tab)):
    if tab[i] > vmax:
        vmax = tab[i]
        imax = i
print(vmax, imax)

Quel type de parcours est utilisé à la ligne 3 ?

  • Un parcours par indice.
  • Un parcours par valeur.
  • Une boucle infinie.
  • Une boucle tant que (while).

Quelles valeurs prend i avec range(len(tab)) ?

for i in range(len(tab)) : i prend les indices 0, 1, 2, 3, 4. C'est un parcours par indice ; on lit la valeur avec tab[i].

Que représente la variable imax ?

  • L'indice (la position) de la plus grande valeur trouvée.
  • La plus grande valeur de la liste.
  • Le nombre de cases de la liste.
  • Le nombre de tours de boucle.

À la ligne 6, imax reçoit i. Et i, c'est quoi ?

imax est l'indice du maximum : chaque fois qu'on trouve une valeur plus grande, on garde sa valeur dans vmax et sa position dans imax.

Que représente la variable imax ?

Complète le tableau d'avancement : pour chaque tour, la valeur de tab[i], celle du test tab[i] > vmax (True ou False), puis vmax et imax à la fin du tour.

# i = 0 : tab[i] = [[9]] test : [[False|false|faux|Faux]] vmax = [[9]] imax = [[0]]
# i = 1 : tab[i] = [[100]] test : [[True|true|vrai|Vrai]] vmax = [[100]] imax = [[1]]
# i = 2 : tab[i] = [[8]] test : [[False|false|faux|Faux]] vmax = [[100]] imax = [[1]]
# i = 3 : tab[i] = [[48]] test : [[False|false|faux|Faux]] vmax = [[100]] imax = [[1]]
# i = 4 : tab[i] = [[73]] test : [[False|false|faux|Faux]] vmax = [[100]] imax = [[1]]

Avant la boucle, vmax vaut tab[0], soit 9, et imax vaut 0.

Au tour 0, 9 > 9 est faux : rien ne change. Au tour 1, 100 > 9 est vrai : vmax et imax changent.

Seul le tour 1 change quelque chose : vmax devient 100 et imax 1. Aucune valeur suivante ne dépasse 100. Le programme affiche 100 1 (vérifié en l'exécutant).

Qu'affiche le programme si on remplace la liste tab de la ligne 1 par chacune de ces listes ?

# tab = [10, 4, 8, 88, 10]   affiche [[88]] [[3]]
# tab = [-10, -2, -10]       affiche [[-2]] [[1]]

Le programme affiche d'abord vmax, puis imax.

Avec des nombres négatifs, -2 est plus grand que -10.

Pour la première liste, le maximum 88 est à l'indice 3 : 88 3. Pour la seconde, -2 > -10 : le maximum -2 est à l'indice 1 : -2 1.

Quelle phrase décrit l'objectif et le fonctionnement de ce programme ?

  • Il parcourt la liste, garde la plus grande valeur vue et sa position, puis les affiche.
  • Il trie la liste dans l'ordre croissant.
  • Il calcule la somme des valeurs de la liste.
  • Il cherche la plus petite valeur et sa position.

Quand vmax change-t-il ?

On part de la première valeur ; à chaque case plus grande que vmax, on retient sa valeur et son indice. À la fin, on affiche le maximum et sa position.

Explique l'objectif et le fonctionnement de ce programme en une phrase.

3. Vérification du tri

tab = [0, 5, 8, 8, 9]
tri = True
for i in range(len(tab)-1):
    if tab[i] > tab[i+1]:
        tri = False
print(tri)

Combien y a-t-il de structures de contrôle (boucles et conditions) dans ce programme ?

Il y a une boucle… et autre chose qui contrôle quelles lignes s'exécutent.

Une structure de contrôle commence par un mot-clé suivi de deux-points : for, while, if…

2 : une boucle for (ligne 3) et une condition if (ligne 4).

Quel type de parcours est utilisé ?

  • Un parcours par indice, de 0 jusqu'à l'avant-dernière case.
  • Un parcours par valeur.
  • Un parcours par indice, de 0 jusqu'à la dernière case.
  • Un parcours avec une boucle while.

Avec 5 cases, range(len(tab)-1) donne range(4) : quelles valeurs ?

Parcours par indice : i va de 0 à 3, l'avant-dernière case. On s'arrête là car on compare chaque case à la suivante, tab[i+1], qui doit exister.

Complète le tableau d'avancement de la boucle : pour chaque tour, tab[i], tab[i+1] et la valeur du test tab[i] > tab[i+1] (True ou False).

# i = 0 : tab[i] = [[0]]  tab[i+1] = [[5]]  test : [[False|false|faux|Faux]]
# i = 1 : tab[i] = [[5]]  tab[i+1] = [[8]]  test : [[False|false|faux|Faux]]
# i = 2 : tab[i] = [[8]]  tab[i+1] = [[8]]  test : [[False|false|faux|Faux]]
# i = 3 : tab[i] = [[8]]  tab[i+1] = [[9]]  test : [[False|false|faux|Faux]]
# le programme affiche [[True|true|vrai|Vrai]]

Il y a 4 tours : i va de 0 à 3.

Au tour 2, on compare 8 et 8 : 8 > 8 est faux (ils sont égaux).

Aucune case n'est plus grande que la suivante : tri reste True, et le programme affiche True (vérifié en l'exécutant).

Qu'affiche le programme pour chacune de ces listes tab ?

# tab = [8, 12, 4]   affiche [[False|false|faux|Faux]]
# tab = [-1, 4]      affiche [[True|true|vrai|Vrai]]
# tab = [5]          affiche [[True|true|vrai|Vrai]]

Dans [8, 12, 4], compare 12 et 4.

Avec une seule case, range(0) ne fait aucun tour : tri garde sa valeur de départ.

[8, 12, 4] : 12 > 4, donc False. [-1, 4] : -1 < 4, donc True. [5] : aucun tour, donc True (une liste d'une case est triée).

Quelle phrase décrit l'objectif et le fonctionnement de ce programme ?

  • Il vérifie que la liste est triée dans l'ordre croissant, en comparant chaque case à la suivante.
  • Il trie la liste dans l'ordre croissant.
  • Il vérifie que toutes les valeurs sont positives.
  • Il compte les cases mal placées.

Quand tri devient-il False ?

On suppose la liste triée (tri = True) ; dès qu'une case est plus grande que la suivante, la liste n'est pas triée (tri = False). Le programme affiche le résultat.

Explique l'objectif et le fonctionnement de ce programme en une phrase.

Mémo

Parcours par indice : for i in range(len(tab)), puis tab[i]. Un tableau d'avancement note les variables à chaque tour. return arrête la fonction aussitôt.
