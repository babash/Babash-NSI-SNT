5. Pour aller plus loin : les listes par compréhension

En Python, on peut créer une liste à partir d'une boucle et d'une condition, le tout en une seule ligne :

l = [i for i in range(4)]  # l = [0, 1, 2, 3]
l = [i for i in range(1, 11) if i%2==0]  # l = [2, 4, 6, 8, 10]
l = [[0] for i in range(2)]  # l = [[0], [0]]
l = [[i for i in range(j)] for j in range(4)]
# l = [[], [0], [0, 1], [0, 1, 2]]

l = [1, 3, 5, 7, 9]
[v+2 for v in l]  # [3, 5, 7, 9, 11]
[v*i for i, v in enumerate(l)]  # [0, 3, 10, 21, 36]

Qu'affichent les lignes suivantes ? Écris une ligne de réponse par print.

print([i**2 for i in range(10)])
print([i for i in range(10) if i%3==0])
print([[] for i in range(3)])
print([['O' for i in range(2)] for j in range(3)])
print([[i+j for i in range(2) if i*j%2==0] for j in range(3)])
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
[0, 3, 6, 9]
[[], [], []]
[['O', 'O'], ['O', 'O'], ['O', 'O']]
[[0, 1], [1], [2, 3]]

i**2 est le carré de i ; i%3==0 garde les multiples de 3.

Pour la dernière ligne, traite j = 0, puis 1, puis 2 : pour chacun, la liste des i+j (avec i = 0 et 1) dont i*j est pair.

Pour la dernière ligne : avec j = 0, i*j vaut toujours 0 (pair) : [0, 1]. Avec j = 1, i*j vaut 0 puis 1 (impair) : on garde seulement i = 0, donc [1]. Avec j = 2 : [2, 3].

Les noms des communes : data[0][1:].

La longueur d'un nom : len(nom). Donc [len(nom) for nom in …].

def longueurs_noms(data):
    return [len(nom) for nom in data[0][1:]]

Récupère les noms des différents critères (« Nom de la commune », « SIREN »…).

Chaque critère est la première case d'une ligne : ligne[0].

def noms_criteres(data):
    return [ligne[0] for ligne in data]

On parcourt les numéros de colonnes : for i in range(1, len(data[0])).

La condition : if float(data[3][i]) > 10000 ; on garde le nom, data[0][i].

def grandes_communes(data):
    return [data[0][i] for i in range(1, len(data[0]))
            if float(data[3][i]) > 10000]

Dix communes : Bandrele, Tsingoni, Sada, Ouangani, Pamandzi, Dzaoudzi, Koungou, Bandraboua, Mamoudzou et Dembeni.

Reprends la question précédente : au lieu de garder data[0][i], garde la paire [data[0][i], data[3][i]].

La première paire est ['Bandrele', '10529']. Un tuple (nom, population) ou une population convertie en nombre conviennent aussi.
