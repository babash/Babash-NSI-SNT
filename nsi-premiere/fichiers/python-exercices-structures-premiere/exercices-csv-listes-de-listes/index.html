2. Manipuler un CSV en Python

En Python, on peut lire un CSV et le convertir en liste de listes grâce à la bibliothèque csv :

import csv

csv_filename = 'comparaisons-communes-mayotte.csv'
with open(csv_filename, encoding='utf-8') as f:
    reader = csv.reader(f)
    tab = list(reader)

La variable tab contient alors une liste de listes. Voici ses trois premières lignes :

[['Nom de la commune', 'Kani-Kéli', 'Chirongui', ..., 'Dembeni'],
 ['SIREN', '200008803', '200008779', '200008746', ..., '200008787'],
 ['Insee', '97609', '97606', '97604', ..., '97607'],
 ...]

Pour la suite, le jeu de données est chargé dans la variable tab.

Quel est le type de la variable tab ? Quelle ligne peut-on écrire en Python pour le vérifier ?

  • une liste (list), de listes ; on vérifie avec print(type(tab))
  • un dictionnaire (dict) ; on vérifie avec print(type(tab))
  • une chaîne (str), le texte du fichier ; on vérifie avec print(tab)
  • une liste (list) ; on vérifie avec print(len(tab))

La fonction qui donne le type d'une valeur s'appelle type.

tab est une liste (list) dont chaque élément est une liste. print(type(tab)) affiche <class 'list'>.

Quels sont les types de tab[0] et de tab[6][5] ?

  • list, puis str
  • list, puis int
  • str, puis str
  • list, puis list

tab[0] est une ligne ; tab[6][5] est une case de la ligne 6.

Le module csv lit toutes les valeurs comme du texte.

tab[0] est la première ligne : une liste (list). tab[6][5] est une case : la chaîne '0' (str), car le module csv lit tout comme du texte.

def stats_communes(data):
    for i in range(1, len(data[ [[0|1|2|3]] ])):
        commune = data[ [[0]] ][i]
        pop = data[3][ [[i]] ]
        siren = data[ [[1]] ][ [[i]] ]
        print("Dans la commune de", commune, "(SIREN", siren,
