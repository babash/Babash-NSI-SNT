3. Filtrer les données manquantes

def filter_null(data):
    new_data = []
    for l in data:
        count_null = 0
        for v in l:
            if v == '0' or v == "":
                count_null += 1
        if count_null < len(l) - 1:
            new_data.append(l)
    return new_data

tab = filter_null(tab)

count_null repart de 0 au début de chaque ligne, et n'augmente que si v vaut '0' ou "".

Chaque ligne a 18 valeurs : len(l) - 1 vaut 17.

Pour la ligne 0, aucune valeur ne vaut '0' ou "" : count_null reste à 0. Pour la ligne 6, le titre ne compte pas (0), puis chacune des 17 valeurs '0' ajoute 1 : count_null finit à 17. Or 17 < 17 vaut False : la ligne 6 n'est pas gardée.

4. Pour aller plus loin : les tranches

En Python, on peut extraire des sous-listes : on parle de tranches (slices, en anglais). Cela marche comme la fonction range :

l = [1, 2, 4, 8, 16, 32, 64, 128, 256, 512]
print(l[0:5])
# extrait les valeurs des indices 0 à 5 (exclu) : [1, 2, 4, 8, 16]
print(l[6:])
# les valeurs à partir de l'indice 6 (inclus) : [64, 128, 256, 512]
print(l[:2])
# les valeurs jusqu'à l'indice 2 (exclu) : [1, 2]
print(l[-2:], l[:-5], l[-5:-2])
# bien sûr, cela marche aussi avec des indices négatifs :
# [256, 512] [1, 2, 4, 8, 16] [32, 64, 128]
print(l[0:-1:4])
# à la manière d'un range, on peut indiquer un pas : [1, 16, 256]

En gardant la liste l ci-dessus, qu'affichent les lignes suivantes ? Écris une ligne de réponse par print.

l = [1, 2, 4, 8, 16, 32, 64, 128, 256, 512]
print(l[-1])
print(l[:-2])
print(l[:5])
print(l[2:7])
print(l[-7:-2:-2])
print(l[len(l)//2:])
print(l[:len(l)//2])
512
[1, 2, 4, 8, 16, 32, 64, 128]
[1, 2, 4, 8, 16]
[4, 8, 16, 32, 64]
[]
[32, 64, 128, 256, 512]
[1, 2, 4, 8, 16]

l[-1] est une seule valeur (sans crochets) ; les autres sont des tranches, donc des listes.

Avec un pas négatif, on avance vers la gauche : il faut partir d'un indice plus à droite que la fin. Ici, -7 est à gauche de -2.

len(l)//2 vaut 5.

l[-1] est la dernière valeur, 512. l[-7:-2:-2] est vide : avec un pas de -2, on part de l'indice -7 vers la gauche, et on n'atteint jamais -2. len(l)//2 vaut 5 : les deux dernières lignes coupent la liste en deux moitiés.

Avec une tranche, comment récupérer la liste des communes, sans 'Nom de la commune' ?

Tu perds Kani-Kéli : la première commune est à l'indice 1.

Les communes sont dans la ligne tab[0] ; on enlève sa première valeur, à l'indice 0.

Les communes sont dans tab[0], à partir de l'indice 1.

tab[0][1:] : la ligne des noms, à partir de l'indice 1.

Mémo

Deux boucles imbriquées : la boucle interne fait tous ses tours pour chaque tour de la boucle externe.

Tranche : l[début:fin:pas], la fin est exclue ; l[1:] enlève le premier élément.
