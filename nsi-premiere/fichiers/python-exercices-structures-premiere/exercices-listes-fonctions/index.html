La moyenne, c'est la somme des éléments divisée par leur nombre.

Additionne les éléments dans une variable total avec une boucle, puis divise par len(liste).

def moyenne(liste):
    total = 0
    for x in liste:
        total = total + x
    return total / len(liste)


print(moyenne([12, 15, 9]))
print(moyenne([10, 11]))
print(moyenne([7]))

On additionne avec une boucle, puis on divise par le nombre d'éléments. En une ligne : sum(liste) / len(liste).

# Programme principal : tes tests

Commence par trier : triee = sorted(liste) donne une copie triée.

Si le nombre d'éléments n est impair, la médiane est l'élément du milieu, d'indice n // 2.

Si n est pair, c'est la moyenne des deux éléments du milieu, d'indices n // 2 - 1 et n // 2.

def mediane(liste):
    triee = sorted(liste)
    n = len(triee)
    if n % 2 == 1:
        return triee[n // 2]
    return (triee[n // 2 - 1] + triee[n // 2]) / 2


print(mediane([3, 1, 2]))
print(mediane([4, 1, 3, 2]))
print(mediane([8, 3, 5, 9, 1]))

On trie, puis on prend l'élément du milieu (nombre impair d'éléments) ou la moyenne des deux du milieu (nombre pair).

Pars d'une liste vide et essaie tous les d de 1 à n : for d in range(1, n + 1):.

def diviseurs(n):
    resultat = []
    for d in range(1, n + 1):
        if n % d == 0:
            resultat.append(d)
    return resultat

Cherche le plus grand et le plus petit élément, puis fais la différence.

Pars du premier élément, liste[0], et compare-le à chaque élément dans une boucle.

def etendue(liste):
    plus_grand = liste[0]
    plus_petit = liste[0]
    for x in liste:
        if x > plus_grand:
            plus_grand = x
        if x < plus_petit:
            plus_petit = x
    return plus_grand - plus_petit


print(etendue([4, 9, 2, 7]))
print(etendue([5, 5]))
print(etendue([-3, 10]))

On cherche le maximum et le minimum en une seule boucle. En une ligne : max(liste) - min(liste).

Pour modifier un élément, il faut son indice : parcours avec for i in range(len(liste)):.

Si liste[i] < 0, écris liste[i] = 0. N'oublie pas de renvoyer la liste.

def zeroSiNegatif(liste):
    for i in range(len(liste)):
        if liste[i] < 0:
            liste[i] = 0
    return liste


print(zeroSiNegatif([3, -1, 0, -7, 5]))
print(zeroSiNegatif([-2]))
print(zeroSiNegatif([]))

On parcourt les indices, pour pouvoir écrire liste[i] = 0. Avec for x in liste:, changer x ne changerait pas la liste.

Mémo

Accumulateur : total = 0 avant la boucle, total = total + x dedans (pour un produit, on part de 1). Compteur : + 1 sous un if.

Nouvelle liste : resultat = [], puis resultat.append(…). Pour modifier un élément, il faut son indice : liste[i] = …. Une fonction renvoie avec return.
