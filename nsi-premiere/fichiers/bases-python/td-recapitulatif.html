Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Que veut dire ce code ?

Qu'affiche ce programme ?

for i in range(3):
    print("Hip hip hip")
print("Hourra !")
Hip hip hip
Hip hip hip
Hip hip hip
Hourra !

« Hourra ! » n'est pas décalé : il n'est pas répété.

Quelles lignes sont décalées sous le for ?

« On affiche 3 fois "Hip hip hip", puis une fois "Hourra !". » La dernière ligne n'est pas décalée : elle est après la boucle.

Robot. Choisis la phrase qui traduit ce programme.

for i in range(4):
    while not obstacleNord():
        nord()
    est()
  • 4 fois : il monte jusqu'à un obstacle (ou au bord), puis fait un pas vers l'est.
  • 4 fois : il monte d'une case, puis fait un pas vers l'est.
  • Il monte jusqu'à un obstacle, puis fait 4 pas vers l'est.
  • Tant que la case au nord est libre, il monte, puis il fait 4 pas vers l'est.

Le while est décalé sous le for : il est refait à chaque tour.

Une boucle dans une boucle : à chacun des 4 tours, le robot monte le plus haut possible, puis fait un pas vers l'est.

2. for ou while ?

Coche les situations où une boucle while est la mieux adaptée. Pour les autres, on choisit for.

  • Afficher les 10 premiers multiples de 7.
  • Redemander un mot de passe jusqu'à ce qu'il soit correct.
  • Faire avancer le robot jusqu'au premier obstacle.
  • Afficher une par une les lettres d'un prénom.
  • Lancer un dé jusqu'à obtenir un 6.
  • Faire avancer le robot de exactement 5 cases.
  • Calculer la somme des nombres de 1 à 1 000.
  • Compter combien d'années il faut pour qu'une somme placée double.

Connaît-on le nombre de tours avant de commencer ? Si oui : for.

« Jusqu'à ce que… » : on répète tant qu'une condition n'est pas remplie, c'est while.

while quand on ne connaît pas le nombre de tours (« jusqu'à… ») : le mot de passe, le premier obstacle, le 6 au dé, les années. for quand on le connaît, ou pour parcourir un texte : les 10 multiples, les lettres du prénom, les 5 cases, les nombres de 1 à 1 000.

Mémo

for : on connaît le nombre de tours (ou on parcourt un texte). while : on répète « jusqu'à… », sans savoir combien de tours.

input renvoie un texte : int(input(…)) pour un nombre.
