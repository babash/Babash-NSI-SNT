Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Que veut dire ce code ?

Exemple : ce programme se traduit par « Tant qu'il n'y a pas d'obstacle à l'est, le robot avance d'une case vers l'est. Il s'arrête donc juste devant le premier obstacle (ou le bord). »

while not obstacleEst():
    est()

Qu'affiche ce programme ?

n = 5
while n > 0:
    print(n)
    n = n - 1
print("Partez !")
5
4
3
2
1
Partez !

Quand n vaut 0, la condition 0 > 0 est fausse : 0 ne s'affiche pas.

Avant chaque tour, Python teste n > 0. Dans la boucle, n diminue de 1.

« Partez ! » n'est pas décalé : il s'affiche une seule fois, après la boucle.

« Tant que n est positif, on affiche n puis on lui enlève 1. Ensuite, on affiche « Partez ! ». » C'est un compte à rebours : 5, 4, 3, 2, 1, Partez !

while i <= 10:

Traceback (most recent call last):

name 'i' is not defined : « le nom i n'est pas défini ». Python ne connaît pas encore i.

Ici, la proposition Did you mean: 'id'? ne t'aide pas : id est une autre fonction de Python. Lis surtout la ligne indiquée.

Ligne 1 : au premier test, i n'a pas encore de valeur. Il manque une ligne avant la boucle : i = 1.

Ce programme affiche 1 sans jamais s'arrêter. Pourquoi ?

i = 1
while i <= 5:
    print(i)
i = i + 1
  • i = i + 1 n'est pas décalée : elle n'est pas dans la boucle, donc i vaut toujours 1.
  • Il faut écrire while i < 5:.
  • print(i) doit être après i = i + 1.
  • Il faut écrire i = 0 au début.
