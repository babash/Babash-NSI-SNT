Feuille 2 sur 3 · 35 minutes · 9 questions · seul·e ou en binôme

Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Complète le code

Si la vitesse dépasse 50, afficher « Ralentis ! ».

vitesse = 72
if vitesse [[>]] 50 [[:]]
    print("Ralentis !")
Ralentis !

« Dépasser 50 » : être plus grand que 50.

Une ligne if finit par deux-points.

vitesse = 72
if vitesse > 50:
    print("Ralentis !")

Robot. Obstacle au nord : aller au sud, sinon au nord.

[[if]] obstacleNord():
    [[sud()]]
[[else:]]
    nord()

« Sinon » s'écrit else:.

if obstacleNord():
    sud()
else:
    nord()

Si mdp vaut "nsi2026" : afficher « OK », sinon « Refusé ».

mdp = "nsi2026"
[[if]] mdp [[==]] "nsi2026":
    print("OK")
[[else:]]
    print("Refusé")
OK

Pour comparer, on utilise ==.

mdp = "nsi2026"
if mdp == "nsi2026":
    print("OK")
else:
    print("Refusé")

Billet : 5 € (moins de 12 ans), 8 € (12 à 25 ans), 12 € sinon.

age = 15
if age [[<]] 12:
    prix = 5
[[elif]] age [[<=]] 25:
    prix = [[8]]
[[else]]:
    prix = 12
print(prix)
8

Trois cas : if, puis elif, puis else.

Au elif, on sait déjà que l'âge est au moins 12 : il reste à tester « au plus 25 ».

age = 15
if age < 12:
    prix = 5
elif age <= 25:
    prix = 8
else:
    prix = 12
print(prix)

Robot. Si la case à l'est est libre, avancer vers l'est.

if [[not]] [[obstacleEst()]]:
    est()

« Libre » : il n'y a pas d'obstacle.

if not obstacleEst():
    est()

Robot. Obstacle à l'est ou au sud : aller vers le nord.

if obstacleEst() [[or]] [[obstacleSud()]]:
    [[nord()]]

« Ou » s'écrit or.

if obstacleEst() or obstacleSud():
    nord()

2. Où se trouve le robot ?

Le robot part de A3, sur la grille dessinée avec chaque programme. Sur papier, trace son trajet sur la grille. Écris la case d'arrivée (par exemple C4).

Robot. Où arrive le robot ?

est()
if obstacleEst():
    nord()
else:
    est()

Après est(), le robot est en B3. Qu'y a-t-il en C3 ?

B3 ; C3 est un obstacle : il monte en B2.

Robot. Où arrive le robot ?

nord()
est()
if obstacleEst():
    sud()
elif obstacleNord():
    est()
else:
    nord()

Après les deux premières lignes, le robot est en B2.

Teste les conditions dans l'ordre : la première vraie gagne.

A2, B2. Est (C2) : libre. Nord (B1) : obstacle, donc est() : C2.

Robot. Où arrive le robot ?

sud()
est()
est()
if not obstacleNord():
    nord()
else:
    sud()

Après les trois premières lignes, le robot est en C4.

A4, B4, C4. Au nord, C3 est un obstacle : not obstacleNord() est faux, donc sud() : C5.

Mémo

Pour plusieurs cas : if, puis autant de elif que nécessaire, puis else pour tous les autres cas. Les conditions se testent dans l'ordre.
