Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Où se trouve le robot ? (suite)

Le robot part de A6. Sur papier, trace son trajet sur la grille. Écris la case d'arrivée et ce qu'on te demande.

Robot. Où arrive le robot ?

pas = 0
for i in range(4):
    if not obstacleNord():
        nord()
        pas = pas + 1
    else:
        est()
print(pas)

4 tours : à chaque tour, le robot monte si c'est libre, sinon il va vers l'est.

A5, A4, A3 ; en A3, A2 bloque : B3. Arrivée B3.

Avec ce même programme, qu'affiche print(pas) ?

Le pas vers l'est n'est pas compté.

pas compte seulement les pas vers le nord.

3 pas vers le nord : 3.

Robot. Où arrive le robot ?

nord()
while not obstacleEst():
    est()
    if obstacleNord():
        print("mur")

Après nord(), le robot est en A5 et avance vers l'est jusqu'au bord.

B5, C5, D5, E5, F5, G5, H5 (le bord).

Avec ce même programme, combien de « mur » s'affichent ?

Après chaque pas, le robot regarde la case au nord.

Les obstacles de la ligne 4 : B4, C4, D4 et G4.

Au nord de B5, C5, D5 et G5 : 4 obstacles, donc 4 « mur ».

Robot. Où arrive le robot ?

for i in range(3):
    nord()
while not obstacleEst():
    est()
    if not obstacleSud():
        sud()

Après le for, le robot est en A3.

À chaque tour : un pas vers l'est, puis un pas vers le sud si c'est libre.

A3 ; B3, C3, D3 (au sud : obstacles) ; E3 puis E4 ; F4 puis F5 ; G5 puis G6 ; H6 : le bord est à l'est. Arrivée H6.

2. Complète ou écris le code à partir d'un objectif

Nombre mystère. On propose des nombres jusqu'à trouver 42. À chaque essai raté, le programme dit « Trop petit » ou « Trop grand ».

secret = 42
essai = int(input("Devine : "))
while essai [[!=]] secret:
    if essai [[<]] secret:
        print("Trop petit")
    [[else]]:
        print("Trop grand")
    essai = int(input("Devine : "))
print("Bravo !")

On recommence tant que l'essai est différent du secret.

Trop petit : l'essai est plus petit que le secret. Sinon : trop grand.

secret = 42
essai = int(input("Devine : "))
while essai != secret:
    if essai < secret:
        print("Trop petit")
    else:
        print("Trop grand")
    essai = int(input("Devine : "))
print("Bravo !")

La fonction moyenne(n) demande n notes et renvoie leur moyenne.

def moyenne(n):
    total = [[0]]
    for i in range([[n]]):
        note = int(input("Note : "))
        total = [[total + note|note + total]]
    return [[total / n]]

On demande n notes : la boucle fait n tours.

La moyenne : le total divisé par le nombre de notes.

def moyenne(n):
    total = 0
    for i in range(n):
        note = int(input("Note : "))
        total = total + note
    return total / n

On appelle moyenne(3) et on tape 10, 14 puis 15. Quelle valeur est renvoyée ?

10 + 14 + 15 = 39.

39 / 3 = 13.0 (la division / donne un nombre à virgule).

Un compteur à 0, puis for lettre in mot:.

Une lettre est une voyelle si lettre in "aeiouy".

def nb_voyelles(mot):
    nb = 0
    for lettre in mot:
        if lettre in "aeiouy":
            nb = nb + 1
    return nb

Une boucle while qui continue tant que le robot n'est pas bloqué des deux côtés : while not (obstacleEst() and obstacleNord()):.

Dans la boucle : si l'est est libre, est() ; sinon, nord().

def aller_au_bout():
    while not (obstacleEst() and obstacleNord()):
        if not obstacleEst():
            est()
        else:
            nord()
