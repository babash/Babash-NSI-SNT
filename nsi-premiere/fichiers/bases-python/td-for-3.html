Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

2. Complète le code à partir d'un objectif

La fonction table(n) affiche la table de multiplication de n, de n x 1 à n x 10.

def table(n):
    for i in range([[1]], [[11]]):
        print(n, "x", i, "=", [[n * i|i * n]])

i doit aller de 1 à 10 : la fin de range est exclue.

Le résultat de « n x i » se calcule avec *.

def table(n):
    for i in range(1, 11):
        print(n, "x", i, "=", n * i)

Quelle est la dernière ligne affichée par table(3) ?

La fin 11 est exclue : le dernier tour se fait avec i égal à 10.

Au dernier tour, i vaut 10.

print sépare ses valeurs par une espace : 3 x 10 = 30.

Au dernier tour, i vaut 10 : 3 x 10 = 30.

La fonction somme_carres(n) renvoie 1 x 1 + 2 x 2 + … + n x n.

def somme_carres(n):
    s = [[0]]
    for i in range(1, [[n + 1|1 + n]]):
        s = [[s + i * i|s + i ** 2|i * i + s|s + i*i]]
    return s

L'accumulateur s vaut 0 avant la boucle.

Pour que i aille jusqu'à n, la fin de range est n + 1.

def somme_carres(n):
    s = 0
    for i in range(1, n + 1):
        s = s + i * i
    return s

Que renvoie somme_carres(3) ?

On s'arrête trop tôt : 3 x 3 compte aussi.

On additionne les carrés : 1 x 1 + 2 x 2 + 3 x 3, pas 1 + 2 + 3.

Calcule 1 x 1 + 2 x 2 + 3 x 3.

1 + 4 + 9 = 14.

Écris la fonction compte(mot, lettre) : elle renvoie le nombre de fois où lettre apparaît dans mot. Par exemple, compte("banane", "n") doit renvoyer 2.

def compte(mot, lettre):

Un compteur qui vaut 0 au départ, et une boucle for c in mot: qui prend les lettres une par une.

Dans la boucle : si c == lettre, on ajoute 1 au compteur. Après la boucle, on renvoie le compteur.

def compte(mot, lettre):
    n = 0
    for c in mot:
        if c == lettre:
            n = n + 1
    return n

Mémo

Dans une fonction, la boucle répète des instructions avec les paramètres : for i in range(n):. Un accumulateur commence à 0 avant la boucle, et return le renvoie après.
