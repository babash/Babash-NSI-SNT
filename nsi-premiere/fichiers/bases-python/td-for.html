Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Que veut dire ce code ?

Exemple : ce programme se traduit par « On répète 3 fois : le robot avance d'une case vers l'est. Il avance donc de 3 cases vers l'est. »

for i in range(3):
    est()

La boucle affiche une lettre à chaque tour, et print passe à la ligne à chaque fois.

Une boucle for sur un texte prend ses caractères un par un.

À chaque tour, lettre vaut le caractère suivant, et print l'affiche sur sa propre ligne.

« Pour chaque lettre du mot "Mayotte", on affiche cette lettre. » Le programme affiche les 7 lettres, une par ligne : M, a, y, o, t, t, e.

Robot. Choisis la phrase qui traduit ce programme.

for i in range(2):
    nord()
    est()
  • 2 fois : il monte d'une case, puis avance d'une case vers l'est (un escalier de 2 marches).
  • Il monte de 2 cases, puis avance de 2 cases vers l'est.
  • Il monte de 2 cases, puis avance d'une seule case vers l'est.
  • 3 fois : il monte d'une case, puis avance d'une case vers l'est.

Les lignes décalées sous le for forment le bloc répété.

range(2) donne 0 et 1 : combien de tours ?

Le bloc répété contient nord() et est() : à chaque tour, le robot monte puis avance. Avec 2 tours, il dessine un escalier de 2 marches.

La fin de range est exclue : i s'arrête à 5.

Ici, range(1, 6) commence à 1, pas à 0.

range(1, 6) donne 1, 2, 3, 4 et 5.

À chaque tour, on affiche i * i, le carré de i.

« Pour i allant de 1 à 5, on affiche le carré de i. » Sortie : 1, 4, 9, 16, 25, un nombre par ligne.

Robot. Choisis la phrase qui traduit ce programme.

for i in range(4):
    if obstacleEst():
        nord()
    else:
        est()
  • Obstacle à l'est : il monte de 4 cases ; sinon, il avance de 4 cases vers l'est.
  • 4 fois : obstacle à l'est, il monte d'une case ; sinon, il avance d'une case vers l'est.
  • Il avance vers l'est jusqu'à un obstacle, puis monte de 4 cases.
  • 4 fois : il monte d'une case, puis avance d'une case vers l'est.

Le if … else est décalé sous le for : il est dans le bloc répété.

À chaque tour, une seule des deux branches s'exécute.

À chaque tour (4 tours), le robot regarde à l'est : obstacle, il monte d'une case ; case libre, il avance d'une case vers l'est.

Robot. Traduis ce programme par une phrase en français.

for i in range(4):
    if obstacleEst():
        nord()
    else:
        est()

Ce programme doit afficher 15 (= 1 + 2 + 3 + 4 + 5), mais il affiche 5. Pourquoi ?

for i in range(1, 6):
    somme = 0
    somme = somme + i
print(somme)
  • somme = 0 est dans la boucle : la somme repart de 0 à chaque tour. Il faut écrire cette ligne avant la boucle.
  • Il faut décaler print(somme) dans la boucle.
  • Il faut range(1, 7).
  • Il faut écrire somme = i.

Suis la valeur de somme tour par tour. Que vaut-elle au début de chaque tour ?

À chaque tour, somme = 0 efface le total, puis on ajoute i : au dernier tour, 0 + 5 = 5. L'accumulateur doit valoir 0 une seule fois, avant la boucle.

Mémo

for i in range(n): répète n fois ; range(début, fin) : la fin est exclue. for lettre in "mot": parcourt les lettres.

Le bloc répété est décalé de 4 espaces, après une ligne qui finit par :. Un accumulateur (somme = 0) se prépare avant la boucle.
