Le robot

Dans les exercices Robot, un robot se déplace sur une grille grâce à ces fonctions :

  • nord(), sud(), est(), ouest() : déplace le robot d'une case dans cette direction ;
  • obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() : renvoie True si la case voisine dans cette direction est un obstacle ou le bord de la grille, False sinon.
  • Si le robot avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur.
