Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

2. Complète le code à partir d'un objectif

La fonction compte_a_rebours(n) affiche n, n - 1, …, 1, puis « Partez ! ».

def compte_a_rebours(n):
    while [[n > 0|n >= 1|0 < n]]:
        print(n)
        n = [[n - 1]]
    print("Partez !")

On affiche tant que n est encore positif.

À chaque tour, n diminue de 1.

def compte_a_rebours(n):
    while n > 0:
        print(n)
        n = n - 1
    print("Partez !")

Qu'affiche compte_a_rebours(3) ? Écris tout sur une ligne.

3, puis 2, puis 1 ; à 0, la boucle s'arrête.

3, 2, 1, puis « Partez ! » (quatre lignes à l'écran).

La fonction somme_jusqua(n) renvoie la somme 1 + 2 + … + n.

def somme_jusqua(n):
    somme = [[0]]
    i = 1
    while i [[<=]] n:
        somme = [[somme + i|i + somme]]
        i = [[i + 1|1 + i]]
    return somme

L'accumulateur somme vaut 0 au départ.

On ajoute i, puis on passe au nombre suivant, tant que i ne dépasse pas n.

def somme_jusqua(n):
    somme = 0
    i = 1
    while i <= n:
        somme = somme + i
        i = i + 1
    return somme

Que renvoie somme_jusqua(4) ?

Avec <=, 4 est aussi ajouté.

1 + 2 + 3 + 4.

1 + 2 + 3 + 4 = 10.

Écris la fonction saisir_note() : elle demande une note jusqu'à ce qu'elle soit comprise entre 0 et 20, puis la renvoie.

def saisir_note():
    note = int(input("Note : "))

Une boucle while qui redemande la note tant qu'elle est en dehors de 0 à 20.

La note est hors de 0 à 20 si note < 0 or note > 20. Après la boucle : return note.

def saisir_note():
    note = int(input("Note : "))
    while note < 0 or note > 20:
        note = int(input("Note : "))
    return note

Un compteur à 0, puis une boucle « tant qu'il n'y a pas d'obstacle à l'est ».

Dans la boucle : est() et le compteur augmente de 1. Après la boucle : return.

def distance_mur():
    cases = 0
    while not obstacleEst():
        est()
        cases = cases + 1
    return cases
