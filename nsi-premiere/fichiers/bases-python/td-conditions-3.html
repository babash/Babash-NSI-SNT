Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. 2. Complète le code à partir d'un objectif

La fonction signe(n) renvoie "positif", "négatif" ou "nul" selon le nombre n.

def signe(n):
    if [[n > 0|0 < n]]:
        return "positif"
    [[elif]] [[n < 0|0 > n]]:
        return "négatif"
    [[else]]:
        return [["nul"]]

Trois cas : plus grand que 0, plus petit que 0, et le reste.

Le dernier cas n'a pas besoin de condition : else.

def signe(n):
    if n > 0:
        return "positif"
    elif n < 0:
        return "négatif"
    else:
        return "nul"

Que renvoie signe(-3) ?

-3 est plus petit que 0.

"négatif".

Que renvoie signe(0) ?

0 n'est ni plus grand ni plus petit que 0.

0 > 0 et 0 < 0 sont faux : else, "nul".

La fonction acces_manege(age, taille) renvoie True si on a au moins 8 ans et si on mesure au moins 1,30 m (taille en mètres), False sinon.

def acces_manege(age, taille):
    if [[age >= 8 and taille >= 1.3|age >= 8 and taille >= 1.30|taille >= 1.3 and age >= 8|taille >= 1.30 and age >= 8]]:
        return True
    [[else]]:
        return [[False]]

Deux conditions à la fois : and.

En Python, 1,30 s'écrit 1.3 (avec un point). « Au moins » : >=.

def acces_manege(age, taille):
    if age >= 8 and taille >= 1.3:
        return True
    else:
        return False

Que renvoie acces_manege(10, 1.25) ?

L'âge suffit, mais pas la taille : avec and, il faut les deux.

10 ans suffit, mais 1,25 m ?

1,25 m est moins que 1,30 m : False.

Réécris le corps de acces_manege en une seule ligne : return suivi d'une condition.

Une condition vaut déjà True ou False : on peut la renvoyer directement.

return age >= 8 and taille >= 1.3

Sinon, compare b et c. Pense aux nombres égaux : >=.

        return a
    elif b >= c:

Robot. Écris la fonction avancer_ou_contourner() : le robot avance d'une case vers l'est. S'il y a alors un obstacle devant lui, il le contourne par le nord pour se placer juste derrière ; sinon, il avance encore d'une case vers l'est. Depuis A3, le robot doit arriver en D3.

def avancer_ou_contourner():
    est()

Après est() : if obstacleEst(): pour contourner, else: pour avancer encore.

Contourner par le nord : monter, avancer deux fois vers l'est, redescendre.

def avancer_ou_contourner():
    est()
    if obstacleEst():
        nord()
        est()
        est()
        sud()
    else:
        est()
