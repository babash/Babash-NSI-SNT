Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

1. Que veut dire ce code ?

Exemple : ce programme se traduit par « S'il y a un obstacle à l'est, le robot avance d'une case vers le nord ; sinon, il avance d'une case vers l'est. »

if obstacleEst():
    nord()
else:
    est()

Choisis la phrase qui traduit ce programme.

if solde < 0:
    print("Compte à découvert")
else:
    print("Compte positif")
  • Si le solde est négatif, on affiche « Compte à découvert » ; sinon, on affiche « Compte positif ».
  • On affiche « Compte à découvert », puis « Compte positif ».
  • Si le solde est positif, on affiche « Compte à découvert ».
  • Tant que le solde est négatif, on affiche « Compte à découvert ».

else veut dire « sinon » : il s'exécute quand la condition est fausse.

Une seule des deux phrases s'affiche : « Compte à découvert » si solde est négatif, « Compte positif » sinon (0 compris).

Robot. Choisis la phrase qui traduit ce programme.

if obstacleNord():
    est()
elif obstacleEst():
    sud()
  • S'il y a un obstacle au nord, il va vers l'est ; sinon, s'il y a un obstacle à l'est, il va vers le sud ; sinon, il ne bouge pas.
  • S'il y a un obstacle au nord, il va vers l'est, puis vers le sud.
  • S'il y a un obstacle au nord ou à l'est, il va vers le sud.
  • S'il n'y a pas d'obstacle au nord, il va vers le sud.

elif veut dire « sinon, si ».

Il n'y a pas de else : dans le dernier cas, le robot ne fait rien.

elif : « sinon, si ». Sans else, si aucune condition n'est vraie, le robot reste sur place.

Choisis la phrase qui traduit ce programme.

if age >= 12 and age <= 25:
    print("Tarif jeune")
else:
    print("Plein tarif")
  • Si l'âge est entre 12 et 25 ans (compris), on affiche « Tarif jeune » ; sinon, « Plein tarif ».
  • Si l'âge est 12 ans ou 25 ans, on affiche « Tarif jeune ».
  • Si l'âge est plus petit que 12 ou plus grand que 25, on affiche « Tarif jeune ».
  • Si l'âge est entre 13 et 24 ans, on affiche « Tarif jeune ».

and : les deux conditions doivent être vraies.

>= : « supérieur ou égal ».

« Tarif jeune » pour 12 à 25 ans, bornes comprises ; « Plein tarif » pour tous les autres âges.

Robot. Choisis la phrase qui traduit ce programme.

if not obstacleSud():
    sud()
    if obstacleSud():
        est()
  • Si la case au sud est libre, il descend ; puis, si la case au sud est alors bloquée, il va vers l'est.
  • Si la case au sud est libre, il descend, puis va vers l'est.
  • Si la case au sud est bloquée, il va vers l'est.
  • Tant que la case au sud est libre, il descend, puis va vers l'est.

Le deuxième if est décalé : il est dans le premier.

Deux tests emboîtés : le second n'a lieu que si le premier est vrai, après la descente.

Avec ce programme, « Très bien » ne s'affiche jamais. Pourquoi ?

if note >= 10:
    print("Passable")
elif note >= 16:
    print("Très bien")
  • Une note de 16 ou plus est aussi au moins 10 : la première condition est vraie, et Python ne teste pas l'elif.
  • Il faudrait else à la place de elif.
  • note >= 16 est toujours faux.
  • Il faut écrire note > 16.

Prends une note de 18 : quelle condition est testée en premier ? Est-elle vraie ?

Dès qu'une condition est vraie, Python saute les elif suivants. Il faut tester note >= 16 avant note >= 10.

Mémo

if : si ; elif : sinon, si ; else : sinon (sans condition). Une seule branche s'exécute : la première dont la condition est vraie.

On compare avec == (et = range une valeur). Chaque ligne if, elif, else finit par :.
