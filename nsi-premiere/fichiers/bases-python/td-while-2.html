Le robot. Dans les questions marquées Robot, un robot se déplace sur une grille : nord(), sud(), est(), ouest() le déplacent d'une case ; obstacleNord(), obstacleSud(), obstacleEst(), obstacleOuest() renvoient True si la case voisine est un obstacle ou le bord, False sinon. S'il avance vers un obstacle ou le bord, il s'écrase : le programme s'arrête avec une erreur. Le nord est en haut de la grille.

Robot. Avancer vers l'est jusqu'au premier obstacle.

[[while]] [[not]] obstacleEst():
    [[est()]]

« Jusqu'au premier obstacle » : on continue tant qu'il n'y a pas d'obstacle.

while not obstacleEst():
    est()

Redemander un nombre tant qu'il est négatif.

n = int(input("Nombre positif : "))

La boucle tourne tant que la saisie est mauvaise : tant que n est négatif.

n = int(input("Nombre positif : "))

Robot. Monter vers le nord jusqu'au bord ou à un obstacle, puis aller d'une case vers l'est.

La condition : « pas d'obstacle au nord ».

est() se fait une seule fois, après la boucle : sans décalage.

while not obstacleNord():
    nord()

annees = 0

On continue tant que l'argent ne dépasse pas 1 000.

Chaque année : l'argent double, et on compte une année de plus.

argent = 100
annees = 0
while argent <= 1000:
    argent = argent * 2
    annees = annees + 1
print(annees)

100, 200, 400, 800, puis 1 600 : il faut 4 ans.

2. Où se trouve le robot ?

Le robot part de A6, sur la grille dessinée avec chaque programme. Sur papier, trace son trajet sur la grille. Écris la case d'arrivée (par exemple C4) et, si on le demande, le nombre de tours de boucle.

Robot. Où arrive le robot ?

while not obstacleEst():
    est()

E6 est un obstacle : le robot s'arrête juste devant.

Avant chaque pas, le robot regarde la case à l'est.

B6, C6, D6 ; en D6, la case E6 est un obstacle : la boucle s'arrête en D6.

Avec ce même programme, combien de tours fait la boucle ?

Le 4e test (en D6) est faux : il n'y a pas de 4e tour.

Un tour = un pas vers l'est.

3 pas (B6, C6, D6) : 3 tours.

Robot. Où arrive le robot ?

while not obstacleNord():
    nord()
est()
while not obstacleEst():
    est()

Première boucle : le robot monte jusqu'à un obstacle au nord. Puis un pas vers l'est. Puis la deuxième boucle.

A5, A4, A3 (A2 est un obstacle) ; puis B3 ; puis C3, D3, E3, F3 (G3 est un obstacle) : F3.

Robot. Où arrive le robot ?

nord()
est()
while obstacleNord():
    est()
nord()

Après nord() et est(), le robot est en B5.

Il avance vers l'est tant qu'il y a un obstacle au-dessus de lui.

A5, B5 ; obstacles au nord en B4, C4, D4 : C5, D5, E5 ; en E5, E4 est libre : la boucle s'arrête. Puis nord() : E4.

Avec ce même programme, combien de tours fait la boucle ?

En E5, le test est faux (E4 est libre) : pas de tour.

Un tour par obstacle au-dessus du robot.

Trois tours : depuis B5, C5 et D5.

La suite : feuille 3 sur 3, suivre le robot (suite) et écrire des fonctions. Avant : feuille 1.

Mémo

Une boucle while a besoin de trois choses : une variable de départ, une condition, et un changement dans la boucle.

Le nombre de tours n'est pas connu d'avance : il dépend de la condition.
