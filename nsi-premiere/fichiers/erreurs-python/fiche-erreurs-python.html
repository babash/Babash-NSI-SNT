NameError

Python ne reconnaît pas le nom utilisé (variable, fonction, mot-clé)
Message d'erreur (console)Ce que ça veut direProtocole
NameError: name 'score' is not defined(ou 'prnit', 'calucl', tout nom inconnu…)
Python cherche quelque chose appelé score — variable ou fonction — mais ne le trouve nulle part : inexistant ou mal orthographié.
1.Va à la ligne indiquée.
2.Vérifie l'orthographe exacte (majuscules, tirets bas).
3.La variable est-elle créée avant d'être utilisée ?
NameError: name 'true' is not defined(ou 'false', 'none', 'AND', 'OR'…)
Un mot-clé Python est mal capitalisé — ex. true au lieu de True.
1.True, False, None → majuscule initiale obligatoire.
NameError: name 'x' is not defined(à l'intérieur d'une fonction)
x existe dans le programme principal mais pas à l'intérieur de la fonction — une fonction ne voit que ses propres variables.
1.Passe x en paramètre : def f(x):
2.Ou définis x à l'intérieur de la fonction.

TypeError

Python reçoit un type de donnée qu'il n'attendait pas (texte, nombre, liste…)
Message d'erreur (console)Ce que ça veut direProtocole
TypeError: can only concatenate str (not "int") to str(ou : unsupported operand type(s) for +: 'int' and 'str')
Tu additionnes un texte et un nombre avec +. Attention : input() renvoie toujours du texte, même si l'utilisateur tape un chiffre.
1.Pour afficher : utilise f"valeur : {n}"
2.Pour calculer : convertis d'abord — int(val) ou float(val)
TypeError: 'int' object is not subscriptable(ou 'float', 'bool'…)
Tu utilises des crochets [ ] sur un entier comme si c'était une liste ou un texte. Python ne peut pas accéder à un "élément" d'un nombre.
1.Affiche le type : print(type(variable))
2.Tu as sans doute confondu une variable simple et une liste — vérifie comment elle a été définie.
TypeError: 'int' object is not iterable(ou 'NoneType' object is not iterable)
Tu essaies de parcourir avec for une valeur qui n'est pas une liste ou un texte — on ne peut pas boucler sur un entier ou sur None.
1.Affiche le type : print(type(variable))
2.La variable devrait-elle être une liste ici ? Vérifie qu'elle est bien initialisée comme telle.
TypeError: 'int' object is not callable(ou 'list', 'str'…)
Tu appelles une variable comme si c'était une fonction — ex. resultat() alors que resultat est un entier.
1.Repère les () suspects — retire-les si ce n'est pas un appel de fonction.
2.Vérifie que tu n'as pas écrasé une fonction avec une variable du même nom.
TypeError: maFonction() takes 2 positional arguments but 3 were given
Tu appelles la fonction avec trop d'arguments (valeurs fournies) par rapport à ce qu'elle attend.
1.Compte les paramètres dans def maFonction(…):
2.Compte les arguments dans l'appel — corrige l'écart.

ValueError

La valeur fournie est incompatible avec l'opération demandée
Message d'erreur (console)Ce que ça veut direProtocole
ValueError: invalid literal for int() with base 10: 'abc'(ou : invalid literal for int() with base 10: '')
Tu convertis avec int() quelque chose qui n'est pas un nombre — texte non numérique ou saisie vide.
1.Affiche la variable avant la conversion.
2.Si la saisie est vide '' : l'utilisateur a appuyé sur Entrée sans rien taper.
ValueError: not enough values to unpack (expected 2, got 1)
Tu attends 2 valeurs dans a, b = … mais le résultat n'en contient qu'une.
1.Vérifie la taille : print(len(liste)).
ValueError: invalid literal for float() with base 10: 'abc'(ou avec float() au lieu de int())
Tu convertis un texte en nombre décimal avec float() — même cause qu'avec int(). Attention : Python utilise le point et non la virgule (3.14).
1.Affiche la variable avant la conversion.
2.Remplace la virgule par un point dans la saisie.

SyntaxError

La grammaire du code est incorrecte — Python ne peut même pas lire le programme
Message d'erreur (console)Ce que ça veut direProtocole
SyntaxError: invalid syntax⚠ Le curseur pointe souvent sur la ligne après l'erreur réelle
Python ne comprend pas la ligne indiquée. L'erreur réelle est souvent une ligne au-dessus — regarde la ligne précédente en priorité.
1.Vérifie les deux-points manquants après if, for, def, while.
2.Si la ligne signalée semble juste, remonte d'une ligne.
SyntaxError: unterminated string literal (detected at line 3)(le numéro de ligne varie)
Un texte n'est pas fermé — il manque un guillemet " ou '.
1.Chaque guillemet ouvrant doit avoir son homologue fermant du même type.
SyntaxError: '(' was never closed(ou '[' was never closed, '{' was never closed)
Le programme se termine alors qu'une parenthèse ou un crochet est encore ouvert.
1.Compte les ( et ) — ils doivent être en nombre égal. Idem pour [ ] et { }.
SyntaxError: cannot assign to literal
Tu as écrit 5 = x au lieu de x = 5 — on n'affecte pas une valeur à un nombre.
1.Le nom de variable est toujours à gauche du =.

IndentationError & TabError

Le décalage des lignes est incorrect
Message d'erreur (console)Ce que ça veut direProtocole
IndentationError: expected an indented block
Après if, for, def… Python attend un bloc décalé vers la droite, mais la ligne suivante n'est pas décalée.
1.Ajoute 4 espaces devant chaque ligne du bloc.
2.Bloc vide provisoire : écris pass.
IndentationError: unexpected indent
Une ligne commence avec des espaces qui n'ont pas lieu d'être — elle est décalée sans raison.
1.Supprime les espaces en début de la ligne signalée.
2.Toutes les lignes d'un même bloc doivent commencer au même niveau.
TabError: inconsistent use of tabs and spaces in indentation
Tu mélanges tabulations et espaces pour décaler les lignes — Python interdit ce mélange.
1.Uniquement des espaces : 4 espaces = 1 niveau.
2.La plupart des éditeurs proposent une option pour convertir les tabulations en espaces.

IndexError

Indice hors des limites d'une liste ou d'un texte
Message d'erreur (console)Ce que ça veut direProtocole
IndexError: list index out of range
Tu utilises un indice trop grand — la liste ne contient pas autant d'éléments.
1.Affiche la liste et sa taille : print(liste, len(liste))
2.Indices valides : 0 à len(liste)−1.
3.En boucle : range(len(liste)).
IndexError: string index out of range
Même erreur qu'au-dessus, mais avec un texte accédé caractère par caractère.
1.Longueur : len(texte). Indice max : len(texte)−1.

AttributeError

Méthode inexistante pour ce type, ou variable valant None
Message d'erreur (console)Ce que ça veut direProtocole
AttributeError: 'list' object has no attribute 'upper'(n'importe quelle méthode sur le mauvais type)
Tu appelles .upper() sur une liste — cette méthode n'existe que pour les textes.
1.Affiche le type : print(type(variable))
2.La méthode appelée existe-t-elle pour ce type ? Ex. .upper() → texte, .append() → liste.
AttributeError: 'NoneType' object has no attribute 'append'
Ta variable vaut None — une fonction a été appelée mais elle ne renvoie rien. On ne peut pas appeler une méthode sur None.
1.Vérifie que la fonction appelée contient bien un return avec une valeur.
2.Affiche la variable avant d'appeler la méthode : print(variable)

KeyError

La clé demandée est absente du dictionnaire
Message d'erreur (console)Ce que ça veut direProtocole
KeyError: 'prenom'
La clé 'prenom' n'existe pas dans le dictionnaire.
1.Affiche les clés disponibles : print(dico.keys())
2.Vérifie l'orthographe exacte (espaces, casse).
3.Accès sans erreur : dico.get('prenom')

ZeroDivisionError

Division par zéro — interdit
Message d'erreur (console)Ce que ça veut direProtocole
ZeroDivisionError: division by zero
La valeur en bas de ta division vaut zéro — diviser par zéro est interdit.
1.Affiche le diviseur avant l'opération.
2.Vérifie que l'utilisateur n'a pas saisi 0.
