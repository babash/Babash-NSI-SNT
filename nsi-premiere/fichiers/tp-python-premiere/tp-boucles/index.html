1. Échauffement

Crée un fichier nommé echauffement.py. Dans la feuille d'exercices, tu as affiché un sapin comme celui-ci :

   *   *  *** ************  ***  ***

Sur le même principe, affiche le motif suivant (les espaces du début de chaque ligne comptent) :

****** ****  **  ** **********
# Ton programme

******
 ****
  **
  **
 ****
******

"*" * 4 donne "****" et " " * 2 donne deux espaces.

Pour la ligne numéro i (0, 1, 2), il y a i espaces, puis 6 − 2 × i étoiles. Une boucle fait le haut, une autre le bas.

for i in range(3):
    print(" " * i + "*" * (6 - 2 * i))
for i in range(2, -1, -1):
    print(" " * i + "*" * (6 - 2 * i))

La première boucle donne 6, 4 puis 2 étoiles ; la seconde reprend les mêmes lignes à l'envers (range(2, -1, -1) donne 2, 1, 0).

2. Le juste prix

Crée un fichier nommé juste_prix.py. Le programme choisit au hasard un prix entre 1 € et 100 €, et tu dois le retrouver. Tu as 10 essais. À chaque essai, le programme dit si ta proposition est trop haute, trop basse, ou si tu as gagné. Si tu n'as pas trouvé au bout de 10 essais, tu as perdu. Les messages : Trop haut, Trop bas, Gagné !.

Importe la fonction randint du module random, puis enregistre dans une variable un prix tiré au hasard. Pour commencer, tire-le entre 1 et 10 : c'est plus facile pour tester.

from random import [[randint]]
prix = randint([[1]], [[10]])

randint(nombre_min, nombre_max) donne un entier au hasard entre les deux, bornes comprises.

from random import randint
prix = randint(1, 10)

Plus tard, quand tout marche, remplace randint(1, 10) par randint(1, 100).

Écris une boucle qui fait les 10 essais : à chaque tour, demande une proposition, puis affiche Trop haut, Trop bas ou Gagné !. En ligne, le prix est 7 et les propositions sont 5, 9, puis 7 à chaque fois.

from random import randint
prix = randint(1, 10)

Trop bas
Trop haut
Gagné !
Gagné !
Gagné !
Gagné !
Gagné !
Gagné !
Gagné !
Gagné !

La boucle : for essai in range(10):. Dans le bloc, proposition = int(input("Ta proposition : ")).

input renvoie un texte : int(...) le change en nombre pour pouvoir le comparer au prix.

Trois cas : if proposition > prix:, elif proposition < prix:, else:.

from random import randint
prix = randint(1, 10)
for essai in range(10):
    proposition = int(input("Ta proposition : "))
    if proposition > prix:
        print("Trop haut")
    elif proposition < prix:
        print("Trop bas")
    else:
        print("Gagné !")

Avec for, la boucle fait toujours 10 tours, même après « Gagné ! » : la question 5 corrige ce défaut.

Tire maintenant le prix entre 1 et 100. Ajoute la ligne qui affiche Perdu, le prix était suivi du prix, si le prix n'est pas trouvé au bout des 10 essais. En ligne, le prix est 42 et les 10 propositions sont fausses.


    
    
Trop haut

Il faut savoir, après la boucle, si le prix a été trouvé : crée une variable trouve = False avant la boucle, et passe-la à True quand c'est gagné.

    
Après la boucle (sans indentation) : if not trouve:, puis print("Perdu, le prix était", prix).

    

      
from random import randint
prix = randint(1, 100)
trouve = False
for essai in range(10):
    proposition = int(input("Ta proposition : "))
    if proposition > prix:
        print("Trop haut")
    elif proposition < prix:
        print("Trop bas")
    else:
        print("Gagné !")
        trouve = True
if not trouve:
    print("Perdu, le prix était", prix)

      
La variable trouve garde en mémoire, après la boucle, ce qui s'est passé pendant la boucle.

    

  


  

    
Si besoin, change ta boucle for en boucle while : le jeu doit s'arrêter dès que le prix est trouvé, même avant le dixième essai. En ligne, le prix est 42 et la sixième proposition est la bonne.

    

    
    
Trop haut
Trop bas
Trop bas
Trop haut
Trop bas
Gagné !

    
Il faut compter les essais toi-même : essai = 0 avant la boucle, et essai = essai + 1 dans le bloc.

    
La condition : on continue tant qu'il reste des essais et que le prix n'est pas trouvé : while essai < 10 and not trouve:.

    

      
from random import randint
prix = randint(1, 100)
trouve = False
essai = 0
while essai < 10 and not trouve:
    proposition = int(input("Ta proposition : "))
    essai = essai + 1
    if proposition > prix:
        print("Trop haut")
    elif proposition < prix:
        print("Trop bas")
    else:
        print("Gagné !")
        trouve = True
if not trouve:
    print("Perdu, le prix était", prix)

      
Dès que trouve vaut True, la condition du while devient fausse : le jeu s'arrête après « Gagné ! ».

    

  


  
3. Dés bloqués (remix)

  
Crée un fichier nommé des_bloques.py. Ce jeu se joue avec 5 dés. Le but est de marquer le plus de points possible. On lance les 5 dés :

  
    
    
  • si au moins deux dés sont des 1, on ne marque aucun point pour ce lancer, et la manche s'arrête ;
    • 
    
  • sinon, on additionne les dés (sans les 1) et on retient ce total.
    • 
  

  
On peut relancer autant de dés qu'on veut, en laissant les 1 de côté, et recalculer les points à chaque lancer. Mais attention : dès que deux dés sont à 1, on perd tout ! À toi de t'arrêter au bon moment. Une manche : on lance des dés tant qu'on n'a pas deux 1 et qu'on ne choisit pas de s'arrêter.


  

    
Étapes 1 à 4. Crée 5 variables pour les dés et simule un premier lancer avec randint(1, 6). Affiche les 5 valeurs sur une ligne. Compte les 1 : s'il y en a au moins deux, le score vaut 0 et une variable booléenne stop vaut True ; sinon, le score est la somme des dés sans les 1, et stop vaut False. Affiche Score : suivi du score. En ligne, les dés donnent 3, 1, 5, 6, 2.

    

    
    
3 1 5 6 2
Score : 16

    
    
Compte les 1 avec une variable nb_un = 0 et un if d1 == 1: par dé.

    
Pour la somme sans les 1 : ajoute chaque dé seulement s'il est différent de 1 (if d1 != 1:).

    

      
from random import randint
d1 = randint(1, 6)
d2 = randint(1, 6)
d3 = randint(1, 6)
d4 = randint(1, 6)
d5 = randint(1, 6)
print(d1, d2, d3, d4, d5)
nb_un = 0
score = 0
for d in [d1, d2, d3, d4, d5]:
    if d == 1:
        nb_un = nb_un + 1
    else:
        score = score + d
if nb_un >= 2:
    score = 0
    stop = True
else:
    stop = False
print("Score :", score)

      
Un seul 1 : on garde la somme 3 + 5 + 6 + 2 = 16. La boucle for d in [...] évite d'écrire cinq fois le même test (cinq if marchent aussi).

    

  


  

    
Teste ton programme avec un lancer perdant : les dés donnent 1, 4, 1, 6, 6. Copie ton programme sous les lignes de départ.

    

    
    
1 4 1 6 6

Deux 1 : le score vaut 0, même si les autres dés font 16.

from random import randint

nb_un = 0

for d in [d1, d2, d3, d4, d5]:
    if d == 1:
        nb_un = nb_un + 1
    else:
        score = score + d
if nb_un >= 2:
    score = 0
    stop = True
else:
    stop = False
print("Score :", score)

Mémo

    
for répète un nombre de fois connu à l'avance ; while répète tant qu'une condition est vraie, et peut donc s'arrêter plus tôt. Une variable booléenne (trouve, stop) garde en mémoire ce qui s'est passé dans la boucle.
