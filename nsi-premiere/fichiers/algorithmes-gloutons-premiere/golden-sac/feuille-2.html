musee = {"Statue d'or": [15, 200], "Tableau de maître": [5, 150],

1. Inspection du code de sélection

def choisir_meilleur(inventaire, deja_pris, place_restante):
    elu = None
    max_prix = -1
    for nom, infos in inventaire.items():
        poids_obj = infos[0]
        prix_obj = infos[1]
        if nom not in deja_pris and poids_obj <= place_restante:
            if prix_obj > max_prix:
                max_prix = prix_obj
                elu = nom
    return elu

Pourquoi initialise-t-on max_prix à -1 plutôt qu'à 0 ?

  • Pour qu'un objet de prix 0 puisse quand même être choisi.
  • Parce que certains prix sont négatifs.
  • Pour compter les objets à partir de -1.
  • Parce que Python refuse 0.

Avec max_prix = 0, que donnerait le test prix_obj > max_prix pour un objet qui vaut 0 ?

Avec 0, le test 0 > 0 est faux : un objet gratuit ne serait jamais choisi. Avec -1, n'importe quel prix positif ou nul est plus grand.

Pourquoi initialise-t-on max_prix à -1 plutôt qu'à 0 ?

À quoi sert la liste deja_pris dans la condition if ?

  • À vérifier que l'objet rentre dans le sac.
  • À ne pas choisir deux fois le même objet.
  • À trier les objets par prix.
  • À ranger l'objet choisi.

nom not in deja_pris écarte les objets déjà dans le sac : sans ce test, la fonction renverrait toujours le même objet.

À quoi sert la liste deja_pris dans la condition if ?

Que contient la variable infos à chaque tour de la boucle for ?

  • Le nom de l'objet
  • Le prix de l'objet
  • La liste [poids, prix] de l'objet
  • Tout le dictionnaire

inventaire.items() donne, à chaque tour, une paire (clé, valeur).

items() donne les paires (clé, valeur) : nom reçoit la clé, infos la valeur, c'est-à-dire la liste [poids, prix].

Que contient la variable infos à chaque tour de la boucle for ?

Que renvoie cette fonction si aucun objet ne rentre dans le sac ?

Regarde la valeur renvoyée : c'est elu, pas max_prix.

Si aucun objet ne passe le test, la variable elu garde sa valeur de départ.

elu n'est jamais modifiée : la fonction renvoie None (« rien »).

Pour la stratégie B (le plus léger d'abord), quelle ligne faut-il changer en priorité ?

  • for nom, infos in inventaire.items():
  • if prix_obj > max_prix:
  • if nom not in deja_pris and …
  • return elu

Quelle ligne décide quel objet est « le meilleur » ?

C'est la comparaison qui fait la stratégie : on compare les poids (if poids_obj < min_poids:) au lieu des prix. Il faut alors aussi partir d'un très grand min_poids (par exemple float("inf")) et le mettre à jour.

2. Le script de fuite

Complète l'algorithme qui remplit le sac automatiquement. Il utilise musee et choisir_meilleur, rappelés en haut du programme.

musee = {"Statue d'or": [15, 200], "Tableau de maître": [5, 150],
         "Vase Ming": [2, 50], "Armure de samouraï": [25, 100],
         "Diadème": [1, 40]}

def choisir_meilleur(inventaire, deja_pris, place_restante):
    elu = None
    max_prix = -1
    for nom, infos in inventaire.items():
        poids_obj = infos[0]
        prix_obj = infos[1]
        if nom not in deja_pris and poids_obj <= place_restante:
            if prix_obj > max_prix:
                max_prix = prix_obj
                elu = nom
    return elu

def braquage_glouton(dico_musee, limite_sac):
    butin = []             # objets volés
    poids_actuel = 0
    fini = False
    while not fini:
        # 1. Calculer l'espace encore disponible
        place_libre = [[limite_sac]] - poids_actuel
        # 2. Chercher l'objet optimal (fonction de la partie 1)
        cible = choisir_meilleur(dico_musee, butin, [[place_libre]])
        if cible == [[None]]:
            # 3. Si aucun objet n'est trouvé, on arrête la boucle
            fini = [[True]]
        else:
            # 4. On ajoute l'objet au butin
            butin.append([[cible]])
            # 5. On met à jour le poids total du sac
            poids_actuel = poids_actuel + dico_musee[ [[cible]]][0]
    return butin, poids_actuel

# Lancement de l'opération
objets_voles, total_kg = braquage_glouton(musee, 10)
print(f"Extraction terminée ! Objets : {objets_voles} | Poids : {total_kg} kg")
Extraction terminée ! Objets : ['Tableau de maître', 'Vase Ming', 'Diadème'] | Poids : 8 kg

La place libre, c'est la limite du sac moins le poids déjà utilisé.

Quand choisir_meilleur ne trouve rien, elle renvoie None (question 4).

dico_musee[cible] donne la liste [poids, prix] : le poids est à l'indice 0.

place_libre = limite_sac - poids_actuel
cible = choisir_meilleur(dico_musee, butin, place_libre)
if cible == None:
    fini = True
else:
    butin.append(cible)
    poids_actuel = poids_actuel + dico_musee[cible][0]

Le programme affiche : Extraction terminée ! Objets : ['Tableau de maître', 'Vase Ming', 'Diadème'] | Poids : 8 kg. C'est la stratégie A de la feuille 1.

Mémo

Recherche du meilleur : on part d'une valeur qui sera battue (-1, ou None pour l'élu), puis on garde le meilleur candidat qui passe les tests.

Glouton : tant qu'un objet rentre, on prend le meilleur et on met à jour la place libre ; on ne revient jamais en arrière.
