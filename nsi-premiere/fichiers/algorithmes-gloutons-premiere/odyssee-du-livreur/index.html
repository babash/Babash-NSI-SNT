1. Maîtrise des tuples : les fondamentaux

Réponds aux questions suivantes pour vérifier ta compréhension avant la suite de la mission.

Laquelle de ces syntaxes crée un tuple qui contient seulement le nombre 42 ?

  • valeur = (42)
  • valeur = [42]
  • valeur = (42,)

C'est la virgule qui fait le tuple, pas les parenthèses.

(42,) : la virgule est obligatoire pour un tuple d'un seul élément. type((42)) donne <class 'int'>, type((42,)) donne <class 'tuple'>.

Qu'affiche ce programme ?

vitesse = (80, 110, 130)
print(vitesse[0])

Les indices commencent à 0 : vitesse[0] est le premier élément.

Le premier élément a l'indice 0.

vitesse[0] est le premier élément : 80.

Qu'affiche ce programme ?

vitesse = (80, 110, 130)
print(vitesse[-1])

Un indice négatif compte à partir de la fin.

vitesse[-1] est le dernier élément : 130.

Quelle fonction donne le nombre d'éléments du tuple vitesse ? Écris l'appel complet.

C'est la même fonction que pour une liste.

len(vitesse), qui vaut 3.

Qu'affiche ce programme dans la console ?

vitesse = (80, 110, 130)
print(type(vitesse))

type donne le type d'une valeur, écrit sous la forme <class '…'>.

<class 'tuple'> : vitesse est un tuple.

On exécute ce programme. Quel est le nom de l'erreur affichée par Python ?

couleurs = ("bleu", "vert")
couleurs[1] = "rouge"

L'indice 1 existe bien (« vert ») : le problème n'est pas l'indice, mais l'affectation.

On essaie de modifier un élément d'un tuple. Est-ce permis ?

L'erreur porte sur le type de couleurs.

Python affiche :

Traceback (most recent call last):
  File "couleurs.py", line 2, in <module>
    couleurs[1] = "rouge"
    ~~~~~~~~^^^
TypeError: 'tuple' object does not support item assignment

« Un objet tuple ne permet pas l'affectation d'un élément » : TypeError.

Pourquoi cette erreur survient-elle ? Complète : « le tuple est … ».

Le mot est dans l'objectif de la mission.

Le tuple est immuable (non modifiable) : une fois créé, on ne peut ni changer, ni ajouter, ni retirer d'élément.

Qu'affiche ce programme ?

config = (1920, 1080)
print(len(config))

On ne demande pas une valeur, mais le nombre d'éléments.

Le tuple contient 2 éléments : 2.

Complète la boucle pour afficher chaque ville du tuple.

etapes = ("Tsimkoura", "Chirongui", "Poroani")
for [[ville in etapes]]:
    print(ville)
Tsimkoura
Chirongui
Poroani

La variable de boucle s'appelle ville (elle est utilisée dans le print).

for ville in etapes:

On parcourt un tuple comme une liste.

On veut maintenant afficher l'indice et la ville. Complète.

etapes = ("Tsimkoura", "Chirongui", "Poroani")
for i, v in [[enumerate(etapes)]]:
    print(f"Escale {i} : {v}")
Escale 0 : Tsimkoura
Escale 1 : Chirongui
Escale 2 : Poroani

Une fonction donne à la fois l'indice et l'élément : son nom vient de l'anglais « énumérer ».

for i, v in enumerate(etapes):

enumerate donne les paires (indice, élément).

Soit data = (10, 20, 30). Que se passe-t-il si on demande data[3] ?

  • On obtient 30, le dernier élément du tuple.
  • On obtient 10 : Python repart au début du tuple.
  • On obtient une erreur IndexError.
  • On obtient None, car la case n'existe pas.

Le tuple a 3 éléments : quels sont leurs indices ?

Les indices vont de 0 à 2. Python affiche :

Traceback (most recent call last):
  File "data.py", line 2, in <module>
    print(data[3])
          ~~~~^^^
IndexError: tuple index out of range

« Indice du tuple hors limites » : c'est la panne sèche annoncée par la mission.

Soit data = (10, 20, 30). Que se passe-t-il si on demande data[3] ?

Écris l'expression qui teste si le nombre 20 est présent dans le tuple data.

Piège : sans parenthèses, Python lit 20 in data == True comme une comparaison enchaînée, 20 in data and data == True. Or data == True est faux : l'expression vaut False. Écris simplement 20 in data : c'est déjà un booléen.

Le même mot-clé sert dans for x in data.

20 in data

Elle vaut True ici.

Qu'affiche ce programme ?

t1 = (1, 2)
t2 = (3, 4)
print(t1 + t2)

Le + ne fait pas d'additions élément par élément : il met les deux tuples bout à bout.

Le + entre deux tuples ne calcule pas une somme : il les colle.

Entre deux tuples, + est une concaténation.

La concaténation donne un nouveau tuple : (1, 2, 3, 4). Les tuples t1 et t2 ne changent pas.

Qu'affiche ce programme ?

point = (5, 12)
x, y = point
print(y)

C'est la valeur de x.

x reçoit le premier élément, y le deuxième.

C'est un dépaquetage : x vaut 5 et y vaut 12.

Quelle est la valeur finale de total ?

scores, total = (12, 15, 18), 0
for s in scores:
    total = total + s
print(total)

Suis la valeur de total à chaque tour : 0, puis 12…

12 + 15 + 18 = 45.

Dans le programme précédent, quelle expression donne la valeur 15 sans boucle ?

L'indice 2 donne 18 : les indices commencent à 0.

15 est le deuxième élément de scores.

scores[1]

Qu'affiche ce programme ?

mystere = (1, (2, 3), 4)
print(len(mystere))

Le tuple (2, 3) compte pour un seul élément de mystere.

Compte les éléments séparés par des virgules au premier niveau.

Trois éléments : 1, (2, 3) et 4. len vaut 3.

Quel symbole utilise-t-on pour délimiter un tuple ?

  • Des crochets []
  • Des parenthèses ()
  • Des accolades {}

Des parenthèses (et des virgules entre les éléments).

Complète ce code pour compter combien de fois le nombre 7 apparaît.

valeurs, compteur = (7, 4, 7, 2), 0
for [[v in valeurs]]:
    if v == 7:
        compteur = [[compteur + 1|1 + compteur]]
print(compteur)
2

La variable de boucle s'appelle v (elle est utilisée dans le if).

Le compteur augmente de 1 chaque fois qu'on trouve un 7.

for v in valeurs:
    if v == 7:
        compteur = compteur + 1

7 apparaît 2 fois.

Vrai ou faux : on peut ajouter un élément à un tuple existant avec la méthode .append(). Choisis la bonne justification.

  • Vrai : .append() marche comme pour une liste.
  • Faux : un tuple est immuable, il n'a pas de méthode append.
  • Faux : pour un tuple, il faut utiliser .add().
  • Vrai, mais seulement à la fin, jamais au début.

Faux. Python affiche :

Traceback (most recent call last):
  File "etapes.py", line 2, in <module>
    etapes.append("Poroani")
    ^^^^^^^^^^^^^
AttributeError: 'tuple' object has no attribute 'append'

On peut seulement créer un nouveau tuple : etapes = etapes + ("Poroani",).

Vrai ou faux : on peut ajouter un élément à un tuple existant avec la méthode .append(). Justifie.

Mémo

Tuple : (a, b, c), et (a,) pour un seul élément. Il se lit et se parcourt comme une liste (t[0], t[-1], len(t), in, for, enumerate).

Il est immuable : ni affectation (TypeError), ni append (AttributeError). t1 + t2 crée un nouveau tuple.
