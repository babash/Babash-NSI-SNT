Question 17 : Filtre¶

Écrivez filtre(objets, m) qui renvoie les noms des objets pesant moins de m.

In [ ]:
def filtre(objets, m):
    ...
Aide

Utilisez .items() pour obtenir à la fois le nom (clé) et le poids (valeur).

In [ ]:
Q17()
Correction 
def filtre(objets, m):
    res = []
    for nom, poids in objets.items():
        if poids <= m:
            res.append(nom)
    return res

In [ ]:
Q20()
Correction 
def braquage(objets, m):
    sac = []
    poids_actuel = 0
    for nom, poids in objets.items():
        if poids_actuel + poids <= m:
            sac.append(nom)
            poids_actuel += poids
    return sac
