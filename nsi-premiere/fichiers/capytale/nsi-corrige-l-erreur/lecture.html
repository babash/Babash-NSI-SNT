🔧 Mission : Maintenance du Système NSI¶

Le code du musée a été endommagé par un stagiaire malhabile. Votre rôle est de déboguer ces fonctions pour les rendre opérationnelles.

💡 Rappels de survie :¶

  1. Exécutez la cellule pour voir l'erreur s'afficher.
  2. Identifiez le groupe d'erreur (Noms, Types, Limites ou Syntaxe).
  3. Corrigez le code et relancez jusqu'à ce que plus aucune erreur n'apparaisse.

💡 Exemple de maintenance : Réparer une NameError¶

Situation : Le stagiaire a voulu calculer le double d'un nombre, mais le code ne fonctionne pas.

Objectif : Identifiez l'erreur grâce à la fiche et corrigez-la.

In [ ]:
# Code cassé (cliquez sur Exécuter pour voir l'erreur)
nombre_depart = 10
resultat = Nombre_depart * 2
print(resultat)

Analyse de la maintenance :

  1. Le message : NameError: name 'Nombre_depart' is not defined.
  2. Diagnostic (Fiche Source 6) : Python ne trouve pas le nom car il y a une erreur de majuscule (Nombre_depart avec un "N" majuscule n'est pas la même chose que nombre_depart).
  3. Correction : Il suffit de remettre le "n" en minuscule à la ligne 3 pour que le programme fonctionne.

🛠️ Niveau 1 : Structure et Identité¶

Ici, le code ne parvient même pas à se lancer ou Python ne reconnaît pas ce que vous écrivez.

Question 1 : Le rapport d'activité¶

Cette fonction doit afficher le score d'un utilisateur.

In [ ]:
def afficher_rapport(nom, points):
    if points > 10
        print(nom + " a réussi avec " + str(points) + " points")

# Test de la fonction
afficher_rapport("Alice", 15)
"Besoin d'aide pour le rapport ?"
  • Syntaxe : Il manque un symbole crucial après le if.
  • Type : On ne peut pas coller (+) du texte avec un nombre directement. Utilisez une f-string : f"{points}".

Question 2 : Le sélecteur de niveau¶

Le stagiaire a fait une erreur d'inattention sur les mots-clés de Python.

In [ ]:
def acces_zone_secrete(est_admin):
    if est_admin == true:
        return "Accès autorisé"
    else:
        return "Accès refusé"

print(acces_zone_secrete(True))
"Indice sur les noms"

Python est sensible à la casse. Les valeurs booléennes comme True et False prennent toujours une majuscule initiale.

🧪 Niveau 2 : Données et Collections¶

Le code se lance, mais s'arrête dès qu'il touche aux listes ou aux dictionnaires.

Question 3 : Calcul de la moyenne¶

Cette fonction doit calculer la moyenne d'une liste de notes.

In [ ]:
def calculer_moyenne(notes):
    total = 0
    for i in range(len(notes)):
        total = total + notes[i+1]
    return total / len(notes)

ma_classe = [12, 15, 10, 18]
print(calculer_moyenne(ma_classe))
"Indice sur les limites"

L'erreur est une IndexError. N'oubliez pas que dans une liste de taille n, les indices vont de 0 à n-1. Si vous faites i+1 à la fin de la boucle, vous sortez de la liste.

Question 4 : Gestion du stock¶

On veut récupérer le prix d'un objet dans le dictionnaire du magasin.

In [ ]:
inventaire = {"épée": 50, "bouclier": 30, "potion": 10}

def prix_objet(nom_objet):
    prix = inventaire[nom_objet]
    return f"L'objet {nom_objet} coûte {prix} pièces."

print(prix_objet("Epee"))
"Indice sur les dictionnaires"

C'est une KeyError. Vérifiez l'orthographe exacte et les accents. Le dictionnaire et l'appel de la fonction doivent correspondre parfaitement.

🏆 Niveau 3 : Logique de fonction¶

Le code s'exécute sans erreur rouge, mais le résultat est None ou incohérent.

Question 5 : L'ajout de bonus¶

Cette fonction est censée ajouter un bonus à une liste de scores.

In [ ]:
def ajouter_bonus(liste_scores):
    nouvelle_liste = []
    for s in liste_scores:
        nouvelle_liste.append(s + 5)

mes_scores = [10, 20, 30]
mes_scores = ajouter_bonus(mes_scores)
mes_scores.append(40) # Doit ajouter 40 à la fin de la nouvelle liste
print(mes_scores)
"Indice sur le NoneType"

Si vous obtenez AttributeError: 'NoneType' object has no attribute 'append', c'est que votre fonction a oublié de renvoyer (return) le résultat. Sans return, la variable devient vide (None).
