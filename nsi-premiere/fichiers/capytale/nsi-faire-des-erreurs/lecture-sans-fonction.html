🛠️ Mission : L'Apprenti Saboteur¶

Bienvenue, agent. Le système de sécurité du lycée est trop parfait. Votre mission est de générer volontairement des erreurs spécifiques.

Règles du jeu :

  1. Lisez l'erreur demandée.
  2. Écrivez le code le plus court possible pour déclencher cette erreur.
  3. Si le message d'erreur correspond exactement à l'énoncé : Mission accomplie.

Consigne : Générez l'erreur TypeError: unsupported operand type(s) for +: 'int' and 'str'.

Indice : Cette erreur survient quand on essaie d'additionner un nombre et du texte.
