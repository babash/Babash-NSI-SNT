À retenir

  • grep motif fichier affiche les lignes du fichier qui contiennent le motif.
  • ls -l montre les droits : le type (d dossier, - fichier), puis trois lettres pour le propriétaire (u), le groupe (g), les autres (o) : r lire, w écrire, x exécuter, - : le droit manque.
  • chmod en octal : un chiffre par catégorie, r = 4, w = 2, x = 1 : chmod 640 donne rw-r-----.
  • chmod en symbolique : qui (u, g, o), puis + (ajouter) ou - (retirer), puis le droit : chmod g+w.
  • root, l'administrateur·rice, a tous les droits ; sudo commande agit en son nom ; changer le propriétaire (chown) lui est réservé.

1. Les commandes des droits

Pour chaque commande, dis ce qu'elle fait.

Que fait ls -l [dossier] ? Exemple : ls -l /home/prof

  • Lister aussi les fichiers cachés
  • Lister les fichiers les plus récents
  • Lister avec droits et propriétaire
  • Lister en une ligne, sans détail
ls -l (long) liste avec, pour chaque fichier, ses droits, son propriétaire, son groupe, sa taille et sa date.

« Lister aussi les fichiers cachés » : non. Les fichiers cachés, c'est ls -a.

« Lister les fichiers les plus récents » : non. -l ne trie pas : il donne les détails (long).

« Lister en une ligne, sans détail » : non. C'est le contraire : -l donne une ligne détaillée par fichier.

3. Les droits

eleve@lycee:~$ ls -l /home/prof
total 8
drwxrwx--- 2 prof info 4096 Nov 25 10:00 examens
-rw-r----- 1 prof info   38 Nov 25 10:00 notes.csv

Exemple : dans la ligne de examens, d : un dossier ; rwx pour le propriétaire, prof ; rwx pour le groupe, info ; --- pour les autres.

À ton tour : quels droits le groupe info a-t-il sur notes.csv ?

  • Lire et écrire (rw-)
  • Aucun droit (---)
  • Lire seulement (r--)
  • Lire et exécuter (r-x)
- (un fichier), rw- (le propriétaire, prof), r-- (le groupe, info), --- (les autres) : le groupe peut lire le fichier, pas le modifier.

« Lire et écrire (rw-) » : non. rw- sont les droits du propriétaire, prof : les trois premières lettres après le tiret.

« Aucun droit (---) » : non. --- sont les droits des autres : les trois dernières lettres.

« Lire et exécuter (r-x) » : non. Il n'y a aucun x dans -rw-r----- : personne ne peut l'exécuter.

À ton tour : quels droits le groupe info a-t-il sur notes.csv ?

- (un fichier), rw- (le propriétaire, prof), r-- (le groupe, info), --- (les autres) : le groupe peut lire le fichier, pas le modifier.

eleve est dans le groupe info. Pourquoi peut-il copier notes.csv ?

  • eleve est le propriétaire de notes.csv
  • cp ne regarde jamais les droits d'un fichier
  • Le groupe a le droit d'écrire dans le fichier
  • Copier demande seulement de lire : le groupe a r
Pour copier, il suffit de lire l'original : le groupe info a le droit r. Il ne pourrait pas le modifier (pas de w).

« eleve est le propriétaire de notes.csv » : non. Le propriétaire est prof : le nom écrit juste après le nombre de liens.

« chown s'écrit avec sudo devant, toujours » : non. La plupart des commandes se lancent sans sudo : c'est l'opération qui demande les droits de root.

« Il faut d'abord écrire le nom du fichier » : non. L'ordre de la commande est juste : d'abord le nouveau propriétaire, puis le fichier.

« Le groupe info n'a pas le droit w » : non. Les droits rwx ne suffisent pas : même le propriétaire ne peut pas donner son fichier.
