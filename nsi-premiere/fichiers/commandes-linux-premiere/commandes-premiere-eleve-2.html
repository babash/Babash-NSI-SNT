Chercher, les droits

Nom et prénom :Classe :

Objectif : chercher dans un fichier, lire et changer les droits d'un fichier.

Je sais :

  • chercher les lignes d'un fichier avec grep ;
  • lire les droits affichés par ls -l ;
  • changer des droits avec chmod, en octal et en symbolique.

1 heure · 9 questions · feuille 2 sur 2 · seul·e ou en binôme

À retenir

  • grep motif fichier affiche les lignes du fichier qui contiennent le motif.
  • ls -l montre les droits : le type (d dossier, - fichier), puis trois lettres pour le propriétaire (u), le groupe (g), les autres (o) : r lire, w écrire, x exécuter, - le droit manque.
  • chmod en octal : un chiffre par catégorie, r = 4, w = 2, x = 1 : chmod 640 donne rw-r-----.
  • chmod en symbolique : qui, puis + ou -, puis le droit : chmod g+w.
  • root, l'administrateur·rice, a tous les droits ; sudo commande agit en son nom ; changer le propriétaire (chown) lui est réservé.

1. Chercher dans un fichier

Le fichier tp1.py (dans nsi), affiché par cat :

eleve@lycee:~/devoirs/nsi$ cat tp1.py
# TP 1 : les horaires de la barge
depart = 6
print("Première barge à", depart, "h")
arrivee = depart + 1
print("Arrivée à Mamoudzou à", arrivee, "h")

Exemple : grep depart tp1.py affiche les trois lignes qui contiennent depart, où qu'il soit dans la ligne :

eleve@lycee:~/devoirs/nsi$ grep depart tp1.py
depart = 6
print("Première barge à", depart, "h")
arrivee = depart + 1

À ton tour : tu es dans nsi. Écris la commande qui affiche seulement les lignes de tp1.py qui contiennent print.

grep print tp1.py (les guillemets autour de print sont permis).

Erreur fréquente : grep tp1.py print : L'ordre compte : d'abord le motif cherché, puis le fichier.

Erreur fréquente : cat tp1.py : cat affiche tout le fichier. Pour n'avoir que les lignes qui contiennent un mot, une autre commande existe.

Erreur fréquente : grep print : Il manque le nom exact du fichier, extension comprise : tp1.py.

À ton tour : qu'affiche cette commande ?

grep barge tp1.py
# TP 1 : les horaires de la barge
print("Première barge à", depart, "h")

La ligne 1 (le commentaire) et la ligne 3 : ce sont les deux lignes qui contiennent barge. grep les affiche entières, dans l'ordre du fichier.

2. Les droits

Exemple : dans la ligne drwxrwx--- 2 prof nsi 4096 Nov 25 10:00 examens, d : un dossier ; rwx pour le propriétaire prof ; rwx pour le groupe nsi ; --- pour les autres.

À ton tour : quels droits le groupe nsi a-t-il sur notes.csv ?

eleve@lycee:~$ ls -l /home/prof
total 8
drwxrwx--- 2 prof nsi 4096 Nov 25 10:00 examens
-rw-r----- 1 prof nsi   38 Nov 25 10:00 notes.csv
  • Lire et écrire (rw-)
  • Lire seulement (r--)
  • Aucun droit (---)
  • Lire et exécuter (r-x)

- (un fichier), rw- (propriétaire prof), r-- (groupe nsi), --- (autres) : le groupe peut lire le fichier, mais pas le modifier.

« Lire et écrire (rw-) » : non. rw- sont les droits du propriétaire, prof : les trois premiers après le tiret.

« Aucun droit (---) » : non. --- sont les droits des autres : les trois derniers.

« Lire et exécuter (r-x) » : non. Il n'y a aucun x dans -rw-r----- : personne ne peut l'exécuter.

À ton tour : quels droits le groupe nsi a-t-il sur notes.csv ?

eleve@lycee:~$ ls -l /home/prof
total 8
drwxrwx--- 2 prof nsi 4096 Nov 25 10:00 examens
-rw-r----- 1 prof nsi   38 Nov 25 10:00 notes.csv

Lire seulement (r--).

eleve est dans le groupe nsi. Pourquoi peut-il copier notes.csv ?

  • Copier demande seulement de lire : le groupe a r
  • Parce que eleve est le propriétaire du fichier
  • Parce que cp ne regarde jamais les droits
  • Parce que le groupe peut écrire dans le fichier

Pour copier, il suffit de lire l'original : le groupe nsi a le droit r. Il ne pourrait pas le modifier (pas de w).

« Parce que eleve est le propriétaire du fichier » : non. eleve n'est pas le propriétaire : c'est prof, le nom écrit juste après le nombre de liens.

« Parce que cp ne regarde jamais les droits » : non. Les droits comptent toujours : sans r, cp répondrait « Permission denied ».

« Parce que le groupe peut écrire dans le fichier » : non. Le groupe n'a pas w : il ne peut pas modifier notes.csv. Et copier ne demande pas d'écrire dans l'original.

eleve est dans le groupe nsi. Pourquoi peut-il copier notes.csv ?

Copier demande seulement de lire l'original, et le groupe nsi a le droit de lecture r.

Exemple : chmod 750 tp1.py donne rwxr-x--- : 7 = 4 + 2 + 1 (rwx), 5 = 4 + 1 (r-x), 0 (---).

À ton tour : quels droits donne chmod 754 tp1.py ?

  • rwxr-xr--
  • rwxrw-r--
  • r--r-xrwx
  • rwxr-xr-x

7 = rwx pour le propriétaire, 5 = r-x pour le groupe, 4 = r-- pour les autres : -rwxr-xr--.

« rwxrw-r-- » : non. 5 = 4 + 1 : lecture et exécution, pas écriture.

« r--r-xrwx » : non. Les chiffres se lisent dans l'ordre propriétaire, groupe, autres.

« rwxr-xr-x » : non. 4 = lecture seule : r--. Le 4 des autres ne donne pas l'exécution.

À ton tour : quels droits donne chmod 754 tp1.py ? Écris-les comme ls -l : 9 caractères.

rwxr-xr--

À ton tour : tu es dans nsi. En octal, rends tp1.py lisible et modifiable par toi seul·e (le propriétaire), sans aucun droit pour les autres.

chmod 600 tp1.py : 6 = rw- pour le propriétaire, 0 = --- pour le groupe et pour les autres.

Erreur fréquente : chmod 700 tp1.py : 7 donne aussi l'exécution (x = 1). On ne demande que lire et écrire : 4 + 2.

Erreur fréquente : chmod 006 tp1.py : Les chiffres sont dans l'ordre propriétaire, groupe, autres : tu as donné les droits aux autres.

Erreur fréquente : chmod 644 tp1.py : Le groupe ou les autres gardent un droit : seul le premier chiffre doit être différent de 0.

Exemple : chmod g+w notes.csv ajoute l'écriture au groupe : -rw-r----- devient -rw-rw----.

À ton tour : en symbolique, ajoute le droit d'exécution au propriétaire de tp1.py, sans changer les autres droits.

chmod u+x tp1.py : u (user, le propriétaire), + (ajouter), x (exécution).

Erreur fréquente : chmod +x tp1.py : Sans lettre (ou avec a), le droit est ajouté à tout le monde. Précise pour qui : u pour le propriétaire.

Erreur fréquente : chmod o+x tp1.py : o, ce sont les autres ; g, le groupe. Le propriétaire, c'est u (user).

Erreur fréquente : chmod x+u tp1.py : L'ordre est : qui, puis + (ajouter), puis le droit.

Erreur fréquente : chmod 700 tp1.py : C'est le mode octal, et il change aussi les droits du groupe et des autres. On demande le mode symbolique.

Dans /home/prof, prof tape chown direction notes.csv et lit : chown: changing ownership of 'notes.csv': Operation not permitted. Pourquoi ?

  • Parce que sudo est obligatoire devant chaque commande
  • Parce que changer le propriétaire demande les droits de root
  • Parce que direction et notes.csv sont dans le mauvais ordre
  • Parce que notes.csv n'existe pas dans /home/prof

Changer le propriétaire est réservé à l'administrateur·rice, root : même prof, propriétaire du fichier, ne le peut pas. Il faut sudo.

« Parce que sudo est obligatoire devant chaque commande » : non. Non : la plupart des commandes (ls, cd, cat…) se lancent sans sudo.

« Parce que direction et notes.csv sont dans le mauvais ordre » : non. L'ordre est le bon : d'abord le nouveau propriétaire, puis le fichier.

« Parce que notes.csv n'existe pas dans /home/prof » : non. Le message parle de permission (permitted), pas d'un fichier introuvable : notes.csv est bien là.

Dans /home/prof, prof tape chown direction notes.csv et lit : chown: changing ownership of 'notes.csv': Operation not permitted. Pourquoi ce refus ?

sudo lance une commande avec les droits de l'administrateur·rice (root), nécessaires pour les opérations réservées au système, comme changer le propriétaire d'un fichier.

Exemple : sudo chown prof tp1.py donne tp1.py à prof, avec les droits de root.

À ton tour : tu es dans /home/prof. Écris la commande qui donne notes.csv à l'utilisateur·rice direction.

sudo chown direction notes.csv

Erreur fréquente : chown direction notes.csv : C'est la commande de la question précédente : elle est refusée. Il manque ce qui donne les droits de root.

Erreur fréquente : sudo chown notes.csv direction : L'ordre compte : d'abord le nouveau propriétaire, puis le fichier.

Erreur fréquente : sudo chmod direction notes.csv : chmod change les droits (r, w, x). Pour changer le propriétaire, c'est une autre commande.
