Corrigé de l'enseignant·e · 1re NSI · Systèmes d'exploitation

Commandes Linux (première)

Les numéros sont ceux des feuilles papier. En ligne, chaque question se corrige toute seule : la page dit si c'est juste, puis propose la correction après deux essais. Ce corrigé est fait par un script à partir des feuilles (source/faire-corrige.py) : il ne peut pas en diverger.

Feuille 1 : Terminal, chemins, droits

1. Les commandes de base

Question 1. Complète la colonne « Ce qu'elle fait ». La première ligne est faite : c'est l'exemple.

ls (list) liste le contenu du répertoire courant, ou du dossier indiqué : ls .. liste le parent.

cd (change directory) change de répertoire : on se déplace dans l'arborescence.

cd .. remonte d'un niveau, vers le répertoire parent ; cd ../.. remonte de deux niveaux.

cd ~ ramène dans le répertoire personnel (ici /home/eleve), d'où que l'on soit.

cat affiche tout le contenu d'un fichier.

grep cherche un motif (un mot) et affiche les lignes du fichier qui le contiennent.

man affiche le manuel d'une commande (on en sort avec la touche q).

touch crée un fichier vide ; si le fichier existe déjà, il change seulement sa date.

mkdir (make directory) crée un dossier.

cp (copy) copie un fichier vers une destination : l'original reste à sa place.

mv (move) déplace ou renomme un fichier ou un dossier.

rm (remove) supprime un fichier, pour de bon : il n'y a pas de corbeille.

rmdir (remove directory) supprime un dossier vide.

2. Chemins absolus et relatifs

Question 2. À ton tour : l'invite affiche eleve@lycee:~/devoirs/nsi$. Donne le chemin absolu du répertoire courant.

/home/eleve/devoirs/nsi : c'est ce qu'afficherait pwd.

Erreur fréquente : ~/devoirs/nsi ou ~/devoirs/nsi/ : c'est ce qu'écrit l'invite : ~ est un raccourci. Le chemin absolu part de la racine / : remplace ~ par le répertoire personnel.

Erreur fréquente : home/eleve/devoirs/nsi ou devoirs/nsi ou /devoirs/nsi : un chemin absolu part de la racine et donne tous les dossiers : il commence par /home.

Acceptées en ligne : /home/eleve/devoirs/nsi · /home/eleve/devoirs/nsi/

Question 3. À ton tour : tu es dans nsi. Copie notes.csv (chez prof) dans projets, avec des chemins relatifs.

cp ../../../prof/notes.csv ../../projets/

Depuis nsi, ../../.. mène à home : la source est ../../../prof/notes.csv ; ../.. mène à eleve : la destination est ../../projets/.

Erreur fréquente : cp ../../prof/notes.csv ../../projets/ ou cp ../../prof/notes.csv ../../projets : presque : depuis nsi, ../.. mène à eleve, pas à home. Il faut remonter d'un niveau de plus pour trouver prof.

Erreur fréquente : cp /home/prof/notes.csv /home/eleve/projets/ ou cp /home/prof/notes.csv /home/eleve/projets ou cp /home/prof/notes.csv ../../projets/ ou cp ../../../prof/notes.csv /home/eleve/projets/ : ta commande marche, mais au moins un chemin est absolu (il commence par /). La consigne demande deux chemins relatifs, qui partent de nsi.

Erreur fréquente : mv ../../../prof/notes.csv ../../projets/ ou mv ../../../prof/notes.csv ../../projets : mv déplacerait le fichier : il disparaîtrait de chez prof. On veut une copie.

Acceptées en ligne : cp ../../../prof/notes.csv ../../projets/ · cp ../../../prof/notes.csv ../../projets · cp ../../../prof/notes.csv ../../projets/notes.csv · cp ../../../prof/notes.csv ../../projets/.

Question 4. À ton tour : tu es dans nsi. Écris la commande à taper avant touch exam1.txt pour créer ce fichier dans examens.

cd ../../../prof/examens (ou, en chemin absolu, cd /home/prof/examens), puis touch exam1.txt.

Erreur fréquente : cd ../../prof/examens ou cd ../../prof/examens/ : depuis nsi, ../.. mène à eleve. Pour trouver prof, il faut remonter jusqu'à home.

Erreur fréquente : cd examens ou cd examens/ ou cd /prof/examens ou cd /prof/examens/ : le dossier examens n'est pas là où tu le cherches : regarde l'arborescence. Donne le chemin complet, relatif ou absolu.

Acceptées en ligne : cd ../../../prof/examens · cd ../../../prof/examens/ · cd /home/prof/examens · cd /home/prof/examens/ · cd ~/../prof/examens · cd ~/../prof/examens/

Question 5. À ton tour : tu es dans nsi et tu tapes ls ../... Qu'affiche la commande ?

devoirs photos projets : depuis nsi, ../.. désigne /home/eleve, et ls en liste le contenu (par ordre alphabétique).

Erreur fréquente : nsi : ça, c'est le contenu de .. (le dossier devoirs). ../.. remonte de deux niveaux.

Erreur fréquente : eleve prof ou prof eleve : ça, c'est le contenu de home, trois niveaux plus haut. ../.. remonte de deux niveaux seulement.

Erreur fréquente : tp1.py : ça, c'est le contenu de nsi lui-même (ls seul).

Acceptées en ligne : devoirs photos projets · devoirs projets photos · photos devoirs projets · photos projets devoirs · projets devoirs photos · projets photos devoirs · devoirs/ photos/ projets/

3. Réorganiser l'arborescence

Question 6. Qu'affiche la dernière commande, ls ../archives ?

nsi : le dossier nsi (avec son fichier tp1.py) a été déplacé dans archives.

Erreur fréquente : rien ou vide ou aucun : Le dossier archives n'est plus vide : la commande mv vient d'y mettre quelque chose.

Erreur fréquente : archives : On liste le contenu de archives, pas son nom.

Erreur fréquente : tp1.py : ls montre le contenu d'archives sur un seul niveau : le dossier qu'il contient, pas ce qu'il y a dedans.

Acceptées en ligne : nsi · nsi/

Question 7. À gauche, /home/eleve avant les commandes. Dessine-le à droite, après les commandes.

eleve/
|-- archives/
|   `-- nsi/
|       `-- tp1.py
|-- devoirs/
|-- photos/
|   `-- lagon.png
`-- projets/
    `-- site.html

« devoirs/, qui contient archives/nsi/ ; photos/ ; projets/ » : non. mkdir archives est lancé depuis /home/eleve, avant cd devoirs : archives est créé à côté de devoirs, pas dedans.

« archives/nsi/ ; devoirs/nsi/ ; photos/ ; projets/ » : non. mv déplace : nsi n'est plus dans devoirs. Garder l'original, c'est ce que fait cp.

« archives/, vide ; devoirs/nsi/ ; photos/ ; projets/ » : non. Depuis devoirs, ../archives désigne /home/eleve/archives : le déplacement a bien eu lieu.

Feuille 2 : Chercher, les droits

1. Chercher dans un fichier

Question 8. À ton tour : tu es dans nsi. Écris la commande qui affiche seulement les lignes de tp1.py qui contiennent print.

grep print tp1.py (les guillemets autour de print sont permis).

Erreur fréquente : grep tp1.py print ou grep tp1.py "print" : L'ordre compte : d'abord le motif cherché, puis le fichier.

Erreur fréquente : cat tp1.py ou cat print tp1.py : cat affiche tout le fichier. Pour n'avoir que les lignes qui contiennent un mot, une autre commande existe.

Erreur fréquente : grep print ou grep print tp1 ou grep print tp1.txt : Il manque le nom exact du fichier, extension comprise : tp1.py.

Acceptées en ligne : grep print tp1.py · grep "print" tp1.py · grep 'print' tp1.py · grep print ./tp1.py · grep "print" ./tp1.py · grep print /home/eleve/devoirs/nsi/tp1.py

Question 9. À ton tour : qu'affiche cette commande ?

La ligne 1 (le commentaire) et la ligne 3 : ce sont les deux lignes qui contiennent barge. grep les affiche entières, dans l'ordre du fichier.

2. Les droits

Question 10. À ton tour : quels droits le groupe nsi a-t-il sur notes.csv ?

- (un fichier), rw- (propriétaire prof), r-- (groupe nsi), --- (autres) : le groupe peut lire le fichier, mais pas le modifier.

« Lire et écrire (rw-) » : non. rw- sont les droits du propriétaire, prof : les trois premiers après le tiret.

« Aucun droit (---) » : non. --- sont les droits des autres : les trois derniers.

« Lire et exécuter (r-x) » : non. Il n'y a aucun x dans -rw-r----- : personne ne peut l'exécuter.

Question 11. eleve est dans le groupe nsi. Pourquoi peut-il copier notes.csv ?

Pour copier, il suffit de lire l'original : le groupe nsi a le droit r. Il ne pourrait pas le modifier (pas de w).

« eleve est le propriétaire de notes.csv » : non. eleve n'est pas le propriétaire : c'est prof, le nom écrit juste après le nombre de liens.

« cp ne regarde jamais les droits d'un fichier » : non. Les droits comptent toujours : sans r, cp répondrait « Permission denied ».

« Le groupe a le droit d'écrire dans le fichier » : non. Le groupe n'a pas w : il ne peut pas modifier notes.csv. Et copier ne demande pas d'écrire dans l'original.

Question 12. À ton tour : quels droits donne chmod 754 tp1.py ? Écris-les comme ls -l : 9 caractères.

7 = rwx pour le propriétaire, 5 = r-x pour le groupe, 4 = r-- pour les autres : -rwxr-xr--.

« rwxrw-r-- » : non. 5 = 4 + 1 : lecture et exécution, pas écriture.

« r--r-xrwx » : non. Les chiffres se lisent dans l'ordre propriétaire, groupe, autres.

« rwxr-xr-x » : non. 4 = lecture seule : r--. Le 4 des autres ne donne pas l'exécution.

Question 13. À ton tour : tu es dans nsi. En octal, rends tp1.py lisible et modifiable par toi seul·e (le propriétaire), sans aucun droit pour les autres.

chmod 600 tp1.py : 6 = rw- pour le propriétaire, 0 = --- pour le groupe et pour les autres.

Erreur fréquente : chmod 700 tp1.py : 7 donne aussi l'exécution (x = 1). On ne demande que lire et écrire : 4 + 2.

Erreur fréquente : chmod 006 tp1.py : Les chiffres sont dans l'ordre propriétaire, groupe, autres : tu as donné les droits aux autres.

Erreur fréquente : chmod 644 tp1.py ou chmod 640 tp1.py ou chmod 660 tp1.py : Le groupe ou les autres gardent un droit : seul le premier chiffre doit être différent de 0.

Acceptées en ligne : chmod 600 tp1.py · chmod 600 ./tp1.py · chmod 0600 tp1.py · chmod 600 /home/eleve/devoirs/nsi/tp1.py

Question 14. À ton tour : en symbolique, ajoute le droit d'exécution au propriétaire de tp1.py, sans changer les autres droits.

chmod u+x tp1.py : u (user, le propriétaire), + (ajouter), x (exécution).

Erreur fréquente : chmod +x tp1.py ou chmod a+x tp1.py : Sans lettre (ou avec a), le droit est ajouté à tout le monde. Précise pour qui : u pour le propriétaire.

Erreur fréquente : chmod o+x tp1.py ou chmod g+x tp1.py : o, ce sont les autres ; g, le groupe. Le propriétaire, c'est u (user).

Erreur fréquente : chmod x+u tp1.py ou chmod u-x tp1.py : L'ordre est : qui, puis + (ajouter), puis le droit.

Erreur fréquente : chmod 700 tp1.py : C'est le mode octal, et il change aussi les droits du groupe et des autres. On demande le mode symbolique.

Acceptées en ligne : chmod u+x tp1.py · chmod u+x ./tp1.py · chmod u+x /home/eleve/devoirs/nsi/tp1.py

Question 15. Dans /home/prof, prof tape chown direction notes.csv et lit : chown: changing ownership of 'notes.csv': Operation not permitted. Pourquoi ce refus ?

Changer le propriétaire est réservé à l'administrateur·rice, root : même prof, propriétaire du fichier, ne le peut pas. Il faut sudo.

« Parce que sudo est obligatoire devant chaque commande » : non. Non : la plupart des commandes (ls, cd, cat…) se lancent sans sudo.

« Parce que direction et notes.csv sont dans le mauvais ordre » : non. L'ordre est le bon : d'abord le nouveau propriétaire, puis le fichier.

« Parce que notes.csv n'existe pas dans /home/prof » : non. Le message parle de permission (permitted), pas d'un fichier introuvable : notes.csv est bien là.

Question 16. À ton tour : tu es dans /home/prof. Écris la commande qui donne notes.csv à l'utilisateur·rice direction.

sudo chown direction notes.csv

Erreur fréquente : chown direction notes.csv : C'est la commande de la question précédente : elle est refusée. Il manque ce qui donne les droits de root.

Erreur fréquente : sudo chown notes.csv direction : L'ordre compte : d'abord le nouveau propriétaire, puis le fichier.

Erreur fréquente : sudo chmod direction notes.csv : chmod change les droits (r, w, x). Pour changer le propriétaire, c'est une autre commande.

Acceptées en ligne : sudo chown direction notes.csv · sudo chown direction ./notes.csv · sudo chown direction /home/prof/notes.csv
