Commandes Linux — Systèmes d'exploitation

NSI — Première
Le terminal (Shell) contrôle l'OS par des commandes textuelles. Tout est organisé en arborescence depuis la racine /. Symboles essentiels : . (répertoire courant)  ·  .. (répertoire parent)  ·  ~ (dossier personnel de l'utilisateur·rice)

1. Navigation dans l'arborescence

CommandeAction (à compléter)Exemple
pwd
pwd → /home/eleve/devoirs/nsi
ls
ls  ·  ls ..
cd [chemin]
cd Documents/
cd ..
cd ../../home
cd ~
cd ~

Chemin Absolu

Part toujours de la racine /, indépendamment du répertoire courant.
Ex. : /home/eleve/devoirs/nsi

Chemin Relatif

Part du répertoire courant (pwd). Utilise .. pour remonter.
Ex. (depuis /home/eleve) : devoirs/nsi ou ../prof

2. Lecture de fichiers

CommandeAction (à compléter)Exemple
cat [fichier]
cat notes.csv
grep [motif] [f.]
grep "password" L.txt
man [cmd]
man ls

3. Création et manipulation de fichiers

CommandeAction (à compléter)Exemple
touch [fichier]
touch exam1.txt
mkdir [dossier]
mkdir archives
cp [src] [dest]
cp notes.csv projets/
mv [src] [dest]
mv nsi ../archives/
rm [fichier]
rm temp.txt
sudo [commande]
sudo chown eleve fich.
💡  Tab : auto-complétion des noms  ·  ↑ : rappeler la dernière commande  ·  Ctrl+C : interrompre
