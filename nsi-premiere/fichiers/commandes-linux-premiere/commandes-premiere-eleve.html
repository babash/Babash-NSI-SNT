Exemple : que fait la commande pwd ? Elle affiche le chemin absolu du répertoire courant (print working directory) : depuis nsi, elle affiche /home/eleve/devoirs/nsi. À ton tour, pour les autres commandes.

Que fait la commande ls ? Exemples : ls · ls ..

  • Afficher le contenu d'un fichier texte
  • Afficher le chemin du répertoire courant
  • Lister le contenu d'un dossier
  • Effacer tout l'écran du terminal

ls (list) liste le contenu du répertoire courant, ou du dossier indiqué : ls .. liste le parent.

« Afficher le contenu d'un fichier texte » : non. Afficher le contenu d'un fichier, c'est cat.

« Afficher le chemin du répertoire courant » : non. Afficher le chemin du répertoire courant, c'est pwd.

« Effacer tout l'écran du terminal » : non. ls n'efface rien : il affiche une liste. Vider l'écran, c'est clear.

Que fait la commande cd [dossier] ? Exemple : cd projets

  • Créer le dossier indiqué
  • Se déplacer dans le dossier indiqué
  • Copier le dossier indiqué
  • Afficher le contenu du dossier indiqué

cd (change directory) change de répertoire : on se déplace dans l'arborescence.

« Créer le dossier indiqué » : non. Créer un dossier, c'est mkdir.

« Copier le dossier indiqué » : non. Copier, c'est cp.

« Afficher le contenu du dossier indiqué » : non. Lister le contenu, c'est ls.

Que fait la commande cd .. ?

  • Revenir au répertoire personnel
  • Aller à la racine du système
  • Remonter au répertoire parent
  • Rester dans le répertoire courant

cd .. remonte d'un niveau, vers le répertoire parent ; cd ../.. remonte de deux niveaux.

« Revenir au répertoire personnel » : non. Pour revenir au répertoire personnel, c'est cd ~.

« Aller à la racine du système » : non. Pour aller à la racine, c'est cd /.

« Rester dans le répertoire courant » : non. Un seul point, c'est le répertoire courant (cd . ne bouge pas). Deux points, c'est le parent.

Que fait la commande cd ~ ?

  • Aller à la racine /
  • Remonter d'un niveau, vers le parent
  • Revenir au répertoire où l'on était avant
  • Aller dans son répertoire personnel

cd ~ ramène dans le répertoire personnel (ici /home/eleve), d'où que l'on soit.

« Aller à la racine / » : non. La racine, c'est /. Le tilde ~ désigne autre chose.

« Remonter d'un niveau, vers le parent » : non. Remonter d'un niveau, c'est cd ..

« Revenir au répertoire où l'on était avant » : non. Revenir au répertoire précédent, c'est cd - (avec un tiret).

Que fait la commande cat [fichier] ? Exemple : cat tp1.py

  • Afficher tout le contenu d'un fichier
  • Créer un fichier vide, prêt à être rempli
  • Chercher un mot à l'intérieur d'un fichier
  • Lister les fichiers d'un dossier, par nom

cat affiche tout le contenu d'un fichier.

« Créer un fichier vide, prêt à être rempli » : non. Créer un fichier vide, c'est touch.

« Chercher un mot à l'intérieur d'un fichier » : non. Chercher un mot, c'est grep : il n'affiche que les lignes qui le contiennent.

« Lister les fichiers d'un dossier, par nom » : non. Lister les fichiers, c'est ls.

Que fait la commande grep [motif] [fichier] ? Exemple : grep print tp1.py

  • Afficher tout le fichier, ligne par ligne
  • Afficher les lignes qui contiennent le motif
  • Remplacer le motif partout dans le fichier
  • Chercher un fichier par son nom

grep cherche un motif (un mot) et affiche les lignes du fichier qui le contiennent.

« Afficher tout le fichier, ligne par ligne » : non. Tout afficher, c'est cat. grep fait un tri.

« Remplacer le motif partout dans le fichier » : non. grep ne modifie jamais le fichier : il affiche seulement des lignes.

« Chercher un fichier par son nom » : non. Chercher un fichier par son nom, c'est find. grep cherche dans le contenu.

Que fait la commande man [commande] ? Exemple : man ls

  • Exécuter une commande en administrateur·rice
  • Afficher l'utilisateur·rice connecté·e
  • Interrompre une commande qui ne répond plus
  • Afficher le manuel d'utilisation d'une commande

man affiche le manuel d'une commande (on en sort avec la touche q).

« Exécuter une commande en administrateur·rice » : non. Exécuter une commande en administrateur·rice, c'est sudo.

« Afficher l'utilisateur·rice connecté·e » : non. Afficher l'utilisateur·rice connecté·e, c'est whoami.

« Interrompre une commande qui ne répond plus » : non. Interrompre une commande, c'est Ctrl+C.

Que fait la commande touch [fichier] ? Exemple : touch exam1.txt

  • Créer un dossier vide, prêt à remplir
  • Créer un fichier vide (ou changer sa date)
  • Ouvrir un fichier dans un éditeur pour l'écrire
  • Afficher le contenu d'un fichier

touch crée un fichier vide ; si le fichier existe déjà, il change seulement sa date.

« Créer un dossier vide, prêt à remplir » : non. Créer un dossier, c'est mkdir.

« Ouvrir un fichier dans un éditeur pour l'écrire » : non. touch n'ouvre aucun éditeur : il crée le fichier, vide, et rend la main.

« Afficher le contenu d'un fichier » : non. Afficher le contenu, c'est cat.

Que fait la commande mkdir [dossier] ? Exemple : mkdir archives

  • Créer un fichier vide
  • Supprimer un dossier
  • Créer un dossier
  • Se déplacer dans un dossier

mkdir (make directory) crée un dossier.

« Créer un fichier vide, prêt à être rempli » : non. Créer un fichier vide, c'est touch.

« Supprimer un dossier » : non. Supprimer un dossier vide, c'est rmdir.

« Se déplacer dans un dossier » : non. Se déplacer, c'est cd.

Que fait la commande cp [source] [destination] ? Exemple : cp tp1.py ../../projets/

  • Copier vers la destination : l'original reste
  • Déplacer vers la destination : l'original disparaît
  • Renommer un fichier, sans le copier
  • Comparer deux fichiers, ligne par ligne

cp (copy) copie un fichier vers une destination : l'original reste à sa place.

« Déplacer vers la destination : l'original disparaît » : non. Si l'original disparaît, c'est un déplacement : mv.

« Renommer un fichier, sans le copier » : non. Renommer, c'est mv.

« Comparer deux fichiers, ligne par ligne » : non. cp ne compare rien : il fabrique une copie.

Que fait la commande mv [source] [destination] ? Exemple : mv nsi ../archives/

  • Copier un fichier, en gardant l'original
  • Supprimer un fichier ou un dossier
  • Créer un dossier à la destination
  • Déplacer ou renommer (fichier, dossier)

mv (move) déplace ou renomme un fichier ou un dossier.

« Copier un fichier, en gardant l'original » : non. Copier en gardant l'original, c'est cp.

« Supprimer un fichier ou un dossier » : non. Supprimer, c'est rm.

« Créer un dossier à la destination » : non. Créer un dossier, c'est mkdir.

Que fait la commande rm [fichier] ? Exemple : rm brouillon.txt

  • Mettre le fichier à la corbeille du bureau
  • Supprimer le fichier, pour de bon
  • Renommer le fichier en brouillon.txt
  • Vider le fichier, en le gardant

rm (remove) supprime un fichier, pour de bon : il n'y a pas de corbeille.

« Mettre le fichier à la corbeille du bureau » : non. Dans le terminal, il n'y a pas de corbeille : le fichier est perdu.

« Renommer le fichier en brouillon.txt » : non. Renommer, c'est mv.

« Vider le fichier, en le gardant » : non. rm ne garde rien : le fichier lui-même disparaît.

Que fait la commande rmdir [dossier] ? Exemple : rmdir archives

  • Créer un dossier, s'il n'existe pas encore
  • Supprimer un dossier et tout ce qu'il contient
  • Supprimer un dossier, seulement s'il est vide
  • Renommer un dossier, sans toucher à son contenu

rmdir (remove directory) supprime un dossier vide ; si le dossier contient quelque chose, il refuse.

« Créer un dossier, s'il n'existe pas encore » : non. Créer un dossier, c'est mkdir.

« Supprimer un dossier et tout ce qu'il contient » : non. rmdir refuse un dossier qui n'est pas vide (« Directory not empty ») : il ne supprime rien d'autre que le dossier.

« Renommer un dossier, sans toucher à son contenu » : non. Renommer, c'est mv.

2. Chemins absolus et relatifs

L'arborescence du TD, telle que l'affiche la commande tree (les dossiers finissent par /). L'utilisateur·rice eleve et l'enseignant·e prof font partie du même groupe, nsi.

/
|-- bin/
|-- home/
|   |-- eleve/
|   |   |-- devoirs/
|   |   |   `-- nsi/
|   |   |       `-- tp1.py
|   |   |-- photos/
|   |   |   `-- lagon.png
|   |   `-- projets/
|   |       `-- site.html
|   `-- prof/
|       |-- examens/
|       `-- notes.csv
`-- tmp/

Pour t'entraîner dans un vrai terminal (facultatif) : ouvre le terminal d'entraînement d'Opération MIRAGE (rien à installer) ou JSLinux (un vrai Linux dans le navigateur), puis recrée l'arborescence du TD avec ces trois commandes :

mkdir -p /home/eleve/devoirs/nsi /home/eleve/photos /home/eleve/projets /home/prof/examens
touch /home/eleve/devoirs/nsi/tp1.py /home/eleve/photos/lagon.png /home/eleve/projets/site.html /home/prof/notes.csv
cd /home/eleve/devoirs/nsi

Là-bas, tu es root (l'administrateur·rice) : ~ y désigne /root, et sudo n'y existe pas.

Un chemin absolu part toujours de la racine /, d'où que l'on soit : /home/eleve/devoirs/nsi. Un chemin relatif part du répertoire courant et remonte avec .. : depuis /home/eleve, devoirs/nsi ou ../prof.

3. Réorganiser l'arborescence

Exemple : depuis /home/eleve, mv projets/site.html photos/ déplace site.html : projets devient vide, et photos contient lagon.png et site.html.

À ton tour : on repart de l'arborescence du TD. Depuis /home/eleve, on tape :

eleve@lycee:~$ mkdir archives
eleve@lycee:~$ cd devoirs
eleve@lycee:~/devoirs$ mv nsi ../archives/
eleve@lycee:~/devoirs$ ls ../archives

Qu'affiche la dernière commande, ls ../archives ?

nsi : le dossier nsi (avec son fichier tp1.py) a été déplacé dans archives.

Erreur fréquente : rien : Le dossier archives n'est plus vide : la commande mv vient d'y mettre quelque chose.

Erreur fréquente : archives : On liste le contenu de archives, pas son nom.

Erreur fréquente : tp1.py : ls montre le contenu d'archives sur un seul niveau : le dossier qu'il contient, pas ce qu'il y a dedans.

« devoirs/, qui contient archives/nsi/ ; photos/ ; projets/ » : non. mkdir archives est lancé depuis /home/eleve, avant cd devoirs : archives est créé à côté de devoirs, pas dedans.

« archives/nsi/ ; devoirs/nsi/ ; photos/ ; projets/ » : non. mv déplace : nsi n'est plus dans devoirs. Garder l'original, c'est ce que fait cp.

« archives/, vide ; devoirs/nsi/ ; photos/ ; projets/ » : non. Depuis devoirs, ../archives désigne /home/eleve/archives : le déplacement a bien eu lieu.
