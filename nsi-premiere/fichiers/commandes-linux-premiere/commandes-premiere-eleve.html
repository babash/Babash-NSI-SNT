Le terminal et l'arborescence

Nom et prénom :Classe :

Objectif : utiliser les commandes de base du terminal et écrire des chemins absolus et relatifs.

Je sais :

  • dire ce que fait chaque commande de base ;

1 heure · 23 questions · seul·e ou en binôme

Le terminal (le shell) contrôle le système d'exploitation par des commandes écrites. Tout est rangé en arborescence, depuis la racine /.

Symboles essentiels : . (répertoire courant) · .. (répertoire parent) · ~ (dossier personnel de l'utilisateur·rice).

1. Navigation dans l'arborescence

Que fait la commande pwd ? Exemple : pwd → /home/eleve/devoirs/nsi

  • Afficher le chemin absolu du répertoire courant
  • Changer de répertoire
  • Lister le contenu du répertoire courant
  • Afficher le mot de passe de l'utilisateur·rice

Regarde l'exemple : la commande affiche un chemin qui part de /.

pwd (Print Working Directory) affiche le chemin absolu du répertoire de travail actuel.

Que fait la commande ls ? Exemples : ls · ls ..

  • Afficher le contenu d'un fichier
  • Afficher le chemin du répertoire courant
  • Lister les fichiers et dossiers d'un répertoire
  • Effacer l'écran du terminal

ls .. agit sur le répertoire parent : il en montre le contenu.

ls (list) liste le contenu (fichiers et dossiers) du répertoire courant, ou du répertoire indiqué : ls .. liste le parent.

Que fait la commande cd [chemin] ? Exemple : cd Documents/

  • Créer le répertoire indiqué
  • Se déplacer dans le répertoire indiqué
  • Copier le répertoire indiqué
  • Afficher le contenu du répertoire indiqué

cd vient de l'anglais Change Directory.

cd (Change Directory) change de répertoire : on se déplace dans l'arborescence.

Que fait la commande cd .. ? Exemple : cd ../../home

  • Revenir au dossier personnel
  • Aller à la racine /
  • Remonter d'un niveau, vers le répertoire parent
  • Rester dans le répertoire courant

Relis les symboles essentiels en haut de la feuille : .. désigne…

cd .. remonte d'un niveau, vers le répertoire parent. cd ../../home remonte de deux niveaux, puis entre dans home.

Que fait la commande cd ~ ?

  • Aller à la racine /
  • Remonter d'un niveau
  • Revenir au répertoire précédent
  • Aller dans le dossier personnel de l'utilisateur·rice

Relis les symboles essentiels en haut de la feuille : ~ désigne…

cd ~ ramène directement dans le dossier personnel de l'utilisateur·rice (ici /home/eleve), d'où que l'on soit.

Chemin absolu : il part toujours de la racine /, quel que soit le répertoire courant. Exemple : /home/eleve/devoirs/nsi.
Chemin relatif : il part du répertoire courant (pwd) et utilise .. pour remonter. Exemples, depuis /home/eleve : devoirs/nsi ou ../prof.

2. Lecture de fichiers

Que fait la commande cat [fichier] ? Exemple : cat notes.csv

  • Afficher tout le contenu d'un fichier
  • Créer un fichier vide
  • Chercher un mot dans un fichier
  • Lister les fichiers d'un répertoire

Avec cat notes.csv, on voit les notes écrites dans le fichier.

cat affiche le contenu complet d'un fichier dans le terminal.

Que fait la commande grep [motif] [fichier] ? Exemple : grep "password" L.txt

  • Afficher tout le fichier
  • Afficher les lignes du fichier qui contiennent le motif
  • Remplacer le motif dans le fichier
  • Chercher un fichier par son nom

Le motif est le mot cherché ; le fichier est l'endroit où on le cherche.

grep recherche un motif (un mot-clé) et affiche les lignes du fichier qui le contiennent.

Que fait la commande man [commande] ? Exemple : man ls

  • Exécuter une commande en administrateur·rice
  • Afficher l'utilisateur·rice connecté·e
  • Interrompre une commande qui ne répond plus
  • Afficher le manuel d'utilisation d'une commande

man est le début d'un mot anglais : manual.

man affiche le manuel d'une commande (on en sort avec la touche q).

3. Création et manipulation de fichiers

Que fait la commande touch [fichier] ? Exemple : touch exam1.txt

  • Créer un dossier
  • Créer un fichier vide (ou changer sa date de modification)
  • Ouvrir un fichier pour l'écrire
  • Afficher le contenu d'un fichier

Après touch exam1.txt, ls montre un nouveau fichier.

touch crée un fichier vide ; si le fichier existe déjà, il met à jour sa date de modification.

Que fait la commande mkdir [dossier] ? Exemple : mkdir archives

  • Créer un fichier vide
  • Supprimer un dossier
  • Créer un dossier
  • Se déplacer dans un dossier

mkdir : MaKe DIRectory.

mkdir (MaKe DIRectory) crée un nouveau dossier.

Que fait la commande cp [source] [destination] ? Exemple : cp notes.csv projets/

  • Copier vers la destination : l'original reste
  • Déplacer vers la destination : l'original disparaît
  • Renommer un fichier
  • Comparer deux fichiers

cp : CoPy.

cp (CoPy) copie un fichier ou un dossier vers une destination : l'original reste à sa place.

Que fait la commande mv [source] [destination] ? Exemple : mv nsi ../archives/

  • Copier, en gardant l'original
  • Supprimer un fichier
  • Créer un dossier
  • Déplacer ou renommer un fichier ou un dossier

mv : MoVe. Renommer, c'est « déplacer » vers un autre nom.

mv (MoVe) déplace ou renomme un fichier ou un dossier.

Que fait la commande rm [fichier] ? Exemple : rm temp.txt

  • Mettre le fichier à la corbeille
  • Supprimer le fichier, définitivement
  • Renommer le fichier
  • Vider le fichier, en le gardant

rm : ReMove.

rm (ReMove) supprime définitivement un fichier : c'est irréversible !

Que fait la commande sudo [commande] ? Exemple : sudo chown eleve fich.

  • Changer le propriétaire d'un fichier
  • Afficher le manuel d'une commande
  • Exécuter une commande avec les droits d'administrateur·rice (root)
  • Arrêter l'ordinateur

Dans l'exemple, sudo est suivi d'une autre commande : il change la façon dont elle s'exécute.

sudo exécute une commande avec les droits d'administrateur·rice (le super-utilisateur root).

Astuces : Tab complète les noms · ↑ rappelle la dernière commande · Ctrl+C interrompt une commande.

4. Navigation et chemins

Arborescence de référence : l'utilisateur·rice connecté·e est eleve ; son répertoire personnel est /home/eleve. prof a donné à eleve le droit de lire notes.csv et d'écrire dans examens. (D) : dossier ; (F) : fichier.

/ (racine)
|-- bin/ (D)
`-- home/ (D)
    |-- prof/ (D)
    |   |-- examens/ (D)
    |   `-- notes.csv (F)
    `-- eleve/ (D)
        |-- devoirs/ (D)
        |   `-- nsi/ (D)
        `-- projets/ (D)

L'utilisateur·rice eleve se trouve dans le dossier nsi.

Donne le chemin absolu du répertoire nsi.

Un chemin absolu part toujours de la racine : il commence par /.

Pars de la racine / et descends dossier par dossier jusqu'à nsi.

/home/eleve/devoirs/nsi

Copie notes.csv (chez prof) vers projets, en chemins relatifs (on est dans nsi).

Presque : ../.. depuis nsi mène à eleve, pas à home. Il faut remonter d'un niveau de plus pour trouver prof.

Ta commande marche, mais avec des chemins absolus. La consigne demande des chemins relatifs, qui partent de nsi.

Depuis nsi : .. mène à devoirs, ../.. à eleve, ../../.. à home.

La source est ../../../prof/notes.csv. Il reste la destination.

cp ../../../prof/notes.csv ../../projets/

Depuis nsi : ../.. → eleve ; ../../.. → home ; ../../../prof/notes.csv est la source ; ../../projets/ est la destination.

Tu veux créer le fichier exam1.txt dans examens (on est dans nsi). Écris la commande qui manque avant touch exam1.txt.

$ ...
$ touch exam1.txt

Depuis nsi, ../.. mène à eleve. Pour trouver prof, il faut remonter jusqu'à home.

Le dossier examens n'est pas dans nsi : cd ne le trouvera pas. Donne le chemin complet, relatif ou absolu.

touch exam1.txt crée le fichier dans le répertoire courant : il faut d'abord aller dans examens.

En chemin absolu, examens est dans /home/prof.

cd ../../../prof/examens (ou, en chemin absolu, cd /home/prof/examens), puis touch exam1.txt.

Depuis nsi, on tape la commande ci-dessous. Qu'affiche-t-elle ?

eleve@serveur:~/devoirs/nsi$ ls ../..

Ça, c'est le contenu de .. (le dossier devoirs). ../.. remonte de deux niveaux.

Ça, c'est le contenu de home, trois niveaux plus haut. ../.. remonte de deux niveaux seulement.

Depuis nsi, .. est devoirs et ../.. est eleve.

devoirs projets : ../.. depuis nsi remonte à /home/eleve, et ls en liste le contenu.

5. Réorganisation de l'arborescence

On repart de l'arborescence de référence. L'administrateur·rice exécute, depuis /home/eleve :

$ mkdir archives
$ cd devoirs
$ mv nsi ../archives/
$ ls ../archives

Qu'affiche la commande ls ../archives ?

Le dossier archives n'est plus vide : la commande mv vient d'y mettre quelque chose.

On liste le contenu de archives, pas son nom.

Après cd devoirs, .. désigne /home/eleve : ../archives est le dossier qu'on vient de créer.

nsi : le dossier nsi a été déplacé dans archives.

Quelle est l'arborescence sous /home/eleve après ces commandes ?

  • devoirs/ contient archives/, qui contient nsi/ ; projets/
  • archives/ contient nsi/ ; devoirs/ contient nsi/ ; projets/
  • archives/ contient nsi/ ; devoirs/ est vide ; projets/
  • archives/ est vide ; devoirs/ contient nsi/ ; projets/

mv déplace : l'original quitte sa place.

eleve/
|-- archives/
|   `-- nsi/
|-- devoirs/   (vide)
`-- projets/

Dessine l'arborescence modifiée sous /home/eleve.

eleve/
|-- archives/
|   `-- nsi/
|-- devoirs/   (vide)
`-- projets/
