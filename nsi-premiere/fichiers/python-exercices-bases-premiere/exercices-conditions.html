Feuille 1 sur 3 · 30 minutes · 10 questions · seul·e ou en binôme

On veut compter les points d'un jeu de dés. On lance 3 dés, et on compte les points ainsi :

  • 3 dés différents : on marque la somme des dés ;
  • 3 dés identiques : on marque 30 points ;
  • 2 dés identiques : on marque 20 points.

1. Test des dés différents

Le programme :

from random import randint
# randint(1,6) tire au hasard une valeur entière comprise entre 1 et 6
de1 = randint(1,6)
de2 = randint(1,6)
de3 = randint(1,6)
score = 0
if de1 != de2 and de2 != de3 and de1 != de3 :
    score = de1 + de2 + de3
    print("Vous marquez ",score," points")
else :
    print("Il y a au moins 2 dés identiques")

Combien de variables y a-t-il dans ce programme ?

randint est une fonction, pas une variable.

4 variables : de1, de2, de3 et score.

2. Test des 3 dés identiques

Le programme :

from random import randint
# randint(1,6) tire au hasard une valeur entière comprise entre 1 et 6
de1 = randint(1,6)
de2 = randint(1,6)
de3 = randint(1,6)
score = 0
if de1 == de2 == de3 :
    score = 30
    print("Vous marquez ",score," points")
else :
    print("Vous n'avez pas eu 3 dés identiques")

Combien de variables y a-t-il dans ce programme ?

randint est une fonction, pas une variable.

Une variable reçoit une valeur avec =. randint est une fonction, pas une variable.

4 variables : de1, de2, de3 et score.

Quel opérateur de comparaison est utilisé ? Que compare-t-il ?

  • == : il teste si les trois dés sont égaux.
  • = : il range de1 dans de2.
  • == : il teste si deux des dés sont égaux.
  • != : il teste si les dés sont différents.

de1 == de2 == de3 se lit « de1 égal à de2, et de2 égal à de3 ».

== compare : de1 == de2 == de3 est vrai si les trois dés sont égaux.
