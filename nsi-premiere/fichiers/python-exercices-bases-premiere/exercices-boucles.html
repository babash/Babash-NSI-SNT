i = 1
while i < 5:

    print(total)

# Ton programme

Les nombres impairs sont enlevés, les pairs sont ajoutés.

Dans la boucle : if i % 2 == 0: on ajoute i ; sinon, on l'enlève.

somme = 0
for i in range(1, 101):
    if i % 2 == 0:
        somme = somme + i
    else:
        somme = somme - i
print(somme)

Mémo

for i in range(a, b): s'écrit aussi i = a, puis while i < b: avec i = i + 1 à la fin de la boucle.

Un accumulateur commence à 0 (pour une somme) ou à 1 (pour un produit), avant la boucle.
