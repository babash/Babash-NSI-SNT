1. Ça se complète

Complète le programme : il demande un mois et affiche son nombre de jours. Janvier, mars, mai, juillet, août, octobre, décembre ont 31 jours ; février a 28 ou 29 jours selon l'année ; avril, juin, septembre, novembre ont 30 jours.

mois = input("Entrez le mois : ")
# On suppose que mois est bien écrit (ex : "Janvier")

if mois == "Janvier" [[or]] mois == "Mars" [[or]] \
   mois == "Mai" [[or]] mois == "Juillet" [[or]] \
   mois == "Août" [[or]] mois == "Octobre" [[or]] \
   mois == "Décembre":
    [[jours = 31]]
[[elif]] mois == "Février":
    jours = 28
elif mois == "Avril" [[or]] mois == "Juin" [[or]] \
     mois == "Septembre" [[or]] mois == "Novembre":
    [[jours = 30]]
[[else]]:
    jours = "Mois non valide"
print(f"Le mois de {mois} a {jours} jours.")

Un mois de 31 jours : janvier ou mars ou mai…

Les cas suivants : « sinon, si » (elif), puis « sinon » (else).

Le \ en fin de ligne dit que la condition continue à la ligne suivante.

mois = input("Entrez le mois : ")

3. Équation du second degré

On cherche les solutions réelles de ax² + bx + c = 0, selon le discriminant delta = b² − 4ac :

  • delta positif : deux solutions, (−b + racine de delta) / 2a et (−b − racine de delta) / 2a ;
  • delta nul : une solution, −b / 2a ;
  • delta négatif : pas de solution réelle.

Complète avec des opérateurs de comparaison (<, ==, >) et math.sqrt (la racine carrée). Le module math est importé.

import math

print("Entrer les coefficients")
a = int(input("a : "))
b = int(input("b : "))
c = int(input("c : "))
delta = b**2 - 4*a*c

if [[delta < 0|0 > delta]] : # pas de solution réelle
    print("Pas de solution réelle.")
elif [[delta == 0|0 == delta]] : # une seule solution
    x0 = -b / (2*a)
    print(f"Une solution double: x = {x0}")
else: # deux solutions réelles
    x1 = (-b + math.sqrt(delta)) / (2*a)
    x2 = [[(-b - math.sqrt(delta)) / (2*a)]]
    print(f"Deux solutions: x1 = {x1} et x2 = {x2}")

Pas de solution si delta est négatif ; une seule s'il est nul.

x2 : comme x1, avec un moins devant la racine.

Dans chaque cas : d'abord le message, puis les solutions.

import math
a = 1
b = -3
c = 2
delta = b**2 - 4*a*c
if delta > 0:
    print("Delta est positif.")
    x1 = (-b + math.sqrt(delta)) / (2*a)
    x2 = (-b - math.sqrt(delta)) / (2*a)
    print(x1, x2)
elif delta == 0:
    print("Delta est nul.")
    print(-b / (2*a))
else:
    print("Delta est négatif. Les solutions sont complexes (non réelles).")
