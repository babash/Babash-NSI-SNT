1. Exemple : le périmètre

PI = 3.1415
rayon = float(input("Saisissez le rayon :"))
perimetre = 2 * PI * rayon
print("Le perimetre du cercle est", perimetre, "m")

Combien y a-t-il de variables dans ce programme ? Coche tous leurs identifiants.

  • PI
  • rayon
  • perimetre
  • float
  • input
  • "m"

Une variable reçoit une valeur avec = : regarde ce qui est à gauche du signe égal.

Trois variables : PI, rayon et perimetre. float, input et print sont des fonctions ; "m" est un texte.

L'utilisateur·rice saisit un rayon de 2 m. Donne la valeur de chaque variable, ligne par ligne.

PI = [[3.1415|3,1415]]                   # après la ligne 1
rayon = [[2.0|2|2,0]]                    # après la ligne 2
perimetre = [[12.566|12,566]]            # après la ligne 3

À la ligne 2, float("2") donne le nombre décimal 2.0.

Ligne 3 : 2 × 3,1415 × 2.

PI vaut 3.1415 ; rayon vaut 2.0 (un décimal, grâce à float) ; perimetre vaut 2 × 3.1415 × 2.0 = 12.566. Le programme affiche (vérifié en l'exécutant) :

Le perimetre du cercle est 12.566 m

Quelle phrase explique ce que fait le programme ?

  • Il demande le rayon, puis calcule et affiche le périmètre du cercle.
  • Il demande le rayon d'un cercle, calcule son aire et l'affiche.
  • Il calcule le périmètre d'un cercle de rayon 3,1415.
  • Il demande un rayon et l'affiche en mètres.

Relis la ligne 3 : quelle formule de géométrie reconnais-tu ?

Le programme range une valeur approchée du nombre π dans PI, demande le rayon (converti en décimal), calcule le périmètre 2 × PI × rayon, puis affiche le résultat suivi de l'unité « m ».

Explique en un paragraphe ce que fait le programme.

nom = [["Doe"|'Doe'|Doe]]                # après la ligne 1

nom vaut "Doe" et prenom vaut "John" (des textes) ; age vaut 35 (un entier, grâce à int). Le programme affiche (vérifié en l'exécutant) :

Vous vous appelez John Doe et vous avez 35 ans.

a = int(input("Saisissez un nombre :"))
b = int(input("Saisissez un nombre :"))
res = a * b
print("Le produit de", a, "et", b, "vaut", res)

Combien y a-t-il de variables dans ce programme ? Coche tous leurs identifiants.

  • a
  • b
  • res
  • "vaut"
  • int
  • input

Regarde ce qui est à gauche de chaque signe =.

Trois variables : a, b et res.

L'utilisateur·rice saisit les nombres 2 et 24. Donne la valeur de chaque variable, ligne par ligne.

a = [[2]]                                # après la ligne 1
b = [[24]]                               # après la ligne 2
res = [[48]]                             # après la ligne 3

La ligne 3 multiplie a par b.

Le produit de 2 et 24 vaut 48

  • Il demande un nombre et affiche son carré.
  • Il affiche les deux nombres saisis, sans calcul.

4. Exercice chichoumeille : niveau 1

Voici le programme. Donne, ligne par ligne, la valeur de la variable qui change.

a = 3                    # a = [[3]]
b = a - 1                # b = [[2]]
c = b * a                # c = [[6]]
a = 12                   # a = [[12]]
a = 2 * a - (c * b)      # a = [[12]]

À la ligne 5, a vaut 12, c vaut 6 et b vaut 2 : on calcule la droite avec ces valeurs.

b = 3 - 1 = 2 ; c = 2 × 3 = 6 ; a = 12 ; puis a = 2 × 12 - (6 × 2) = 24 - 12 = 12. À la fin : a = 12, b = 2, c = 6 (vérifié en l'exécutant).

Combien y a-t-il de variables dans ce programme ?

Il y a 5 lignes, mais certaines changent une variable qui existe déjà.

Une variable qui reçoit une nouvelle valeur reste la même variable.

3 variables : a, b et c. a change de valeur trois fois, mais c'est toujours la même variable.

5. Exercice chichoumeille : niveau 2

Voici le programme. Donne, ligne par ligne, la valeur de la variable qui change.

a = 3                    # a = [[3]]
b = 6                    # b = [[6]]
c = b // a               # c = [[2]]
c = 2**c                 # c = [[4]]
b = c % a                # b = [[1]]

// est le quotient de la division entière ; % est son reste ; ** est la puissance.

Ligne 5 : 4 divisé par 3, combien reste-t-il ?

c = 6 // 3 = 2 ; puis c = 2² = 4 ; puis b = 4 % 3 = 1 (4 = 1 × 3 + 1). À la fin : a = 3, b = 1, c = 4 (vérifié en l'exécutant).

Combien y a-t-il de variables dans ce programme ?

Il y a 5 lignes, mais certaines changent une variable qui existe déjà.

Compte les noms différents à gauche des signes =.

3 variables : a, b et c.

6. Exercice chichoumeille : niveau 3

Voici le programme. Donne, ligne par ligne, la valeur de la variable qui change (True ou False pour un booléen).

a = 1                    # a = [[1]]
b = a > 0                # b = [[True|true|vrai|Vrai]]
a = (a+1)**2             # a = [[4]]
b = a <= 4               # b = [[True|true|vrai|Vrai]]
b = (a % 2) == 0         # b = [[True|true|vrai|Vrai]]

Ligne 3 : (1 + 1)² ; ligne 4 : 4 est-il inférieur ou égal à 4 ?

Ligne 5 : a % 2 est le reste de la division par 2. Il vaut 0 quand a est pair.

1 > 0 est vrai ; a = (1 + 1)² = 4 ; 4 <= 4 est vrai ; 4 % 2 vaut 0, donc (a % 2) == 0 est vrai. À la fin : a = 4, b = True (vérifié en l'exécutant).

Combien y a-t-il de variables dans ce programme ?

Compte les noms différents à gauche des signes =.

2 variables : a et b.

Quel est le type de la variable b ?

  • Un booléen (bool) : True ou False.
  • Un entier (int) : 1 si c'est vrai, 0 sinon.
  • Un texte (str) : le mot True ou False.
  • Un décimal (float), car on compare des nombres.

Que donne une comparaison comme 1 > 0 ?

b reçoit toujours le résultat d'une comparaison : c'est un booléen, qui vaut True ou False. a, lui, est un entier.

7. Exercice chichoumeille : hardcore

Voici le programme. Donne, ligne par ligne, la valeur de la variable qui change.

a = 15                   # a = [[15]]
b = (a % 3 + 1)**a       # b = [[1]]
c = (b * 5 // 3) >= 2    # c = [[False|false|faux|Faux]]
a = a + a / 2            # a = [[22.5|22,5]]
b = b % (b+1) - a        # b = [[-21.5|-21,5]]

Ligne 2 : 15 est un multiple de 3, donc 15 % 3 vaut 0. Et 1 à n'importe quelle puissance vaut 1.

Ligne 4 : la division / donne un décimal. Ligne 5 : 1 % 2 vaut 1.

b = (0 + 1)15 = 1 ; c : 1 × 5 // 3 = 1, et 1 >= 2 est faux, donc False ; a = 15 + 7.5 = 22.5 ; b = 1 % 2 - 22.5 = 1 - 22.5 = -21.5. À la fin : a = 22.5, b = -21.5, c = False (vérifié en l'exécutant).

Combien y a-t-il de variables dans ce programme ?

Compte les noms différents à gauche des signes =.

3 variables : a, b et c.

Mémo

Une variable a un identifiant (son nom) et une valeur, qui peut changer. Pour suivre un programme, on calcule la partie droite du = avec les valeurs du moment, puis on range le résultat à gauche.
