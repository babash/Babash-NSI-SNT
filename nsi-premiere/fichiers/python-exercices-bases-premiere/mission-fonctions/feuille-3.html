2. Protocoles de l'équipage : rédiger

La fonction calculer_carburant (simple). L'équipage doit prévoir le ravitaillement de ses vaisseaux. Chaque moteur consomme exactement 15 litres de carburant pour parcourir un parsec. Ta mission : créer une fonction qui, à partir d'une distance donnée, calcule le volume total de carburant nécessaire.

calculer_carburant. Quelles sont l'entrée et la sortie de la fonction ?

  • entrée : la distance (en parsecs) ; sortie : le volume de carburant (en litres)
  • entrée : le volume de carburant ; sortie : la distance
  • entrée : le nombre 15 ; sortie : la distance
  • entrée : la distance ; sortie : aucune, la fonction affiche le carburant

Qu'est-ce qu'on connaît au départ ? Qu'est-ce qu'on cherche ?

L'entrée est la distance à parcourir (en parsecs) ; la sortie est le volume de carburant nécessaire (en litres).

calculer_carburant. Explicite l'entrée et la sortie de la fonction.

Entrée : la distance à parcourir, en parsecs (un nombre). Sortie : le volume de carburant nécessaire, en litres (un nombre).

calculer_carburant. Si l'entrée est 10, quelle est la sortie ?

Tu as additionné. Chaque parsec coûte 15 litres : on multiplie.

15 litres pour 1 parsec : combien pour 10 parsecs ?

10 * 15 vaut 150 litres.

calculer_carburant. Donne une entrée pour laquelle la sortie est 30000.

Tu as multiplié la sortie par 15. Ici, on cherche la distance : on fait l'opération inverse.

On cherche la distance d telle que d × 15 = 30 000.

30000 / 15 vaut 2000 : pour 2000 parsecs, il faut 30 000 litres.

calculer_carburant. La logique : complète chaque case.

# Je commence par définir la fonction nommée [[calculer_carburant]].
# Cette fonction accepte un paramètre d'entrée appelé [[distance|d|parsecs|nb_parsecs]].
# À l'intérieur, je crée une variable locale appelée [[carburant|volume|litres|consommation]].
# Pour calculer sa valeur, je multiplie la distance reçue en entrée
# par le coefficient de consommation, qui est de [[15]].
# Enfin, j'utilise l'instruction [[return]] pour renvoyer la valeur
# contenue dans la variable [[carburant|volume|litres|consommation]].

Le nom de la fonction est dans le titre de l'exercice.

Pour le paramètre et la variable locale, choisis des noms qui disent ce qu'ils contiennent. La correction en ligne accepte distance (ou d) et carburant (ou volume, litres).

La logique décrit exactement cette fonction :

def calculer_carburant(distance):
    carburant = distance * 15
    return carburant

La fonction est_allie (simple). Pour éviter les tirs amis, les systèmes de défense doivent identifier les matricules des vaisseaux. Un vaisseau appartient à notre flotte si son matricule commence par les caractères "RX" ou "CZ". La fonction répond par vrai (True) ou faux (False).

est_allie. Quelles sont l'entrée et la sortie de la fonction ?

  • entrée : matricule, une chaîne (str) ; sortie : un booléen (bool)
  • entrée : matricule, une chaîne ; sortie : le texte "Vrai" ou "Faux"
  • entrée : matricule, un entier (int) ; sortie : un booléen
  • entrée : un booléen ; sortie : matricule, une chaîne

Un matricule comme RXD6 contient des lettres. La réponse est vrai ou faux.

Entrée : matricule, une chaîne de caractères. Sortie : un booléen, True ou False.

est_allie. Explicite l'entrée (la chaîne matricule) et la sortie (un booléen).

Entrée : matricule, une chaîne de caractères (par exemple "RXD6"). Sortie : un booléen, True si le matricule commence par "RX" ou "CZ", False sinon.

est_allie. Quelle est la sortie si l'entrée est "RXD6", puis si l'entrée est "D6F4" ?

  • True, puis False
  • False, puis False
  • True, puis True
  • False, puis True

Regarde seulement les deux premiers caractères de chaque matricule.

"RXD6" commence par "RX" : True. "D6F4" commence par "D6" : False.

est_allie. Quelle est la sortie si l'entrée est "RXD6", puis si l'entrée est "D6F4" ?

"RXD6" commence par "RX" : True. "D6F4" commence par "D6" : False.

est_allie. Quelle entrée donne la sortie True ?

  • "CZ81"
  • "XR12"
  • "cz81"
  • "A-RX5"

Le matricule doit commencer par RX ou CZ, en majuscules.

"CZ81" commence par "CZ" : la fonction renvoie True. Toute chaîne qui commence par RX ou CZ convient.

est_allie. Donne une entrée pour la sortie True.

Toute chaîne qui commence par RX ou CZ : par exemple "CZ81".

est_allie. Quelle entrée donne la sortie False ?

  • "ZC07"
  • "RX7"
  • "CZCZ"
  • "RX00"

Il faut un matricule qui ne commence ni par RX, ni par CZ.

"ZC07" commence par "ZC" : ni RX, ni CZ, donc False.

est_allie. Donne une entrée pour la sortie False.

Toute chaîne qui ne commence ni par RX, ni par CZ : par exemple "D6F4".

est_allie. La logique : complète chaque case.

# Je définis la fonction [[est_allie]] avec pour paramètre
# la variable [[matricule]].
# J'utilise une structure de condition [[if]] pour vérifier
# le début de la chaîne.
# Le test consiste à vérifier si les deux premiers caractères du
# matricule sont égaux à [["RX"|RX]] ou bien égaux à [["CZ"|CZ]].
# Si le test est positif, je renvoie immédiatement la valeur [[True]].
# Dans le cas contraire (sinon), je renvoie la valeur [[False]].

Les mots à écrire sont des mots de Python : le mot de la condition, et les deux valeurs d'un booléen.

Écris RX et CZ dans l'ordre de l'énoncé.

Fonction est_allie, paramètre matricule ; une structure if ; les deux premiers caractères comparés à "RX" puis à "CZ" ; True si le test est positif, False sinon.

est_allie. À toi de coder : écris la fonction complète. Les tests l'essaient avec plusieurs matricules quand tu lances ton programme.

def est_allie(matricule):
    # ta fonction ici
    pass

Les deux premiers caractères d'une chaîne : matricule[0:2].

Deux tests réunis par or : matricule[0:2] == "RX" or matricule[0:2] == "CZ".

La fonction doit renvoyer (return) True ou False, pas les afficher.

def est_allie(matricule):
    if matricule[0:2] == "RX" or matricule[0:2] == "CZ":
        return True
    else:
        return False

On peut aussi écrire return matricule[0:2] in ("RX", "CZ").
