Parcourir des listes

Exercices de base

Cours-quiz

Nom et prénom :Classe :

Objectif : écrire des scripts qui parcourent une liste, par valeur ou par indice, et une liste de listes.

Je sais :

  • parcourir une liste par valeur pour lire ses éléments ;
  • parcourir une liste par indice pour trouver une position ou modifier une case ;
  • trouver un maximum sans la fonction max ;
  • parcourir un tableau à deux dimensions avec deux boucles imbriquées.

55 minutes · 5 programmes à écrire · seul·e ou en binôme

Les petits rappels

  • Parcours par valeur (for x in L:) : c'est le plus simple. À utiliser quand on a juste besoin de « lire » les données, sans savoir où elles sont.
  • Parcours par indice (for i in range(len(L)):) : indispensable si on a besoin de l'indice (pour un affichage ou une recherche) ou si on doit modifier le contenu de la liste.
  • Pour « entrer » dans un tableau à deux dimensions, on utilise deux paires de crochets : salle[rangee][siege]. Par exemple, salle[0] donne la première liste, [1, 0, 1, 1], et salle[0][1] donne le deuxième élément de la première liste : 0.

1. Le grand classique : parcours par valeur

On dispose d'une liste notes contenant des nombres entiers. Écris un script qui calcule et affiche la moyenne de la liste. Contrainte : utilise une boucle for element in notes:. Pour la liste [10, 20, 15], le script doit afficher 15.0.

notes = [10, 20, 15]

15.0

Il te faut une variable somme qui commence à 0, et à laquelle tu ajoutes chaque element.

Après la boucle, la moyenne est somme / len(notes).

notes = [10, 20, 15]
somme = 0
for element in notes:
    somme = somme + element
print(somme / len(notes))

La division / donne toujours un nombre décimal : 45 / 3 s'affiche 15.0.

2. Parcours par indice

Recherche d'indice : écris un script qui affiche l'indice de la première occurrence de la variable cible dans une liste. Si l'élément n'est pas présent, le script doit afficher -1. Contrainte : utilise for i in range(len(liste)): et une variable cible. Exemple : la liste [10, 50, 20] avec une cible de 50 doit afficher 1.

liste = [10, 50, 20]
cible = 50

1

Une variable position commence à -1. Si liste[i] == cible et que tu n'as encore rien trouvé, elle prend la valeur i.

Pour garder la première occurrence, ne change position que si elle vaut encore -1. Affiche position après la boucle, une seule fois.

liste = [10, 50, 20]
cible = 50
position = -1
for i in range(len(liste)):
    if liste[i] == cible and position == -1:
        position = i
print(position)

On parcourt par indice, car c'est la position qu'on veut. Autre solution juste : break juste après position = i, pour quitter la boucle dès qu'on a trouvé.

Transformation : on veut doubler la valeur de chaque nombre d'une liste. Écris un script qui modifie la liste L, puis l'affiche. Rappel : pour modifier une liste, on accède aux cases par leurs indices : L[i] = …. Si L = [1, 2, 3], le script doit afficher [2, 4, 6].

L = [1, 2, 3]

[2, 4, 6]

Parcours par indice : for i in range(len(L)):.

Dans la boucle, la case L[i] reçoit le double de sa valeur : L[i] = L[i] * 2. Affiche L après la boucle.

L = [1, 2, 3]
for i in range(len(L)):
    L[i] = L[i] * 2
print(L)

Avec for x in L:, x = x * 2 changerait seulement la variable x, pas la liste : pour modifier, il faut l'indice.

3. Le maximum : parcours par valeur

Sans utiliser la fonction max(), écris un script qui parcourt la liste nombres et affiche le plus grand élément. Pour la liste de départ, [12, 5, 31, 8], il doit afficher 31.

nombres = [12, 5, 31, 8]

31

Indice : initialise une variable maximum avec le premier élément de la liste, puis compare-la avec les suivants.

Dans la boucle for x in nombres:, si x > maximum, alors maximum prend la valeur x.

nombres = [12, 5, 31, 8]
maximum = nombres[0]
for x in nombres:
    if x > maximum:
        maximum = x
print(maximum)

On commence avec nombres[0] et pas avec 0 : si tous les nombres étaient négatifs, 0 serait faux.

4. Le gestionnaire de cinéma

On représente une petite salle de cinéma par un tableau à deux dimensions nommé salle. Chaque sous-tableau est une rangée de sièges ; 0 signifie que le siège est libre, 1 qu'il est occupé.

salle = [
    [1, 0, 1, 1],  # Rangée 0
    [0, 0, 1, 0],  # Rangée 1
    [1, 1, 1, 1],  # Rangée 2
    [0, 0, 0, 0]   # Rangée 3
]

La mission : écris un script qui parcourt la salle et affiche le nombre total de sièges libres. Contraintes : deux boucles imbriquées (une boucle for à l'intérieur d'une autre) ; la première parcourt les rangées, la deuxième les sièges de chaque rangée.

salle = [
    [1, 0, 1, 1],  # Rangée 0
    [0, 0, 1, 0],  # Rangée 1
    [1, 1, 1, 1],  # Rangée 2
    [0, 0, 0, 0]   # Rangée 3
]

8

Une variable libres commence à 0. La première boucle : for rangee in salle: ; rangee est alors une liste.

La deuxième boucle, dans la première : for siege in rangee:. Si siege == 0, ajoute 1 à libres.

salle = [
    [1, 0, 1, 1],  # Rangée 0
    [0, 0, 1, 0],  # Rangée 1
    [1, 1, 1, 1],  # Rangée 2
    [0, 0, 0, 0]   # Rangée 3
]
libres = 0
for rangee in salle:
    for siege in rangee:
        if siege == 0:
            libres = libres + 1
print(libres)

Avec des indices, c'est aussi juste : for r in range(len(salle)):, puis for s in range(len(salle[r])):, et le test salle[r][s] == 0.

Mémo

Lire : for x in L:. Une position ou une modification : for i in range(len(L)): et L[i]. Un tableau à deux dimensions : deux boucles imbriquées et salle[r][s].
