On veut compter les points d'un jeu de dés. On lance 3 dés, et on compte les points ainsi :

  • 3 dés différents : on marque la somme des dés ;
  • 3 dés identiques : on marque 30 points ;
  • 2 dés identiques : on marque 20 points.

1. Test des 2 dés identiques

Le programme :

from random import randint
# randint(1,6) tire au hasard une valeur entière comprise entre 1 et 6
de1 = randint(1,6)
de2 = randint(1,6)
de3 = randint(1,6)
score = 0
if de1 == de2 :
    score = 20
    print("Vous marquez ",score," points")
elif de1 == de3 :
    score = 20
    print("Vous marquez ",score," points")
elif de2 == de3 :
    score = 20
    print("Vous marquez ",score," points")
else :
    print("Vous n'avez pas eu 2 dés identiques")

Quel opérateur de comparaison est utilisé ? Que compare-t-il ?

  • == : il compare deux dés à la fois.
  • == : il compare les trois dés à la fois.
  • != : il teste si deux dés sont différents.
  • elif : il compare les dés.

2. Un seul programme pour le score

On veut un seul programme qui affiche le bon score, quel que soit le lancer. Voici une proposition :

from random import randint
# randint(1,6) tire au hasard une valeur entière comprise entre 1 et 6
de1 = randint(1,6)
de2 = randint(1,6)
de3 = randint(1,6)
score = 0
if de1 != de2 != de3 :
    score = de1+de2+de3
elif de1 == de2 :
    score = 20
elif de1 == de3 :
    score = 20
elif de2 == de3 :
    score = 20
elif de1 == de2 == de3 :
    score = 30
print("Vous marquez ",score," points")

3 != 6 != 4 est vrai : le score vaut 3 + 6 + 4 = 13.

Avec de1 = 3, de2 = 4 et de3 = 4, qu'affiche le programme ? (Sur papier, fais aussi le tableau des variables.)

Remplace les dés par leurs valeurs, puis teste les conditions dans l'ordre.

3 != 4 != 4 : 4 != 4 est faux, donc tout est faux. Puis de2 == de3 : 20.

Avec de1 = 4, de2 = 4 et de3 = 4, qu'affiche le programme ? (Sur papier, fais aussi le tableau des variables.)

Les tests se font dans l'ordre : de1 == de2 est vrai avant.

Le premier test est faux ; de1 == de2 est vrai : 20. La dernière branche (30) n'est jamais atteinte.

  • Oui : 20 est le bon score.
  • Non : il faut remplacer tous les elif par des if.
  • Non : il faut supprimer la ligne print.

Dès qu'une condition est vraie, Python saute les suivantes. Quel test doit passer en premier ?

On place de1 == de2 == de3 (et score = 30) en premier : if de1 == de2 == de3 :, puis elif de1 != de2 != de3 :…

Attention : de1 != de2 != de3 ne compare pas de1 et de3. Avec 3, 4, 3, ce programme donne 10 au lieu de 20. Le test sûr : de1 != de2 and de2 != de3 and de1 != de3.

Mémo

Dans une suite if … elif … else, seule la première condition vraie compte : le cas le plus particulier se teste en premier.
