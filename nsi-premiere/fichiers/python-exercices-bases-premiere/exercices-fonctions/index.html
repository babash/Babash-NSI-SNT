1. Appréhendez une définition de fonction

def compteur3():
    i = 0
    while i < 3:
        print(i)
        i = i + 1

def double_compteur3():
    compteur3()
    compteur3()

def compteur(stop):
    i = 0
    while i < stop:
        print(i)
        i = i + 1

def compteur_complet(start, stop, step):
    i = start
    while i < stop:
        print(i)
        i = i + step

def calcule_cube(a):
    cube = a * a * a # ou bien a**3
    return cube

def somme_produit(a,b):
    """Calcule la somme et le produit de deux nombres"""
    s = a + b
    p = a * b
    return s, p

Pour chaque fonction, écris le nom de ses paramètres, séparés par des virgules (écris aucun s'il n'y en a pas).

# compteur3          paramètres : [[aucun|aucune|-|rien|0|None]]
# double_compteur3   paramètres : [[aucun|aucune|-|rien|0|None]]
# compteur           paramètres : [[stop]]
# compteur_complet   paramètres : [[start, stop, step]]
# calcule_cube       paramètres : [[a]]
# somme_produit      paramètres : [[a, b]]

Les paramètres s'écrivent entre les parenthèses, sur la ligne def.

Des parenthèses vides () : aucun paramètre.

compteur3 et double_compteur3 : aucun paramètre ; compteur : 1 (stop) ; compteur_complet : 3 (start, stop, step) ; calcule_cube : 1 (a) ; somme_produit : 2 (a, b).

Pour chaque fonction, écris ses variables locales (aucune s'il n'y en a pas), puis le nombre de valeurs qu'elle renvoie.

# compteur3          locales : [[i]]  renvoie [[0|aucune|aucun|zéro]] valeur(s)
# double_compteur3   locales : [[aucune|aucun|-|rien|0|None]]  renvoie [[0|aucune|aucun|zéro]] valeur(s)
# compteur           locales : [[i]]  renvoie [[0|aucune|aucun|zéro]] valeur(s)
# compteur_complet   locales : [[i]]  renvoie [[0|aucune|aucun|zéro]] valeur(s)
# calcule_cube       locales : [[cube]]  renvoie [[1|une|un]] valeur(s)
# somme_produit      locales : [[s, p|p, s]]  renvoie [[2|deux]] valeur(s)

Une variable locale reçoit une valeur dans la fonction, avec =. Les paramètres ne comptent pas.

Compte les valeurs écrites après return. Sans return, la fonction ne renvoie rien d'utile (Python renvoie None).

Les quatre compteurs ne renvoient rien : ils affichent avec print. i est leur variable locale (double_compteur3 n'en a pas : elle appelle seulement compteur3). calcule_cube renvoie 1 valeur (cube) ; somme_produit en renvoie 2 (s et p).

Coche les appels justes : chacun donne les bons arguments et garde les éventuelles valeurs renvoyées dans des variables.

  • c = calcule_cube(3)
  • s, p = somme_produit(2, 5)
  • compteur_complet(0, 10, 2)
  • compteur(5)
  • cube = calcule_cube()
  • s = somme_produit(2)
  • compteur3(3)
  • compteur_complet(0, 10)

Un appel donne autant d'arguments que la fonction a de paramètres.

Une fonction qui renvoie deux valeurs se range dans deux variables : x, y = ….

Les quatre premiers appels sont justes (vérifié en les exécutant). Les compteurs ne renvoient rien : on les appelle sans variable. Les quatre autres provoquent une TypeError : un argument manque ou est en trop.

2. Il y a un truc qui cloche

Pour chacun des codes suivants, découvre ce qui cloche dans la définition ou dans l'appel de la fonction.

Ce programme s'arrête avec une erreur. Quelle ligne faut-il corriger ?

def aire_carre(longueur):
    return longueur**2

aire = aire_carre()
print("L'aire du carre est de", aire, "m²")
Traceback (most recent call last):
  File "aire.py", line 4, in <module>
    aire = aire_carre()
TypeError: aire_carre() missing 1 required positional argument: 'longueur'

missing 1 required positional argument : « il manque 1 argument obligatoire ».

Ligne 4 : la fonction attend une longueur, mais l'appel n'en donne pas. Par exemple : aire = aire_carre(5).

Ce programme se lance, mais il affiche 48, puis Le perimetre du carre est None m. Qu'est-ce qui cloche ?

def perimetre_carre(longueur):
    print(4*longueur)

perimetre = perimetre_carre(12)
print("Le perimetre du carre est", perimetre, "m")
  • La fonction affiche le résultat avec print au lieu de le renvoyer avec return.
  • La formule du périmètre est fausse.
  • Il manque un argument dans l'appel.
  • La dernière ligne affiche mal le texte.

None veut dire « rien » : la fonction n'a rien renvoyé.

La fonction affiche 48 mais ne renvoie rien : perimetre reçoit None. Il faut écrire return 4*longueur à la ligne 2 (sortie vérifiée en l'exécutant).

Ce programme ne se lance pas. Trouve la ligne, puis écris-la corrigée.

def quotient(x,y)
    return x/y

print(quotient(1.7,2.5))
  File "quotient.py", line 1
    def quotient(x,y)
                     ^
SyntaxError: expected ':'

expected ':' : « deux-points attendus ».

Ligne 1 : une ligne def se termine par deux-points : def quotient(x,y):.

Ce programme se lance sans erreur, mais il n'affiche rien. Pourquoi ?

def aire_triangle_rectangle(base,hauteur):
    return base*hauteur/2

aire_triangle_rectangle(1.7,2.5)
  • La valeur renvoyée n'est ni affichée ni gardée dans une variable.
  • La fonction ne renvoie rien.
  • Les nombres décimaux sont mal écrits.
  • La formule de l'aire est fausse.

return renvoie une valeur à l'appel, mais ne l'affiche pas.

La fonction renvoie l'aire, mais personne ne l'utilise. Il faut l'afficher, print(aire_triangle_rectangle(1.7, 2.5)), ou la garder : aire = aire_triangle_rectangle(1.7, 2.5).

Ce programme s'arrête avec une erreur. Quelle ligne provoque l'erreur ?

def distance_euclidienne(x1, x2, y1, y2):
    dx = (x1-x2)
    dy = (y1-y2)
    distance = math.sqrt(dx**2 + dy**2)

x1, y1, x2, y2 = 1, 2, 5, 7
distance = distance_euclidienne(x1, x2, y1, y2)
print(f"La distance euclidienne entre ({x1}, {y1}) et ({x2}, {y2}) "
      f"est {distance} m")
Traceback (most recent call last):
  File "distance.py", line 7, in <module>
    distance = distance_euclidienne(x1, x2, y1, y2)
  File "distance.py", line 4, in distance_euclidienne
    distance = math.sqrt(dx**2 + dy**2)
               ^^^^
NameError: name 'math' is not defined. Did you forget to import 'math'?

Le message cite deux lignes : la 7 (l'appel), puis la 4 (dans la fonction). L'erreur se produit à la dernière citée.

Did you forget to import 'math'? : « As-tu oublié d'importer math ? »

Ligne 4 : math n'est pas importé. On ajoute import math au début du programme (ou on écrit (dx**2 + dy**2)**0.5). Attention : ce n'est pas le seul problème, voir la question suivante.

On ajoute import math au début du programme précédent. Il affiche alors : La distance euclidienne entre (1, 2) et (5, 7) est None m. Qu'est-ce qui cloche encore ?

  • La fonction calcule distance mais ne la renvoie pas : il manque return distance.
  • Les arguments de l'appel sont dans le mauvais ordre.
  • La racine carrée est mal calculée.
  • La f-string est mal écrite.

None : la fonction n'a rien renvoyé. Cherche le mot return dans la fonction.

La variable distance de la fonction est locale : elle disparaît à la fin de l'appel. Sans return distance, l'appel vaut None (sortie vérifiée en l'exécutant).

La suite : feuille 2 sur 3 (encore trois trucs qui clochent, puis prévoir la sortie), et feuille 3 sur 3 (compléter puis écrire des fonctions).

Mémo

Une fonction a un nom, des paramètres (entre parenthèses) et peut renvoyer des valeurs avec return. print affiche mais ne renvoie rien : l'appel vaut alors None.
