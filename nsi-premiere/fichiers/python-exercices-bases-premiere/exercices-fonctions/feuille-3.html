4. Les fonctions à trous

Complète les codes ci-dessous. Une ligne d'appel, à la fin de chaque code, permet de vérifier.

def pair_entre_deux_nombres([[a, b]]):

        if [[i % 2 == 0|i % 2 != 1|0 == i % 2|not i % 2]]:

La boucle utilise a et b : ce sont les paramètres.

Un nombre est pair quand le reste de sa division par 2 vaut 0 : i % 2 == 0.

def pair_entre_deux_nombres(a, b):
    for i in range(a, b):
        if i % 2 == 0:
            print(i)

L'appel pair_entre_deux_nombres(3, 10) affiche 4, 6 et 8 (vérifié en l'exécutant).

def factorielle(x): # 1 * 2 * ... * x-1 * x
    produit = [[1]]
    for i in range([[1|2]], [[x + 1|x+1]]):
        produit = produit * [[i]]

produit commence à 1 : multiplier par 1 ne change rien (avec 0, tout vaudrait 0).

range(1, x + 1) donne 1, 2, …, x : la fin est exclue.

def factorielle(x): # 1 * 2 * ... * x-1 * x
    produit = 1
    for i in range(1, x + 1):
        produit = produit * i
    return produit

factorielle(5) vaut 1 × 2 × 3 × 4 × 5 = 120 (vérifié en l'exécutant).

La fonction échange les valeurs de x et y.

def inverser(x, y):
    temp = x
    x = [[y]]
    y = [[temp]]
    return [[x, y|(x, y)]]

print(inverser(3, 8))
(8, 3)

temp garde l'ancienne valeur de x, avant qu'on la remplace.

def inverser(x, y):
    temp = x
    x = y
    y = temp
    return x, y

inverser(3, 8) renvoie (8, 3) (vérifié en l'exécutant).

La fonction renvoie la plus grande des trois valeurs.

def maximum(a, b, c):
    if a > b :
        [[if c > a :|if a < c :|if c >= a :]]
            return c
        else :
            return [[a]]
    else :
        if c > b :
            return [[c]]
        [[else :]]
            return b

print(maximum(4, 9, 7), maximum(8, 2, 5), maximum(1, 2, 3))
9 8 3

Si a > b, le maximum est a ou c : il reste à les comparer.

Le mot qui va avec if et qui n'a pas de condition : else :.

def maximum(a, b, c):
    if a > b :
        if c > a :
            return c
        else :
            return a
    else :
        if c > b :
            return c
        else :
            return b

L'appel affiche 9 8 3 (vérifié en l'exécutant).

Code une fonction plus_grand qui renvoie la plus grande de deux valeurs entières données en paramètres. Exemple d'appel : plus_grand(2, 3) vaut 3.

def plus_grand(a, b):
    pass  # remplace pass par ton code

print(plus_grand(2, 3))

3

Avec if a > b:, renvoie a ; sinon, renvoie b.

Pense à return : print afficherait la valeur sans la renvoyer.

def plus_grand(a, b):
    if a > b:
        return a
    else:
        return b

print(plus_grand(2, 3))

Une boucle for i in range(n): fait n tours.

def repete(mot, n):
    for i in range(n):
        print(mot)

repete("Tartuffe", 3)

Mémo

Une fonction se définit avec def nom(paramètres): et renvoie ses résultats avec return. Pour l'utiliser, on l'appelle avec autant d'arguments que de paramètres.
