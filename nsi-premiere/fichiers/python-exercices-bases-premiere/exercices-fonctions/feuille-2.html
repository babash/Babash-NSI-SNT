2. Il y a un truc qui cloche (suite)

Ce programme s'arrête avec une erreur. Trouve la ligne, puis écris-la corrigée.

import random

def de():
    tirage = random.randrange(1, 6)
    return tirage

print("Les trois des sont :", DE(), DE(), "et", DE())
Traceback (most recent call last):
  File "de.py", line 7, in <module>
    print("Les trois des sont :", DE(), DE(), "et", DE())
                                  ^^
NameError: name 'DE' is not defined. Did you mean: 'de'?

Did you mean: 'de'? : « Voulais-tu dire de ? » Python distingue majuscules et minuscules.

Ligne 7 : la fonction s'appelle de, en minuscules : print("Les trois des sont :", de(), de(), "et", de()).

Autre chose cloche : random.randrange(1, 6) donne un entier de 1 à 5 (6 est exclu, vérifié en l'exécutant). Pour un dé, il faut random.randrange(1, 7).

Ce programme ne se lance pas. Quelle ligne faut-il corriger ?

def volume_pave(l, l, h):
    return l * l * h

print(volume_pave(2, 72, 10))
  File "volume.py", line 1
SyntaxError: duplicate argument 'l' in function definition

duplicate argument 'l' : « paramètre l en double ».

Ligne 1 : deux paramètres ne peuvent pas avoir le même nom. Par exemple def volume_pave(longueur, largeur, h):, puis return longueur * largeur * h.

Ce programme s'arrête avec une erreur. Quelle ligne faut-il corriger ?

def n_print(s, n):

def est_premier(num):
    if num > 2 and num % 2 == 0:
        return False
    for x in range(2, num // 2):
        if num % x == 0:
            return False
    return True

def premiers(x):
    for i in range(2, x+1):
        if est_premier(i):
            print(i)

est_premier(num) renvoie True quand num n'a aucun diviseur autre que 1 et lui-même : c'est un nombre premier.

premiers(22) teste les nombres de 2 à 22 et affiche ceux qui sont premiers.

Les nombres premiers jusqu'à 22 : 2, 3, 5, 7, 11, 13, 17 et 19, un par ligne (vérifié en l'exécutant).

def f(x, y, z):
    return x + y, x + z, y + z

def g(x, y):
    if x > 10 :
        return 1/y, x/y
    else :
        return 1/x, y/x

def combo(x, y, z):
    a, b, c = f(x, y, z)
    d, e = g(z, x)
    u, v, w = f(a, b, e**2)
    return v - w, b - a

print(f"combo(4, 9, 2) = {combo(4 ,9 ,2)}")
combo(4, 9, 2) = (7.0, -7)

Avance pas à pas : f(4, 9, 2) renvoie (13, 6, 11), donc a = 13, b = 6, c = 11.

g(2, 4) : 2 n'est pas plus grand que 10, donc on renvoie 1/2, 4/2, soit 0.5, 2.0. La division / donne des décimaux.

a, b, c = 13, 6, 11 ; d, e = 0.5, 2.0 ; f(13, 6, 4.0) donne 19, 17.0, 10.0, donc v = 17.0 et w = 10.0. La fonction renvoie (17.0 - 10.0, 6 - 13), soit (7.0, -7) (vérifié en l'exécutant).

def triangle(c, x):
    for i in range(1, x):
        print(c * i)
    for i in range(x, 1, -1):
        print(c * i)

def pixel_art(n):
    for i in range(1, n, 2):
        triangle("=", i)

"=" * 3 vaut "===". pixel_art(7) appelle triangle avec i = 1, 3, puis 5.

triangle("=", 1) n'affiche rien : range(1, 1) et range(1, 1, -1) sont vides.

triangle("=", 3) affiche =, == (montée), puis ===, == (descente) ; triangle("=", 5) affiche de 1 à 4 signes, puis de 5 à 2. En tout, 12 lignes (vérifié en l'exécutant).

Mémo

return renvoie une valeur à l'appel ; print l'affiche seulement. Pour prévoir une sortie, suis chaque appel de fonction, pas à pas.
