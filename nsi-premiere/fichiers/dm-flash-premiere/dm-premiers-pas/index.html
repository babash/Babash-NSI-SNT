1. Les outils de base

Quelle fonction permet d'afficher du texte à l'utilisateur·rice en Python ?

input fait l'inverse : elle lit ce que l'utilisateur·rice tape.

En anglais, « imprimer » se dit print.

print affiche à l'écran : print("Bonjour").

Quelle fonction permet de récupérer une saisie de l'utilisateur·rice en Python ?

print affiche ; ici, on veut lire ce qui est tapé au clavier.

En anglais, « entrée » se dit input.

input attend que l'utilisateur·rice tape quelque chose, puis renvoie ce texte : nom = input("Ton prénom ? ").

À quoi servent les commentaires en programmation ?

  • À expliquer le code aux humains qui le lisent.
  • À afficher un message à l'écran.
  • À rendre le programme plus rapide.
  • À demander une valeur à l'utilisateur·rice.

Python saute les commentaires sans les exécuter. Pour qui sont-ils écrits, alors ?

Un commentaire explique le code à la personne qui le lit (toi dans un mois, ou un·e camarade). Python ne l'exécute pas.

À quoi servent les commentaires en programmation ?

Avec quel symbole commence un commentaire en Python ? Écris ce seul symbole.

C'est le symbole de commentaire d'autres langages (JavaScript, C…). En Python, c'en est un autre.

C'est le symbole qu'on appelle aussi « dièse » ou « hashtag ».

Le symbole # : tout ce qui le suit, sur la ligne, est un commentaire. Exemple : # calcul de l'IMC.

2. Un programme qui calcule l'IMC

Voici un programme qui calcule l'indice de masse corporelle (IMC) :

poids = float(input("Saisissez votre poids (en kg)"))
taille = float(input("Saisissez votre taille (en m)"))
imc = poids/(taille**2)
print("Votre Indice de Masse Corporelle est de", imc)

Que permet de faire la première ligne de ce programme ?

  • Demander le poids, le convertir en décimal et le ranger dans poids.
  • Afficher le poids de l'utilisateur·rice avec print, sans rien calculer.
  • Calculer l'IMC à partir du poids et de la taille saisis.
  • Afficher la question, sans rien garder de la réponse tapée au clavier.

Lis la ligne de l'intérieur vers l'extérieur : d'abord input(…), puis float(…), puis poids = ….

input affiche la question et lit ce qui est tapé ; float transforme ce texte en nombre décimal ; poids = range ce nombre dans la variable poids.

Pourquoi est-il nécessaire d'utiliser la fonction float ?

  • Pour calculer : input renvoie un texte, float en fait un nombre décimal.
  • Pour arrondir le résultat de l'IMC au dixième près avec float.
  • Pour que la saisie s'affiche : sans float, input n'affiche rien.
  • Pour transformer la saisie en nombre entier, comme le ferait int.

Que renvoie input : un nombre ou un texte ?

Une taille comme 1.80 a une virgule (un point en Python) : ce n'est pas un entier.

input renvoie un texte (type str), par exemple "1.80". On ne peut pas calculer avec un texte : float("1.80") donne le nombre décimal 1.8. On prend float et non int, car le poids et la taille peuvent avoir une partie décimale.

Que signifie la double étoile ** dans taille**2 ?

  • La puissance : taille**2 est la taille au carré.
  • Une multiplication par 2 : taille**2 est le double de la taille.
  • Le début d'un commentaire, comme le signe #.
  • Une division : taille**2 est la moitié de la taille.

L'IMC se calcule avec le poids divisé par la taille au carré.

** est l'opérateur puissance : 2**3 vaut 8, et taille**2 vaut taille * taille.

Qu'affiche la dernière ligne du programme si l'utilisateur·rice tape 83 puis 1.80 ?

C'est bien environ 25,6 ! Mais Python n'arrondit pas : il affiche tous les chiffres du résultat.

Python remplace la variable par sa valeur : calcule le nombre affiché.

Calcule d'abord 1.80**2, puis divise 83 par ce nombre.

1.80**2 vaut 3.24. Avec une calculatrice, fais 83 ÷ 3,24 et écris tous les chiffres.

taille**2 vaut 3.24, et 83 / 3.24 donne 25.61728395061728. Python affiche (vérifié en l'exécutant) :

Votre Indice de Masse Corporelle est de 25.61728395061728

Python n'arrondit pas tout seul. Pour arrondir, on écrirait round(imc, 1).

Mémo

print affiche, input lit une saisie (toujours un texte), float et int la transforment en nombre ; # commence un commentaire, ** est la puissance.
