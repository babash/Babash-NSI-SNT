1. Boucles imbriquées

Voici un programme avec une boucle for à l'intérieur d'une autre :

x = int(input("Saisissez un nombre entier :"))
acc = 0
for i in range(x):
    for j in range(i):
        acc = (i-j)**2
print(f"Le total vaut {acc}")

Coche toutes les variables de ce programme.

  • x
  • acc
  • i
  • j
  • input
  • range

Une variable reçoit une valeur : avec =, ou comme variable de boucle après for.

Quatre variables : x et acc (reçoivent une valeur avec =), i et j (variables des boucles). input et range sont des fonctions.

Quel est le type de ces quatre variables ?

  • Entier (int)
  • Texte (str)
  • Décimal (float)
  • Booléen (bool)

Regarde la fonction qui entoure input à la ligne 1, et les valeurs que donne range.

Toutes sont des entiers (int) : int(input(…)) transforme la saisie en entier, range donne des entiers, et (i-j)**2 est un entier.

Donne les variables de ce programme et leurs types.

Tableau d'avancement pour la saisie x = 2 : chaque ligne ci-dessous est une étape où une variable change (le commentaire donne la ligne du programme). Complète les valeurs.

x = [[2]]                        # ligne 1
acc = [[0]]                      # ligne 2
i = [[0]]                        # ligne 3, premier tour
i = [[1]]                        # ligne 3, deuxième tour
j = [[0]]                        # ligne 4
acc = [[1]]                      # ligne 5
print(f"Le total vaut {acc}")    # ligne 6
Le total vaut 1

range(2) donne 0 puis 1 : ce sont les valeurs de i.

Quand i vaut 0, range(0) est vide : la boucle sur j ne fait aucun tour. Quand i vaut 1, j prend la seule valeur 0.

x vaut 2 et acc vaut 0. Premier tour : i vaut 0 et range(0) est vide, donc la ligne 5 n'est pas exécutée. Deuxième tour : i vaut 1, j vaut 0, et acc = (1-0)**2 vaut 1. La ligne 6 affiche « Le total vaut 1 ».

Pour comprendre la ligne 6 et les f-strings (le f devant les guillemets), une vidéo : youtube.com/watch?v=RgzX4qrLmPM.

Qu'affichera le programme pour chacune de ces saisies ? Complète.

# x = 5   : Le total vaut [[1]]
# x = 12  : Le total vaut [[1]]
# x = 120 : Le total vaut [[1]]
# x = -1  : Le total vaut [[0]]

Regarde bien la ligne 5 : acc = … remplace la valeur de acc, elle n'ajoute rien. Seul compte le dernier passage.

Au dernier passage, i vaut x - 1 et j vaut i - 1. Que vaut alors i - j ? Et pour x = -1, range(-1) fait-il des tours ?

À la ligne 5, acc est remplacé à chaque passage (=), pas augmenté. Au dernier passage, i - j vaut 1, donc acc vaut 1 pour 5, 12 et 120. Pour x = -1, range(-1) est vide : acc garde sa valeur 0.

Malgré son message « Le total vaut », ce programme ne fait pas de total : pour additionner, il faudrait acc = acc + (i-j)**2.

2. La factorielle

La factorielle d'un nombre x est le produit de tous les entiers de 1 à x. Par exemple, la factorielle de 5, notée 5!, vaut 5 × 4 × 3 × 2 × 1. Écris un programme qui calcule et affiche la factorielle de x, pour n'importe quel entier x.

Sur papier, utilise input pour lire x. En ligne, on ne peut pas saisir : la première ligne donne x = 5 ; change-la ensuite pour essayer d'autres valeurs.

x = 5

120

Une variable fact commence à 1 (et pas à 0 : tout produit par 0 vaut 0).

Une boucle for k in range(1, x + 1): donne 1, 2, …, x. À chaque tour, multiplie fact par k.

x = 5
fact = 1
for k in range(1, x + 1):
    fact = fact * k
print(fact)

Sur papier, la première ligne devient x = int(input("Saisissez un nombre entier :")). Pour 5, le programme affiche 120.

Mémo

Dans deux boucles imbriquées, la boucle intérieure fait tous ses tours à chaque tour de la boucle extérieure. range(0) ne fait aucun tour. acc = … remplace une valeur ; acc = acc + … l'accumule.
