1. Variables et opérations

Dans les questions 1 et 2, assert vérifie qu'une égalité est vraie : si ta réponse est juste, Python n'affiche rien.

Quelle est la valeur finale de la variable c ? Quel est son type ?

a = 5
b = 2
c = a / b
a = a + 1
c = c * a
assert c == [[15.0|15.|15]]
assert type(c) == [[float]]

En Python, la division / donne toujours un nombre à virgule : 5 / 2 vaut 2.5.

Ligne 4, a passe à 6. Ligne 5, on multiplie 2.5 par 6.

c vaut 5 / 2 = 2.5 (type float), puis a vaut 6, puis c vaut 2.5 × 6 = 15.0, de type float (un nombre à virgule fois un entier donne un nombre à virgule).

Après l'exécution de ce code, quelle est la valeur finale de la variable y ? Quel est son type ?

x = 5
y = 2
x = (x + 1) * y
y = x % 5  # opérateur modulo
assert y == [[2]]
assert type(y) == [[int]]

x % 5 donne le reste de la division entière de x par 5.

Ligne 3 : x vaut (5 + 1) × 2 = 12.

x vaut (5 + 1) × 2 = 12. Puis 12 = 5 × 2 + 2 : le reste est 2. y est de type int (entier).

2. Conditions (if / else)

Soient A = 10 et B = 5. Évalue l'expression suivante, en tenant compte de la priorité des opérateurs (ET avant OU) :
(A < B) OU ((A + B) > 12) ET (B ≥ 5)

  • VRAI
  • FAUX
  • Une erreur de syntaxe
  • Cela dépend du langage

Remplace d'abord chaque comparaison par VRAI ou FAUX.

On obtient FAUX OU VRAI ET VRAI. Calcule le ET en premier.

(10 < 5) est FAUX ; (15 > 12) est VRAI ; (5 ≥ 5) est VRAI. Le ET d'abord : VRAI ET VRAI = VRAI. Puis FAUX OU VRAI = VRAI.

Quelle est la valeur finale de la variable resultat si la variable age vaut 17 ?

if age < 13:
    resultat = "Enfant"
elif age >= 18:
    resultat = "Adulte"
else:
    resultat = "Adolescent"

17 >= 18 est faux : on ne rentre pas dans le elif.

Teste les conditions dans l'ordre : 17 < 13 ? 17 >= 18 ?

17 < 13 est faux, 17 >= 18 est faux : on exécute le else. resultat vaut "Adolescent".

Quel est le message obtenu avec temp = 25 et pluie = True ?

if temp > 20:
    if pluie:
        message = "Journée fraîche et pluvieuse"
    else:
        message = "Journée ensoleillée"
else:
    message = "Journée froide"

Le else de la ligne 4 sert quand pluie est faux. Ici, pluie vaut True.

Le deuxième if est dans le premier : on ne le teste que si temp > 20.

25 > 20 est vrai, on entre dans le premier bloc ; pluie est vrai : "Journée fraîche et pluvieuse".

Quelles conditions vérifient que x n'est pas dans l'intervalle fermé [10 ; 20] (c'est-à-dire x < 10 ou x > 20) ?

  • x > 10 and x < 20
  • x >= 10 or x <= 20
  • x < 10 or x > 20
  • not (x >= 10 and x <= 20)

Essaie chaque condition avec x = 15 (dans l'intervalle) et x = 25 (dehors).

« Ne pas être dans l'intervalle », c'est le contraire (not) de « être dans l'intervalle ».

Deux conditions sont justes : x < 10 or x > 20 et not (x >= 10 and x <= 20). Elles disent la même chose : le contraire d'un ET est le OU des contraires.

3. Boucles (for / while)

Quelle est la valeur finale de la variable somme ?

somme = 0
# range(1, 5) génère les nombres 1, 2, 3, 4
for i in range(1, 5):
    somme = somme + i

5 n'est pas compris : range(1, 5) s'arrête à 4.

Note la valeur de somme après chaque tour : 1, puis 1 + 2…

0 + 1 + 2 + 3 + 4 = 10.

Combien de fois le corps de la boucle while est-il exécuté ?

compteur = 0
a = 1
while a <= 5:
    a = a + 2
    compteur = compteur + 1

Suis a : 1, 3, 5, puis 7. Compte les tours où la condition est vraie.

Écris les valeurs de a au début de chaque tour, et teste a <= 5.

a vaut 1, 3, puis 5 : trois tours. Ensuite a vaut 7 et 7 <= 5 est faux. Le corps est exécuté 3 fois (compteur vaut 3).

Quel bloc de code, placé dans la boucle, donne une boucle infinie ?

  • i = 10
while i > 0:
    i = i - 1
  • i = 10
while i > 0:
    i = i + 1
  • i = 10
while i > 0:
    i = i - 3
  • i = 10
while i > 0:
    i = i // 2

Pour chaque bloc, demande-toi : i finit-il par être inférieur ou égal à 0 ?

Avec i = i + 1, i vaut 11, 12, 13… : il reste toujours positif, la condition i > 0 reste vraie et la boucle ne s'arrête jamais.

Quel bloc de code, placé dans la boucle (à la place de # BLOC DE CODE), donne une boucle infinie ?

i = 10
while i > 0:
    # BLOC DE CODE

Combien de fois le message « OK » est-il affiché ?

# range(1, 11) génère les nombres 1, 2, ..., 10
for k in range(1, 11):
    if k % 3 == 0:
        print("OK")

Le print est dans le if : il ne s'exécute que pour certains k.

k % 3 == 0 est vrai quand k est un multiple de 3.

Les multiples de 3 entre 1 et 10 sont 3, 6 et 9 : « OK » s'affiche 3 fois.

4. En autonomie (ou presque) : le calcul des points

Une équipe de sport joue une série de 5 matchs. On calcule son total de points en demandant le résultat de chaque match : victoire (V) : +3 points ; nul (N) : +1 point ; défaite (D) : +0 point. Bonus : si l'équipe a au moins 7 points à la fin de la série, elle reçoit 1 point de plus.

Étape 1. Crée une variable score_total qui vaut 0, et une variable match_actuel qui vaut 1 (le numéro du match en cours). Étape 2. Avec une boucle while, traite exactement 5 matchs : la boucle continue tant que match_actuel est inférieur ou égal à 5. Étape 3. Dans la boucle : demande le résultat (V, N ou D) du match, mets à jour score_total avec if, elif, else, puis augmente match_actuel de 1 (sinon, la boucle est infinie). Étape 4. Après la boucle, applique le bonus, puis affiche le total.

Écris le programme. À la fin, il affiche le total avec print("Score total :", score_total). En ligne, la page fait lire à input() les résultats V, N, D, V, V.


    
    
Score total : 11

    
    
Le squelette : while match_actuel <= 5:, puis dans le bloc resultat = input("Résultat du match : ").

    
Dans la boucle : if resultat == "V": ajoute 3, elif resultat == "N": ajoute 1. N'oublie pas match_actuel = match_actuel + 1.

    
Après la boucle (sans indentation) : if score_total >= 7: ajoute 1.

    

      
score_total = 0
match_actuel = 1
while match_actuel <= 5:
    resultat = input("Résultat (V, N ou D) : ")
    if resultat == "V":
        score_total = score_total + 3
    elif resultat == "N":
        score_total = score_total + 1
    else:
        score_total = score_total + 0
    match_actuel = match_actuel + 1
if score_total >= 7:
    score_total = score_total + 1
print("Score total :", score_total)

      
Avec V, N, D, V, V : 3 + 1 + 0 + 3 + 3 = 10 points ; 10 ≥ 7, donc le bonus donne 11. La ligne else peut s'omettre : une défaite n'ajoute rien.

    

  


  
5. Conversions de bases

  
Sur papier, justifie chaque conversion par un calcul. Les lignes se lisent comme à la partie 1 : 0b annonce un nombre en binaire, 0x un nombre en hexadécimal. Rappel : A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.


  

    
Partie A : convertis entre la base 2 et la base 10.

    
assert 0b10110 == [[22]]
assert 0b111111 == [[63]]
assert 45 == 0b[[101101|00101101]]
assert 100 == 0b[[1100100|01100100]]

    
De droite à gauche, les bits valent 1, 2, 4, 8, 16, 32, 64…

    
Du décimal au binaire : divise par 2 et note les restes, puis lis-les de bas en haut.

    

      
10110 = 16 + 4 + 2 = 22 ; 111111 = 32 + 16 + 8 + 4 + 2 + 1 = 63.

      
45 = 32 + 8 + 4 + 1, donc 101101 ; 100 = 64 + 32 + 4, donc 1100100.

    

  


  

    
Partie B : convertis entre la base 2 et la base 16, par paquets de 4 bits.

    
assert 0b10101101 == 0x[[AD|ad|Ad|aD]]
assert 0b001101011110 == 0x[[35E|35e|035E|035e]]
assert 0x9C == 0b[[10011100]]
assert 0x1F8 == 0b[[111111000|000111111000]]

    
Coupe le nombre binaire en paquets de 4 bits, en partant de la droite. Chaque paquet donne un chiffre de 0 à F.

    
Dans l'autre sens, chaque chiffre hexadécimal devient 4 bits : 9 = 1001, C = 1100.

    

      
1010 1101 = A D, donc AD ; 0011 0101 1110 = 3 5 E, donc 35E.

      
9C = 1001 1100, donc 10011100 ; 1F8 = 0001 1111 1000, donc 111111000.

    

  


  

    
Partie C : convertis entre la base 16 et la base 10.

    
assert 0x2B == [[43]]
assert 0xFF == [[255]]
assert 78 == 0x[[4E|4e]]
assert 300 == 0x[[12C|12c]]

    
De l'hexadécimal au décimal : 2B = 2 × 16 + 11.

    
Du décimal à l'hexadécimal : divise par 16 et note les restes (300 = 16 × 18 + 12, puis 18 = 16 × 1 + 2).

    

      
2B = 2 × 16 + 11 = 43 ; FF = 15 × 16 + 15 = 255.

      
78 = 16 × 4 + 14, donc 4E ; 300 = 256 + 2 × 16 + 12, donc 12C.

    

  


  

    
Mémo

    
/ donne un float, % le reste. ET se calcule avant OU. Une boucle while s'arrête seulement si une variable du bloc rend sa condition fausse. Un chiffre hexadécimal = 4 bits.
