# La pédagogie du site : par où commencer

*Pourquoi les ressources de ce site sont faites ainsi, et comment s'en servir. Retour au [sommaire de la documentation](../README.md) ou au [README](../../README.md).*

Ces documents s'adressent à toi, collègue de SNT ou de NSI, spécialiste ou non, qui découvres le projet et veux utiliser une ressource, l'adapter ou en créer une dans le même esprit.

Ils décrivent les choix de l'auteur des ressources, **Babash - NSI Tani Malandi**, enseignant de SNT et de NSI dans l'académie de Mayotte. Ce sont ses choix, pour ses classes : aucun n'est une consigne de l'institution.

## Les quatre lectures

1. **[La philosophie pédagogique](philosophie-pedagogique.md)** (10 minutes). Le public, les conditions de classe et les principes. Chaque principe est montré par une ressource du site.
2. **[Les règles universelles](regles-universelles.md)** (10 minutes). Ce que respecte toute ressource, quel que soit son type : lisibilité, impression, téléphone, langage, licences, données des élèves… Chaque règle a sa raison et un exemple.
3. **[Les types de ressources](types-de-ressources.md)** (5 minutes). Le rôle de chaque type dans une séquence : lequel choisir, à quel moment.
4. **Le document du type qui t'intéresse** (5 minutes chacun) :
   [fiche de révision](types/fiche-de-revision.md),
   [cours-quiz](types/cours-quiz.md),
   [TD](types/td.md),
   [notebook](types/notebook.md),
   [application de jeu](types/application-de-jeu.md),
   [quiz Pronote](types/quiz.md),
   [contrôle](types/controle.md),
   [exercices de bac](types/exercices-de-bac.md),
   [frise](types/frise.md).

## Ce que ces documents ne sont pas

- **Pas un état d'avancement.** Une règle peut être décidée sans être encore appliquée partout. Quand c'est le cas, le document le dit, dans un paragraphe « Où on en est ».
- **Pas figés.** Ils sont écrits en novembre 2026 et suivent les décisions de l'auteur. La recherche du style graphique des feuilles de TD, par exemple, est en cours : seules ses contraintes déjà décidées sont écrites ici.
