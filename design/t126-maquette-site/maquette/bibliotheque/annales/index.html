315 exercices

Les exercices de l'épreuve écrite de terminale depuis 2021, rangés dans les chapitres des fiches de révision. Le classement est déduit de l'en-tête de chaque exercice (« Cet exercice porte sur… ») : il reste à vérifier. Les en-têtes ne nomment presque jamais les variables, les boucles ou les fonctions, que tous les exercices utilisent.

On lie, on n'héberge pas : chaque lien mène au PDF sur le site qui le publie (AEIF, kxs, Math93…). Les sujets restent ceux du ministère ; les corrigés de kxs ne sont pas officiels ; seule l'AEIF indique une licence (CC BY-SA 4.0). Les pages d'un exercice sont celles de la mise en page indiquée.
