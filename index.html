Programmation

  • Compute-it, progression Python

    Les élèves jouent l'ordinateur : ils lisent un programme Python et l'exécutent eux-mêmes avec les flèches du clavier. On avance des instructions simples jusqu'aux boucles et aux conditions.

    En lignePython

  • Fiche de révision et TD débranché

    Recto : indentation, if / elif / else, opérateurs logiques, while et for. Verso : cinq exercices papier dans l'esprit de Compute-it, avec des grilles à suivre case par case. Format A4 recto-verso.

    À imprimerDébranché

  • Activité interactive

    Activité en ligne pour accompagner la séquence de programmation.

    En ligne

  • Execubot

    Jeu de lecture de code : à partir d'un programme Python, les élèves prévoient le déplacement d'un robot sur une grille de couleurs. Conçu par des enseignants d'informatique de lycée.

    En lignePython

Ajouter une ressource

Le site tient dans un seul fichier, index.html, hébergé sur GitHub. Pour ajouter une activité, on y copie un bloc existant et on change le lien et la description. Ouvrir le dépôt et son mode d'emploi

Pas à l'aise avec GitHub ? Envoyez simplement le lien et une phrase de description à la personne qui gère le site.

Les ressources externes restent la propriété de leurs auteurs.
